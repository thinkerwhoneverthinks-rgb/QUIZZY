MATRIX CONCEPT

📖Definition & Introduction

  • A matrix is an ordered rectangular array of numbers or functions written in brackets.
  • Individual numbers/functions are called elements or entries.
  • Arrangement is by rows (horizontal) and columns (vertical); position matters.
  • If there are m rows and n columns, the order is m × n ("m by n").
  • The entry aij means element in i-th row and j-th column; total entries = mn.
  • Matrices give compact notation for systems of linear equations and for representing linear transformations.

🖼️Diagram

Matrix entry aij is fixed by its row (i) and column (j) position.


🎯Key Concepts

  • 📦Matrix = grid; each entry is fixed by its row index and column index.
  • 🧾Spreadsheet view: rows = records, columns = attributes/fields.
  • 🔎Interpret aij only after defining what rows and columns represent.
  • 🧩Linear equations can be represented using coefficient matrix, variable column, and constants column.
  • 🧭Matrices can represent linear transformations (e.g., scaling, reflection, rotation).
  • 🔐In some coding/cryptography models, matrices are used to combine data linearly.

🔎WHY MATRICES? (MOTIVATION + USES)

  • Store multi-person, multi-item data in one rectangular array.
  • Represent linear relationships compactly.
  • Used in systems of linear equations, transformations, spreadsheets, and some coding models.

⚙️ORDER, NOTATION, AND READING ENTRIES

  • Order m × n: m rows, n columns; total entries = mn.
  • Notation: A = [aij]m×n, with 1 ≤ i ≤ m, 1 ≤ j ≤ n.
  • aij is the (i,j)-th entry: i selects a row, j selects a column.
  • Swapping rows and columns changes the matrix (in general, m×n ≠ n×m).

TOPIC2

ORDER AND NOTATION (MATRICES)

📖Definition & Introduction

  • A matrix with m rows and n columns has order m×n (read m by n).
  • Standard notation: A = [aij]m×n, where 1 ≤ i ≤ m and 1 ≤ j ≤ n.
  • aij means the element in the i-th row and j-th column (the (i, j)-th element).
  • Total number of elements in an m×n matrix is mn.
  • i-th row contains: ai1, ai2, …, ain.
    j-th column contains: a1j, a2j, …, amj.
  • Do not confuse m×n with n×m; swapping rows/columns changes the matrix and its order (unless the matrix is square and happens to match after swapping).

🖼️Diagram

🎯Key Concepts

  • 📏Order tells only the shape: rows first, columns second.
  • 🔎In aij, i = row index, j = column index.
  • 🧩Counting entries: total elements in order m×n is mn.
  • ⚠️Same numbers in different positions usually give a different matrix.

🔎HOW TO READ Aij (POSITION LOGIC)

  • First index i counts down rows: 1, 2, …, m.
  • Second index j counts across columns: 1, 2, …, n.
  • The i-th row is a 1×n row-matrix extracted from A.
  • The j-th column is a m×1 column-matrix extracted from A.

⚙️ORDER CHECKS EXAMINERS LOVE

  • State order as (rows)×(columns), never the other way.
  • Before reading an entry, write (i, j) = (row, column).
  • Meaning depends on what rows/columns represent (data context).
  • Matrices are equal only if order and corresponding entries match.

TOPIC3

FORMING MATRICES

📖Definition & Introduction

  • Forming a matrix means arranging given information into a rectangular array (rows × columns) with a fixed meaning for each position.
  • First decide what the rows represent and what the columns represent; then fill entries accordingly.
  • If order is m × n, total number of elements is mn.
  • The entry aij means the element in the i-th row and j-th column.
  • A point (x, y) can be stored as a row matrix [x y] or a column matrix [x
    y].
  • Vertices of a polygon can be stored systematically in a matrix for easy comparison and later transformations.

🖼️Diagram

🎯Key Concepts

  • 📊From data: fix row/column labels first, then place each value at the correct (row, column) position.
  • 🔢From total entries N: list ordered factor pairs (m, n) with mn = N; order matters (m×n ≠ n×m).
  • 🧩From an entry-rule aij: compute each entry for i = 1…m and j = 1…n, and place it at (i, j).
  • 📍Geometry: store each point (x, y) as a 2×1 column; stack k points as a 2×k matrix (each column a vertex).

🔎FROM REAL-LIFE DATA (ROWS/COLUMNS MEANING)

  • Fix labels first: e.g., rows = Factory I, II, III; columns = Men, Women.
  • Fill each cell with the correct value for that (row label, column label) pair.
  • Interpret aij using: i-th row meaning + j-th column meaning.

⚙️FROM TOTAL ELEMENTS / FROM AN ENTRY-RULE / FROM GEOMETRY

  • If total elements = mn, list ordered factor pairs (m, n); m×n and n×m are different orders.
  • If entries are given by a rule aij(i, j), compute for i = 1…m and j = 1…n and place in the matching position.
  • Point P(x,y): column form is 2×1; store k points as a 2×k matrix (each column a point).

TOPIC4

TYPES OF MATRICES

📖Definition & Introduction

  • A type of matrix is identified using its order (rows × columns) and special element positions.
  • Row matrix: exactly 1 row, order 1×n.
  • Column matrix: exactly 1 column, order m×1.
  • Square matrix: rows = columns, order n×n; main diagonal is a11, a22, …, ann.
  • Diagonal / scalar / identity are square matrices defined by restrictions on off-diagonal and diagonal entries.
  • Zero (null) matrix O: all entries 0; its order must be tracked (e.g., O2×3 ≠ O3×2).

🖼️Diagram

🎯Key Concepts

  • 📐Order m×n: m rows, n columns; do not interchange (shape changes).
  • 🧱Main diagonal exists only for square matrices: positions (1,1),(2,2),…,(n,n).
  • 🔻Diagonal matrix: all off-diagonal entries are 0 (i≠j).
  • 🔷Scalar matrix: diagonal with equal diagonal entries; equals kIn.
  • 🆔Identity matrix In: 1 on main diagonal, 0 elsewhere.
  • 0️⃣Zero matrix Om×n: every entry is 0; order decides compatibility in operations.

🔎SHAPE-BASED TYPES (ORDER)

  • Row matrix: order 1×n; elements are a1j only.
  • Column matrix: order m×1; elements are ai1 only.
  • Square matrix: order n×n; only here the main diagonal is defined.
  • Main diagonal entries are at positions (i,i): a11, a22, …, ann.

⚙️DIAGONAL-STRUCTURE TYPES (SQUARE ONLY) + ZERO MATRIX

  • Diagonal matrix B=[bij]: bij=0 for i≠j (diagonal entries may be any real numbers).
  • Scalar matrix: diagonal + all diagonal entries equal to same constant k; written as kIn.
  • Identity matrix In: aij=1 if i=j, and 0 if i≠j.
  • Zero (null) matrix Om×n: every entry is 0; always mention order when needed.

EQUALITY OF MATRICES

📖Definition & Introduction

  • Two matrices A = [aij] and B = [bij] are equal iff they have the same order and aij = bij for all i, j.
  • Equality compares corresponding positions: (1,1) with (1,1), (1,2) with (1,2), etc.
  • Position matters: swapping entries usually makes matrices unequal even if the numbers are the same as a set.
  • If the orders differ (e.g., 2×3 and 3×2), matrices cannot be equal.
  • If matrices contain unknowns, equality gives a system of equations by equating corresponding entries.

🖼️Diagram

🎯Key Concepts

  • 📏First check order: m×n must match before comparing entries.
  • 🎯Equality is entrywise: aij = bij for every (i,j).
  • 🔁Do not reorder rows/columns; equality is “same value at same position”.
  • 🧮Unknown entries → equate positions → solve the resulting simultaneous equations.

🔎HOW TO USE MATRIX EQUALITY (EXAM METHOD)

  • Step 1: Compare orders (m×n). If different, matrices are not equal.
  • Step 2: Match each position (i,j) and write the corresponding entry equations.
  • Step 3: Solve the simultaneous equations for the unknowns.
  • Step 4: Substitute back and verify every entry matches.

⚙️POSITION MATTERS (QUICK CHECKS)

  • A swap like (1,2)↔(2,1) changes the matrix, so equality fails.
  • Equality is not “same elements”; it is “same element at same address”.
  • Address = (row, column). Track row first, then column.

ADDITION AND SUBTRACTION OF MATRICES

📖Definition & Introduction

  • Addition: If A=[aij] and B=[bij] have the same order m×n, then A+B=[cij] where cij=aij+bij.
  • Subtraction: For same order matrices, A−B=[dij] where dij=aij−bij.
  • If orders differ, A+B and A−B are not defined.
  • Negative of a matrix: −A means multiply every entry of A by −1, i.e. −A=(−1)A.
  • Rewrite subtraction as addition: A−B=A+(−B).
  • Order is preserved: if A, B are m×n, then A±B is also m×n.

🖼️Diagram

🎯Key Concepts

  • 📐Dimension check first: only same m×n matrices can be added/subtracted.
  • 🔢Entrywise rule: operate on matching positions (i,j); do not mix rows/columns.
  • ➖−A flips sign of every entry; it is the additive inverse of A.
  • 🔁Compute A−B by forming −B first, then adding.
  • 🧩Expressions like 2A−B use scalar multiplication and subtraction entrywise.

🔎WORKING METHOD (EXAM SPEED)

  • Step 0: Verify both matrices have identical order m×n.
  • For A+B: add entries at the same (i,j) position.
  • For A−B: subtract entries at the same (i,j) position.
  • Shortcut: compute −B first, then do A+(−B).
  • For 2A−B: scale A first, then subtract entrywise.

⚙️PROPERTIES YOU MAY USE (ONLY WHEN SAME ORDER)

  • Commutative (addition only): A+B=B+A.
  • Associative (addition): (A+B)+C=A+(B+C).
  • Additive identity: A+O=A, where O is zero matrix of same order.
  • Additive inverse: A+(−A)=O.
  • Subtraction not commutative: generally A−B≠B−A.

SCALAR MULTIPLICATION (kA)

📖Definition & Introduction

  • If A = [aij] and k is a number (scalar), then kA = [kaij].
  • Entrywise rule: (kA)ij = kaij for all valid i, j.
  • Order does not change: if A is m×n, then kA is also m×n.
  • Negative of a matrix: −A = (−1)A = [−aij].
  • Scalar multiplication is uniform scaling of the whole matrix; scaling only one row/column is a different operation.

🖼️Diagram


🎯Key Concepts

  • 🔢Multiply each entry: kA means k times every element, not just diagonal/row/column.
  • 🧩Distributive over matrix addition: k(A+B) = kA+kB (same order needed).
  • ➕Distributive over scalar addition: (k+l)A = kA+lA.
  • 📉0A = O (zero matrix of same order), and 1A = A.
  • 🏭Application idea: doubling a data matrix means multiplying the entire matrix by 2.

🔎ENTRYWISE VIEW (WHY THE PROPERTIES HOLD)

  • Matrix addition and scalar multiplication are entrywise, so compare the (i,j) entry on both sides.
  • Use the distributive law of real numbers inside each entry.

⚙️REAL-LIFE INTERPRETATION (DATA SCALING)

  • If a matrix stores counts/costs, multiplying by k scales all recorded quantities by k.
  • Example: doubling every category of production ⇒ new matrix = 2A.

SOLVING MATRIX EQUATIONS

📖Definition & Introduction

  • Solving a matrix equation means finding unknown matrix/scalars so the equality holds entrywise.
  • Use allowed operations: add/subtract same-order matrices; multiply a matrix by a scalar.
  • To isolate X: move known matrix terms to the other side, then multiply by the reciprocal scalar (scalar ≠ 0).
  • If A = B, then aij = bij for all (i, j) → linear equations in unknowns.
  • Standard split: if X+Y=M and X−Y=N, add/subtract to get 2X, 2Y.

🖼️Diagram

🎯Key Concepts

  • ➕Same order is compulsory for addition/subtraction; otherwise equation is invalid.
  • 🧮Scalar division means multiplying every entry by the reciprocal (e.g., ÷3 = ×13).
  • 🔁Pattern: (X+Y)+(X−Y)=2X and (X+Y)−(X−Y)=2Y.
  • 📍Entrywise comparison: match (1,1) with (1,1), (1,2) with (1,2), etc.
  • ✅Always verify by substituting back into the original matrix equation.

🔎CORE METHODS (EXAM ROUTES)

  • Isolation route: rearrange like algebra: move known matrices, then scale to isolate X.
  • Split route: treat (X+Y) and (X−Y) as two linear equations in matrices.
  • Entrywise route: if two matrices are equal, set corresponding entries equal → usual linear equations.
  • Dimension check first: every term in an equation must have the same order.

⚙️FAST CHECKLIST BEFORE YOU SOLVE

  • Confirm all matrices being added/subtracted have identical order.
  • While scaling, multiply every entry by the scalar (including zeros/negatives).
  • Use negatives carefully: −A means sign change of every entry.
  • After finding unknowns, substitute back to confirm LHS = RHS.

MATRIX MULTIPLICATION

📖Definition & Introduction

  • For matrices A (m×n) and B (n×p), the product AB is defined and is of order m×p.
  • The (i,k) entry of AB is obtained by dot product: i-th row of A with k-th column of B.
  • Compatibility condition: columns(A) = rows(B); otherwise AB is not defined.
  • Matrix multiplication is generally non-commutative: even if both exist, usually AB ≠ BA.
  • Possible to have AB = O with A ≠ O, B ≠ O (matrices can be zero divisors).

🖼️Diagram

🎯Key Concepts

  • 📏Dimension rule: (m×n)(n×p) → (m×p); inner n must match.
  • 🔢Entry rule: each cik uses n products and a sum (dot product).
  • 🔁Order matters: swapping factors changes meaning; AB and BA may differ in size or value.
  • 🧱Zero product pitfall: AB=O does not force A=O or B=O.
  • ✅When defined, multiplication is associative and distributive over addition (dimension check required).

🔎HOW TO COMPUTE EACH ENTRY (ROW × COLUMN)

  • To find cik, take i-th row of A and k-th column of B.
  • Multiply corresponding elements, then add: n terms in the sum.
  • Write at least one entry fully in exams to show the method clearly.

⚙️NON-COMMUTATIVITY + ZERO DIVISORS (EXAM FAVOURITES)

  • Case 1: AB and BA may have different orders, so cannot be equal.
  • Case 2: Even if same order, entries can differ: AB ≠ BA.
  • Zero divisors exist: AB=O possible with A≠O, B≠O.

MULTIPLICATION PROPERTIES (MATRICES)

📖Definition & Introduction

  • Matrix multiplication properties apply only when the required products/sums are defined (dimension-compatible).
  • Associative: (AB)C = A(BC) (grouping changes; order of factors does not change).
  • Distributive: A(B+C)=AB+AC and (A+B)C=AC+BC.
  • Multiplicative identity: for square A (order n), InA = AIn = A.

🖼️Diagram

Always check inner dimensions first; then apply associative/distributive/identity laws.

🎯Key Concepts

  • 📐Dimension check: if A is m×n and B is n×p then AB exists and is m×p.
  • 🔗Associativity is about brackets only: A·B·C keeps factor order A then B then C.
  • 🧩Distributive expansion keeps side: A(B+C)=AB+AC, not BA+CA.
  • 🆔Identity matrix must be same order as square A; otherwise IA or AI is not defined.
  • 🧮In kI, the scalar k affects only diagonal entries (off-diagonal entries remain 0).

🔎HOW TO VERIFY LAWS (EXAM WORKFLOW)

  • Step 0: Write orders of A, B, C; confirm both sides exist (same final order).
  • Associative: compute (AB)C and A(BC) and compare (same order matrices).
  • Distributive: compare A(B+C) with AB+AC (or (A+B)C with AC+BC).
  • Identity: use In where n matches the order of square matrix; show IA and AI.
  • Show at least one entry (row × column) clearly to secure method marks.

APPLICATIONS WITH MATRICES

📖Definition & Introduction

  • Matrix application: represent quantities, prices, rates, or contacts as matrices so totals come from multiplication.
  • A row often stores requirements for one person/shop/month; a column stores unit prices/costs.
  • The product entry is a dot product: one row with one column gives one meaningful total.
  • Profit/discount/tax on a whole table is scalar multiplication (e.g. 2% of sales = 0.02×sales matrix).

🖼️Diagram

🎯Key Concepts

  • 📦Requirements × prices = money needed (row×column gives total cost)
  • 📊Sales matrices across months: add/subtract to combine or find change
  • 💹Profit percentage: p% of sales matrix S is (p/100)S
  • 📞Contacts matrix × cost-per-contact column = spending per city
  • 🏦Rates/percent changes on a table are handled by scalar multiplication

🔎HOW TO SET UP A REAL-LIFE MATRIX MODEL

  • Decide what rows mean (people/cities/months) and what columns mean (items/types).
  • Build the data matrix (e.g. quantities sold, contacts made).
  • Build the rate/price matrix with compatible size (inner dimensions must match).
  • Multiply: output entry cik is total for row i against column k.
  • Attach units: (quantity)×(₹/unit) → ₹, (contacts)×(paise/contact) → paise.

⚙️COMMON APPLICATION PATTERNS (EXAM-FRIENDLY)

  • Buyers & items: (buyers×items)×(item prices column) = bill for each buyer.
  • Sales Sept/Oct: total sales = A+B; change Sept→Oct = B−A.
  • Profit/discount: 2% of sales matrix S is 0.02S (scalar multiply).
  • Promotion: (city×methods)×(cost per method column) = spending per city.
  • Unit conversion: if data is in dozens, multiply by 12 as a scalar before pricing.

  • Check compatibility: if A is m×n and B is n×p, then AB exists (order m×p).

TRANSPOSE AND SYMMETRY

📖Definition & Introduction

  • Transpose of A = [aij] is A′ (or AT) = [aji].
  • If A is m×n, then A′ is n×m (order swaps).
  • Symmetric matrix: square A with A′ = A (so aij=aji).
  • Skew-symmetric matrix: square A with A′ = −A (so aij=−aji).
  • In any skew-symmetric matrix, diagonal entries are zero: aii=0.
  • Every square matrix A can be written as: A = 12(A+A′) + 12(A−A′).

🖼️Diagram

Transpose swaps indices (i,j) → (j,i), so the matrix shape flips m×n → n×m.

🎯Key Concepts

  • 🧩Entry rule: (A′)ij = aji (indices swap).
  • ✅Involution: (A′)′ = A for every matrix.
  • ➕Linearity: (A+B)′=A′+B′, (kA)′=kA′.
  • 🔄Reverse order: (AB)′ = B′A′ (when AB is defined).
  • 🟦A+A′ is always symmetric; A−A′ is always skew-symmetric.
  • ⚔️If A, B are symmetric, then AB−BA is skew-symmetric.

🔎CORE PROPERTIES (USED IN JEE/BOARDS PROOFS)

  • (A′)′ = A (swap indices twice).
  • (A+B)′=A′+B′ and (A−B)′=A′−B′ (requires same order).
  • (kA)′=kA′ (scalar comes out).
  • (AB)′=B′A′ (order reverses).

⚙️SYMMETRIC / SKEW-SYMMETRIC + DECOMPOSITION

  • Symmetric: A′=A; Skew-symmetric: A′=−A (both require square matrices).
  • Skew-symmetric ⇒ aii=0 because aii=−aii ⇒ 2aii=0.
  • S=12(A+A′) is symmetric; K=12(A−A′) is skew-symmetric.
  • Hence A=S+K (unique decomposition into symmetric + skew-symmetric parts).
  • If A,BAB−BA)′=BA−AB=−(AB−BA).

✏️Solved Q&A

1
Concept check: Why must a skew-symmetric matrix have all diagonal entries equal to 0?
Answer:
Skew-symmetric means A′=−A.
Comparing diagonal entries: (i,i) entry of A′ equals aii (transpose does not change diagonal position).
So aii = −aii ⇒ 2aii=0 ⇒ aii=0.
✓  Every diagonal entry of a skew-symmetric matrix is 0.
2
Concept check: Explain why A+A′ is symmetric and A−A′ is skew-symmetric (for square A).
Answer:
Use linearity of transpose: (A+A′)′ = A′ + (A′)′ = A′ + A = A+A′.
Similarly, (A−A′)′ = A′ − (A′)′ = A′ − A = −(A−A′).
✓  A+A′ satisfies transpose-equals-itself (symmetric) and A−A′ satisfies transpose-equals-negative (skew-symmetric).

⭐Important Points

  • Transpose changes order m×n ↔ n×m; symmetry/skew-symmetry requires square matrices.
  • Always check sizes: (A±B)′ rules need A and B of same order.
  • For products: (AB)′=B′A′ (reverse order).
  • Diagonal zeros are necessary for skew-symmetry, but not sufficient.
  • Every square matrix splits uniquely into symmetric and skew-symmetric parts using halves of (A±A′).

INVERTIBLE MATRICES (INVERSE)

📖Definition & Introduction

  • A square matrix A is invertible if there exists a square matrix B of the same order such that AB = BA = I.
  • Such a matrix B is called the inverse of A and is denoted by A−1.
  • If A has an inverse, then A−1A = AA−1 = I (both left and right identity).
  • A two-sided inverse is defined only for square matrices. If A is m×n with m≠n, it cannot satisfy both AB=Im and BA=In.
  • If B is inverse of A, then A is inverse of B; i.e., (A−1)−1 = A.

🎯Key Concepts

  • 🧾Notation: inverse of A is A−1, not 1A (no division defined).
  • 🔁Inverse is unique: a matrix cannot have two different inverses.
  • 🧱If A is invertible, the equation AX=B has the unique solution X=A−1B.
  • 🔄Product rule: (AB)−1 = B−1A−1 (order reverses).

🔎UNIQUENESS OF INVERSE (PROOF SKELETON)

  • Assume B and C are both inverses of A.
  • Then AB=BA=I and AC=CA=I.
  • Start: B = BI = B(AC).
  • Associate: B(AC) = (BA)C.
  • Use BA=I: (BA)C = IC = C.

⚙️INVERSE OF A PRODUCT (ORDER REVERSAL)

  • If A and B are invertible (same order), then AB is invertible.
  • Claim: (AB)−1 = B−1A−1.
  • Check: (AB)(B−1A−1) = A(BB−1)A−1 = AIA−1 = I.
  • Also: (B−1A−1)(AB) = B−1(A−1A)B = B−1IB = I.

✏️Solved Q&A

1
Why must an inverse (as used in school textbooks) be defined only for square matrices?
Answer:
For inverse, we need a matrix B such that AB=I and BA=I.
If A is m×n, then AB (if defined) is m×m, while BA (if defined) is n×n.
A single matrix A cannot produce two different identity orders as a two-sided inverse unless m=n.
Hence a two-sided inverse is only for square matrices.
✓  A two-sided inverse requires matching identity orders on both sides, which forces the matrix to be square.
2
If (AB)−1 exists, what is the correct order of inverses: A−1B−1 or B−1A−1?
Answer:
Matrix multiplication is not commutative in general, so reversing order matters.
To undo AB, you must undo B first and then undo A.
Therefore the inverse of the product is taken in reverse order.
✓  The correct relation is (AB)−1 = B−1A−1 (order reverses).

⭐Important Points

  • Inverse (two-sided) exists only for square matrices; always check order before any claim.
  • To prove B=A−1 by definition, verify both AB=I and BA=I.
  • Special fact (square case): if A and B are square of the same order and AB=I, then automatically BA=I and B=A−1.
  • If A is invertible, then (A−1)−1 = A.
  • Inverse of product reverses order: (AB)−1=B−1A−1.
