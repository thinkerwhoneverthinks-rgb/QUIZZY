Inverse Trigonometric Functions

TOPIC1

NEED FOR INVERSES (INVERSE TRIG FUNCTIONS)

📖Definition & Introduction

  • An inverse function f−1 exists iff f is bijective (one‑one and onto).
  • Natural trig functions are periodic ⇒ many different x give the same value ⇒ not one‑one.
  • So “inverse trigonometric function” is defined only after restricting the domain of the trig function to a one‑one interval.
  • The chosen restriction gives a principal value branch: a single-valued output with a fixed range.
  • Then the inverse identities work with domain warnings: f(f−1(x))=x for x in domain of f−1, and f−1(f(x))=x only on the restricted domain.

🖼️Diagram

Periodic trig curves fail the horizontal line test; selecting one monotonic piece makes them invertible.

🎯Key Concepts

  • 🔑Invertibility condition: inverse exists iff function is one-one and onto.
  • 🌀Periodicity causes failure of one-one: e.g. sin(0)=sin(π)=0.
  • 📍Restrict domain to a monotonic interval to make trig function bijective onto its range.
  • 🏁Principal value: agreed branch so each input gives a unique angle output.
  • 🪞Graph idea: inverse curve is reflection of the restricted trig graph in line y=x.

🔎HOW RESTRICTION CREATES AN INVERSE

  • Start with f:X→Y. Inverse exists iff every y in the range has exactly one preimage in X.
  • Trig functions repeat values: for sin, replacing x by x+2π keeps the output unchanged.
  • Choose an interval where the trig function is strictly monotonic ⇒ one-one on that interval.
  • Keep the natural range (e.g. [−1,1] for sin, cos) ⇒ onto still holds for that range.
  • Define inverse as the inverse of the restricted function; its range equals that chosen interval.

⚙️PRINCIPAL VALUE BRANCHES (WHAT WE STANDARDISE)

  • arcsin: restrict sin x to [−π/2,π/2] so output is unique.
  • arccos: restrict cos x to [0,π].
  • arctan: restrict tan x to (−π/2,π/2).
  • Other branches are possible; exam default is the principal branch unless stated.
  • Always check which composition is valid: f(f−1(…)) vs f−1(f(…)).

✏️Solved Q&A

1
Why can’t sin−1 be defined as the inverse of sin on all of ℝ (without restriction)?
Answer:
For an inverse to exist as a function, sin must be one-one on its domain.
But sin0 = 0 and sinπ = 0, with 0 ≠ π.
So the output 0 has more than one preimage; one-one fails ⇒ inverse (as a function) does not exist on ℝ.
Restrict domain to [−π/2,π/2], where sin is strictly increasing and covers [−1,1].
✓  Because sin is not one-one on ℝ; restricting to [−π/2,π/2] makes it bijective onto [−1,1] and defines sin−1 uniquely.
2
Evaluate the principal value: sin−1(sin(3π/5)).
Answer:
Identity warning: sin−1(sinx)=x only if x is in [−π/2,π/2].
Here 3π/5 lies in quadrant II, so it is not in [−π/2,π/2].
Use sine symmetry: sin(π−α)=sinα, so sin(3π/5)=sin(π−3π/5)=sin(2π/5).
Now 2π/5 is in [−π/2,π/2], so the principal value is 2π/5.
✓  2π/5

⭐Important Points

  • Inverse exists iff function is bijective (one-one + onto).
  • Trig functions are periodic ⇒ generally not one-one on natural domains.
  • Inverse trig functions are defined via restricted trig functions (principal branches).
  • Principal ranges must be memorised; answers must lie inside them.
  • f(f−1(…)) works for inputs in domain of f−1; f−1(f(…)) needs the restriction on f.

TOPIC2

TRIG DOMAINS AND RANGES

📖Definition & Introduction

  • Domain = set of all x for which the function value exists; Range = set of all possible outputs y.
  • sin x and cos x are defined for every real x, but their outputs stay between −1 and 1.
  • tan x, sec x are undefined where cos x = 0 (odd multiples of π/2).
  • cot x, cosec x are undefined where sin x = 0 (integral multiples of π).
  • sec x and cosec x never give outputs strictly between −1 and 1; endpoints ±1 are included.
  • Set-notation pitfall: ℝ \ (−1,1) means (−∞,−1] ∪ [1,∞), not “remove only −1 and 1”.

🖼️Diagram

Odd multiples of π/2 break tan & sec; multiples of π break cot & cosec; (−1,1) is missing from sec/cosec outputs.

🎯Key Concepts

  • 🧭Shared exclusions: tan & sec exclude (2n+1)π/2; cot & cosec exclude nπ.
  • 🚫Undefined points come from division by zero: tan=sin/cos, cot=cos/sin, sec=1/cos, cosec=1/sin.
  • 📌Range blocks: sin, cos ∈ [−1,1]; sec, cosec ∈ ℝ \ (−1,1); tan, cot ∈ ℝ.
  • 🧾Write exclusions in set-builder form: ℝ \ { (2n+1)π/2 : n∈ℤ } etc.

🔎MASTER LIST (AS FUNCTIONS)

  • sin x: Domain ℝ; Range [−1,1].
  • cos x: Domain ℝ; Range [−1,1].
  • tan x: Domain ℝ \ { (2n+1)π/2 : n∈ℤ }; Range ℝ.
  • cot x: Domain ℝ \ { nπ : n∈ℤ }; Range ℝ.
  • sec x: Domain ℝ \ { (2n+1)π/2 : n∈ℤ }; Range ℝ \ (−1,1).

⚙️SET-NOTATION PITFALLS (EXAM FAVOURITES)

  • ℝ \ (−1,1) = (−∞,−1] ∪ [1,∞); endpoints ±1 are allowed.
  • Don’t write ℝ − (−1,1) as if it means subtracting numbers; use set difference \.
  • Domain exclusions are for x; range exclusions are for y (don’t swap them).
  • Use set-builder form for infinite excluded sets: {(2n+1)π/2 : n∈ℤ}, not a few values.

✏️Solved Q&A

1
Why is sec x undefined at odd multiples of π/2?
Answer:
Reason: sec x = 1/cos x, so it is undefined exactly when cos x = 0.
Key fact: cos x = 0 at x = (2n+1)π/2 for integers n.
✓  sec x is undefined where cos x = 0, i.e. at x = (2n+1)π/2, n∈ℤ.
2
Does adding a constant change the domain? Explain for tan x + 2.
Answer:
Idea: A constant shift changes outputs (range shift) but does not remove any division-by-zero points.
So: tan x + 2 is undefined at the same x-values where tan x is undefined.
✓  No. Domain(tan x + 2) = Domain(tan x) = ℝ \ { (2n+1)π/2 : n∈ℤ }.

⭐Important Points

  • tan & sec have identical domain breaks (cos x = 0): x = (2n+1)π/2.
  • cot & cosec have identical domain breaks (sin x = 0): x = nπ.
  • Range(sec) and Range(cosec) are (−∞,−1] ∪ [1,∞); do not exclude ±1.
  • Range(sin) = Range(cos) = [−1,1] (closed interval).
  • Output shift (like +2) keeps domain same; it shifts the range by the same amount.

TOPIC3

INVERSE FUNCTION BASICS

📖Definition & Introduction

  • For f:X→Y, an inverse exists iff f is bijective (one–one and onto).
  • The inverse f−1:Range(f)→Domain(f) satisfies f−1(y)=x ⇔ f(x)=y.
  • Domain(f−1) = Range(f); Range(f−1) = Domain(f).
  • If f−1 exists, it is unique; also (f−1)−1=f.
  • Composition identities are true only on correct sets: inputs must lie in the relevant domains.

🖼️Diagram

Inverse reverses arrows and swaps domain with range (for bijective f).

🎯Key Concepts

  • 1Bijective ⇔ inverse function exists and is single-valued.
  • 2Inverse swaps roles of input/output: (a,b) on f becomes (b,a) on f−1.
  • 3Domain warning: f−1(f(x))=x needs x∈Domain(f), not arbitrary inputs.
  • 4If a function is not one–one on its full domain, it may become invertible after restricting to a one–one part.

🔎WORKING: EXISTENCE & UNIQUENESS

  • Existence: f−1 exists iff f is one–one and onto.
  • Uniqueness: if g and h both satisfy g(f(x))=x for all x∈Domain(f), then g=h.
  • If f−1 exists, then f−1 is also bijective and (f−1)−1=f.

⚙️COMPOSITION IDENTITIES (WITH DOMAIN WARNING)

  • (f−1∘f)(x)=x for x∈Domain(f).
  • (f∘f−1)(y)=y for y∈Domain(f−1)=Range(f).
  • Outside these sets, the expressions may be undefined (because some input is not allowed).

⚖️Two identities that look similar but have different validity domains

ExpressionWhat it equalsValid for
(f−1∘f)(x)xx in Domain(f)
(f∘f−1)(y)yy in Domain(f−1) = Range(f)

✏️Solved Q&A

1
Concept check: If f:X→Y is bijective, what must be the domain of f−1 and why?
Answer:
By definition, f−1 takes as inputs exactly those outputs that actually occur from f.
So the allowed inputs of f−1 are precisely Range(f).
Hence Domain(f−1)=Range(f), and Range(f−1)=Domain(f).
✓  Domain(f−1)=Range(f) because f−1 can only accept values that f actually outputs.
2
Domain warning: Suppose a function is made invertible only after restricting its domain. Why can f−1(f(x)) fail to equal x for an x outside the restricted domain?
Answer:
The identity f−1(f(x))=x is guaranteed only for x in the domain on which f is one–one (the domain used to define the inverse).
If you plug an x outside that restricted domain, f(x) may coincide with f(x0) for some allowed x0 inside the restriction.
Then f−1(f(x)) returns the allowed preimage x0, not the original forbidden input x.
✓  Because the inverse is defined to undo f only on the chosen restricted (one–one) domain; outside it, the same output can correspond to a different allowed input.

⭐Important Points

  • Inverse exists iff the function is bijective (injective + surjective).
  • Domain(f−1)=Range(f); Range(f−1)=Domain(f).
  • (f−1∘f) is identity on Domain(f); (f∘f−1) is identity on Range(f).
  • Inverse is unique; also (f−1)−1=f.
  • Graph idea: points swap coordinates, so inverse graph is reflection in y=x (for the invertible part).

💡Memory Technique

“BISO: BIjective ⇒ Swap & Obtain”
BIjective needed for inverse to exist.Swap Domain↔Range to get inverse’s Domain/Range.Order matters: (f−1∘f) uses Domain(f), (f∘f−1) uses Range(f).
TOPIC4

INVERSE SINE (ARCSIN)

📖Definition & Introduction

  • Principal inverse sine is defined by restricting sin to [−π/2, π/2] (where it is one–one), then taking the inverse.
  • Since sin is not one–one on ℝ, an inverse function does not exist without restriction.
  • Principal value branch: sin⁻¹ : [−1,1] → [−π/2, π/2] (single-valued output).
  • If y = sin⁻¹(x), then sin y = x and y must lie in [−π/2, π/2].
  • Other valid branches exist: restrict sin to any interval of length π on which it is monotonic and onto [−1,1].

🖼️Diagram

Graph of y = sin⁻¹x (principal branch): domain [−1,1], range [−π/2, π/2]; dashed line shows reflection in y = x.

🎯Key Concepts

  • 🧭Principal range forces the output angle into [−π/2, π/2].
  • 🔁Different inverse branches come from different monotonic restriction intervals of sin of length π.
  • ✅sin(sin⁻¹ x) = x holds for all x ∈ [−1,1].
  • ⚠️sin⁻¹(sin x) = x only when x ∈ [−π/2, π/2].
  • 🧾Notation trap: sin⁻¹ x (arcsin) ≠ (sin x)⁻¹ = 1/sin x.

🔎WHY RESTRICTION IS NEEDED (sin not one–one)

  • On ℝ, outputs repeat: sin(π/6) = sin(5π/6) = 1/2 ⇒ not injective.
  • Choose an interval where sin is strictly monotonic and covers all values in [−1,1].
  • Standard choice: [−π/2, π/2] (increasing; endpoints give −1 and 1).
  • Then the inverse becomes a well-defined function with a unique output angle.

⚙️BRANCHES + PRINCIPAL VALUE (what sin⁻¹ means in exams)

  • Any monotonic restriction interval of sin of length π gives an inverse branch with domain [−1,1].
  • Examples of valid branch ranges: [−3π/2, −π/2], [−π/2, π/2], [π/2, 3π/2].
  • Unless a branch is specified, sin⁻¹ always means the principal branch (range [−π/2, π/2]).
  • To evaluate sin⁻¹(sin θ), replace θ by an equivalent angle in [−π/2, π/2] having the same sine value.

INVERSE GRAPH REFLECTION

📖Definition & Introduction

  • If y = f(x) is invertible, then the graph of y = f−1(x) is the reflection of y = f(x) in y = x.
  • Point mapping rule: if (a, b) lies on y = f(x), then (b, a) lies on y = f−1(x).
  • Graph method: take only the restricted one-one part of the original function, then reflect.
  • The inverse exists as a function only when the chosen portion of the original graph is one-one (passes horizontal-line test).
  • For inverse trig graphs, the restriction interval decides the inverse’s principal range (output interval).

🎯Key Concepts

  • swapInverse graph = interchange x and y (swap axes roles).
  • poinCoordinate swap: (a,b) → (b,a) gives mirror image about y=x.
  • testReflect only the one-one (restricted) segment; full trig graph is not one-one.
  • domaDomain–Range swap: Dom(f−1) = Ran(f), Ran(f−1) = Dom(f).
  • sineFor sin: use restricted x ∈ [−π/2, π/2] to get y = sin−1x.

🔎HOW TO DRAW THE INVERSE GRAPH (EXAM STEPS)

  • Step 1: Choose the one-one (monotone) interval of f; darken only this part.
  • Step 2: Mark easy points on the restricted graph (endpoints, intercepts, special values).
  • Step 3: Swap coordinates of marked points: (a,b) → (b,a).
  • Step 4: Draw the mirror image about y=x through the swapped points.
  • Step 5: Read off: Dom(f−1) equals restricted Ran(f), and vice-versa.

⚙️WHY "RESTRICTED PORTION ONLY" MATTERS (TRIG CASE)

  • sin x is periodic, so multiple x values can give the same y (fails horizontal-line test).
  • Reflecting the full sine curve would give multiple outputs for one input on the reflected graph, so it would not be a function.
  • Principal branch for sine: restrict x ∈ [−π/2, π/2] so inverse outputs lie in [−π/2, π/2].

INVERSE COSINE (ARCCOS)

📖Definition & Introduction

  • Principal value definition: cos−1 x (arccos) is the unique y in [0, π] such that cos y = x.
  • Because cos x is not one-one on ℝ, we restrict its domain to make an inverse function.
  • Standard restriction: cos : [0, π] → [−1, 1] is bijective (strictly decreasing and onto).
  • Thus cos−1 : [−1, 1] → [0, π] (domain is [−1,1], range is [0,π]).
  • Other branches exist by restricting cosine to intervals like [−π, 0], [π, 2π]; each gives a different inverse branch.
  • Graph of y = cos−1 x is the reflection of restricted y = cos x (for x in [0,π]) in the line y = x.

🖼️Diagram

Left: restricted cosine on [0,π]; right: y=cos−1x is its reflection in y=x.

🎯Key Concepts

  • 🎯Principal range forces a single answer: cos−1 x always lies in [0, π].
  • 🔁Inverse identities: cos(cos−1 x)=x for x∈[−1,1]; but cos−1(cos θ)=θ only for θ∈[0,π].
  • 📌Endpoints: cos−1(1)=0, cos−1(−1)=π, cos−1(0)=π/2.
  • 🧭Monotonicity: cos−1 x is decreasing on [−1,1].
  • 🪞Graph method: reflect the restricted cosine arc (x from 0 to π) across y=x.

🔎WHY RESTRICT COS?

  • cos repeats values: cos 0 = cos(2π) = 1, so it is not one-one on ℝ.
  • On [0, π], cosine is strictly decreasing from 1 to −1, hence one-one.
  • Also cos([0,π]) = [−1,1], so it is onto [−1,1].
  • Therefore inverse exists uniquely as cos−1 : [−1,1] → [0,π].

⚙️OTHER BRANCHES (NON-PRINCIPAL)

  • Cosine is one-one on each interval of length π where it is monotonic.
  • Examples of valid restriction intervals: [−π,0], [0,π], [π,2π], …
  • Each restriction gives an inverse branch with domain [−1,1] but a different output interval.
  • Unless stated, cos−1 means the principal branch with range [0,π].

⭐Important Points

  • Write clearly: cos−1x means inverse function, not reciprocal 1/cos x.
  • Principal branch: cos−1 : [−1,1] → [0,π] is assumed unless stated.
  • Always force the final angle into [0,π] (principal range).

  • Graph link: inverse graph is obtained by swapping coordinates (reflection in y=x) of the restricted cosine.

TOPIC7

INVERSE COSECANT (ARCCSC / COSEC⁻¹)

📖Definition & Introduction

  • Inverse cosecant (arccsc) is the inverse of cosec on a chosen one–one (bijective) restricted interval.
  • cosec x means 1sin x; it is undefined where sin x = 0, i.e. at x = nπ.
  • Domain of cosec: ℝ \\ {nπ : n∈ℤ}.
  • Range of cosec: ℝ \\ {0} (it can never be 0, but takes every other real value).
  • To define the principal branch of cosec⁻¹, restrict cosec to [−π/2, π/2] \\ {0} (0 excluded because cosec 0 is undefined).
  • Principal value branch: cosec⁻¹ has domain ℝ \\ (−1,1) and range [−π/2, π/2] \\ {0}.

🖼️Diagram

Define principal cosec⁻¹ by restricting cosec, then reflect the restricted curve in y=x.

🎯Key Concepts

  • 🧩Input condition: ℝ \\ (−1,1) = (−∞,−1] ∪ [1,∞); values between −1 and 1 are not allowed for cosec⁻¹.
  • ⛔Exclusions: For cosec x, exclude x=nπ; for cosec⁻¹ x, the output can never be 0 in the principal branch.
  • 🎯Principal value: the output angle must lie in [−π/2, π/2] \\ {0}, not any other coterminal angle.

  • cosec x range: ℝ \\ {0} because 1sin x can never be 0.

INVERSE SECANT (ARCSEC)

📖Definition & Introduction

  • Inverse secant (arcsec) is defined as the inverse of sec after restricting sec to a one-one interval.
  • sec x = 1cos x, so it is undefined where cos x = 0.
  • Domain of sec: ℝ \ { (2n+1)π/2 : n∈ℤ }.
  • Range of sec: ℝ \ (−1, 1) i.e. (−∞, −1] ∪ [1, ∞).
  • Standard principal restriction to make sec invertible: x∈[0, π] \ {π/2}.
  • Principal value branch: sec−1: ℝ \ (−1,1) → [0, π] \ {π/2}.

🖼️Diagram

Secant becomes invertible on [0,π] \ {π/2}; reflect this part in y=x to get arcsec.

🎯Key Concepts

  • 🚫sec x is undefined at odd multiples of π/2: x ≠ (2n+1)π/2
  • 🎯Principal range excludes π/2, so arcsec output is never 90°
  • 🔁Inverse-graph idea: restricted sec reflects in the line y=x
  • 📌Input to arcsec must satisfy |x| ≥ 1 (no values between −1 and 1)
  • 🧭On (0,π/2): sec is strictly decreasing; on (π/2,π): sec is strictly increasing

🔎RESTRICTION & PRINCIPAL VALUE (WHY [0,π]\{π/2}?)

  • sec is periodic, so it is not one-one on full ℝ; an inverse would be multi-valued.
  • On [0,π], cos goes from 1 to −1 and hits 0 at π/2, so sec is undefined at π/2.
  • On (0,π/2) and on (π/2,π), sec is monotonic, so outputs are unique within the chosen range.
  • This choice gives outputs in QI for x≥1 and in QII for x≤−1 (principal values).

⚙️BRANCHES & SET PRECISION (EXAM LANGUAGE)

  • Other valid branches exist, e.g. [−π,0]\{−π/2}, [π,2π]\{3π/2}; each defines a different inverse.
  • ℝ \ (−1,1) means (−∞,−1] ∪ [1,∞); endpoints ±1 are included.
  • Principal range is [0,π] \ {π/2}; include 0 and π, exclude π/2 only.
  • Final answers must be adjusted to lie inside the chosen principal range.

INVERSE TAN AND COT (PRINCIPAL BRANCH)

📖Definition & Introduction

  • Principal inverses: tan−1: ℝ → (−π/2, π/2) and cot−1: ℝ → (0, π).
  • tan θ is not one–one on ℝ, so restrict to a monotonic interval, typically (−π/2, π/2).
  • cot θ is not one–one on ℝ, so restrict to a monotonic interval, typically (0, π).
  • A branch of tan−1 / cot−1 comes from choosing a different monotonic interval as the inverse range.
  • Graphs of inverses are obtained by reflecting the restricted trig graph in the line y = x.

🖼️Diagram

Take tan θ only on (−π/2, π/2) (endpoints excluded), then reflect in y=x to get tan−1 x.


🎯Key Concepts

  • 🚫tan undefined at θ=(2n+1)π/2; cot undefined at θ=nπ.
  • 📈On (−π/2, π/2), tan θ is strictly increasing ⇒ bijective onto ℝ.
  • 📉On (0, π), cot θ is strictly decreasing ⇒ bijective onto ℝ.
  • 🧭Final answer must lie in the principal range; for tan/cot, adjust angles by adding/subtracting kπ.
  • 🔁Inverse graphs: (a,b) on y=f(x) ↔ (b,a) on y=f−1(x), reflection in y=x.

🔎MONOTONIC INTERVALS → BRANCHES

  • tan θ is bijective on each interval (−π/2+kπ, π/2+kπ); each choice gives a branch of tan−1.
  • Principal tan−1 uses range (−π/2, π/2), excluding endpoints (vertical asymptotes).
  • cot θ is bijective on each interval (kπ, (k+1)π); each choice gives a branch of cot−1.
  • Principal cot−1 uses range (0, π); outputs are never 0 or π.

⚙️INVERSE IDENTITIES (WITH DOMAIN WARNINGS)

  • tan(tan−1 x) = x for all real x.
  • tan−1(tan θ) = θ only if θ ∈ (−π/2, π/2); otherwise add/subtract kπ to bring it into (−π/2, π/2).
  • cot(cot−1 x) = x for all real x.
  • cot−1(cot θ) = θ only if θ ∈ (0, π); otherwise add/subtract kπ to bring it into (0, π).

📖Definition & Introduction

  • Principal value of an inverse trig function is the unique output lying in its principal range.
  • To evaluate, rewrite as a trig equation (e.g. sin y=x) and pick the solution in the stated principal range.
  • If multiple angles give the same trig value, use quadrant selection + range enforcement to choose the unique principal value.
  • Unless a branch is specified, assume principal branch for sin−1, cos−1, tan−1, cot−1, sec−1, csc−1.
  • Notation trap: sin−1x is inverse function, while (sin x)−1=1/sin x is reciprocal.

  • 📌For cot−1, principal range is (0, π); negative cot implies quadrant II.

  • Step 1: Set y = inverse trig value; rewrite as a trig equation in y.

  • Step 4: Choose the unique y that lies in the inverse function’s principal range.

IDENTITIES AND SIMPLIFICATION (INVERSE TRIG)

📖Definition & Introduction

  • Inverse-trig simplification means rewriting expressions like sin−1(sin x) using principal ranges and restrictions.
  • Key idea: f(f−1(x))=x for x in the domain of f−1 (i.e., valid input set).
  • f−1(f(x))=x holds only when x lies in the restricted (one-one) domain of f (principal interval).
  • When an angle falls outside an inverse’s principal range, replace it using trig symmetries and then apply the inverse.
  • Many results become piecewise because multiple angles share the same trig value, but the inverse returns only the principal one.

🖼️Diagram

🎯Key Concepts

  • 🎯Principal ranges: sin−1→[−π/2,π/2], cos−1→[0,π], tan−1→(−π/2,π/2).
  • 🔁tan−1(tan θ): add/subtract π until the result lies in (−π/2, π/2).
  • 🧭sin−1(sin θ): replace θ by an equivalent angle in [−π/2,π/2] using sin(π−θ)=sin θ and sin(θ−2π)=sin θ.
  • ✂️Double-angle inside an inverse often becomes valid only on a restricted x-interval to keep the output principal.

🔎CORE IDENTITIES (WITH DOMAIN WARNINGS)

  • sin(sin−1 x)=x for −1≤x≤1.
  • sin−1(sin x)=x only if x∈[−π/2, π/2]; otherwise take an equivalent angle in that interval.
  • tan(tan−1 x)=x for all real x; but tan−1(tan θ) equals θ only after ±π adjustment to the principal range.
  • Final check: Is the output angle inside the inverse’s principal range?

⚙️PIECEWISE OUTCOMES (EXAM-FAVOURITE PATTERNS)

  • If y=sin−1(sin θ), then y is the unique angle in [−π/2,π/2] with sine = sin θ.
  • Mapping rule (one clean way): first reduce θ to (−π,π] by adding/subtracting 2π; then if θ∈[−π/2,π/2] keep it, else replace by π−θ (for θ∈(π/2,π]) or by −π−θ (for θ∈(−π,−π/2)).
  • Double-angle inside inverse: sin−1(sin 2θ)=2θ only when 2θ∈[−π/2,π/2] ⇒ θ∈[−π/4,π/4].
  • Hence expressions like sin−1(2x√(1−x²)) simplify differently on different x-intervals.
