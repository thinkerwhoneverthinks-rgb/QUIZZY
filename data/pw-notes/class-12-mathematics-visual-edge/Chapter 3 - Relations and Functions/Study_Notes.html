TOPIC1

RELATIONS BASICS

📖Definition & Introduction

  • Relation from A to B: any subset R of A×B; i.e. R ⊆ A×B.
  • An ordered pair (a,b) has first element from A, second from B; order matters: (a,b) ≠ (b,a) generally.
  • If (a,b) ∈ R, we say a is related to b under R and write a R b.
  • Relation in a set A: a relation on A means R ⊆ A×A (both entries from the same set).
  • Key shift: in mathematics, any subset of A×B is a valid relation, even without a “real-life meaning”.
  • Domain/codomain idea (for relations): first components come from A (source), second from B (target).

🖼️Diagram

A relation R from A to B is a chosen subset of ordered pairs in A×B.

🎯Key Concepts

  • 🧩A×B is the “universe of all possible pairings”; a relation selects some pairings.
  • ✍️(a,b) ∈ R and aRb state the same fact in two notations.
  • 🎯Relations are more general than functions; functions are special relations with extra rules.
  • 🧭From A to B means pairs live in A×B; in A means pairs live in A×A.

🔎HOW TO FORM A RELATION (ROSTER & SET-BUILDER)

  • Step 1: write the product set A×B (all possible ordered pairs).
  • Step 2: choose pairs satisfying a condition, or list selected pairs explicitly.
  • Roster form: R = {(a1,b1),(a2,b2),…}.
  • Set-builder form: R = {(a,b) ∈ A×B : property holds}.
  • Reality-check: selection can be arbitrary; “meaningful story” is not required mathematically.

⚙️RELATION FROM A TO B vs RELATION IN A

  • From A to B: first entry must lie in A, second in B ⇒ R ⊆ A×B.
  • In A (on A): both entries lie in A ⇒ R ⊆ A×A.
  • Two boundary relations in A: empty φ and universal A×A (often called trivial).
  • To show empty: prove no ordered pair satisfies the condition; to show universal: prove every ordered pair does.

1
Let A = {1,2,3} and B = {a,b}. Define R = {(1,a),(2,a),(3,b)}. Write R in set-builder form and interpret the statement 2Ra.
Answer:
Here each pair has first element from A and second from B, so R ⊆ A×B.
Set-builder description: R = {(x,y) ∈ A×B : (x=1 and y=a) or (x=2 and y=a) or (x=3 and y=b)}.
2Ra means (2,a) ∈ R, i.e. 2 is related to a under relation R.
✓  R = {(x,y) ∈ A×B : (x=1,y=a) or (x=2,y=a) or (x=3,y=b)}; 2Ra ⇔ (2,a) ∈ R.
2
Let A = {1,2,3,4}. Consider the relation in A defined by R = {(x,y) ∈ A×A : x+y = 10}. Is R empty, universal, or neither? Justify.
Answer:
A relation in A must be a subset of A×A.
Check whether any ordered pair from A×A can satisfy x+y=10.
Maximum possible sum in A is 4+4=8, which is less than 10.
So no (x,y) ∈ A×A satisfies the condition, hence no pair belongs to R.
✓  R = φ (empty relation), because no ordered pair in A×A can have sum 10.

⭐Important Points

  • Core definition: relation from A to B means R ⊆ A×B.
  • Always respect order: first component belongs to A, second to B.
  • Use both notations confidently: (a,b) ∈ R ⇔ aRb.
  • Relation in A specifically means subset of A×A (not A×B).
  • To prove empty relation: show condition is impossible within the allowed sets.

TOPIC2

EMPTY AND UNIVERSAL RELATIONS

📖Definition & Introduction

  • Empty relation on a set A: R=φ ⊂ A×A; no ordered pair is related.
  • Universal relation on A: R=A×A; every ordered pair is related.
  • A relation R in A means R ⊆ A×A (pairs only from A).
  • Empty + universal are called trivial relations (extreme subsets of A×A).
  • To prove empty: show no (a,b) ∈ A×A satisfies the defining condition.
  • To prove universal: show the condition is always true for all (a,b) ∈ A×A.

🖼️Diagram

In a set A, relations live inside A×A; extremes are φ and A×A.

🎯Key Concepts

  • IDEAUniverse of pairs: A×A is the full list of possible ordered pairs.
  • EMPTEmpty relation logic: ∀(a,b)∈A×A, condition is false ⇒ R=φ.
  • UNIVUniversal relation logic: ∀(a,b)∈A×A, condition is true ⇒ R=A×A.
  • NOTESet-builder vs roster: set-builder gives a rule; roster explicitly lists pairs (finite A).
  • TIPFast check: if condition is an identity (always true) ⇒ universal; if impossible by bounds ⇒ empty.

🔎HOW TO PROVE (EXAM LANGUAGE)

  • Empty: take arbitrary (a,b) ∈ A×A; show defining condition is impossible.
  • Use bounds/contradiction: show condition forces a value outside what A allows.
  • Universal: take arbitrary (a,b) ∈ A×A; show condition always holds.
  • If condition is always true (e.g. |a−b| ≥ 0), conclude R=A×A.

⚙️REPRESENTATIONS (SET-BUILDER ↔ ROSTER)

  • Set-builder empty example (A={1,2,3,4}): R={(a,b): a−b=10}=φ since impossible in A×A.
  • Set-builder universal example: R={(a,b): |a−b|≥0}=A×A since always true.
  • Roster empty: write nothing; just state R=φ (do not list any pair).
  • Roster universal (finite A): list all pairs in A×A (or state equivalently R=A×A).

✏️Solved Q&A

1
Let A={1,2,3}. Define R={(a,b)∈A×A : a+b=10}. Identify R and justify.
Answer:
For any a,b∈{1,2,3}, the maximum a+b is 3+3=6.
So a+b=10 is impossible for all (a,b)∈A×A.
Hence no ordered pair satisfies the condition ⇒ R=φ.
✓  R is the empty relation (φ).
2
Let A be any non-empty set. Define R in A by R={(a,b)∈A×A : a=a}. Identify R and justify.
Answer:
The statement a=a is true for every element a (a basic property of equality).
So for every ordered pair (a,b)∈A×A, the condition holds (it does not even depend on b).
Thus every pair is included ⇒ R=A×A.
✓  R is the universal relation (A×A).

⭐Important Points

  • A relation in A must be a subset of A×A; do not use elements outside A.
  • Empty relation means zero pairs, not “hard to find pairs”. Provide an impossibility reason.
  • Universal relation means all pairs; prove condition holds for arbitrary (a,b).
  • For finite A with |A|=n: |A×A|=n²; helps sanity-check universality.
  • Set-builder conditions that are always true (identities) generate universal relations.

TOPIC3

REPRESENTING RELATIONS

📖Definition & Introduction

  • A relation R from A to B is any subset of A×B.
  • Membership statement: (a,b) ∈ R means the ordered pair (a,b) is selected in the relation.
  • Shorthand: a R b is another way to write (a,b) ∈ R (same fact, different notation).
  • Roster form represents R by listing ordered pairs explicitly: { (a,b), (c,d), ... }.
  • Set-builder form represents R by a property: { (x,y) ∈ A×B : condition }.
  • Always interpret pairs as ordered: (a,b) ≠ (b,a) unless a=b.

🖼️Diagram

A relation selects some arrows (ordered pairs) from A to B; each arrow means (a,b) ∈ R i.e. aRb.

🎯Key Concepts

  • 🧾Roster method: best for small finite sets; list every ordered pair in R.
  • 🧩Set-builder method: best when a clear condition generates pairs; avoids long listing.
  • ✅Core meaning is membership: (a,b) ∈ R; aRb is just shorthand.
  • 🔁Conversion idea: from condition → filter pairs from A×B to get roster.
  • 🧭Direction matters for relations from A to B: first element from A, second from B.

🔎HOW TO WRITE A RELATION (2 REPRESENTATIONS)

  • Roster: R = { (a1,b1), (a2,b2), ... } where each ai∈A, bi∈B.
  • Set-builder: R = { (x,y) ∈ A×B : P(x,y) } where P is a condition/property.
  • Use roster when A, B small; use set-builder when a clean rule defines membership.
  • Writing aRb is best for sentence-like relations (e.g., “a is brother of b”).

⚙️CONVERSION SKILLS (EXAM-FAVOURITE)

  • From set-builder → roster (finite sets): list A×B candidates, keep only those satisfying the condition.
  • From roster → set-builder: spot a pattern in listed pairs; state it as P(x,y) with domain restriction (x,y) ∈ A×B.
  • Always attach the universe: write (x,y) ∈ A×B; otherwise condition may allow extra pairs.
  • To test membership quickly, check: (a,b) ∈ R ? ⇔ does (a,b) satisfy P(a,b)?

✏️Solved Q&A

1
Let A={1,2,3,4}. Define R in A by R = { (a,b) ∈ A×A : b = a + 1 }. Write R in roster form and express it using aRb notation.
Answer:
Since (a,b) must lie in A×A, only keep pairs where both a and b are in A.
List valid pairs satisfying b=a+1: (1,2), (2,3), (3,4).
Reject (4,5) because 5 ∉ A (so it is not in A×A).
Use the equivalence: (a,b)∈R is the same as aRb.
✓  R = { (1,2), (2,3), (3,4) } and aRb means “b=a+1” with a,b ∈ A.
2
Let A={1,2,3} and B={2,4,6}. Define R from A to B by R = { (a,b) ∈ A×B : b = 2a }. (i) Write R in roster form. (ii) Decide whether (2,6) ∈ R. (iii) Write the equivalent aRb statement.
Answer:
To convert set-builder to roster, test each a ∈ A and keep b=2a only if it lies in B.
Valid pairs are (1,2), (2,4), (3,6).
For (2,6), check the defining condition: if a=2 then 2a=4, not 6, so the condition fails.
✓  (i) R = { (1,2), (2,4), (3,6) } (ii) (2,6) ∉ R (iii) aRb ⇔ b=2a (with a∈A, b∈B).

⭐Important Points

  • A relation is any subset of A×B; no real-life meaning is required.
  • Always keep the universe clear: (x,y) ∈ A×B comes before the condition P(x,y).
  • (a,b) ∈ R and aRb are equivalent; do not treat them as different conditions.
  • Ordered pairs are directional: relation from A to B uses first component from A only.
  • When converting to roster, drop pairs that satisfy the rule but fall outside the given sets.

💡Memory Technique

“MRP: Meaning → Roster → Property”
Meaning is always membership: (a,b) ∈ R.Roster is the explicit list of all such members.Property (set-builder) is the rule that picks those members from A×B.

REFLEXIVE • SYMMETRIC • TRANSITIVE (RST)

📖Definition & Introduction

  • Relation R on set A is a subset of A×A (ordered pairs).
  • Reflexive: for every a∈A, (a,a)∈R.
  • Symmetric: if (a,b)∈R then (b,a)∈R.
  • Transitive: if (a,b)∈R and (b,c)∈R, then (a,c)∈R.
  • To disprove a property, one valid counterexample pair/chain is enough.
  • Equivalence relation ⇔ Reflexive + Symmetric + Transitive.

🎯Key Concepts

  • ✅Reflexive test: all diagonal pairs (a,a) must be present.
  • 🔄Symmetric test: every arrow a→b must have b→a.
  • 🔗Transitive test: whenever a→b and b→c, must have a→c.
  • 🎯Finite-set strategy: list pairs; check diagonal, reverses, then all 2-step paths.
  • ⚠️Transitivity needs the middle element matching: (a,b) and (b,c), not any two pairs.

🔎QUICK CHECKING METHODS (FINITE SET A)

  • Reflexive: scan for all diagonal pairs (a,a). Missing one ⇒ not reflexive.
  • Symmetric: for each listed (a,b), search for (b,a).
  • Transitive: build all 2-step chains: for each (a,b), pair it with every (b,c).
  • If any required (a,c) is absent, that single chain disproves transitivity.
  • Pairs like (a,a) create chains such as (a,a) & (a,c) ⇒ require (a,c); they usually don’t introduce new demands beyond existing pairs.

⚙️COUNTEREXAMPLE PATTERNS (FAST DISPROOFS)

  • Not reflexive: find an element a with (a,a)∉R.
  • Not symmetric: find (a,b)∈R but (b,a)∉R.
  • Not transitive: find (a,b),(b,c)∈R but (a,c)∉R.
  • Classic trap: “perpendicular” in a plane is symmetric, but not reflexive or transitive.

✏️Solved Q&A

1
Let A={1,2,3} and R={(1,1),(2,2),(3,3),(1,2),(2,3)}. Check reflexive, symmetric, transitive.
Answer:
Reflexive: (1,1),(2,2),(3,3) are all present ⇒ reflexive.
Symmetric: (1,2)∈R but (2,1)∉R ⇒ not symmetric.
Transitive: (1,2)∈R and (2,3)∈R would require (1,3)∈R, but (1,3)∉R ⇒ not transitive.
✓  Reflexive: Yes; Symmetric: No; Transitive: No.
2
On integers ℤ, define R by (a,b)∈R ⇔ 2 divides (a−b). Prove R is reflexive, symmetric, transitive.
Answer:
Reflexive: for any a, a−a=0 and 2 divides 0 ⇒ (a,a)∈R.
Symmetric: if 2 divides (a−b), then (b−a)=−(a−b) is also divisible by 2 ⇒ (b,a)∈R.
Transitive: if 2 divides (a−b) and 2 divides (b−c), then their sum (a−c)=(a−b)+(b−c) is divisible by 2 ⇒ (a,c)∈R.
✓  R is reflexive, symmetric, and transitive; hence an equivalence relation (same parity).

⭐Important Points

  • To disprove reflexive/symmetric/transitive, one correct counterexample is enough.
  • For symmetry, check: if (a,b)∈R, then (b,a) must also be in R.
  • For transitivity, only matching-middle chains matter: (a,b) and (b,c).
  • Reflexive + symmetric does not imply transitive.
  • Equivalence relation ⇔ reflexive ∧ symmetric ∧ transitive.

💡Memory Technique

“Mnemonic: RST = Mirror–Swap–Shortcut”

EQUIVALENCE RELATIONS (RST)

📖Definition & Introduction

  • Equivalence relation on a set A: a relation R ⊆ A×A that is reflexive, symmetric, and transitive.
  • Reflexive: ∀a∈A, (a,a)∈R (every element relates to itself).
  • Symmetric: (a,b)∈R ⇒ (b,a)∈R.
  • Transitive: (a,b)∈R and (b,c)∈R ⇒ (a,c)∈R.
  • To disprove any of R/S/T, one counterexample is enough; proving needs a general argument.
  • If R is an equivalence relation, it partitions A into disjoint equivalence classes.

🖼️Diagram

Think: RST gatekeeper; pass all three to earn “equivalence relation”.


🎯Key Concepts

  • [CHKRST checklist: prove Reflexive, then Symmetric, then Transitive (order helps avoid missed cases).
  • [EX]Standard equivalence examples: congruence of triangles; congruence modulo n (difference divisible by n).
  • [TRAStandard non-example: perpendicularity is symmetric but not reflexive/transitive (in a plane).
  • [CLSClasses: [a] = {x∈A : xRa}. If [a]∩[b]≠φ then [a]=[b].
  • [NOTExam trap: “n divides (a−b)” means same remainder mod n, not “both divisible by n”.

🔎HOW TO PROVE / DISPROVE (RST PLAYBOOK)

  • Reflexive: start with arbitrary a∈A; show (a,a) satisfies the defining condition.
  • Symmetric: assume aRb; logically rearrange to deduce bRa.
  • Transitive: assume aRb and bRc; combine both to deduce aRc.
  • To disprove a property, give one explicit counterexample pair/triple.
  • Finite set shortcut: reflexive needs all diagonal pairs; symmetric needs mirror pairs; transitive needs closure of all 2-step chains.

⚙️STANDARD EXAMPLES + TRAPS (JEE/Boards FAVOURITES)

  • Congruence of triangles (≅) is equivalence: self congruent, reversible, and chainable.
  • Perpendicularity of lines (⟂): symmetric, but not reflexive; also not transitive (two lines ⟂ to the same line become ∥).
  • Parity / divisible-by-2 difference: on ℤ, aRb ⇔ 2∣(a−b) gives two classes: evens and odds.
  • Mod n: aRb ⇔ n∣(a−b) is always an equivalence relation on ℤ.
  • Function-induced relation: for f:X→Y, define aRb ⇔ f(a)=f(b); this is always an equivalence relation on X.

✏️Solved Q&A

1
On ℤ, define aRb ⇔ 2∣(a−b). (i) Prove R is an equivalence relation. (ii) Find [3] and [−4].
Answer:
Reflexive: for any a∈ℤ, a−a=0 and 2∣0, so aRa.
Symmetric: if 2∣(a−b), then 2∣−(a−b)=2∣(b−a), so bRa.
Transitive: if 2∣(a−b) and 2∣(b−c), then 2 divides their sum (a−c)=(a−b)+(b−c), so aRc.
Hence R is reflexive, symmetric, transitive ⇒ equivalence relation.
[3]={x∈ℤ:2∣(x−3)} = all odd integers.
[−4]={x∈ℤ:2∣(x+4)} = all even integers.
✓  R is an equivalence relation; [3]=set of all odd integers, [−4]=set of all even integers.
2
Let L be the set of all lines in a plane. Define L1 R L2 ⇔ L1 ⟂ L2. Decide whether R is an equivalence relation (justify each property).
Answer:
Reflexive? Would need L ⟂ L for every line L, which is impossible in a plane, so not reflexive.
Symmetric? If L1 ⟂ L2, then L2 ⟂ L1 by definition, so symmetric.
Transitive? If L1 ⟂ L2 and L2 ⟂ L3, then L1 ∥ L3, not perpendicular, so transitivity fails.
Since reflexive and transitive fail, it is not an equivalence relation.
✓  Not an equivalence relation: symmetric only; neither reflexive nor transitive.

⭐Important Points

  • Equivalence ⇔ RST all true; failing even one property means NOT equivalence.
  • To disprove R/S/T, one counterexample is sufficient; proving needs a general argument.
  • For divisibility-type relations: use 0 is divisible by n; divisibility is preserved under negation; divisibility is preserved under addition.
  • Perpendicularity: ⟂ and ⟂ to the same line ⇒ parallel (classic transitivity trap in a plane).
  • Equivalence classes form a partition: non-empty, pairwise disjoint, and union equals the whole set.

EQUIVALENCE CLASSES & PARTITIONS

📖Definition & Introduction

  • Equivalence class of a (under an equivalence relation R on X): [a] = {x ∈ X : x R a}.
  • Members of [a] are exactly the elements related to a (under R).
  • If R is an equivalence relation, then every element of X lies in exactly one equivalence class.
  • For an equivalence relation, any two classes are either identical or disjoint: a R b ⇒ [a]=[b]; if a is not related to b, then [a]∩[b]=∅.
  • The family of all distinct equivalence classes forms a partition of X: pairwise disjoint nonempty subsets whose union is X.

🖼️Diagram

Equivalence classes [a],[b],… are disjoint blocks whose union is the whole set X.

🎯Key Concepts

  • 🧷Core idea: equivalence relation = "same category"; class [a] = all in a's category.
  • 🧱Partition properties: Ai ∩ Aj = ∅ for i≠j and ⋃Ai = X.
  • 🔁Theorem (equivalence relations): a R b ⇔ [a]=[b].
  • ⚖️Parity on ℤ gives two classes: E (even) and O (odd), with E ∩ O = ∅.
  • 🎯On finite sets, compute [a] for one representative from each class; repeats give no new class.

🔎HOW CLASSES FORCE A PARTITION

  • If x ∈ [a], then x R a by definition of [a].
  • If [a] ∩ [b] ≠ ∅, choose z in the intersection: z R a and z R b.
  • By symmetry: a R z. By transitivity with z R b: a R b.
  • Hence [a]=[b]. Therefore any two classes are either equal or disjoint.
  • Reflexive: a R a ⇒ a ∈ [a], so every element lies in some class and ⋃a∈X[a] = X.

⚙️ILLUSTRATIONS: PARITY ON ℤ AND A FINITE SET

  • On ℤ define a R b ⇔ 2 divides (a−b) (same parity). This is an equivalence relation.
  • Then [0]=E (all even integers) and [1]=O (all odd integers).
  • Partition facts: E ∩ O = ∅ and ℤ = E ∪ O.
  • Finite example A={1,2,3,4,5,6,7} with same-parity relation: classes are {1,3,5,7} and {2,4,6}.

PARTITION TO RELATION (MOD 3)

📖Definition & Introduction

  • Given a partition {A1,A2,A3} of a set X, define aRb ⇔ a and b lie in the same Ai.
  • A partition means: Ai ≠ φ, Ai ∩ Aj = φ (i ≠ j), and A1 ∪ A2 ∪ A3 = X.
  • This "same block" relation is always reflexive, symmetric, transitive ⇒ an equivalence relation.
  • For X = ℤ, the partition into remainders mod 3 gives three congruence classes: multiples of 3, numbers ≡1, and numbers ≡2.
  • Then aRb ⇔ 3 divides (a − b) ⇔ a and b have the same remainder on division by 3.

🖼️Diagram

Partition into A1,A2,A3 (remainders 0,1,2 mod 3) induces aRb: "same subset" ⇔ 3 | (a−b).


🎯Key Concepts

  • 🔁Reverse direction: partition ⇒ equivalence relation by "same subset".
  • 🧱Each block Ai becomes an equivalence class (a bin of mutually-related elements).
  • ➗Mod 3 classes: A1 = [0], A2 = [1], A3 = [2] under 3 | (a−b).
  • ⚠️Key meaning: 3 | (a−b) means same remainder, not "3 divides a and b".

🔎WHY "SAME SUBSET" IS ALWAYS AN EQUIVALENCE RELATION

  • Reflexive: any a lies in some Ai, so a and a are in same Ai ⇒ aRa.
  • Symmetric: if a and b are in same Ai, then b and a are in same Ai ⇒ bRa.
  • Transitive: if a,b in Ai and b,c in Ai, then a,c in Ai ⇒ aRc.
  • Disjointness ensures: if aRb, then a and b cannot belong to two different blocks.

⚙️CONNECTING TO CONGRUENCE MODULO 3

  • Define blocks: A1={x: 3|x}, A2={x: 3|(x−1)}, A3={x: 3|(x−2)}.
  • Then aRb ⇔ a,b in same Ai ⇔ a ≡ b (mod 3) ⇔ 3 | (a−b).
  • Equivalence classes: [0]=A1, [1]=A2, [2]=A3; also [3r]=[0], [3r+1]=[1], [3r+2]=[2].
  • Quick test: compute remainders of a and b on division by 3; equal remainders ⇒ related.

TOPIC8

FUNCTION TYPES (INJECTIVE / SURJECTIVE / BIJECTIVE)

📖Definition & Introduction

  • Injective (one-one): for all x1,x2 in domain, f(x1)=f(x2) ⇒ x1=x2.
  • Many-one: not injective; ∃ x1≠x2 with f(x1)=f(x2).
  • Surjective (onto): for every y in codomain Y, ∃ x in domain X such that f(x)=y.
  • Range–codomain test: onto ⇔ Range(f) = codomain.
  • Bijective: both injective and surjective (perfect pairing between domain and codomain).
  • Domain/codomain dependence: same rule f(x)=2x is not onto on ℕ→ℕ, but is onto on ℝ→ℝ.

🖼️Diagram

Bijective map: no two arrows land together (injective) and every codomain element is hit (onto).

🎯Key Concepts

  • 🧷Injective proof: start with f(x1)=f(x2), then deduce x1=x2.
  • 🎯Onto proof: take arbitrary y∈Y (codomain) and construct x∈X such that f(x)=y.
  • 🧭To disprove: injective → two distinct inputs with same output; onto → one codomain element with no preimage.
  • 🧮Finite-set fact: for f: X→X with finite X, one-one ⇔ onto.
  • 🔁Bijective functions are exactly the invertible functions (existence of f−1).

🔎STANDARD PROOF STRATEGIES

  • To prove injective: assume f(x1)=f(x2) and deduce x1=x2.
  • Alternative injective: prove contrapositive: x1≠x2 ⇒ f(x1)≠f(x2).
  • To prove not injective: exhibit explicit x1≠x2 with same image.
  • To prove onto: take arbitrary y∈Y, solve f(x)=y, and show the solution lies in X.
  • To prove not onto: choose a y∈Y and show f(x)=y has no solution in X.

⚙️DOMAIN/CODOMAIN DEPENDENCE (EXAM FAVOURITE)

  • Injective/onto are properties of the triple (rule, domain, codomain), not only the rule.
  • Example: f(x)=2x is not onto for ℕ→ℕ (odd y have no preimage).
  • Same rule is onto for ℝ→ℝ since for any y, choose x=y/2.
  • Example: f(x)=x2 is not one-one on ℝ→ℝ, but becomes one-one on [0,∞)→[0,∞).

  • For finite X, if f:X→X is one-one then onto, and if onto then one-one.

FINITE VS INFINITE SELF-MAPS

📖Definition & Introduction

  • A self-map is a function f:X→X (domain = codomain = X).
  • One–one (injective): f(x1)=f(x2) ⇒ x1=x2.
  • Onto (surjective): For every y∈X, ∃ x∈X such that f(x)=y.
  • Key finite-set fact: If X is finite and f:X→X, then injective iff surjective.
  • When X is finite, any bijective self-map is a permutation of elements of X.
  • For infinite sets (e.g. ℕ), injective and surjective become independent; counterexamples exist.

🎯Key Concepts

  • 🧩Finite pigeonhole idea: injective self-map can’t “miss” an element without repeating.
  • 📦Finite counting idea: |Range(f)|=|X| forces Range(f)=X when X is finite.
  • 🔀Bijective self-map on a finite set ⇔ permutation (relabeling) of elements of X.
  • ♾️Infinite sets allow “shift/doubling” maps: can be one–one not onto, or onto not one–one.

🔎WHY IN FINITE X: ONE–ONE ⇔ ONTO

  • Let |X|=n and f:X→X.
  • (A) One–one ⇒ onto: injective gives n distinct outputs, all lying in X.
  • A subset of a finite set with n distinct elements must be the whole set ⇒ Range(f)=X.
  • (B) Onto ⇒ one–one: if not one–one, two distinct inputs share an output, so distinct outputs are fewer than n.
  • Then Range(f) cannot equal X, contradicting surjectivity.

⚙️INFINITE SETS: WHY THE EQUIVALENCE FAILS (ℕ)

  • Injective but not onto: f:ℕ→ℕ, f(x)=2x hits only even numbers; odd numbers have no preimage.
  • Onto but not injective: define g(1)=g(2)=1; for x>2, g(x)=x−1.
  • Then every y∈ℕ has a preimage (1 has 1 or 2; y≥2 has y+1), but 1 and 2 collide.
  • Key reason: in infinite sets, you can “shift” elements and still cover the whole set, unlike finite sets.

COMPOSITION OF FUNCTIONS

📖Definition & Introduction

  • If f: A→B and g: B→C, then g∘f: A→C is defined by (g∘f)(x)=g(f(x)).
  • Order is fixed: first apply f, then apply g.
  • Domain compatibility: for g∘f to be defined, Range(f) ⊆ Domain(g) (often codomain of f equals domain of g).
  • In general, g∘f ≠ f∘g (composition is usually non-commutative).
  • To compute safely, always start with: (g∘f)(x)=g(f(x)) before substituting specific functions/values.

🖼️Diagram

Composition g∘f maps A to C by sending x through f then g.

🎯Key Concepts

  • ➡️Meaning of g∘f: input x goes through f then through g.
  • 🧩Compatibility test: outputs of f must be valid inputs for g.
  • ⚠️Non-commutative: swapping order usually changes the function and its value.
  • 📋Finite-set method: compute f(x) for each x, then apply g on that result.

🔎DOMAIN–CODOMAIN COMPATIBILITY (EXAM CHECKLIST)

  • Given f: A→B, g: D→C, g∘f exists only if Range(f) ⊆ D.
  • If g is not defined on some output of f, then g∘f is not defined for those inputs of f.
  • When domains are restricted, the composition’s domain may need restriction to valid x only.

⚙️FINITE-SET COMPOSITION (TABLE METHOD)

  • Write mapping list for f. For each x in Domain(f), compute f(x).
  • Apply g to that value: (g∘f)(x)=g(f(x)). Record the final image.
  • If some f(x) is not in Domain(g), that x is invalid for g∘f.

INVERTIBLE FUNCTIONS

📖Definition & Introduction

  • f : X → Y is invertible if ∃ g : Y → X such that g∘f = IX and f∘g = IY.
  • Such g is unique and is called the inverse function of f, written as f−1.
  • Identity function: IX(x)=x for all x∈X (similarly IY(y)=y).
  • Invertible means: every y∈Y has exactly one preimage in X (existence + uniqueness).
  • Necessary and sufficient: f is invertible ⇔ f is bijective (one–one and onto).

🖼️Diagram

Invertible means f and g undo each other on X and on Y (two-sided inverse).


🎯Key Concepts

  • 🧩Two-sided inverse required: g∘f fixes X, and f∘g fixes Y.
  • 🎯Bijective test beats guessing: prove injective + surjective ⇒ inverse exists.
  • 🧠To construct inverse: set y=f(x), solve x in terms of y, then write f−1(y)=x.
  • ⚠️Domain/codomain decide invertibility; same formula may be invertible on ℝ but not on ℕ.

🔎WHY INVERTIBLE ⇔ BIJECTIVE (EXAM PROOF SKELETON)

  • Invertible ⇒ one–one: if f(x1)=f(x2), apply g to get x1=x2.
  • Invertible ⇒ onto: for any y∈Y, take x=g(y) ⇒ f(x)=f(g(y))=(f∘g)(y)=y.
  • Bijective ⇒ inverse exists: define g(y) as the unique x with f(x)=y; then g∘f=IX, f∘g=IY.
  • Uniqueness: if g and h both satisfy g∘f=IX and f∘g=IY, then g=h (check on any y).

⚙️CONSTRUCTING f−1 (QUICK ALGORITHM)

  • Step 1: Write y=f(x).
  • Step 2: Solve for x in terms of y (use domain/codomain restrictions).
  • Step 3: Swap names: x=f−1(y).
  • Step 4: Verify by composition: f(f−1(y))=y and f−1(f(x))=x.
  • Note: inverse is a function only when each y has exactly one preimage (bijective).

g∘f = IX and f∘g = IY
Invertible ⇒ one–one (core move):
f(x1)=f(x2) ⇒ g(f(x1))=g(f(x2)) ⇒ x1=x2
Invertible ⇒ onto (core move):
For y∈Y, let x=g(y). Then f(x)=f(g(y))=(f∘g)(y)=y
X, Y =Domain and codomain sets
f : X→Y =Given function
g : Y→X =Candidate inverse function
IX, IY =Identity functions on X and Y
f−1 =Inverse of f (a function), not the reciprocal 1/f
Invertibility criterion
f is invertible ⇔ f is bijective

📈Graph

Graph of an invertible function passes horizontal line test; inverse is reflection in y=x.

✏️Solved Examples

1
Given f : ℕ → Y, f(x)=4x+3 where Y={y∈ℕ : y=4x+3 for some x∈ℕ}. Show f is invertible and find f−1.
Solution:
Take arbitrary y∈Y. By definition of Y, ∃ x∈ℕ such that y=4x+3.
Solve for x: x=(y−3)÷4.
Define g : Y→ℕ by g(y)=(y−3)÷4.
Check: (g∘f)(x)=g(4x+3)=((4x+3)−3)÷4=4x÷4=x ⇒ g∘f=Iℕ.
Check: (f∘g)(y)=f((y−3)÷4)=4((y−3)÷4)+3=(y−3)+3=y ⇒ f∘g=IY.
✓  f is invertible and f−1(y)=(y−3)÷4 for y∈Y.
2
Let f : ℝ → ℝ, f(x)=4x+3. Find f−1 and evaluate f−1(19).
Solution:
Write y=f(x)=4x+3 and solve: 4x=y−3 ⇒ x=(y−3)÷4.
Hence f−1(y)=(y−3)÷4 (domain ℝ, codomain ℝ).
Compute: f−1(19)=(19−3)÷4=16÷4=4.
Quick check: f(4)=4·4+3=16+3=19, consistent.
✓  f−1(x)=(x−3)÷4 and f−1(19)=4.

⭐Important Points

  • Always state sets: f : X→Y; invertibility depends on both domain and codomain.
  • For inverse, need both g∘f=IX and f∘g=IY (not just one).
  • If f is invertible, then f is one–one and onto; use this to disprove invertibility quickly.
  • If f is bijective, inverse exists and is unique; denote it by f−1 : Y→X.
  • Graph test (real functions): invertible ⇔ passes horizontal line test on the given domain.

💡Memory Technique

“Mnemonic: BI = IN”
BIjective ⇔ INvertible.Inverse means "back-and-forth gives identity": go f then g → same x, go g then f → same y.

ADVANCED RELATION APPLICATIONS

📖Definition & Introduction

  • A relation R on A is a subset of A×A; equivalence relation ⇔ reflexive + symmetric + transitive.
  • Intersection: if R1, R2 are equivalence on A, then R1 ∩ R2 is equivalence.
  • Function-induced relation: for f:X→Y, define R={(a,b): f(a)=f(b)}; it is always an equivalence relation on X.
  • Equality of relations is proved by inclusions: R1⊂R2 and R2⊂R1 ⇒ R1=R2.
  • Counting (finite): number of relations from A to B is 2|A|·|B|; number of one-one maps on a 3-element set = 3!.

🖼️Diagram

Two key constructions: intersection of equivalence relations and equivalence induced by a function.

🎯Key Concepts

  • ✅Equivalence check = RST; one counterexample kills symmetry/transitivity.
  • ∩R1∩R2: inherits RST because each property is checked pairwise.
  • 🎯Induced by f: classes are preimages (fibres) of single outputs.
  • 🧮Counting relations: choose ordered pairs independently only when no property constraints link pairs.
  • ⚠️For transitivity, always test: (a,b) and (b,c) present ⇒ (a,c) must be present.

🔎STANDARD RESULTS YOU MUST BE ABLE TO PROVE

  • Intersection: show RST for R1∩R2 using “in both” ⇒ property holds in each.
  • Cross-multiplication relation on pairs: (x,y)~(u,v) ⇔ xv=yu; behaves like equality of fractions x/y (require y,v≠0).
  • Induced by function: a~b ⇔ f(a)=f(b); classes are all elements sharing the same image.
  • Equality of relations: always do two containments; avoid “looks same” arguments.

⚙️COUNTING & CONSTRAINT APPLICATIONS (EXAM STYLE)

  • Total relations from A to B: each ordered pair is chosen/not chosen independently.
  • One-one maps on a 3-element set are permutations: 3!.
  • With constraints (reflexive/symmetric/transitive), pairs are no longer independent: add forced pairs via properties before counting.
  • To disprove a property fast, one valid counterexample ordered pair (or missing forced pair) is enough.

✏️Solved Q&A

1
Let A={1,2,3} and B={a,b}. How many relations R from A to B contain both (1,a) and (2,b)?
Answer:
There are 6 ordered pairs in A×B.
A relation is any subset of A×B.
(1,a) and (2,b) are compulsory, so only the remaining 4 pairs are optional.
Each of those 4 pairs can be chosen or not chosen independently, so total relations = 24 = 16.
✓  16
2
On X={1,2,3,4}, define f(x)=x mod 2 with codomain {0,1}. Relation R on X is given by (a,b)∈R ⇔ f(a)=f(b). Find equivalence classes and number of ordered pairs in R.
Answer:
Compute images: f(1)=1, f(2)=0, f(3)=1, f(4)=0.
Elements with the same image are related, so the partition is {1,3} (odd) and {2,4} (even).
All ordered pairs within a class belong to R (including (a,a)). Each class has 2 elements, giving 2×2=4 pairs per class.
Total ordered pairs in R = 4+4 = 8.
✓  Classes: {1,3} and {2,4}; |R| = 8

⭐Important Points

  • To prove a relation is equivalence, always write RST in three separate mini-proofs.
  • For intersection, use: (a,b)∈R1∩R2 ⇒ in both R1 and R2.
  • For equality R1=R2, prove both containments using definitions.
  • Induced relation f(a)=f(b) always gives an equivalence relation; classes are preimages of single outputs.
  • Counting with constraints: list forced pairs (reflexive/symmetric/transitive closure ideas) before counting choices.

💡Memory Technique

“RST + 2C + 1CE”
RST: Reflexive, Symmetric, Transitive for equivalence checks.2C: Two Containments for equality of relations (R1⊂R2 and reverse).1CE: One CounterExample is enough to break symmetry/transitivity.
