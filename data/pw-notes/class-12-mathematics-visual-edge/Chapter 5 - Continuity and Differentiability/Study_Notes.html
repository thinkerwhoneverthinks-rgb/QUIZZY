Continuity and Differentiability

TOPIC1

CONTINUITY BASICS

📖Definition & Introduction

  • f is continuous at x=c iff limx→c f(x) = f(c).
  • All conditions: f(c) exists, LHL exists, RHL exists, and all three are equal.
  • If LHL = RHL = L, then limx→c f(x) exists and equals L.
  • If any condition fails, f is discontinuous at c; c is a point of discontinuity.
  • Intuition: nearby x-values give nearby f(x)-values; no "pen-lift" near x=c.
  • Continuity is checked only at points in the domain; if f(c) is not defined, continuity at c is not applicable.

🖼️Diagram

Jump: LHL ≠ RHL. Removable-type mismatch: LHL = RHL but point value differs.

🎯Key Concepts

  • 🧭Two-sided limit exists ⇔ LHL and RHL exist and are equal.
  • ⬅️LHL: approach c from left (x<c); use left branch in piecewise functions.
  • ➡️RHL: approach c from right (x>c); use right branch in piecewise functions.
  • 🪜Jump discontinuity: LHL ≠ RHL, so the (real) limit does not exist.
  • 🕳️Removable-type mismatch: LHL = RHL = L but f(c) ≠ L (or f(c) undefined).
  • 🚫Unbounded behaviour near c (like 1/x near 0): one-sided limits may be ±∞, so the real-number limit does not exist.

🔎HOW TO TEST CONTINUITY AT x=c (EXAM FLOW)

  • Step 1: Check f(c) is defined (c ∈ domain).
  • Step 2: Compute LHL: limx→c− f(x) using x<c rule.
  • Step 3: Compute RHL: limx→c+ f(x) using x>c rule.
  • Step 4: If LHL = RHL = L, then limx→c f(x) = L exists.
  • Step 5: Compare with value: continuity ⇔ L = f(c).

⚙️TYPICAL DISCONTINUITY PATTERNS (WHAT YOU SAY IN WORDS)

  • Jump: LHL and RHL are different real numbers ⇒ limit does not exist.
  • Removable-type mismatch: LHL = RHL, but f(c) is missing or assigned another value.
  • Not in domain: if c ∉ domain, do not test “continuity at c”; test continuity on the domain.
  • Infinite discontinuity: one-sided limits go to ±∞; describe as unbounded (not a real-number limit).

✏️Solved Q&A

1
Concept check: For f(x)=x²−1x−1 for x≠1, and f(1)=5, is f continuous at x=1? Explain.
Answer:
For x≠1, x²−1=(x−1)(x+1), so the expression equals x+1 (a simple line) for all x≠1.
As x approaches 1, x+1 approaches 2, so the two-sided limit at 1 is 2.
But the defined value is f(1)=5, which does not match the limit.
So the graph has a "hole" at the limit-value and an "extra/misplaced" point at (1,5): not continuous.
✓  Discontinuous at x=1 because the limit (2) does not equal the assigned value 5; it is a removable-type mismatch.
2
Concept check: For f(x)=|x−2|x−2 (x≠2) and f(2)=0, test continuity at x=2 using one-sided behaviour.
Answer:
For x>2, |x−2|=x−2 ⇒ f(x)=1, so RHL at 2 is 1.
For x<2, |x−2|=−(x−2) ⇒ f(x)=−1, so LHL at 2 is −1.
Since LHL ≠ RHL, the two-sided limit at 2 does not exist (as a real number).
Even though f(2)=0 is defined, unequal one-sided limits mean the function cannot be continuous at 2.
✓  Not continuous at x=2 (jump discontinuity: LHL=−1, RHL=1).

⭐Important Points

  • Continuity at c requires all three: LHL = RHL = f(c).
  • If LHL = RHL but f(c) differs (or is missing), discontinuity is removable by defining f(c) as the common limit.
  • If LHL ≠ RHL, changing only f(c) cannot fix continuity (jump remains).
  • For piecewise functions, always check the join point(s); each branch is usually continuous on its own interval.
  • Do not claim continuity at points outside the domain (e.g., 1/x at 0): continuity is defined only where the function is defined.

TOPIC2

CONTINUITY ON INTERVALS

📖Definition & Introduction

  • Continuous at c (with c in domain): limx→c f(x) = f(c) (i.e., LHL = RHL = value).
  • Continuous function: continuous at every point of its domain (do not test points outside the domain).
  • On a closed interval [a,b], continuity means: continuous on (a,b) plus endpoint one-sided conditions.
  • At left endpoint a: limx→a+ f(x) = f(a); at right endpoint b: limx→b− f(x) = f(b).
  • If domain is a singleton {c}, the function is automatically continuous (no other domain points to approach).

🖼️Diagram

On [a,b], continuity at endpoints uses only approach from within the interval.

🎯Key Concepts

  • 🎯Continuity claim should be: continuous at every point of its domain (especially for rational/trig quotients).
  • 🚪Endpoints of [a,b] use only the inside approach: right-limit at a, left-limit at b.
  • 🧩A point outside the domain is not a “discontinuity point”; continuity is not defined there.
  • 🧠For piecewise functions, check continuity mainly at joining points (and endpoints if the interval is closed).

🔎CHECKLIST: CONTINUITY ON (a,b) VS [a,b]

  • On (a,b): for every c in (a,b), require LHL = RHL = f(c).
  • On [a,b]: also require limx→a+f(x)=f(a) and limx→b−f(x)=f(b).
  • Do not use outside-approach limits (limx→a−, limx→b+) when the domain is only [a,b].
  • If the function is not defined at an endpoint, it cannot be continuous on the closed interval.

⚙️DOMAIN-RESTRICTION IDEA (EXAM TRAP-BUSTER)

  • Correct phrasing: “f is continuous at every point of its domain”, not “continuous everywhere”.
  • Example: f(x)=1/x is continuous for x≠0; continuity at 0 is not a valid question.
  • A function can be continuous on its domain even if its graph has a gap where it is undefined.

Answer:
Its domain excludes x=2 (denominator cannot be 0).

✓  Continuous on its domain ℝ-{2}; not continuous on [1,3] because it is not defined at x=2.

⭐Important Points

  • Continuity is a pointwise property: always start by stating the domain clearly.
  • For [a,b], endpoint tests are one-sided: at a use right-limit, at b use left-limit.
  • Writing “continuous everywhere” is wrong if the domain has exclusions; write “continuous on its domain”.
  • To be continuous on [a,b], the function must be defined at every x in [a,b].
  • Singleton domain {c}: automatically continuous (no approach from other domain points).

TOPIC3

PIECEWISE CONTINUITY TESTS

📖Definition & Introduction

  • For piecewise f(x), continuity at a joining point a requires LHL = RHL = f(a).
  • On an open interval where one formula applies, continuity usually follows from that formula (polynomial/linear etc.).
  • At non-joining points c, use the branch valid near c: limx→c f(x) = f(c) if that branch is continuous.
  • At each joining point, compute LHL using the left branch and RHL using the right branch.
  • If LHL ≠ RHL, the limit does not exist, so no choice of f(a) can make f continuous at a.
  • Continuity is checked only at points in the domain; if a point (like 0) is excluded, do not test continuity there.

🖼️Diagram

Only the joining point needs one-sided limits; inside each branch, use that branch’s continuity.


🎯Key Concepts

  • 🔀Split by cases: c<a, c>a, and c=a (the critical joining point).
  • ⬅️LHL at a: approach from left, use the left-side formula only.
  • ➡️RHL at a: approach from right, use the right-side formula only.
  • 🧷If LHL = RHL = L, then continuity needs f(a) = L (removable if f(a) mismatched).
  • ⛔If the domain excludes a point, continuity there is not a valid question.

🔎FAST TEST ALGORITHM (EXAM-FRIENDLY)

  • Step 1: Identify joining point(s) where the formula changes (typically a, b, …).
  • Step 2: For any c inside one region, apply the same formula near c ⇒ usually continuous there.
  • Step 3: At joining point a: compute LHL using left formula; compute RHL using right formula.
  • Step 4: If LHL ≠ RHL ⇒ discontinuous at a; setting f(a) cannot fix it.
  • Step 5: If LHL = RHL = L, then continuity needs f(a) defined and equal to L.

⚙️JOINING-POINT CASES (c<1, c>1, c=1 PATTERN)

  • Case 1: c<1 ⇒ use the x≤1 or x<1 branch; limits behave like that branch.
  • Case 2: c>1 ⇒ use the x>1 branch; limits behave like that branch.
  • Case 3: c=1 ⇒ compute LHL from left-branch expression, RHL from right-branch expression.
  • If LHL ≠ RHL, then limx→1 f(x) does not exist (real number).
  • If the domain excludes 0, then continuity at 0 is not tested; check continuity on each side separately.

STANDARD CONTINUOUS FUNCTIONS

📖Definition & Introduction

  • A function f is continuous at c (with c in the domain) if limx→c f(x) = f(c).
  • Equivalently: limx→c− f(x) and limx→c+ f(x) exist, are equal, and equal f(c).
  • Every polynomial p(x)=a0+a1x+…+anxn is continuous for all real x.
  • A rational function p(x)q(x) is continuous at all x where q(x)≠0 (i.e., on its domain).
  • For f(x)=1x, x=0 is not in the domain; as x→0+ the values grow without bound and as x→0− they decrease without bound (vertical asymptote x=0).
  • Greatest integer function f(x)=[x] is continuous at non-integers and discontinuous at every integer.

🖼️Diagram

Illustration: polynomial is smooth; 1/x has vertical asymptote at x=0; [x] has unit jumps at integers.

🎯Key Concepts

  • •Continuity is checked only at points where the function is defined.
  • •Constants and x are continuous everywhere; sums/products preserve continuity.
  • •If f,g are continuous at c and g(c)≠0, then fg is continuous at c.
  • •For 1x, one-sided limits at 0 are not real numbers (±∞ describes unbounded behaviour).
  • •For [x], at an integer n: LHL = n−1 and RHL = n (jump discontinuity).

🔎WHY THESE FAMILIES ARE CONTINUOUS (EXAM LOGIC)

  • Continuity at c requires: f(c) exists and LHL = RHL = f(c).
  • Sums, differences and products of functions continuous at c remain continuous at c.
  • Quotient fg is continuous at c if f,g are continuous at c and g(c)≠0.
  • Polynomial = finite sum of terms akxk; built using + and × ⇒ continuous on ℝ.
  • Rational = pq; continuous wherever q(x)≠0 (only on its domain).

⚙️TWO KEY DISCONTINUITY MODELS TO REMEMBER

  • Unbounded behaviour: for 1/x at 0, values blow up to +∞ from the right and to −∞ from the left; no real limit at 0.
  • Jump behaviour: for [x] at integer n, limx→n−[x]=n−1 and limx→n+[x]=n.
  • At non-integer c, [x] is constant in a neighbourhood of c ⇒ continuous at c.

ALGEBRA OF CONTINUITY

📖Definition & Introduction

  • Closure idea: if f and g are continuous at c, then combinations of them are also continuous at c (with domain conditions).
  • Sum rule: f+g is continuous at c.
  • Difference rule: f−g is continuous at c.
  • Product rule: f·g is continuous at c.
  • Quotient rule: fg is continuous at c only if g(c)≠0 (and the quotient is defined near c).
  • Key takeaway: limit laws ⇒ continuity laws because continuity means limx→cf(x)=f(c).

🖼️Diagram

Closure flow: continuity of f, g at c ⇒ continuity of algebraic combinations at c.

🎯Key Concepts

  • NoneClosure at a point: continuous + continuous ⇒ continuous (with denominator restriction).
  • NonePolynomials are continuous on ℝ; use them as building blocks.
  • NoneRational functions p(x)q(x) are continuous on their domain: q(x)≠0.
  • NoneReciprocal: if g is continuous at c and g(c)≠0, then 1g is continuous at c.
  • NoneScalar multiple: if λ∈ℝ and g is continuous at c, then λg is continuous at c.
  • NoneExam language: say "continuous on its domain", not "everywhere", for quotients/rationals.

🔎PROOF SKELETON (WHY THE RULES ARE TRUE)

  • Start with definition: f continuous at c means limx→cf(x)=f(c). Same for g.
  • Use limit laws: lim(f±g)=limf±limg and lim(fg)=(limf)(limg).
  • For quotient: lim fg = lim flim g needs limg≠0; continuity gives limg=g(c), so ensure g(c)≠0.
  • Then show: limit of the new function equals its value at c ⇒ continuity.

⚙️HOW TO APPLY IN QUESTIONS (FAST CHECKLIST)

  • Step 1: Identify known continuous pieces (polynomial, constant, |x|, sin x, cos x, etc.).
  • Step 2: Rewrite the target using +, −, ×, ÷ and scalar multiples (closure at a point).
  • Step 3: For any quotient/reciprocal, write the restriction: denominator ≠ 0 (and hence point must lie in the domain).
  • Step 4: Conclude precisely: "continuous at c" or "continuous on its domain".

CONTINUITY OF COMPOSITES

📖Definition & Introduction

  • Composite function: (f∘g)(x)=f(g(x)); it is defined only when Range(g) ⊆ Domain(f) (or at least g(c) ∈ Domain(f) for a point c).
  • Continuity at a point c: limx→cF(x)=F(c) (F must be defined at c).
  • Theorem (Composite continuity): If (f∘g) is defined at c, g is continuous at c, and f is continuous at g(c), then (f∘g) is continuous at c.
  • Typical use: name inner g and outer f, then apply the theorem.
  • For nested | |, treat the outer | | as f(t)=|t| and the inside as g(x).

🖼️Diagram

🎯Key Concepts

  • ✅Always state the domain condition: g(c) must lie in Domain(f) for (f∘g) at c.

  • ⚠️If f is not continuous at g(c) (or undefined there), continuity of g alone cannot make f∘g continuous at c.
  • 🔁Nested composition: apply the condition link-by-link (h at c, then g at h(c), then f at g(h(c))).

🔎THEOREM WITH DOMAIN CONDITIONS (EXAM VERSION)

  • Let F=(f∘g). For continuity at c, ensure c ∈ Domain(g) and g(c) ∈ Domain(f).
  • If g is continuous at c and f is continuous at g(c), then F is continuous at c.
  • If f is continuous everywhere on its domain, it is enough to check g(c) lies in that domain.
  • For triple composition f∘g∘h: need h continuous at c, g continuous at h(c), f continuous at g(h(c)).

⚙️HOW TO APPLY (FAST WORKING TEMPLATE)

  • Step 1: Identify outer f(t) and inner g(x); write F(x)=f(g(x)).
  • Step 2: State definition/domain: confirm g(c) ∈ Domain(f) (or globally Range(g) ⊆ Domain(f)).
  • Step 3: Quote continuity of building blocks and use algebra rules to justify continuity of g at c.
  • Step 4: Conclude by theorem: g continuous at c and f continuous at g(c) ⇒ F continuous at c.

DIFFERENTIABILITY CONCEPT

📖Definition & Introduction

  • Differentiable at x=c if f′(c) exists: f′(c) = lim h→0 f(c+h)−f(c)h
  • If the above limit exists (finite), it equals slope of the tangent at x=c.
  • Derivative function: f′(x) is defined by the same limit for each x where it exists.
  • One-sided derivatives: LHD = lim h→0− f(c+h)−f(c)h, RHD = lim h→0+ f(c+h)−f(c)h
  • Differentiable at c ⇔ LHD and RHD both exist and are equal.
  • Key theorem: Differentiable at c ⇒ continuous at c; but continuity alone may fail to give differentiability (sharp corner).

🖼️Diagram

At a sharp corner (like |x| at 0), left and right slopes differ ⇒ not differentiable.


🎯Key Concepts

  • 🧠Derivative is a limit of difference quotient; it may fail if the quotient approaches different values.
  • ↔️LHD = RHD is the checkpoint for differentiability at joining points in piecewise graphs.
  • 📌If f is differentiable at c, then lim x→c f(x) = f(c) automatically.
  • ⚠️f(x)=|x| is continuous at 0 but has a sharp corner, so not differentiable at 0.

🔎ONE-SIDED DERIVATIVES (EXAM CHECKLIST)

  • Compute LHD using points x<c (i.e., h→0−) and RHD using x>c (i.e., h→0+).
  • If LHD = RHD = finite number, then f is differentiable at c and equals that number.
  • If LHD ≠ RHD or either is ±∞ or does not exist, then f is not differentiable at c.
  • At endpoints of [a,b]: use only RHD at a and only LHD at b.

⚙️DIFFERENTIABLE ⇒ CONTINUOUS (CORE PROOF IDEA)

  • Start from definition: f′(c) = lim x→c f(x)−f(c)x−c exists.
  • Rewrite for x≠c: f(x)−f(c) = f(x)−f(c)x−c(x−c).
  • Take limit as x→c: LHS → lim(f(x)−f(c)), RHS → f′(c)·0 = 0.
  • Thus lim x→c f(x) = f(c) ⇒ continuity at c.

DERIVATIVE RULES

📖Definition & Introduction

  • Derivative gives the instantaneous rate of change: dydx for y=f(x).
  • Standard derivatives help differentiate basic functions directly (power, trig, etc.).
  • Algebra of derivatives lets you differentiate combinations: (sum/difference), (product), (quotient).
  • For quotient rule, derivative exists where denominator v(x)≠0 and derivative uses v2 in the denominator.
  • Brackets are essential: keep (u'v − uv') together to avoid sign errors.

🖼️Diagram

Safe workflow: identify u, v → choose rule → compute u', v' → assemble → check domain (esp. v≠0).

🎯Key Concepts

  • 🧠Write expression as u, v first; then apply the correct rule.
  • ➕Linearity: (u±v)' = u'±v' and (k·u)' = k·u' for constant k.
  • ✖️Product rule: differentiate one factor at a time; keep the other unchanged.
  • ➗Quotient rule: denominator is always v2; also require v≠0.
  • ⚠️Trig signs: (cos x)' = −sin x is a frequent trap.

🔎STANDARD DERIVATIVES (MUST-KNOW)

  • ddx(xn) = nxn−1 (real n; where defined).
  • ddx(sin x) = cos x
  • ddx(cos x) = −sin x
  • ddx(tan x) = sec2 x (defined when cos x≠0).
  • ddx(constant) = 0

⚙️ALGEBRA OF DERIVATIVES (RULES + CAUTIONS)

  • Sum/Difference: (u±v)' = u'±v' (differentiate term-wise).
  • Product (Leibnitz): (uv)' = u'v + uv' (two terms only, not u'v').
  • Quotient: ddx(uv) = u'v − uv'v2, with v≠0.
  • Always bracket numerator in quotient: (u'v − uv'); sign of uv' is negative.
  • After differentiating, state restriction from original function (e.g., v≠0, cos x≠0).

CHAIN RULE APPLICATIONS

📖Definition & Introduction

  • Chain rule: if y=v(t) and t=u(x), then dydx=dvdt·dtdx.
  • Used for composite functions: “function inside a function”, e.g. sin(x²), (2x+1)³.
  • Works because a small change in x changes the inner variable, which changes the outer value.
  • For three layers, multiply three derivatives: dwdx=dwds·dsdt·dtdx.
  • Final answer must be in terms of x (substitute back inner variables).

🖼️Diagram

Flow of variables in a composite: x → t → y; multiply derivatives along arrows.


🎯Key Concepts

  • 🧩Identify layers: outer( inner(x) ) before differentiating
  • ✖️Rule in words: differentiate outside and multiply by derivative of inside
  • 🧱For 3 layers: multiply derivatives of each layer, from outside to inside
  • ⚡Avoid expansion: (2x+1)100 is instant by chain rule, painful by expansion
  • 🎯Most common factor: inner derivative appears as a multiplier (e.g. 2x in sin(x2))

🔎HOW TO APPLY (2 LAYERS + 3 LAYERS)

  • Step 1: set inner variable: t=u(x).
  • Step 2: rewrite as outer: y=v(t).
  • Step 3: compute dydt and dtdx, then multiply.
  • For 3 layers: t=v(x), s=u(t), y=w(s) ⇒ multiply 3 derivatives.
  • Always substitute back to x at the end.

⚙️EXPAND VS CHAIN RULE (WHEN TO USE WHAT)

  • Expansion works for small powers: (2x+1)³; but still slower and error-prone.
  • Chain rule is the default for big powers and nested functions: sin(x²), eg(x), ln(g(x)).
  • Exam speed: spotting the inner function gives the derivative in one line.

IMPLICIT DIFFERENTIATION

📖Definition & Introduction

  • Implicit differentiation: differentiate both sides w.r.t. x while treating y as y(x).
  • Used when relation is given as F(x,y)=0 and solving explicitly for y is hard/unwanted.
  • Any term containing y needs chain rule: ddx[g(y)] = g'(y)dydx.
  • Products like xy need product rule: ddx(xy) = xdydx+y.
  • After differentiating, collect all dydx terms on one side and factor it out.
  • When you divide to isolate dydx, state the restriction that the divisor ≠ 0.

🖼️Diagram

  • ✖️Product rule trigger: any term like xy, xy2, etc.
  • 🚫Division step must carry domain restriction (denominator ≠ 0).
  • 🧊Constants (π, κ, 100, a, b) differentiate to 0.

🔎CORE RULES YOU USE INSIDE IMPLICIT DIFFERENTIATION

  • ddx(y) = dydx (not 1).
  • ddx(yn) = nyn−1dydx.
  • ddx(sin y) = cos y·dydx; ddx(cos y) = −sin y·dydx.
  • If u=xy, then dudx=xdydx+y (product rule).

EXPONENTIAL AND LOG FUNCTIONS

📖Definition & Introduction

  • Exponential: for b>0, b≠1, define f(x)=bx (real x).
  • For b>1, bx is strictly increasing; for 0<b<1, strictly decreasing.
  • Logarithm: logba=x ⇔ bx=a, with a>0, b>0, b≠1.
  • Natural base e≈2.71828… gives y=ex and lnx=logex.
  • Convention used in this sheet: log x means lnx unless a base is explicitly written. (If your exam uses log for base 10, replace accordingly.)
  • Exponential and logarithm are inverse functions: ln(ex)=x (all real x) and elnx=x (for x>0).

🖼️Diagram

🎯Key Concepts

  • 🧭Domain/Range: bx: domain ℝ, range (0,∞); logbx: domain (0,∞), range ℝ.
  • 🔁Inverse pair: y=bx ⇔ x=logby; graphs reflect in line y=x.
  • 📌Anchor points: b0=1, so curve passes (0,1); logb1=0, so log curve passes (1,0).
  • 🧱Asymptotes: bx has horizontal asymptote y=0; logbx has vertical asymptote x=0.
  • 🧮Change of base: logba = (logka)/(logkb) = (lna)/(lnb).
  • ⚡Derivatives (safe form): ddx(ex)=ex; ddx(ln x)=1x, x>0.

🔎DOMAIN, RANGE & MONOTONICITY (EXAM QUICK CHECK)

  • y=bx, b>1: domain ℝ, range (0,∞), increasing, passes (0,1).
  • y=bx, 0<b<1: domain ℝ, range (0,∞), decreasing, passes (0,1).
  • y=logbx, b>1: domain (0,∞), range ℝ, increasing, passes (1,0).
  • y=logbx, 0<b<1: domain (0,∞), range ℝ, decreasing, passes (1,0).
  • Inverse fact: if y=bx then x=logby (domain and range swap).

⚙️LOG LAWS (VALIDITY CONDITIONS MATTER)

  • Always require arguments positive: p>0, q>0, a>0; base b>0, b≠1.
  • Product: logb(pq)=logbp+logbq.
  • Quotient: logb(pq)=logbp−logbq.
  • Power: logb(pr)=rlogbp (needs p>0).
  • Change base: logba=(lna)/(lnb) ⇒ compute on calculator.

LOGARITHMIC DIFFERENTIATION

📖Definition & Introduction

  • A technique to differentiate functions where both base and exponent depend on x, e.g. y=[u(x)]v(x), by taking ln on both sides.
  • Use lny = v·lnu to convert a complicated power into a product, then differentiate implicitly.
  • Works cleanly when u(x)>0 so that lnu is defined (and y>0 for lny).
  • After differentiating, multiply by y to get dydx in terms of x only.
  • Special case gives exponential derivative: ddx(ax) = axlna for a>0, a≠1.

🖼️Diagram

Flow: power form → log → implicit derivative → multiply by y.


🎯Key Concepts

  • 🔁Key identity: ln(uv) = vlnu (requires u>0).
  • 🧷Implicit step: ddx(lny) = 1ydydx.
  • 🧩General result: dydx = y[vu'u + v'lnu].
  • 🚫Always state domain: u(x)>0 (for lnu); plus original function’s domain constraints.
  • ⚡Fast handling of forms like xsinx, (sinx)x, (xx)….

🔎CORE ALGORITHM (EXAM STEPS)

  • Let y = [u(x)]v(x); write domain: u(x)>0.
  • Take natural log: lny = vlnu.
  • Differentiate both sides w.r.t. x using product + chain rule.
  • Replace back y and simplify; final answer must be in terms of x only.

⚙️WHEN TO USE (HIGH-YIELD PATTERNS)

  • Variable base & exponent: xx, xsinx, (sinx)x, (f(x))g(x).
  • Products/quotients of many powers: y=(x+1)2(x−1)3… ⇒ take ln and expand into sums.
  • Exponential with constant base: ax is easiest via lny=xlna.

PARAMETRIC DIFFERENTIATION

📖Definition & Introduction

  • If x=f(t) and y=g(t), then dydx=dy/dtdx/dt wherever dx/dt≠0.
  • t (or θ) is a parameter: varying it traces the curve in the x-y plane.
  • Slope is the ratio of rates of change: how fast y changes per unit change in x along the same t.
  • If dx/dt=0 at some t, slope is infinite (vertical tangent) if dy/dt≠0.
  • Second derivative: d2ydx2=d/dt(dy/dx)dx/dt (again require dx/dt≠0).

🖼️Diagram

At the same parameter t, slope of tangent is dy/dtdx/dt.


🎯Key Concepts

  • 🔁Always differentiate x(t) and y(t) separately first.
  • ➗Then divide: slope = (rate in y) ÷ (rate in x).
  • ⛔Check dx/dt≠0 for finite slope; else look for vertical tangent.
  • 🧩Eliminate parameter only if needed; parametric form often simplifies differentiation.
  • 🧠For trig parametrisations, simplify slope using identities (sin2θ+cos2θ=1).

🔎STANDARD PARAMETRISATIONS (EXAM-FAVOURITES)

  • Circle radius a: x=acosθ, y=asinθ ⇒ dydx=−cotθ.
  • Parabola-like: x=at2, y=2at ⇒ dydx=1t; at t=0, dx/dt=0 but dy/dt=2a≠0 ⇒ vertical tangent.
  • Cycloid (generating circle radius a): x=a(θ+sinθ), y=a(1−cosθ).
  • Astroid: x=acos3θ, y=asin3θ ⇒ eliminates to x2/3+y2/3=a2/3.

⚙️HOW TO FIND TANGENT / NORMAL AT A PARAMETER VALUE

  • Compute point: (x0,y0)=(f(t0),g(t0)).
  • Compute slope m=dy/dtdx/dt at t0 (if finite).
  • Tangent: y−y0=m(x−x0); Normal slope = −1m when m≠0.
  • If dx/dt=0 and dy/dt≠0 ⇒ tangent is vertical: x=x0.
