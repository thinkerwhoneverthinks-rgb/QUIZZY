Ch-04 : Complex Numbers and Quadratic Equations

Introduction

In the real numbers, the equation x2 + 1 = 0 has no solution because it gives x2 = −1, and any real square is ≥ 0.
To solve quadratics ax2 + bx + c = 0 when the discriminant D = b2 − 4ac < 0, we must extend the real number system to include numbers whose square can be negative.

Complex Numbers

Define i by i = √(−1), so i2 = −1. Therefore i solves x2 + 1 = 0.
A complex number has the form a + ib, where a and b are real.
  • Examples: 2 + i3, (−1) + i√3, 14+i(115 ).
For z = a + ib:
  • Real part: Re(z) = a
  • Imaginary part: Im(z) = b
Example: if z = 2 + i5, then Re(z) = 2, Im(z) = 5.
Equality of complex numbers: If z1 = a + ib and z2 = c + id, then z1 = z2 ⇔ a = c and b = d.

Worked Example 1: Equating real and imaginary parts

Given: 4x + i(3x − y) = 3 + i(−6), where x, y are real. Match real parts + match imaginary parts:
  • Real parts: 4x = 3 ⟹ x=34
  • Imaginary parts: 3x − y = −6
Substitute x=34 into 3x − y = −6: 3(34)−y=−6 ⟹ 94−y=−6 ⟹ −y=−6−94=−334 ⟹ y=334.
⚠ If two complex numbers are equal: equate real with real and imaginary with imaginary (don’t cross-match).

Algebra of Complex Numbers

Addition of two complex numbers

Let z1 = a + ib, z2 = c + id z1 + z2 = (a + c) + i(b + d)
  • a, b, c, d are real numbers
  • i is the imaginary unit, i2 = −1
Example: (2 + i3) + (−6 + i5) = (2−6) + i(3+5) = −4 + i8
Properties of addition (for all complex numbers z, z1, z2, z3):
  • Closure: z1 + z2 is complex.
  • Commutative: z1 + z2 = z2 + z1.
  • Associative: (z1 + z2) + z3 = z1 + (z2 + z3).
  • Additive identity: 0 + i0 (written 0) so z + 0 = z.
  • Additive inverse: if z = a + ib then −z = −a + i(−b), and z + (−z) = 0.

Difference of two complex numbers

z1 − z2 = z1 + (−z2)
  • −z2 is the additive inverse of z2
  • (6 + 3i) − (2 − i) = (6 + 3i) + (−2 + i) = 4 + 4i
  • (2 − i) − (6 + 3i) = (2 − i) + (−6 − 3i) = −4 − 4i

Multiplication of two complex numbers

Let z1 = a + ib, z2 = c + id z1z2 = (ac − bd) + i(ad + bc)
  • a, b, c, d are real numbers
Example: (3 + i5)(2 + i6) = (3·2 − 5·6) + i(3·6 + 5·2) = −24 + i28
Properties of multiplication (no proofs):
  • Closure: z1z2 is complex.
  • Commutative: z1z2 = z2z1.
  • Associative: (z1z2)z3 = z1(z2z3).
  • Multiplicative identity: 1 + i0 (written 1) so z·1 = z.
  • Multiplicative inverse: for each non-zero z = a + ib, there is 1z such that z·(1z) = 1.
  • Distributive:
    • z1(z2 + z3) = z1z2 + z1z3
    • (z1 + z2)z3 = z1z3 + z2z3
Multiplicative inverse (explicit): For z = a + ib ≠ 0, 1z=aa2+b2−iba2+b2
  • a, b real; not both zero
  • a2+b2 is real and positive when z ≠ 0
Don’t leave the inverse as 1a+ib. In exams you must simplify to standard p + iq (use the conjugate or the explicit formula).

Division of two complex numbers

z1z2=z1⋅1z2,z2≠0
  • z1, z2 are complex numbers
Worked example (as in text): let z1 = 6 + 3i, z2 = 2 − i. Compute z1z2 by multiplying top & bottom by the conjugate of 2 − i, i.e. 2 + i: 6+3i2−i=(6+3i)(2+i)(2−i)(2+i)
  • Denominator: (2−i)(2+i) = 22 + 12 = 5
  • Numerator: (6+3i)(2+i) = 12 + 6i + 6i + 3i2 = 12 + 12i − 3 = 9 + 12i
So 6+3i2−i=9+12i5=95+125i
For division: always remove i from the denominator using the conjugate, and check z2 ≠ 0.

Powers of i

Using i2 = −1:
  • i3 = i2·i = (−1)i = −i
  • i4 = (i2)2 = (−1)2 = 1
  • i5 = i4·i = 1·i = i
  • i6 = i4·i2 = 1·(−1) = −1
Negative powers (examples from text):
  • i−1=1i=1i⋅ii=ii2=i−1=−i
  • i−2=1i2=1−1=−1
  • i−3=1i3=1−i=i
  • i−4=1i4=11=1
General cycle: for any integer k,
  • i4k = 1
  • i4k+1 = i
  • i4k+2 = −1
  • i4k+3 = −i
  • k can be any integer (positive, negative, or 0)

The square roots of a negative real number

Since i2 = −1 and (−i)2 = (−1)2i2 = −1, the square roots of −1 are i and −i.
Convention: √(−1) means i only (not both roots).
Example: square roots of −3:
  • (√3 i)2 = 3i2 = −3
  • (−√3 i)2 = (−1)2·3·i2 = −3
So the square roots of −3 are √3 i and −√3 i, while √(−3) means √3 i only.
For a positive real number a: √(−a) = √(−1)·√a = i√a
  • a is positive real
Caution: multiplying square roots We know √a · √b = √(ab) for positive real a, b. This is still true when exactly one of a, b is negative (a>0, b<0 or a<0, b>0). But if a<0 and b<0, then (in general): √a · √b ≠ √(ab)
Reason (contradiction from text): If we (wrongly) assume √a · √b = √(ab) for all reals, then √(−1) · √(−1) = √((−1)(−1)) = √1 = 1 But √(−1) = i, so LHS = i·i = i2 = −1. Contradiction.
If a = 0 or b = 0, then √a · √b = √(ab) = 0.
Common exam mistake: √(−1)√(−1) → √1. Wrong. Correct: i·i = −1.

Identities

Square of a sum (works for all complex z1, z2): (z1 + z2)2 = z12 + 2z1z2 + z22
  • z1, z2 are complex
Proof idea (as in text: distributive + commutative): (z1 + z2)2 = (z1 + z2)(z1 + z2)
  • Distribute: (z1 + z2)z1 + (z1 + z2)z2
  • Distribute again: z12 + z2z1 + z1z2 + z22
  • Commutative mult.: z2z1 = z1z2
  • Collect terms: z12 + 2z1z2 + z22
Other identities (also for all complex numbers):
  • (z1 − z2)2 = z12 − 2z1z2 + z22
  • (z1 + z2)3 = z13 + 3z12z2 + 3z1z22 + z23
  • (z1 − z2)3 = z13 − 3z12z2 + 3z1z22 − z23
  • (z1 − z2)(z1 + z2) = z12 − z22
Most real-number algebra identities still work for complex numbers because the same laws (commutative, associative, distributive) hold.

Worked Example 2: Express in the form a + bi

(i) Express (15−8i) in a + bi form. Key step: 1i=−i (since i·(−i)=1). 15−8i=15−8(1i)=15−8(−i)=15+8i So a=15,b=8. (ii) Express (2−i)(38−18i) in a + bi form. First simplify 18i:
  • 18i=18⋅1i=18(−i)=−i8
So the second bracket is: 38−18i=38−(−i8)=38+i8=3+i8 Now multiply: (2−i)3+i8=18(2−i)(3+i) Compute (2 − i)(3+i):
  • (2 − i)(3+i) = 6 + 2i − 3i − i2 = 6 − i + 1 = 7 − i
Hence: 18(7−i)=78−18i
To get a + bi: kill i in denominators using 1i=−i (or multiply by ii), then simplify fully.

Expanding and Simplifying Powers/Fractions of Complex Numbers (Worked Examples)

Example 3: Express (5−3i)3 in the form a+ib

Use binomial: (a−b)3=a3−3a2b+3ab2−b3, with a=5, b=3i. (5−3i)3=53−3⋅52(3i)+3⋅5(3i)2−(3i)3 Work term-by-term:
  • 53=125
  • −3⋅52(3i)=−3⋅25⋅3i=−225i
  • (3i)2=9i2=9(−1)=−9 so 3⋅5(3i)2=15(−9)=−135
  • (3i)3=27i3=27(−i)=−27i, so −(3i)3=−(−27i)=+27i
So: 125−225i−135+27i=(125−135)+(−225+27)i=−10−198i.
Simplifying powers of i: i2=−1, i3=−i, i4=1. Reduce any higher power using these.

Example 4: Express (32−23i)(23−2i) in the form a+ib

Multiply like normal binomials + use i2=−1. Safe method: expand fully, then collect real + i parts.
  • Multiply the real parts and the i-parts carefully.
  • Any (⋅i)(⋅i) gives an i2=−1 term → becomes real.
  • Finish as (real)+i(real).
In multiplying complex numbers, the main sign “flip” happens only when i2 shows up (since i2=−1). Most mistakes come from missing this.

Modulus and Conjugate of a Complex Number

Definitions

Let z=a+ib where a,b∈ℝ.
  • Modulus |z|: the non-negative real number a2+b2.
  • Conjugate z¯: z¯=a−ib.
|z|=a2+b2 z=a+ib a= real part of z b= imaginary coefficient of z
z¯=a−ib z=a+ib z¯= change the sign of the imaginary part

Examples of modulus and conjugate

Modulus examples:
  • |3+i|=32+12=10
  • |5−2i|=52+(−2)2=29
Conjugate examples:
  • 3+i¯=3−i
  • 5−2i¯=5+2i
  • −5+3i¯=−5−3i (only the i-part sign changes)

Multiplicative Inverse of a Complex Number

Derivation and standard form

For non-zero z=a+ib, the multiplicative inverse is: z−1=1a+ib. Multiply top + bottom by the conjugate a−ib: 1a+ib=1a+ib⋅a−iba−ib=a−iba2+b2.
z−1=1a+ib=a−iba2+b2=z¯|z|2, for z≠0 z=a+ib z¯=a−ib |z|2=a2+b2
a2+b2 is always real and ≥0, and it’s 0 only if a=b=0 (so z=0). Inverse exists exactly when z≠0.

Properties involving conjugate

For any complex numbers z1,z2:
(i) z1z2¯=z1¯z2¯ z1,z2= complex numbers
(ii) (z1z2)¯=z1¯z2¯, provided z2≠0 z2≠0 ensures division is defined
(iii) |z1z2|=|z1||z2| |⋅|= modulus
(iv) (z1±z2)¯=z1¯±z2¯ ± means both plus and minus cases work
(v) |z1z2|=|z1||z2|, provided z2≠0 z2≠0 ensures division is defined
Don’t mix up z¯ and |z|: z¯ is a complex number; |z| is a non-negative real number.

Example 5: Find the multiplicative inverse of 2−3i

Let z=2−3i. Then z¯=2+3i and |z|2=22+(−3)2=4+9=13. So: z−1=z¯|z|2=2+3i13=213+313i. Equivalent working (rationalising the denominator): 12−3i=12−3i⋅2+3i2+3i=2+3i(2)2+(3)2=2+3i13.

Example 6: Express in the form a+ib

(i) 5+2i1−2i

Multiply top + bottom by conjugate of denominator (1+2i): 5+2i1−2i⋅1+2i1+2i=(5+2i)(1+2i)(1−2i)(1+2i).
  • Denominator: (1−2i)(1+2i)=1−(2i)2=1−4i2=1+4=5.
  • Numerator: (5+2i)(1+2i)=5+10i+2i+4i2=5+12i−4=1+12i.
Hence 5+2i1−2i=1+12i5=15+125i.

(ii) i−35

Powers of i cycle every 4 since i4=1. Reduce the exponent mod 4. −35≡1(mod4) because −35=−36+1 and i−36=(i4)−9=1. So i−35=i−36⋅i1=1⋅i=i.
For any integer k: i4k=1,i4k+1=i,i4k+2=−1,i4k+3=−i k= any integer

Argand Plane and Polar Representation (Geometric Meaning)

Complex number as a point in a plane

x+iy↔(x,y), i.e. point P(x,y) on a plane. This plane is the complex plane / Argand plane.
Examples (complex number ↔ point):
  • 2+4i↔(2,4)
  • −2+3i↔(−2,3)
  • 0+1i↔(0,1)
  • 2+0i↔(2,0)
  • −5−2i↔(−5,−2)
  • 1−2i↔(1,−2)

Real axis, imaginary axis, and modulus as distance

In the Argand plane:
  • Points on the x-axis ↔ a+i0 (purely real).
  • Points on the y-axis ↔ 0+ib (purely imaginary).
  • x-axis = real axis; y-axis = imaginary axis.
If z=x+iy is point P(x,y), then |z|=x2+y2 is the distance OP from O(0,0) to P.

Geometric meaning of conjugate

If z=x+iy is point P(x,y), then z¯=x−iy is point Q(x,−y).
(x,−y) is the mirror image of (x,y) in the real axis ⇒ z¯ is z reflected across the real axis on the Argand plane.

Miscellaneous Worked Examples

Example 7: Conjugate of (3−2i)(2−3i)(1−2i)(2−i)

Step 1: simplify the whole complex number into a+ib. Step 2: take conjugate by flipping the sign of the i-part. Textbook simplification: (3−2i)(2−3i)(1−2i)(2−i)=6325−1625i. So the conjugate is: (6325−1625i)¯=6325+1625i.
⚠ Conjugate AFTER simplifying: if w=a+ib, then w¯=a−ib. Don’t conjugate top/bottom separately unless you’re using (z1z2)¯=z1¯z2¯.

Example 8: If x+iy=a+iba−ib, prove x2+y2=1

Start + rationalise (multiply by conjugate of the denominator): x+iy=a+iba−ib⋅a+iba+ib=(a+ib)2a2+b2. Expand: (a+ib)2=a2+2abi+(ib)2=a2−b2+2abi. So split into real + imaginary parts: x+iy=a2−b2a2+b2+i⋅2aba2+b2. Hence:
  • x=a2−b2a2+b2
  • y=2aba2+b2
Now compute x2+y2: x2+y2=(a2−b2)2+(2ab)2(a2+b2)2=a4−2a2b2+b4+4a2b2(a2+b2)2=a4+2a2b2+b4(a2+b2)2=(a2+b2)2(a2+b2)2=1.
Key identity: (x+iy)(x−iy)=x2+y2. Use it to turn a complex expression into something purely real.

Historical Note (Complex Numbers)

Early issue: negative doesn’t exist in ℝ. Mahavira (850) clearly said a negative quantity has no square root; Bhaskara (1150) also noted there’s no square root of a negative quantity. Cardan (1545), solving x+y=10, xy=40, got x=5+−15, y=5−−15, but rejected them as “useless”. Albert Girard (about 1625) accepted square roots of negatives, saying this gives as many roots as the degree of a polynomial. Euler introduced the symbol i for −1. W. R. Hamilton (about 1830) defined a+ib as an ordered pair (a,b), giving a fully mathematical foundation.
