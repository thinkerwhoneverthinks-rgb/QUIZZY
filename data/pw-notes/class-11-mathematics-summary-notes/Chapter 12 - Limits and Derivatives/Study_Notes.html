Ch-12 : Limits and Derivatives

12.1 Introduction

Calculus = branch of maths mainly about the study of change in a function’s value as inputs (domain points) change.
This part of the chapter builds the main ideas in this order:
  • Intuitive idea of derivative (before the formal definition).
  • Naive idea of limit + basic limit sense (incl. one-sided limits).
  • Later portions (not included here) come back to derivative definition + rules/standard derivatives.

12.2 Intuitive Idea of Derivatives

Distance fallen as a function of time

A body dropped from a tall cliff falls distance (metres) given by:
s = 4.9t2 s = distance fallen (m) t = time elapsed (s)

Instantaneous velocity and derivative (informal meaning)

The left-approach and right-approach average velocities should (physically) head to the same limit. That shared limiting value is the instantaneous velocity at t = 2.
From the data:
  • Left-side averages near t = 2: about 19.551 m/s.
  • Right-side averages near t = 2: about 19.649 m/s.
So instantaneous velocity at t = 2 is estimated between 19.551 m/s and 19.649 m/s.
Velocity = rate of change of displacement (distance) w.r.t. time. So “instantaneous velocity at a time” = “instantaneous rate of change of the distance function” at that time.

Geometric interpretation: slope of tangent

On a graph of s vs t: as the time interval → 0, the average-velocity ratios → the slope of the tangent at the point.
So the instantaneous velocity v(t) at t = 2 equals the slope of the tangent to s = 4.9t2 at t = 2.
Exam tip: Don’t mix up average velocity (slope of a secant over an interval) with instantaneous velocity (slope of the tangent at a point, found as a limit as the interval → 0).

12.3 Limits

Why limits are needed

The derivative idea depends on a limiting process (make the time interval shrink to 0). So we need a clear idea of limits.

Intuitive meaning of a limit

If, as x → a, the values of f(x) get closer and closer to a number l, then l is the limit of f(x) as x tends to a.
limx→a f(x) = l x → a: x takes values very close to a (not necessarily equal to a) l: the value that f(x) approaches
Think of limx→a f(x) as the value f(x) should be at x = a, judging from values of f near a (even if f(a) is undefined or different).

Illustrations of limits from graphs/values

1) f(x) = x2
  • When x is close to 0, f(x) = x2 is close to 0.
limx→0 f(x) = 0 (for f(x) = x2) 0: value approached by x2 as x approaches 0
2) g(x) = |x|, x ≠ 0
  • g(0) is not defined (function only given for x ≠ 0).
  • But if x is near 0, then |x| is near 0.
limx→0 g(x) = 0 (for g(x) = |x|, x ≠ 0) g(x) = |x| for x not equal to 0
3)h(x)=(x2−4)(x−2),x≠2
  • h(2) is not defined (division by 0 if x = 2).
  • For x extremely close to 2 (but not 2), the values come out close to 4.
  • The graph shows the y-values heading towards 4 as x → 2.
Exam tip: A limit can exist even if the function value at that point is not defined (like g at 0, and h at 2).

One-sided limits: left-hand and right-hand limits

x can approach a number a in two different ways:
  • From the left (x near a but less than a).
  • From the right (x near a but greater than a).
Left-hand limit of f at a: the value suggested by f(x) as x → a from the left. Right-hand limit of f at a: the value suggested by f(x) as x → a from the right.
Left-hand limit: limx→a− f(x) a−: x approaches a using values with x < a
Right-hand limit: limx→a+ f(x) a+: x approaches a using values with x > a

Example showing limits may fail to exist

Piecewise function:
f(x) = 1, for x ≤ 0 f(x) = 2, for x > 0 x: input variable
From the definition/graph:
  • As x → 0 from the left (x ≤ 0), values stay at 1.
  • As x → 0 from the right (x > 0), values stay at 2.
limx→0− f(x) = 1 limx→0+ f(x) = 2
If the left-hand limit and right-hand limit are different, then the (two-sided) limit does not exist there — even if the function is defined at that point.

Summary: existence of limit via one-sided limits

  • limx→a− f(x): “expected” f-value at x = a using values of f near a on the left.
  • limx→a+ f(x): “expected” f-value at x = a using values of f near a on the right.
  • If limx→a− f(x) = limx→a+ f(x), that common value is the two-sided limit limx→a f(x).
Common mistake: Thinking a limit exists just because f(a) exists. Always check both left + right behaviour near a.

Illustration 1: Limit of a linear function near a point (setup)

Let f(x) = x + 10. Find the limit at x = 5.
  • Work out f(x) for x very close to 5.
  • Examples just left of 5: 4.9, 4.95, 4.99, 4.995, …
  • Also pick x slightly bigger than 5 (e.g. 5.001, …) and compare.
This is showing: for a simple function like x + 10, the values near x = 5 point to a single clear “expected value” at 5 (the limit), and it matches from both left and right.

Numerical and Graphical Approach to Limits (Illustrations)

To estimate a limit numerically: plug in x-values close to the target a and watch what f(x) does.
  • Approach from the left (x < a) → estimate limx→a− f(x)
  • Approach from the right (x > a) → estimate limx→a+ f(x)
If left-hand and right-hand limits match, then the two-sided limit limx→a f(x) should exist and equal that common value.
For many “nice” functions, limx→a f(x) = f(a). But not always:
  • The limit can fail to exist even if f(a) is defined.
  • The limit can exist even if f(a) is defined as a different value.

12.3.1 Algebra of Limits

At a point a, the function value f(a) and the limit limx→a f(x) can be different — even if both exist.

Theorem 1 (Limit Laws / Algebra of Limits)

Laws below work only if the stated limits exist. They let you do limits by substitution + algebra in many cases.
(i) Sum law: limx→a[f(x)+g(x)] = limx→af(x) + limx→ag(x) (ii) Difference law: limx→a[f(x)−g(x)] = limx→af(x) − limx→ag(x) (iii) Product law: limx→a[f(x)·g(x)] = (limx→af(x))·(limx→ag(x)) (iv)Quotientlaw:limx→af(x)g(x)=(limx→af(x))(limx→ag(x)),providedlimx→ag(x)≠0Symbols: f, g = functions; a = real number; x→a means x approaches a.

Special case: constant multiple

If g(x)=λ (constant), then limx→a[λ·f(x)] = λ·limx→af(x) Symbols: λ = real constant; f = function with an existing limit at a.
Quotientlawworksonlyifthedenominator’slimit≠0.Ifsubstitutiongivesdenominatorlimit0,youmustgofurther(factorisecancel,orshowthelimitdoesn’texist).

12.3.2 Limits of Polynomials and Rational Functions

Polynomial functions: definition and limit

A polynomial of degree n: f(x)=a0 + a1x + a2x2 + … + anxn, where ai are real, an ≠ 0, and n ∈ ℕ.
Basic limit: limx→a x = a. Using product law repeatedly: limx→a xn = an for n ∈ ℕ (by induction).
Power limit (natural n): limx→a xn = an Symbols: n = positive integer; a = real number.
Polynomial limit = polynomial value: limx→a f(x) = f(a). Why: use sum law (split terms) + constant multiple law (pull coefficients) + power limit (xk).

Rational functions: definition and limit rules

Arationalfunction:f(x)=g(x)h(x),whereg(x),h(x)arepolynomialsandh(x)≠0(forxinthedomain).
If h(a) ≠ 0, then substitution is fine: limx→af(x)=g(a)h(a).
Ifx=agives00,don’tdecidethelimityet.Factorise,cancelonlycommonfactors,thentakethelimit.

When h(a)=0: scenarios and factor-power comparison

If h(a)=0, two cases:
  • (i) g(a) ≠ 0: limit does not exist (in this text’s approach).
  • (ii) g(a) = 0: pull out highest powers of (x−a) top and bottom, then compare.
When g(a)=0 and h(a)=0, write: g(x)=(x−a)k g1(x), where k is the max power of (x−a) dividing g(x). h(x)=(x−a)l h1(x), where l is the max power of (x−a) dividing h(x).
  • If k > l: after cancelling, (x−a)k−l stays in numerator ⇒ limx→a f(x) = 0.
  • If k < l: limit not defined (denominator → 0 faster).

All are polynomials ⇒ limit = value at the point.
(i) limx→1 [x3 − x2 + 1] = 13 − 12 + 1 = 1 (ii) limx→1 (x + x3) = 1 + 1 = 2 (text shows by evaluating at 1) (iii) limx→−1 [1 + x + x2 + … + x10] Put x=−1: 1 − 1 + 1 − 1 + … + 1 (11 alternating terms). Cancel in pairs ⇒ leftover 1, so limit = 1.

12.4 Limits of Trigonometric Functions

Theorem 3 (Order preservation under limits)

If f and g are real-valued, same domain, and for every x in the domain: f(x) ≤ g(x) and both limits exist: limx→a f(x), limx→a g(x), then: limx→a f(x) ≤ limx→a g(x)

Theorem 4 (Sandwich Theorem / Squeeze Theorem)

If real functions f, g, h satisfy (common domain): f(x) ≤ g(x) ≤ h(x) and for some real a: limx→a f(x) = l = limx→a h(x) then: limx→a g(x) = l

Key trigonometric inequality (geometric result)

For 0 < x < π/2: (sinx)x<(cosx)<1Symbols: x in radians; sin x, cos x are trig functions.
This inequality is the launchpad for the standard trig limits (usually via the Sandwich Theorem) later on.

Important Trigonometric Inequality Leading to Standard Limits

Reduction to the case 0<x<π2

Use parity:
  • sin(−x)=−sinx (odd)
  • cos(−x)=cosx (even)
So for “small-angle” inequalities, it’s enough to prove them for: 0<x<π2

Geometric set-up on the unit circle and area comparison

Take a unit circle with centre O, radius OA=1. Let ∠AOC=x radians where 0<x<π2.
  • Draw perpendiculars BA⊥OA and CD⊥OA (as in the figure).
  • Join A to C.
  • Compare areas: △OAC, sector OAC, and △OAB.
Area squeeze: Area(△OAC)<Area(sector OAC)<Area(△OAB) This is where sinx<x<tanx comes from (for 0<x<π2).

Deriving sinx<x<tanx

Area formulas:
  • Area(△OAC)=12OA⋅CD
  • Area(sector OAC)=x2⋅(OA)2 (radians)
  • Area(△OAB)=12OA⋅AB
So: 12OA⋅CD<x2(OA)2<12OA⋅AB Multiply by 2, divide by positive OA: CD<x⋅OA<AB Link to trig ratios:
  • From △OCD, and OC=OA (radii): sinx=CDOA⇒CD=OAsinx
  • tanx=ABOA⇒AB=OAtanx
Sub in: OAsinx<OA⋅x<OAtanx Since OA>0:
sinx<x<tanxfor 0<x<π2 x: radians

Converting to the “sandwich” inequality for sinxx

For 0<x<π2, sinx>0. Divide sinx<x<tanx by sinx: 1<xsinx<tanxsinx=1cosx Reciprocals (all positive) flip the signs:
cosx<sinxx<1for 0<x<π2 x: radians
Reciprocals reverse inequalities only if everything is positive. Here: 0<x<π2⇒sinx,cosx,x>0.

Theorem 5: Two Fundamental Trigonometric Limits

(i) limx→0sinxx=1

limx→0sinxx=1 x: radians
From (for 0<x<π2): cosx<sinxx<1 As x→0, cosx→1. So sinxx is squeezed between two things → 1.
Sandwich Theorem reminder: If g(x)≤f(x)≤h(x) near a and limx→ag(x)=limx→ah(x)=L, then limx→af(x)=L.

(ii) limx→01−cosxx=0

limx→01−cosxx=0 x: radians
Use:
1−cosx=2sin2(x2) x: radians
Then: limx→01−cosxx=limx→02sin2(x2)x Rewrite using limu→0sinuu=1:
  • 2sin2(x2)x=(sin(x2)x2)⋅sin(x2)
As x→0, also x2→0, so:
  • sin(x2)x2→1
  • sin(x2)→0
Product → 1⋅0=0.
Hidden step: “x→0” ⇔ “x2→0”. Let y=x2; then x→0⇔y→0.

General Rule for Evaluating Limits of the Form limx→af(x)g(x)

For limx→af(x)g(x) (assume it exists): start by plugging in x=a: check f(a), g(a).
  • If f(a)=0 and g(a)=0 (indeterminate 00): factor out the vanishing factors.
  • Write f(x)=f1(x)f2(x) with f1(a)=0, f2(a)≠0.
  • Write g(x)=g1(x)g2(x) with g1(a)=0, g2(a)≠0.
  • Cancel common factors (if possible) to get f(x)g(x)=p(x)q(x) with q(x)≠0 near a.
If f(x)g(x)=p(x)q(x) after cancelling and q(a)≠0, then limx→af(x)g(x)=p(a)q(a) f,g: original functions; p,q: after cancelling common factors
Only cancel factors, never “terms in a sum”. Factor fully first, then cancel.

12.5 Derivatives

Motivation: rate of change in real-life contexts

Often we need the rate of change: how one quantity changes w.r.t. another.
  • Motion: velocity from position vs time
  • Reservoir management: predict overflow from depth vs time
  • Rocket science: velocity needed from height vs time data
  • Finance: change in stock value over time
Main tool: the derivative of a function at a point.

Definition of derivative at a point (first principles)

f′(a)=limh→0f(a+h)−f(a)h, provided the limit exists. f: real-valued function a: point in the domain of f h: small change in input (x), with h→0 f′(a): derivative of f at a
f′(a) tells how f(x) changes at x=a w.r.t. x → the instantaneous rate of change at a.

Example 5: Derivative of f(x)=3x at x=2

Using first principles: f′(2)=limh→0f(2+h)−f(2)h f(2+h)=3(2+h)=6+3h, and f(2)=6. So: f′(2)=limh→0(6+3h)−6h=limh→03hh=limh→03=3
The derivative of 3x at x=2 is 3.

Example 6: Derivative of f(x)=2x2+3x−5 at x=−1, and verify f′(0)+3f′(−1)=0

Step 1: Compute f′(−1) from first principles

f′(−1)=limh→0f(−1+h)−f(−1)h
  • f(−1+h)=2(−1+h)2+3(−1+h)−5
  • (−1+h)2=1−2h+h2

  • f(−1)=2(1)+3(−1)−5=2−3−5=−6
Then: f(−1+h)−f(−1)=(2−4h+2h2−3+3h−5)−(−6) =(2−3−5+6)+(−4h+3h)+2h2=0−h+2h2 So: f′(−1)=limh→0−h+2h2h=limh→0(−1+2h)=−1

Step 2: Compute f′(0) from first principles

f′(0)=limh→0f(0+h)−f(0)h=limh→0f(h)−f(0)h
  • f(h)=2h2+3h−5
  • f(0)=−5
So: f′(0)=limh→0(2h2+3h−5)−(−5)h=limh→02h2+3hh =limh→0(2h+3)=3

Step 3: Verify the given relation

f′(0)+3f′(−1)=3+3(−1)=3−3=0
Results: f′(−1)=−1, f′(0)=3, and f′(0)+3f′(−1)=0 ✓ verified.
Expand f(a+h) and simplify fully before subtracting f(a). Most mistakes = sign errors during subtraction.

Remark: Limits and derivative evaluation

Finding a derivative at a point is basically a limit question. Speed + accuracy come from using limit laws + standard limits correctly (next examples).

Geometric Interpretation of the Derivative (Tangent as Limit of Secants)

Let y=f(x). Take two points:
  • P=(a,f(a))
  • Q=(a+h,f(a+h)), with small h
Slope of the secant line PQ: f(a+h)−f(a)(a+h)−a=f(a+h)−f(a)h As h→0: secant → tangent at P, and slope → f′(a).
So f′(a) = slope of the tangent to y=f(x) at (a,f(a)).

Geometric meaning of the derivative (slope of tangent)

For y=f(x) and point P(a,f(a)) on the curve, the derivative at x=a is f′(a)=limh→0f(a+h)−f(a)h.
Take the secant (chord) PQ, where Q(a+h,f(a+h)). In the triangle formed, QRPR=f(a+h)−f(a)h is the slope of chord PQ, i.e. tan(∠QPR). As h→0, we have Q→P, so chord PQ tends to the tangent at P. Hence the limit gives the tangent slope.
If ψ is the angle the tangent at P makes with the positive x-axis, then f′(a)=tanψ.

Derivative as a function (first principle) and notations

Definition (Derivative / First principle)

Let f be real-valued. Define f′(x)=limh→0f(x+h)−f(x)h wherever the limit exists. This new function is the derivative function of f. This definition is the first principle of derivative.
The domain of f′ = all x where the limit limh→0f(x+h)−f(x)h exists.

Standard notations for derivative

  • f′(x)
  • df(x)dx
  • If y=f(x), then dydx (derivative of y w.r.t. x)
  • D(f(x))
  • Derivative at x=a: f′(a) or (dfdx)x=a (same as value of the derivative function at a).

Power function derivative

Theorem 6: Derivative of xn (positive integer n)

ddx(xn)=nxn−1,foranypositiveintegernn: positive integer power x: variable

Start from the definition: f′(x)=limh→0[(x+h)n−xn]hBy binomial theorem: (x+h)n = xn + n xn−1h + ... + hn So (x+h)n − xn = h( n xn−1 + ... + hn−1) Divide by h and take the limit as h→0: f′(x) = limh→0 [n xn−1 + ... + hn−1] = n xn−1.

  • Basecase:n=1givesddx(x)=1.

Summary (Limits and Derivatives)

One-sided limits and limit at a point

Left-hand limit at a: the value we expect for f(x) as x → a from the left. Right-hand limit at a: the value we expect for f(x) as x → a from the right. Limit at a exists and equals L iff both one-sided limits exist and both = L.
limx→a f(x) and f(a) do not have to match. Either one might exist while the other doesn’t.

Algebra of limits

limx→a [f(x) ± g(x)] = limx→a f(x) ± limx→a g(x) limx→a [f(x)·g(x)] = (limx→a f(x))·(limx→a g(x)) limx→a[f(x)g(x)]=(limx→af(x))(limx→ag(x)),providedlimx→ag(x)≠0f, g = functions; a = real number
Quotient law condition is about lim of the denominator being non-zero (not just whether g(a) is non-zero).

Historical Development and Impact of Calculus

Key mathematicians and the rigorous foundation of calculus

A.L. Cauchy, J.L. Lagrange, and Karl Weierstrass are named as major contributors.
  • Cauchy: gave calculus the rigorous foundation used in modern textbooks.
  • The text links Cauchy’s work with contributions by Lagrange and Weierstrass (key names historically).

D’Alembert’s limit concept and Cauchy’s definition of derivative

Cauchy used D’Alembert’s limit concept to define the derivative: derivative = limit of a difference quotient.
Difference quotient (increment form) Δy=f(x+i)−f(x) Δy: change in the function value (increment in y) f(x): value of the function at x f(x+i): value after an increment i in the input x: independent variable i: increment in x (text uses i; many books use Δx or h)
Cauchy’s derivative idea (limit of the difference quotient) ΔyΔx=f(x+i)−f(x)i Δy: change in output Δx=i: change in input (increment) f: function x: point where the derivative is taken
Derivative (Cauchy’s “function dérivée”) f′(x)=y′=limi→0f(x+i)−f(x)i f′(x) or y′: derivative of f at x limi→0: limit as increment i → 0 f(x+i)−f(x): change in function value due to increment i i: increment in x approaching zero
Exam focus: derivative comes from limits (not “rules first”). Always this structure:
  • Take a small increment i in x
  • Build f(x+i)−f(x)i
  • Take the limit as i→0
Common confusion: here the increment is written as i. It’s not the imaginary unit—just a small change in x (often h or Δx).

Limit example used by Cauchy: limα→0sinαα

Cauchy started from the definition of a limit and used key examples, esp.: limα→0sinαα This matters because it supports derivatives of trig functions.
Must-know: the text specifically points to the limit sinαα at α=0 as a key example in building calculus via limits.

Changing perceptions: calculus teaching before and after 1900

  • Around 1900: shift in view — core ideas/methods are simple enough for schools.

John Perry (England, ~1900) (and others) pushed the idea that:

  • calculus can be taught in schools (not only for advanced learners).

F.L. Griffin and early university-level calculus teaching

F.L. Griffin pioneered teaching calculus to first-year students—seen as a very daring move at the time.
