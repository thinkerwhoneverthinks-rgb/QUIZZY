13.2 Measures of Dispersion

Dispersion/scatter depends on the observations and also on which central tendency is taken as reference. Measures listed:
  • Range
  • Quartile deviation
  • Mean deviation
  • Standard deviation
In this chapter we study all these except quartile deviation.

13.3 Range

Range = (maximum value) − (minimum value) in the dataset.
Range = Maximum value − Minimum value Maximum value = largest observation Minimum value = smallest observation

Range in the batsmen example

  • For batsman A: Range = 117 − 0 = 117
  • For batsman B: Range = 60 − 46 = 14
Since Range(A) > Range(B): A is more dispersed, B is more concentrated.
Limitation of range: only a rough idea of variability; it does not show how values spread around a central value.
So we need measures based on deviations from a central tendency, mainly:
  • Mean deviation
  • Standard deviation

13.4 Mean Deviation

Deviation of a value x from a fixed value a = x − a.
If we average (x − a) directly, + and − deviations cancel out. In particular, sum of deviations from the mean is 0, so mean deviation about mean becomes 0 and is not useful.
For deviations from the mean x̄:
  • Sum of deviations = 0
  • Meanofdeviations=(0n)=0
Mean deviation about a = the mean of absolute deviations from a fixed central value a. Absolute value = distance on number line → no cancellation.
Mean Deviation about a M.D.(a)=(Sumof|x−a|)(Numberofobservations)M.D.(a) = mean deviation about a x = observation a=chosencentralvalue(meanmedian,etc.)|x − a| = absolute deviation
Remark (from text): Mean deviation can be taken about any measure of central tendency, but commonly:
  • Mean deviation about mean
  • Mean deviation about median

13.4.1 Mean deviation for ungrouped data

Let n observations be: x1, x2, x3, …, xn.
Algorithm: mean deviation about a (mean/median), ungrouped
  1. Find the central value a (mean/median) required.
  2. Find deviations xi − a for each i.
  3. Convert to absolute deviations |xi − a| (ignore − sign).
  4. Average them: (1/n) Σ |xi − a|.
Mean deviation about a (ungrouped) M.D.(a)=(1n)Σ|xi−a|xi = i-th observation a = chosen central value n = number of observations
Mean deviation about mean M.D.(x̄)=(1n)Σ|xi−x̄|x̄ = mean xi = i-th observation n = number of observations
Mean deviation about median M.D.(M)=(1n)Σ|xi−M|M = median xi = i-th observation n = number of observations
Note (chapter notation): M means median unless stated otherwise.

To avoid lengthy arithmetic while finding x̄, use step-deviation.
  • Assumed mean (a): pick a value near the middle.
  • Common factor (h): if deviations have a common factor (usually class width), divide by it.
  • Why it helps: step-deviation = shift origin to a + change scale by h → smaller numbers.
Step-deviation variable: di=(xi−a)hxi=observationclassmid−pointa = assumed mean h = common factor (step size)
Mean (step-deviation): x̄=a+h×(∑fidi)NN = ∑ fi

Limitations of Mean Deviation

Why Mean Deviation may be Unsatisfactory

  • If variability is very high, the median may not represent the data well → M.D. about median may be less reliable.
  • Sum of deviations from the mean (ignoring minus signs) is greater than sum of deviations from the median → so M.D. about mean isn’t very scientific.
  • Uses absolute values → not suitable for further algebraic treatment (hard to use in advanced formulas).
So we need a better dispersion measure: standard deviation.

Variance and Standard Deviation

Motivation: Squaring Deviations Instead of Using Absolute Values

To stop + and − deviations from cancelling out (like in mean deviation), use squared deviations. Squares are always ≥ 0.
Let x1, x2, …, xn be observations and x̄ be the mean. Look at:
  • (x1−x̄)2 + (x2−x̄)2 + … + (xn−x̄)2 = Σ (xi−x̄)2
  • If Σ (xi−x̄)2 = 0 ⇒ each (xi−x̄)=0 ⇒ all observations equal ⇒ no dispersion.
  • If Σ (xi−x̄)2 is small ⇒ values close to mean ⇒ low dispersion.
  • If Σ (xi−x̄)2 is large ⇒ values far from mean ⇒ high dispersion.

Why “Sum of Squares” Alone is Not a Proper Dispersion Measure

Set A: 6 observations: 5, 15, 25, 35, 45, 55
  • Mean x̄ = 30
  • Σ (xi−x̄)2 = (5−30)2 + (15−30)2 + (25−30)2 + (35−30)2 + (45−30)2 + (55−30)2
  • = 625 + 225 + 25 + 25 + 225 + 625 = 1750
Set B: 31 observations: 15, 16, 17, …, 45
  • Mean ȳ = 30 (same mean as set A)
  • Σ (yi−ȳ)2 = (15−30)2 + (16−30)2 + … + (45−30)2
  • = (−15)2 + (−14)2 + … + (−1)2 + 02 + 12 + … + 142 + 152
  • = 2[152 + 142 + … + 12]
Sum of squares of first n natural numbers: 12+22+…+n2=n(n+1)(2n+1)6n = how many first natural numbers are being squared + added
Here n = 15, so:
  • 152+142+…+12=15×16×316
  • ThusΣ(yi−ȳ)2=2×(15×16×316)=5×16×31=2480
If we only use Σ(deviation)2, we’d say A has less dispersion than B (1750 < 2480) — but that’s wrong: set A is more spread (deviations −25 to 25) than set B (−15 to 15).

Fix: Use the Mean of Squares of Deviations ⇒ Variance

To remove the effect of “how many observations”, take the average of squared deviations:
  • ForsetA:(16)×1750=291.67
  • ForsetB:(131)×2480=80
Now it correctly shows set A has more dispersion than set B (matches the scatter/range idea).
Variance = mean of squared deviations from the mean. Symbol: σ2 (“sigma square”).
Variance (ungrouped, n observations): σ2=(1n)Σ(xi−x̄)2σ2 = variance n = number of observations xi = i-th observation x̄ = mean

Standard Deviation

Definition and Need

Variance is in squared units. To get a spread measure in the same unit as the data, take the positive square root of variance = standard deviation (σ).
Standard Deviation: σ=(1n)Σ(xi−x̄)2σ = standard deviation n = number of observations xi = i-th observation x̄ = mean
SD is always the positive square root of variance.

For a continuous (grouped) frequency distribution, swap each class interval for its mid-point xi. Then treat the data as a discrete frequency distribution with frequencies fi.

13.5.4 Shortcut method to find variance and standard deviation (Step-deviation method)

Why the shortcut is used

If xi values (or class mid-points) are big, direct mean/variance gets long. The step-deviation method makes arithmetic easier by using an assumed mean + scaling by class width (or another handy factor).

Definitions: assumed mean, scale, step-deviations

Step-deviation transformation  ... (1): yi=(xi−A)horxi=A+hyiA = assumed mean (pick near centre) h = scaling factor (usually class width for grouped data) yi = step-deviation (no units)

Mean in step-deviation form

Mean (step-deviation method)  ... (3): x̄=A+hȳ,whereȳ=(1N)∑fiyix̄ = mean of x ȳ = mean of y values (with frequencies) N = ∑fi
Thiscomesfromsubstitutingxi=A+hyiintox̄=(1N)∑fixi,thensimplifyingusingN=∑fi.

Variance and standard deviation under scaling

If a variable is scaled by h: variance scales by h², and standard deviation scales by |h|.
Relationship between variances  ... (4): σx² = h² σy² σx = h σy (h taken positive as class width) σx, σy = standard deviations of x and y

Shortcut formula for standard deviation (step-deviation)

Standard deviation using step-deviations  ... (5): σ=h(1N)∑fiyi2−((1N)∑fiyi)2h=classwidthscalingfactorN = ∑fi yi=(xi−A)h
Choose A and h so yi becomes small integers (like −3, −2, −1, 0, 1, 2, 3). That’s the whole point.

Example 13: Effect on variance when each observation is multiplied by 2

Scaling rule: if every observation is multiplied by k, then:
  • New mean = k × old mean
  • New variance = k² × old variance
  • New standard deviation = |k| × old standard deviation
Given: n = 20 observations, variance σ² = 5.
Let observations be x1, x2, …, x20 with mean x̄. Then:
σ2=(120)∑(xi−x̄)2=5So ∑(xi − x̄)² = 20 × 5 = 100   ... (1)
If each observation is multiplied by 2, new observations are yi = 2xi. Then new mean is ȳ = 2x̄ and:
Newvarianceσy2=(120)∑(yi−ȳ)2But yi − ȳ = 2xi − 2x̄ = 2(xi − x̄) So (yi − ȳ)² = 4(xi − x̄)² Henceσy2=(120)∑4(xi−x̄)2=4(120)∑(xi−x̄)2=4σ2
Therefore, new variance = 4 × 5 = 20.
Don’t multiply variance by 2 when data are multiplied by 2. Variance scales with the square of the multiplier.

Multiply every data value by a constant k ⟹ variance gets multiplied by k².
Original: xi, mean x̄, variance σ² New: yi = kxi ȳ = kx̄ σy² = k²σ² k = constant multiplier x̄,ȳ=oldnewmeansσ2,σy2=oldnewvariances
Scaling changes spread quadratically: double all values ⟹ variance becomes 4×.

Example 14: Finding Missing Observations Using Mean and Variance

Given

  • Number of observations n = 5
  • Mean x̄ = 4.4
  • Variance σ² = 8.24
  • Known observations: 1, 2, 6
  • Unknown observations: x, y

x̄=(∑xi)n∑xi = sum of all observations n = number of observations
Data: 1, 2, 6, x, y Mean condition: 4.4=(1+2+6+x+y)5So, 22 = 9 + x + y ⇒ x + y = 13 … (1)

Step 2: Use the Variance

σ2=(1n)∑(xi−x̄)2σ² = variance xi = observations x̄ = mean n = number of observations
Given σ² = 8.24 and x̄ = 4.4: 8.24=(15)[(1−4.4)2+(2−4.4)2+(6−4.4)2+(x−4.4)2+(y−4.4)2]Multiply by 5: 41.20 = (−3.4)² + (−2.4)² + (1.6)² + (x−4.4)² + (y−4.4)² Known squares:
  • (−3.4)² = 11.56
  • (−2.4)² = 5.76
  • (1.6)² = 2.56

Step 3: Expand and Simplify

(x−4.4)² = x² − 8.8x + 19.36 (y−4.4)² = y² − 8.8y + 19.36 Add: (x−4.4)² + (y−4.4)² = x² + y² − 8.8(x+y) + 38.72 Sub into variance equation: 41.20 = 11.56 + 5.76 + 2.56 + x² + y² − 8.8(x+y) + 38.72 Use (1): x + y = 13: 41.20 = (11.56+5.76+2.56) + x² + y² − 8.8×13 + 38.72 41.20 = 19.88 + x² + y² − 114.4 + 38.72 41.20 = x² + y² − 55.8 Therefore x² + y² = 97 … (2)

Example 15: Effect on Variance When Adding a Constant

Add/subtract the same constant a to every value ⟹ variance stays the same.

Proof (as required)

  • Original observations: x1, x2, …, xn
  • Mean of original observations = x̄
  • Originalvariance:σ2=(1n)∑(xi−x̄)2
Add ‘a’ to each observation, define: yi = xi + a … (1) Mean of new observations: ȳ=(1n)∑yi=(1n)∑(xi+a)=(1n)(∑xi+na)=(1n)∑xi+a=x̄+aTherefore ȳ = x̄ + a … (2) Variance of new observations: σy2=(1n)∑(yi−ȳ)2=(1n)∑[(xi+a)−(x̄+a)]2(using(1)and(2))=(1n)∑(xi−x̄)2=σ2
Adding/subtracting shifts everything equally: mean changes, but spread doesn’t ⟹ variance unchanged.
Don’t mix up: add constant → variance same; multiply by k → variance becomes k² times.

Summary (Measures of Dispersion and Key Formulae)

Measures of dispersion = how “spread out” the data are. Listed in this chapter: Range, Quartile Deviation, Mean Deviation, Variance, Standard Deviation.

Range = Maximum value − Minimum value Maximum value = largest observation Minimum value = smallest observation

σ2=(1n)∑(xi−x̄)2σ=(1n)∑(xi−x̄)2xi = observations x̄ = mean n = number of observations σ² = variance σ = standard deviation

Historical Note (Development of Statistics)

Origin of the Term

Statistics comes from Latin status = a political state. So, early statistics was mainly for state administration + record-keeping.

Early Data Collection

  • 3050 B.C. (Egypt): possibly the first census was held.
  • India (~2000 years ago): efficient administrative statistics, esp. during Chandra Gupta Maurya (324–300 B.C.).
  • Kautilya’s Arthshastra (~300 B.C.): mentions systems for collecting data on births and deaths.
  • Akbar’s regime: administrative surveys recorded in Ain-I-Akbari by Abul Fazl.

Key Contributors and Milestones

  • Captain John Graunt (1620–1674): father of vital statistics; studies on births and deaths.
  • Jacob Bernoulli (1654–1705): stated the Law of Large Numbers in “Ars Conjectandi” (published 1713).
  • Mid-17th century onwards: big theoretical growth, boosted by theory of games and chance (probability).
  • Francis Galton (1822–1921): pioneered statistical methods in Biometry.
  • Karl Pearson (1857–1936): major work; discovered the Chi-square test and founded a statistical laboratory in England (1911).
  • Sir Ronald A. Fisher (1890–1962): Father of modern statistics; applied stats in Genetics, Biometry, Education, Agriculture, etc.
