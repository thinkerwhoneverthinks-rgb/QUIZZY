Ch-05 : Linear Inequalities

5.1 Introduction

Real-life conditions often aren’t exact equalities. We compare using <, >, ≤, ≥. These statements are called inequalities.
Examples → how statements turn into inequalities:
  • “Height of all students in a class is less than 160 cm” → height < 160
  • “A classroom can occupy at most 60 tables or chairs or both” → (tables + chairs) ≤ 60
We study linear inequalities in one and two variables. Inequalities appear a lot in science, maths, statistics, economics, psychology, etc.

5.2 Inequalities

Forming inequalities from situations

Situation (i): Ravi buying rice
  • Ravi has ₹200.
  • Rice is sold in 1 kg packets, cost ₹30 each.
  • Let x = number of packets ⇒ money spent = 30x.
  • He may not be able to spend the full ₹200 (must buy whole packets).
30x < 200 x = number of 1 kg rice packets bought
This is not an equation (no “=” sign). Situation (ii): Reshma buying registers and pens
  • Reshma has ₹120.
  • Cost: register ₹40 each, pen ₹20 each.
  • Let x = number of registers, y = number of pens ⇒ money spent = 40x + 20y.
  • She can spend up to ₹120 (could be less or exactly ₹120).
40x + 20y ≤ 120 x = number of registers y = number of pens
Note: “≤” means two cases are allowed:
  • 40x + 20y < 120 (an inequality)
  • 40x + 20y = 120 (an equation)

Definition and types of inequalities

Definition: If two real numbers or two algebraic expressions are related by <, >, ≤, or ≥, we get an inequality.
Numerical inequalities (numbers only):
  • 3 < 5
  • 7 > 5
Literal inequalities (involve variables):
  • x < 5
  • y > 2
  • x ≥ 3
  • y ≤ 4
Double inequalities (a chain):
  • 3 < 5 < 7 (means 5 is greater than 3 and less than 7)
  • 3 < x < 5
  • 2 < y < 4
Read a double inequality as two inequalities at the same time. Example: 3 < x < 5 means (i) 3 < x and (ii) x < 5.

Standard forms and classification

Common inequality forms:
  • ax + b < 0
  • ax + b > 0
  • ax + b ≤ 0
  • ax + b ≥ 0
  • ax + by < c
  • ax + by > c
  • ax + by ≤ c
  • ax + by ≥ c
  • ax2 + bx + c ≤ 0
  • ax2 + bx + c > 0
Strict inequalities: use < or > Slack inequalities: use ≤ or ≥
  • Strict: ax + b < 0, ax + b > 0, ax + by < c, ax + by > c, ax2 + bx + c > 0
  • Slack: ax + b ≤ 0, ax + b ≥ 0, ax + by ≤ c, ax + by ≥ c, ax2 + bx + c ≤ 0
Linear inequality in one variable: ax + b (relation) 0, with a ≠ 0. Linear inequality in two variables: ax + by (relation) c, with a ≠ 0 and b ≠ 0. Quadratic inequalities like ax2 + bx + c (relation) 0 are not linear (here a ≠ 0).
In this chapter portion, we stick to linear inequalities in one and two variables.

5.3 Algebraic Solutions of Linear Inequalities in One Variable and their Graphical Representation

Solutions and solution set (illustration using 30x < 200)

Inequality: 30x < 200, where x = number of rice packets.
Since x counts packets: x cannot be negative and x cannot be a fraction.
Check values (trial method):
  • x = 0 → 30·0 = 0 < 200 (true)
  • x = 1 → 30 < 200 (true)
  • x = 2 → 60 < 200 (true)
  • x = 3 → 90 < 200 (true)
  • x = 4 → 120 < 200 (true)
  • x = 5 → 150 < 200 (true)
  • x = 6 → 180 < 200 (true)
  • x = 7 → 210 < 200 (false)
Solution = a value of the variable that makes the inequality true. Solution set = the set of all solutions.
So (whole-number packets): solution set = {0, 1, 2, 3, 4, 5, 6}.
Trial-and-error is OK for tiny cases, but usually too slow/impossible → use algebraic rules.

Rules for solving inequalities

Recall (equations):
  • Rule (equations) 1: Add/subtract equal numbers on both sides.
  • Rule (equations) 2: Multiply/divide both sides by the same non-zero number.
Rule 1 (Inequalities): Add/subtract the same number on both sides → sign stays the same. Rule 2 (Inequalities): Multiply/divide both sides by the same positive number → sign stays. Multiply/divide by a negative number → reverse the sign ( < ↔ >, ≤ ↔ ≥ ).
Why the sign flips with a negative multiplier:
  • 3 > 2 but −3 < −2 (× −1 reverses order)
  • −8 < −7 but (−8)(−2) > (−7)(−2), i.e. 16 > 14 (× −2 reverses sign)
Most common mistake: multiply/divide by a negative and forget to flip the inequality sign.

Example 1: Solve 30x < 200 for different domains

Given: 30x < 200 Divide both sides by 30 (positive) → sign unchanged (Rule 2):
x < 200/30 = 20/3 x = variable (number of packets / number)
(i) If x is a natural number (1, 2, 3, …):
  • Natural numbers less than 20/3 ≈ 6.66 are: 1, 2, 3, 4, 5, 6
  • Solution set: {1, 2, 3, 4, 5, 6}
(ii) If x is an integer (…, −2, −1, 0, 1, 2, …):
  • All integers less than 20/3 are …, −3, −2, −1, 0, 1, 2, 3, 4, 5, 6
  • Solution set: {…, −3, −2, −1, 0, 1, 2, 3, 4, 5, 6}
Solutions depend on the domain (ℕ vs ℤ vs ℝ). Always check what the question asks for.

Example 2: Solve 5x − 3 < 3x + 1 for integers and real numbers

Start: 5x − 3 < 3x + 1
  1. Add 3 both sides (Rule 1): 5x < 3x + 4
  2. Subtract 3x both sides (Rule 1): 2x < 4
  3. Divide by 2 (positive) (Rule 2): x < 2
(i) If x is an integer: …, −4, −3, −2, −1, 0, 1 (ii) If x is a real number: all real x with x < 2
Solution set: x ∈ (−∞, 2) (−∞, 2) = all real numbers strictly less than 2
From here on (unless stated), solve inequalities in real numbers.

Example 3: Solve 4x + 3 < 6x + 7

Given: 4x + 3 < 6x + 7
  1. Group x-terms: 4x − 6x < 7 − 3
  2. So: −2x < 4
  3. Divide by −2 (negative) → reverse sign (Rule 2): x > −2
Solution set: (−2, ∞) (−2, ∞) = all real numbers strictly greater than −2
Key move: dividing by −2 flips “<” to “>”.

Example 4: Solve (5 − 2x)/2 ≤ (x − 30)/5

Given:
(5 − 2x)/2 ≤ (x − 30)/5 x = real variable
Clear denominators: multiply by 10 (positive → sign unchanged):
  1. 10·(5 − 2x)/2 ≤ 10·(x − 30)/5
  2. 2(5 − 2x) ≤ x − 30
  3. 10 − 4x ≤ x − 30
  4. Collect terms: −5x ≤ −40
  5. Divide by −5 (negative) → reverse sign: x ≥ 8
Solution set: x ∈ [8, ∞) [8, ∞) = all real numbers greater than or equal to 8

Example 5: Solve 7x + 3 < 5x + 9 and represent on number line

Given: 7x + 3 < 5x + 9
  1. Subtract 5x: 2x + 3 < 9
  2. Subtract 3: 2x < 6
  3. Divide by 2: x < 3
Number line for x < 3: open circle at 3 (3 not included), shade/arrow to the left.

Example 6: Solve (3x − 4)/4 + 1 ≥ (1 − 2x)/4 and represent on number line (setup shown)

Given:
(3x − 4)/4 + 1 ≥ (1 − 2x)/4 x = real variable
Steps shown (up to a simpler inequality):
  • Rewrite 1 with denominator 4: 1 = 4/4
  • (3x − 4)/4 + 1 = (3x − 4)/4 + 4/4 = (3x)/4
  • So: 3x/4 ≥ (1 − 2x)/4
  • Multiply both sides by 4 (positive): 3x ≥ 1 − 2x
  • Also shown: 2(3x − 4) ≥ (x − 3) (another equivalent form from the text)
To clear fractions: multiply by the LCM. If the LCM is positive, the inequality sign does not change.

Examples Based on Linear Inequalities

Solving a Linear Inequality (Algebraic Steps + Graph)

Solve like an equation, but: multiply/divide by a negative → flip the inequality sign.
Example: 6x – 8 ≥ x – 3 Collect like terms: 6x – x ≥ –3 + 8 ⟹ 5x ≥ 5 ⟹ x ≥ 1
Number line for x ≥ 1: filled (dark) circle at 1, dark ray to the right.

Example 7: Minimum Marks for a Required Average

“Average at least …” → set up an inequality using: Average = (sum of marks)/(number of exams).
Marks: 62, 48, and x (annual). Required average ≥ 60.
Average = (sum of observations) / (number of observations) sum of observations = total of all marks/scores number of observations = number of exams/tests
Set up: (62 + 48 + x)/3 ≥ 60 110 + x ≥ 180 x ≥ 70
Minimum required mark = 70.

Example 8: Consecutive Odd Natural Numbers with Conditions

Consecutive odd natural numbers differ by 2. If smaller = x, next = x + 2.
Conditions:
  • Both larger than 10 ⟹ x > 10
  • Sum less than 40 ⟹ x + (x + 2) < 40
Solve sum condition: 2x + 2 < 40 ⟹ 2x < 38 ⟹ x < 19 Combine: 10 < x < 19 x must be odd ⟹ x ∈ {11, 13, 15, 17}
Required pairs: (11,13), (13,15), (15,17), (17,19).

Miscellaneous Examples

Example 9: Solving a Double Inequality

Double inequality a ≤ (expression) < b = two inequalities true at the same time.
Solve: –8 ≤ 5x – 3 < 7 Add 3 everywhere: –5 ≤ 5x < 10 Divide by 5 (positive ⇒ signs stay): –1 ≤ x < 2
Final solution set: –1 ≤ x < 2.

Example 10: Double Inequality Involving a Linear Expression

Solve: –5 ≤ (5 – 3x)/2 ≤ 8 ×2 everywhere (positive): –10 ≤ 5 – 3x ≤ 16 –5 everywhere: –15 ≤ –3x ≤ 11 ÷(–3) everywhere (negative ⇒ reverse BOTH signs): 5 ≥ x ≥ –11/3 Write increasing order:
–11/3 ≤ x ≤ 5
Divide/multiply by a negative in a chain inequality ⇒ flip both inequality signs.

Example 11: System of Inequalities + Number Line Representation

System solution = intersection (overlap) of the solution sets.
Solve simultaneously: (1) 3x – 7 < 5 + x (2) 11 – 5x ≤ 1 From (1): 3x – x < 5 + 7 ⟹ 2x < 12 ⟹ x < 6 From (2): 11 – 5x ≤ 1 ⟹ –5x ≤ –10 ⟹ x ≥ 2 (sign flips when ÷ by –5)
Common solution: 2 ≤ x < 6.
Number line meaning:
  • x ≥ 2: filled circle at 2, ray right
  • x < 6: open circle at 6, ray left
  • Intersection: from 2 (included) up to 6 (excluded)

Example 12: Temperature Range Conversion Using Inequalities

If a variable is given in a range, substitute using the formula, then solve the new inequality.
Given safe range: 30 < C < 35
C = (5/9)(F – 32) C = temperature in degree Celsius F = temperature in degree Fahrenheit
Substitute: 30 < (5/9)(F – 32) < 35 ×(9/5) everywhere (positive): (9/5)·30 < F – 32 < (9/5)·35 54 < F – 32 < 63 +32 everywhere: 86 < F < 95
Required Fahrenheit range: 86°F < F < 95°F.

Example 13: Mixture (Percentage) Inequality Problem

Mixtures: solute (acid) amount = (percentage/100) × (volume). Inequalities happen when final % must be between two values.
Given: 600 L of 12% acid solution. Add x L of 30% solution.
  • Total volume = x + 600
  • Acid initially = 12% of 600
  • Acid added = 30% of x
Required final concentration: more than 15% but less than 18%: 30% of x + 12% of 600 > 15% of (x + 600) 30% of x + 12% of 600 < 18% of (x + 600) Convert to fractions: (30/100)x + (12/100)(600) > (15/100)(x + 600) (30/100)x + (12/100)(600) < (18/100)(x + 600) ×100: 30x + 7200 > 15x + 9000 30x + 7200 < 18x + 10800 Solve: 15x > 1800 ⟹ x > 120 12x < 3600 ⟹ x < 300
Required amount to add: 120 < x < 300 litres.

Standard Problem Types Appearing in Exercises (Exam-Style Patterns)

Average/Marks Minimum Requirement Problems

Pattern: required average ≥ A over n tests, known sum = S, unknown mark = x: (S + x)/n ≥ A ⟹ x ≥ nA – S

Consecutive Integer Pair Problems

Common representations:
  • Consecutive odd integers: x, x + 2
  • Consecutive even integers: x, x + 2
  • Consecutive integers: x, x + 1
After you get the inequality range, restrict x to the needed set (odd/even/natural/positive) and list the valid pairs.

Board-Cutting / Length Constraints Problems (Model Setup)

Turn each sentence into an inequality, then solve together (take the intersection).
Typical setup from the given hint:
  • If shortest length = x, other lengths = x, (x + 3), 2x
  • Total length constraint: x + (x + 3) + 2x ≤ 91
  • “Third at least 5 cm longer than second”: 2x ≥ (x + 3) + 5
Words checklist: “at least” ⇒ ≥, “at most” ⇒ ≤, “more than” ⇒ >, “less than” ⇒ <.

Key Laws/Rules and Graphing Conventions (Summary Notes)

Definition of Inequality

Two real numbers (or expressions) linked by <, >, ≤, ≥ make an inequality.

Operations on Inequalities

  • Add/Subtract same number both sides ⇒ sign stays the same
  • Multiply/Divide by same positive number ⇒ sign stays the same
  • Multiply/Divide by same negative number ⇒ sign reverses
Most common exam slip: forgetting to flip the sign when ×/÷ by a negative.

Solution of an Inequality

All values of x that make the inequality true are the solutions.

Number Line Representation Rules

  • x < a: open circle at a; shade left
  • x > a: open circle at a; shade right
  • x ≤ a: filled circle at a; shade left
  • x ≥ a: filled circle at a; shade right
