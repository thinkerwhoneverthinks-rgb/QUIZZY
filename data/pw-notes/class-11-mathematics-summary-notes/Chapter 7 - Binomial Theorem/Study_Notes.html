Ch-07 : Binomial Theorem

7.1 Introduction

Need for Binomial Theorem: Small powers are easy to expand: (a+b)2, (a+b)3 → quick number tricks, e.g. 982 = (100−2)2, 9993 = (1000−1)3. But big powers like (98)5 or (101)6 make repeated multiplication long + tedious. Binomial Theorem: Gives a simpler way to expand (a+b)n (in general, n may be integer or rational). Here we only use positive integral indices: n ∈ ℕ.

7.2 Binomial Theorem for Positive Integral Indices

Patterns from earlier identities

Known expansions (revise):
  • (a+b)0 = 1, provided a+b ≠ 0
  • (a+b)1 = a+b
  • (a+b)2 = a2 + 2ab + b2
  • (a+b)3 = a3 + 3a2b + 3ab2 + b3
  • (a+b)4 = a4 + 4a3b + 6a2b2 + 4ab3 + b4
3 quick patterns in (a+b)n:
  1. # of terms: n+1 (always one more than n)
  2. Powers shift: power of a goes down by 1 each term; power of b goes up by 1
  3. Powers add to n: in every term, (power of a) + (power of b) = n

Pascal’s Triangle (Meru Prastara)

Pascal’s Triangle: triangle of numbers: top is 1, and 1’s on both slant sides; every inside entry = (two entries just above it) added. Names: called Pascal’s triangle (Blaise Pascal); also Meru Prastara (Pingla).
How it gives binomial coefficients:
  • Each row starts with 1 and ends with 1.
  • Middle numbers come from adding adjacent numbers in the previous row (e.g. 1,2,1 → next row has 3,3 in the middle).
  • Row for index n = coefficients of (a+b)n.

Worked expansion using Pascal’s triangle: (2x + 3y)5

Row for n=5: 1, 5, 10, 10, 5, 1 Use: (i) 6 terms, (ii) (2x)5 down to (2x)0, and (3y)0 up to (3y)5, (iii) powers add to 5: (2x + 3y)5 = (2x)5 + 5(2x)4(3y) + 10(2x)3(3y)2 + 10(2x)2(3y)3 + 5(2x)(3y)4 + (3y)5 = 32x5 + 240x4y + 720x3y2 + 1080x2y3 + 810xy4 + 243y5.
Exam tip: For (2x+3y)n, treat (2x)=a and (3y)=b first. Then simplify: (2x)k=2kxk, (3y)m=3mym.

Combinations and rewriting Pascal’s triangle

Combination: nCr = n! / (r!(n−r)!) n = non-negative integer r = integer with 0 ≤ r ≤ n Also: nC0 = 1 = nCn
Pascal row = combinations: nth row is nC0, nC1, …, nCn (so you don’t need earlier rows). Eg (n=7): 7C0, 7C1, 7C2, 7C3, 7C4, 7C5, 7C6, 7C7.
Example template (using combinations): (a+b)7 = 7C0a7 + 7C1a6b + 7C2a5b2 + 7C3a4b3 + 7C4a3b4 + 7C5a2b5 + 7C6ab6 + 7C7b7.

7.2.1 Binomial theorem for any positive integer n

Binomial Theorem (n ∈ ℕ): (a + b)n = nC0an + nC1an−1b + nC2an−2b2 + … + nCn−1abn−1 + nCnbn n = positive integer nCr = binomial coefficient (combination) General term: nCran−rbr, r = 0,1,2,…,n

Proof by Principle of Mathematical Induction (PMI)

Claim P(n): (a + b)n = nC0an + nC1an−1b + nC2an−2b2 + … + nCnbn
Step 1: Base case (n=1) (a+b)1 = a+b RHS: 1C0a1 + 1C1b1 = a+b So P(1) true.
Step 2: Induction hypothesis Assume P(k) true for some positive integer k: (a + b)k = kC0ak + kC1ak−1b + kC2ak−2b2 + … + kCkbk … (1)
Step 3: Prove P(k+1) (a+b)k+1 = (a+b)(a+b)k Sub (1) and multiply by (a+b):
  • ×a: kC0ak+1 + kC1akb + kC2ak−1b2 + … + kCkabk
  • ×b: kC0akb + kC1ak−1b2 + … + kCkbk+1
Group like terms (same powers of a, b): = kC0ak+1 + (kC1+kC0)akb + (kC2+kC1)ak−1b2 + … + (kCk+kCk−1)abk + kCkbk+1 Use: k+1Cr = kCr + kCr−1, and k+1C0=1, kCk=1=k+1Ck+1. So: (a+b)k+1 = k+1C0ak+1 + k+1C1akb + k+1C2ak−1b2 + … + k+1Ckabk + k+1Ck+1bk+1 Hence P(k+1) true if P(k) true ⇒ by PMI, P(n) true for all positive integers n.

Illustration: Expand (x + 2)6

(x+2)6 = 6C0x6 + 6C1x5·2 + 6C2x4·22 + 6C3x3·23 + 6C4x2·24 + 6C5x·25 + 6C6·26 = x6 + 12x5 + 60x4 + 160x3 + 240x2 + 192x + 64.

Observations (exam-useful properties of the expansion)

  1. Sigma notation: ∑k=0n nCkan−kbk means: nC0anb0 + nC1an−1b1 + … + nCran−rbr + … + nCnan−nbn, where b0=1 and an−n=a0=1. So compact form: (a+b)n = ∑k=0n nCkan−kbk
  2. Binomial coefficients: nCr are called binomial coefficients.
  3. # of terms: (a+b)n has exactly (n+1) terms.
  4. Index flow: powers of a go n → 0; powers of b go 0 → n.
  5. Sum of indices: in every term, (power of a)+(power of b)=n.

7.2.2 Some special cases

(i) Expansion of (x − y)n

Binomial with minus: (x−y)n = nC0xn − nC1xn−1y + nC2xn−2y2 − nC3xn−3y3 + … + (−1)nnCnyn General term: (−1)rnCrxn−ryr
Example: (x−2y)5 = 5C0x5 − 5C1x4(2y) + 5C2x3(2y)2 − 5C3x2(2y)3 + 5C4x(2y)4 − 5C5(2y)5 = x5 − 10x4y + 40x3y2 − 80x2y3 + 80xy4 − 32y5.
Common mistake: Signs in (x−y)n alternate because (−y)r gives (−1)r. Don’t alternate blindly—match sign to r (odd r → −, even r → +).

(ii) Expansion of (1 + x)n and a key identity

(1+x)n: (1+x)n = nC0 + nC1x + nC2x2 + nC3x3 + … + nCnxn (take a=1, b=x in (a+b)n)
Sum of binomial coefficients: 2n = nC0 + nC1 + nC2 + … + nCn (put x=1 in (1+x)n)

(iii) Expansion of (1 − x)n and an alternating-sum identity

(1−x)n: (1−x)n = nC0 − nC1x + nC2x2 − … + (−1)nnCnxn (take a=1, b=−x in (a+b)n)
Alternating sum of binomial coefficients: 0 = nC0 − nC1 + nC2 − … + (−1)nnCn (put x=1 in (1−x)n)

Example 1: Expand (x2 + 3/x)4, x ≠ 0

Let a = x2, b = 3/x. (x2 + 3/x)4 = 4C0(x2)4 + 4C1(x2)3(3/x) + 4C2(x2)2(3/x)2 + 4C3(x2)(3/x)3 + 4C4(3/x)4 Compute term-by-term:
  • 4C0(x2)4 = x8
  • 4C1(x2)3(3/x) = 4·x6·(3/x) = 12x5
  • 4C2(x2)2(3/x)2 = 6·x4·(9/x2) = 54x2
  • 4C3(x2)(3/x)3 = 4·x2·(27/x3) = 108/x
  • 4C4(3/x)4 = 81/x4
So: (x2 + 3/x)4 = x8 + 12x5 + 54x2 + 108/x + 81/x4.
Common mistake: If b=3/x, then (3/x)r=3r/xr. Combine with (x2)4−r=x2(4−r) carefully (exponents slip easily).

Example 2: Compute 985

98 = 100 − 2 985 = (100−2)5 = 5C0(100)5 − 5C1(100)4(2) + 5C2(100)3(2)2 − 5C3(100)2(2)3 + 5C4(100)(2)4 − 5C5(2)5 = 10000000000 − 5×100000000×2 + 10×1000000×4 − 10×10000×8 + 5×100×16 − 32 = 10040008000 − 1000800032 = 9039207968.

Example 3: Comparing (1.01)1000000 and 10,000

Method indicated: Split 1.01 and use binomial theorem to write the first few terms. (Rest of solution continues on next page of the chapter.)

Comparing large powers using Binomial Theorem

Idea: To compare something like (1+x)n with a given number, expand (binomial theorem) and keep only the first few terms. If the leftover terms are all positive, ignoring them still gives a true inequality (a lower bound).
Given work: (1.01)1000000 = (1 + 0.01)1000000 = 1000000C0 + 1000000C1(0.01) + other positive terms = 1 + 1000000 × 0.01 + other positive terms = 1 + 10000 + other positive terms > 10000
Reasoning used: If x > 0, then every term in (1+x)n is positive. So (1+x)n = 1 + nx + (positive terms) > 1 + nx. Super exam-useful: shows one value is bigger without fully calculating it.
⚠ Don’t drop terms unless you justify the sign. “Other positive terms” only works because x = 0.01 > 0 and binomial coefficients are positive.

Example 4: Proving a remainder statement using Binomial Theorem

Remainder definition (used in the solution)

For numbers a and b, if we can find q and r such that a = bq + r, then b divides a with q as the quotient and r as the remainder.

Statement to prove

Using binomial theorem, prove that 6n − 5n always leaves remainder 1 when divided by 25.
To show “remainder 1 when divided by 25”, it’s enough to show: 6n − 5n = 25k + 1 for some natural number k.

Binomial expansion used

(1 + a)n = nC0 + nC1a + nC2a2 + … + nCnan n = positive integer (power) a = the added term in the binomial (here substituted as 5) nCr = binomial coefficient

Apply with a = 5

(1 + 5)n = nC0 + nC15 + nC252 + … + nCn5n i.e. 6n = 1 + 5n + 52·nC2 + 53·nC3 + … + 5n

Form 6n − 5n and factor out 25

6n − 5n = 1 + 52(nC2 + nC3·5 + … + 5n−2) or 6n − 5n = 1 + 25(nC2 + 5·nC3 + … + 5n−2) or 6n − 5n = 25k + 1 where k = nC2 + 5·nC3 + … + 5n−2.
Conclusion: Since 6n − 5n = 25k + 1, it leaves remainder 1 when divided by 25.
⚠ Key exam step: pull out 25 = 52 from every term except the first “1”. The last term 5n cancels when subtracting 5n, so what’s left all has at least 52.

Summary: Binomial Theorem and Pascal’s Triangle

Binomial Theorem (for positive integral n)

(a + b)n = nC0an + nC1an−1b + nC2an−2b2 + … + nCn−1a·bn−1 + nCnbn a, b = the two terms in the binomial n = positive integer nCr = binomial coefficient (coefficient of an−rbr)

Pascal’s Triangle

The coefficients in binomial expansions can be arranged in an array called Pascal’s triangle.

Historical Note (Binomial coefficients and Pascal’s triangle)

  • Ancient Indian mathematicians knew coefficients in expansions of (x + y)n for 0 ≤ n ≤ 7.
  • Pingla (about 200 B.C.), in Chhanda shastra, gave a triangular diagram arrangement called Meru-Prastara.
  • A similar triangular arrangement appears in the work of Chinese mathematician Chu-shi-kie (1303).
  • The term binomial coefficients was first introduced by German mathematician Michael Stipel (1486–1567) around 1544.
  • Bombelli (1572) gave coefficients for (a + b)n for n = 1,2,…,7.
  • Oughtred (1631) gave them for n = 1,2,…,10.
  • The arithmetic triangle, popularly known as Pascal’s triangle (similar to Meru-Prastara), was constructed by French mathematician Blaise Pascal (1623–1662) in 1665.
  • The present form of the binomial theorem for integral n appeared in Traité du triangle arithmétique, written by Pascal and published posthumously in 1665.
