EVENTS AND SAMPLE SPACE

1Definition & Introduction

  • Sample space S = set of all possible outcomes of a random experiment.
  • Event E = any subset of S; i.e., E ⊆ S.
  • Occurrence: event E occurs if actual outcome ω satisfies ω ∈ E.
  • Sure event is S; it always occurs.
  • Impossible event is φ (empty set); it never occurs.

2Diagram

Flow: experiment → sample space S (universal set) → event E as subset.

3Key Concepts

  • 🎲Random experiment: outcome is uncertain but outcomes set S is known.
  • 🧩Sample space acts as the universal set for all event-sets in that experiment.
  • 📌Writing an event means selecting outcomes in S satisfying a condition.
  • ⭕φ corresponds to an event description that no outcome can satisfy.
  • ✅S corresponds to an event description that every outcome satisfies.

4WORDING → SUBSET: COIN TOSSED TWICE

  • Experiment: toss a coin twice; S = {HH, HT, TH, TT}.
  • Event “exactly one head” ⇒ E = {HT, TH} (pick outcomes with one H).
  • Event “exactly two tails” ⇒ {TT}.
  • Event “at least one tail” ⇒ {HT, TH, TT}.
  • Event “second toss is not head” ⇒ {HT, TT} (second symbol is T).

5CHECKING OCCURRENCE (USING ω ∈ E)

  • If actual outcome ω lies in the set for E, then E has occurred.
  • Die example: S = {1,2,3,4,5,6}; E: “number < 4” ⇒ E = {1,2,3}.
  • If result is 2, then 2 ∈ E ⇒ event occurs; if result is 5, 5 ∉ E ⇒ does not occur.

6Key event-types as subsets of S

7Solved Q&A

1
A coin is tossed twice. Write the sample space S and the event E: “exactly one head”. Also state whether outcome TH implies that E occurred.
Answer:
All possible outcomes: S = {HH, HT, TH, TT}.
Exactly one head means one H and one T: E = {HT, TH}.
Given outcome TH satisfies TH ∈ E, so E occurs.
✓  S = {HH, HT, TH, TT}, E = {HT, TH}; for outcome TH, the event occurs.
2
A die is thrown. Let E be the event “number is a multiple of 7”. Write S and E. Name the type of event E.
Answer:
Sample space for one die throw: S = {1,2,3,4,5,6}.
No element of S is a multiple of 7, so the corresponding subset is empty.
Hence E = φ, which is an impossible event.
✓  S = {1,2,3,4,5,6}, E = φ; E is an impossible event.

8⭐Important Points

  • For a fixed experiment, every event must be a subset of the same sample space S.
  • Translate conditions using the outcome format: for coin twice, each outcome has 2 symbols.
  • Sure event = S; impossible event = φ.
  • Event occurs exactly when the observed outcome lies inside its set: ω ∈ E.
  • Simple event = singleton {ω}; compound event contains multiple outcomes.

9❌Common Mistakes

  • Writing the sample space incompletely (missing HT or TH in coin twice).
  • Confusing “at least one tail” with “exactly one tail”.
  • Using φ when the event is rare but still possible (should be non-empty subset).
  • Treating an event as a sentence only, not converting it into a subset of S.

TOPIC2

OCCURRENCE OF AN EVENT

1Definition & Introduction

  • For a random experiment, an event E is said to occur if the outcome ω satisfies ω ∈ E.
  • If the observed outcome ω satisfies ω ∉ E, then event E has not occurred.
  • An event is a subset of sample space S; outcome ω is a sample point with ω ∈ S.
  • Occurrence/non-occurrence is decided after performing the experiment and observing ω.
  • Always check membership: first write E as a set, then test ω ∈ E.

2Diagram

Decide occurrence by membership: compare observed ω with event set E.

3Key Concepts

  • 🧩Outcome is a single sample point ω; event E is a set of outcomes.
  • ✅Event occurs when observed result is favourable: ω ∈ E.
  • ❌Event does not occur when observed result is not favourable: ω ∉ E.
  • 🎲Die example: E = {1,2,3} for “number less than 4”.

4HOW TO CHECK OCCURRENCE (EXAM STEPS)

  • Write the sample space S and the event as a set E ⊆ S.
  • Perform the experiment; record the actual outcome ω (one element of S).
  • If ω ∈ E ⇒ event occurs; if ω ∉ E ⇒ event not occurred.
  • Same event can occur for many outcomes (all outcomes inside E).

5DIE EXAMPLE: “NUMBER LESS THAN 4”

  • Experiment: throw a die; S = {1,2,3,4,5,6}.
  • Event E: “number less than 4” ⇒ E = {1,2,3}.
  • If ω = 1,2,3 ⇒ ω ∈ E ⇒ E occurs.
  • If ω = 4,5,6 ⇒ ω ∉ E ⇒ E does not occur.

Answer:
Write event set: E = {1,2,3}.
Observed outcome is ω = 3.

✓  Yes, event E occurs.

Answer:
Event set is E = {1,2,3}.
Observed outcome is ω = 5.

✓  No, event E has not occurred.

8⭐Important Points

  • Outcome ω is a single result; event E is a subset of S.
  • Use only the membership rule: ω ∈ E (occurs) or ω ∉ E (not occurs).
  • First convert the verbal description into a set E; then test the observed ω.
  • Event occurrence is not probability; it is a yes/no statement after observation.
  • For a die, “less than 4” means {1,2,3}, not including 4.

9❌Common Mistakes

  • Treating event as a single outcome: writing E = 3 instead of E = {1,2,3}.
  • Including wrong elements while forming E from language (e.g., adding 4 in “less than 4”).
  • Confusing ω ∈ E with E ∈ S (event is subset, not an element).
  • Saying “event occurs” without checking the observed outcome ω.

ALGEBRA OF EVENTS

1Definition & Introduction

  • An event is any subset of sample space S; algebra of events uses set operations on events.
  • Complement of A: A′ = S − A, called not A.
  • Union A ∪ B: event A or B (or both).
  • Intersection A ∩ B: event A and B simultaneously.
  • Difference A − B: event A but not B; equals A ∩ B′.

2Diagram

Venn view: union, intersection, difference, and complement regions in sample space S.

3Key Concepts

  • 🟦Complement: A′ contains exactly those outcomes not in A.
  • 🟪Union collects outcomes in either event; overlap is counted once.
  • 🟩Intersection is the overlap region: outcomes satisfying both conditions.
  • 🟧Difference keeps only the part of A outside B: A ∩ B′.
  • 🔁De Morgan: ( A ∪ B )′ = A′ ∩ B′ and ( A ∩ B )′ = A′ ∪ B′.

4SET-LANGUAGE OPERATIONS ON EVENTS

  • Complement: A′ = {ω : ω ∈ S and ω ∉ A} = S − A.
  • Union: A ∪ B = {ω : ω ∈ A or ω ∈ B}.
  • Intersection: A ∩ B = {ω : ω ∈ A and ω ∈ B}.
  • Difference: A − B = {ω : ω ∈ A and ω ∉ B} = A ∩ B′.
  • Basic identities: A ∪ A′ = S, A ∩ A′ = φ.

5DE MORGAN + QUICK PROBABILITY LINKS

  • De Morgan: ( A ∪ B )′ = A′ ∩ B′ ("not(A or B)" = "not A and not B").
  • De Morgan: ( A ∩ B )′ = A′ ∪ B′ ("not(A and B)" = "not A or not B").
  • Link to probability: Taking probability preserves set equalities, e.g. from A′ = S − A we get P(A′) = 1 − P(A).
  • Union probability rule: For any events A, B, P(A ∪ B) = P(A) + P(B) − P(A ∩ B).

7Solved Q&A

1
A die is rolled. S={1,2,3,4,5,6}. Let A={2,3,5} (prime) and B={1,3,5} (odd). Write (i) A∪B (ii) A∩B (iii) A−B (iv) A′.
Answer:
(i) Union collects outcomes that are in A or in B (or both): {1,2,3,5}.
(ii) Intersection collects outcomes common to both sets: {3,5}.
(iii) Difference A−B keeps outcomes in A but not in B: {2}.
(iv) Complement A′ is everything in S except A: {1,4,6}.
✓  A∪B={1,2,3,5}, A∩B={3,5}, A−B={2}, A′={1,4,6}.
2
Explain why ( A ∪ B )′ equals A′ ∩ B′ using outcome-by-outcome reasoning.
Answer:
Take any outcome ω.
ω ∈ ( A ∪ B )′ means ω is NOT in the union, i.e., ω is neither in A nor in B.
That is equivalent to: (ω ∉ A) AND (ω ∉ B).
So ω belongs to A′ and also belongs to B′, i.e., ω ∈ A′ ∩ B′.
✓  For every ω, membership in ( A ∪ B )′ is equivalent to membership in A′ ∩ B′, hence the sets are equal.

8⭐Important Points

  • "Or" in probability is inclusive: A∪B includes overlap A∩B.
  • Difference is directional: A−B ≠ B−A generally.
  • Partition idea: A = (A−B) ∪ (A∩B), disjoint union.
  • Use De Morgan to convert complements of unions/intersections before taking probability.
  • If A and B are mutually exclusive: A∩B=φ ⇒ A∪B is a disjoint union.

9❌Common Mistakes

  • Treating "A or B" as exclusive-or; forgetting that overlap is included in A∪B.
  • Mixing direction in difference: A−B means in A but not in B.
  • Applying De Morgan incorrectly: flipping ∪/∩ but not complementing both events.
  • Taking complement without fixing the sample space S, causing a wrong A′.

TOPIC4

MUTUALLY EXCLUSIVE EVENTS

1Definition & Introduction

  • Two events A and B are mutually exclusive if they cannot occur simultaneously in the same trial.
  • Set language: A and B are disjoint (no common outcomes).
  • Key test: A ∩ B = φ (empty set).
  • If A ∩ B contains even one outcome, events are not mutually exclusive.
  • Remark: Two distinct simple events {ωi} and {ωj} (i ≠ j) are mutually exclusive.

2Diagram

Mutually exclusive events are disjoint: intersection is empty.

3Key Concepts

  • 🧩Mutually exclusive ⇔ disjoint sets ⇔ no common sample point
  • ✖️Same trial: if A happens, B cannot happen in that trial
  • ∩Fast check: find A ∩ B; empty means mutually exclusive
  • 🎲Die: odd vs even are mutually exclusive; odd vs < 4 are not
  • 🗂️Mutual exclusivity is about impossibility of overlap, not about independence

4HOW TO TEST (INTERSECTION TEST)

  • Write both events as subsets of the same sample space S.
  • List the outcomes in A and in B clearly.
  • Find A ∩ B (common outcomes).
  • If A ∩ B = φ, they are mutually exclusive; otherwise they are not.

5STANDARD EXAMPLES (DIE)

  • Odd: A={1,3,5}, Even: B={2,4,6} ⇒ A ∩ B=φ (mutually exclusive).
  • Odd: A={1,3,5}, Less than 4: B={1,2,3} ⇒ A ∩ B={1,3} (not mutually exclusive).
  • If one outcome belongs to both events, they can occur together in that outcome.
  • Distinct simple events {1} and {2} cannot occur together in one die roll.

1
A fair die is thrown. Let A be "odd number" and B be "number less than 4". Are A and B mutually exclusive?
Answer:
Write the outcome sets: A={1,3,5} and B={1,2,3}.
Common outcomes are 1 and 3, so A ∩ B={1,3}.
Since the intersection is not empty, the events can occur together (e.g., outcome 3 satisfies both).
✓  A and B are not mutually exclusive.
2
From a standard 52-card deck, consider the event A: "first card is an Ace" and B: "first card is a King". Are A and B mutually exclusive?
Answer:
Both events refer to the identity of the first card only.
A single card cannot be both an Ace and a King at the same time.
Therefore, there is no common outcome where both happen together, i.e., A ∩ B = φ.
✓  Yes, A and B are mutually exclusive.

8⭐Important Points

  • Mutually exclusive means cannot occur together in the same trial.
  • To test: show A ∩ B = φ (set method) or argue logical impossibility.
  • If events are mutually exclusive, their intersection is the impossible event (empty set).
  • Do not confuse mutually exclusive with independent; they are different ideas.
  • Distinct simple events {ωi} and {ωj} (i ≠ j) are mutually exclusive.

9❌Common Mistakes

  • Calling events mutually exclusive without checking for any shared outcome.
  • Confusing "mutually exclusive" with "exhaustive" (together cover all outcomes).
  • Mixing up mutually exclusive with independent events.
  • Comparing events from different experiments/trials (they must share the same sample space).

TOPIC5

EXHAUSTIVE EVENTS

1Definition & Introduction

  • Events E1, E2, …, En are exhaustive if at least one must occur in every trial.
  • Set form: E1 ∪ E2 ∪ … ∪ En = S (sample space).
  • Exhaustive does not mean disjoint; events may overlap and still cover S.
  • Mutually exclusive and exhaustive means they are pairwise disjoint and cover S.
  • Such a collection is a partition of S: each outcome belongs to exactly one event.

2Diagram

Exhaustive means the union of events covers the entire sample space S.

3Key Concepts

  • 🧩Exhaustive ⇔ union is whole: ∪i=1nEi = S
  • 🚫Mutually exclusive ⇔ no overlap: Ei ∩ Ej = φ for i ≠ j
  • 📦Mutually exclusive + exhaustive ⇔ partition (exactly one occurs)
  • ✅For a partition, probabilities of parts add to 1 (total certainty)
  • 🔁Complement pair: A and A′ are always mutually exclusive and exhaustive

4CHECKLIST: EXHAUSTIVE vs MUTUALLY EXCLUSIVE + EXHAUSTIVE

  • Exhaustive: every outcome ω ∈ S lies in at least one Ei.
  • Not required: overlaps allowed; some ω may lie in two events.
  • Mutually exclusive & exhaustive: union covers S and pairwise intersections are φ.
  • Then each ω belongs to exactly one event (a partition).

5QUICK EXAMPLES (WHAT THEY LOOK LIKE)

  • Die: A={1,2,3}, B={3,4}, C={5,6} ⇒ A∪B∪C=S (exhaustive but not mutually exclusive).
  • Die partition: E1={1,2}, E2={3,4}, E3={5,6} ⇒ disjoint and exhaustive.
  • Coin tossed thrice: A(no head), B(exactly one head), C(at least two heads) ⇒ mutually exclusive and exhaustive.

7Solved Q&A

1
A die is thrown once. Let E1={1,2}, E2={3}, E3={4,5,6}. (i) Are they exhaustive? (ii) Are they mutually exclusive and exhaustive?
Answer:
Write the sample space S={1,2,3,4,5,6}.
Check exhaustiveness: E1∪E2∪E3={1,2,3,4,5,6} which equals S.
Check mutual exclusivity: pairwise intersections are empty (no number is common to two sets).
So they are mutually exclusive and exhaustive; they form a partition of S.
✓  (i) Yes, exhaustive. (ii) Yes, mutually exclusive and exhaustive (a partition).

Answer:

Every outcome has a unique head-count category, so A∪B∪C=S (exhaustive).
No outcome can belong to two different head-count categories, so intersections are φ (mutually exclusive).
✓  Yes. They are mutually exclusive and exhaustive.

8⭐Important Points

  • Exhaustive means covering: at least one event in the list must occur.
  • Exhaustive events may overlap; disjointness is a separate condition.
  • Mutually exclusive + exhaustive implies exactly one event occurs (partition).
  • To test exhaustiveness: verify the union equals S (no outcome left out).
  • Complementary events A and A′ always form an exhaustive and mutually exclusive pair.

9❌Common Mistakes

  • Assuming exhaustive events must be disjoint; overlaps are allowed.
  • Declaring 'exhaustive' by intuition without checking the union equals S.
  • Using the disjoint-sum probability idea when events overlap.
  • Missing outcomes that belong to neither listed event, so the collection is not exhaustive.

AXIOMS OF PROBABILITY

1Definition & Introduction

  • A probability function P maps each event E ⊆ S to a real number in [0,1].
  • Domain: power set 2S (all subsets of S); range: [0,1].
  • Axiom 1 (Non-negativity): For any event E, P(E) ≥ 0.
  • Axiom 2 (Normalization): P(S) = 1, where S is the sample space.
  • Axiom 3 (Additivity for disjoint events): If E and F are mutually exclusive, P(E ∪ F) = P(E) + P(F).
  • Consequence: P(φ) = 0 where φ is the empty set (impossible event).

2Diagram

Additivity axiom applies when events are mutually exclusive (disjoint sets).

3Key Concepts

  • 🧩Events are sets: probability is a set function P: 2S → [0,1].
  • ✅Mutually exclusive means E ∩ F = φ (cannot occur together).
  • ➕Axiom 3 applies only when events are disjoint. For overlapping events, one uses the standard derived rule P(E∪F) = P(E)+P(F)−P(E∩F).
  • 0️⃣Using additivity with φ gives P(φ)=0, a frequently tested inference.
  • 🎯P(S)=1 fixes the scale: total probability over the sample space is 1.

4AXIOMS (KOLMOGOROV) IN EXAM LANGUAGE

  • Treat P like a rule that assigns a number to every subset (event) of S.
  • Axiom 1: probabilities cannot be negative: P(E) ≥ 0.
  • Axiom 2: certainty of the sample space: P(S) = 1.
  • Axiom 3: if events cannot occur together (E ∩ F = φ), then probabilities add.
  • Extension: for pairwise disjoint E1, E2, ..., En, P(E1∪E2∪...∪En) = P(E1)+P(E2)+...+P(En).

5STANDARD CONSEQUENCE: P(φ)=0 (ONE-LINE PROOF IDEA)

  • φ is disjoint from every event E: E ∩ φ = φ.
  • Apply additivity to E and φ: P(E ∪ φ) = P(E) + P(φ).
  • But E ∪ φ = E, so the only way the equation can hold is P(φ)=0.

7Solved Q&A

1
Why must P(φ)=0 in the axiomatic approach?
Answer:
Take any event E. The empty set φ cannot occur with anything, so E and φ are disjoint.
By additivity for disjoint events: P(E∪φ) = P(E) + P(φ).
But E∪φ is just E, so P(E) = P(E) + P(φ).
Therefore P(φ)=0.
✓  P(φ)=0.
2
A student adds P(E) + P(F) to get P(E∪F) without checking overlap. What is the axiom-level error?
Answer:
Axiom 3 allows addition only when events are mutually exclusive.
Mutually exclusive means E ∩ F = φ.
If E and F overlap, directly adding double-counts the overlap region, so the axiom does not apply.
✓  They used additivity without verifying E ∩ F = φ.

8⭐Important Points

  • State clearly: P is defined on 2S, i.e., on all events (subsets), not only on single outcomes.
  • Axiom 3 needs mutual exclusivity; check E ∩ F = φ before adding.
  • P(φ)=0 is derived from the axioms (not an independent axiom).
  • From axioms: always 0 ≤ P(E) ≤ 1 for every event E.

9❌Common Mistakes

  • Applying P(E∪F)=P(E)+P(F) even when E and F overlap.
  • Forgetting that φ is an event (subset) and its probability is 0.
  • Confusing the sample space S with an event; S is the universal set of outcomes and always has probability 1.

PROBABILITY OF AN EVENT

1Definition & Introduction

  • If sample space S = {ω1, …, ωn}, then for any event A ⊆ S, P(A) = Σ P(ωi) over all ωi ∈ A.
  • A singleton event {ωi} is an elementary (simple) event; write P(ωi) for P({ωi}).
  • A probability assignment is valid only if 0 ≤ P(ωi) ≤ 1 for every outcome and Σ P(ωi) = 1 over all outcomes in S.
  • For equally likely outcomes, P(ωi) = 1n(S), so P(A) = n(A)n(S).
  • Always list outcomes in A first, then add their probabilities; do not assume equal likelihood unless stated.

2Diagram

Workflow: define S, pick event A, verify assignment, then sum probabilities of outcomes in A.

3Key Concepts

  • 🧩Event A is a set of outcomes; probability is a set-sum over its outcomes.
  • 🔎Use elementary outcomes (HH, HT, …) as building blocks: P(A) adds their P-values.
  • ⚖️Non-uniform assignments are allowed if non-negative and sum to 1.
  • ✅Quick validity check: any negative? any > 1? total ≠ 1? → assignment invalid.

4VALID ASSIGNMENT CONDITIONS (AXIOM CHECK)

  • Non-negativity: for every outcome ω, P(ω) ≥ 0.
  • Upper bound: for every outcome ω, P(ω) ≤ 1.
  • Total probability: Σ P(ωi) over all outcomes in S equals 1.
  • If any condition fails, computed event probabilities become meaningless.

5HOW TO COMPUTE P(A) (SET-SUM METHOD)

  • Step 1: Write S explicitly (or describe outcomes clearly).
  • Step 2: Write event A as a subset of S (list outcomes).
  • Step 3: Use P(A) = Σ P(ω) for all ω ∈ A.
  • Tip: For a single outcome event {ω}, P({ω}) = P(ω).

Let S = {ω1, …, ωn} be the sample space.
P(S) = Σ P(ωi) = 1
For any event A ⊆ S, probability is the sum over outcomes in A.
P(A) = Σ P(ωi), for all ωi ∈ A
If outcomes are equally likely and n(S) = n, then each P(ω) is same.
P(ω) = 1n
Then for an event with n(A) = m outcomes:
P(A) = mn = n(A)n(S)

ωi =i-th elementary outcome (sample point)

8Solved Examples

1
Pens produced by a machine: examine 3 consecutive pens. Outcomes are sequences of B(bad/defective) and G(good).

S = {BBB, BBG, BGB, GBB, BGG, GBG, GGB, GGG}. Each outcome has probability 18.
Find (i) P(A) for A: "exactly one defective pen" and (ii) P(B) for B: "at least two defective pens".
Solution:
Write the events as subsets.
A = {BGG, GBG, GGB} (exactly one B).
B = {BBB, BBG, BGB, GBB} (two or three B).
Use P(event) = Σ P(outcomes in event).
P(A) = P(BGG)+P(GBG)+P(GGB) = 18+18+18 = 38.
P(B) = P(BBB)+P(BBG)+P(BGB)+P(GBB) = 4×18 = 48 = 12.
✓  P(A) = 38, P(B) = 12.
2
A coin is tossed twice with unequal assigned probabilities:
P(HH)=14, P(HT)=17, P(TH)=27, P(TT)=928.

(i) Check if this is a valid assignment. (ii) Find P(E) for E: "both tosses yield same result".
Solution:
Validity check: all probabilities are non-negative.
Also each is ≤ 1 (obvious from fractions).
Sum over S:
14+17+27+928 = 728+428+828+928 = 2828 = 1, so valid.
Event E = {HH, TT}. So P(E) = P(HH)+P(TT).
P(E) = 14 + 928 = 728 + 928 = 1628 = 47.
✓  Valid assignment; P(E) = 47.

9⭐Important Points

  • Always express event A as a subset of S; probability comes after set-writing.
  • For any finite S, P(A) is the sum of probabilities of outcomes inside A.
  • Elementary event {ω} has probability P(ω); do not multiply by counts unless equally likely.
  • Non-uniform outcome probabilities are allowed; only constraints are 0 ≤ P ≤ 1 and total = 1.
  • In numerical questions, first check validity quickly; it prevents impossible answers.

10❌Common Mistakes

  • Assuming outcomes are equally likely when explicit P(HH), P(HT), … are given.
  • Forgetting to list event outcomes correctly (e.g., mixing "exactly one B" with "at least one B").
  • Not checking Σ P(ω) = 1; proceeding with an invalid distribution.
  • Double-counting outcomes when forming the event set (writing duplicates, then summing twice).

11💡Memory Technique

“S-A-S: Space → Assemble → Sum”
Space: write the sample space S (all outcomes).Assemble: collect the outcomes that satisfy event A.Sum: add their probabilities: P(A) = Σ P(ω) for ω ∈ A.

TOPIC8

EQUALLY LIKELY OUTCOMES (CLASSICAL PROBABILITY)

1Definition & Introduction

  • Equally likely outcomes: each elementary outcome ωi in S has the same probability.
  • If S has n outcomes, then P(ωi)=p for all i and np=1.
  • Hence p=1/n; every simple event has probability 1n.
  • For an event E with m favourable outcomes, P(E)=m/n.
  • Favourable outcomes = outcomes in E; total outcomes = outcomes in S.

2Diagram

Flow: equal chances + counting outcomes ⇒ classical probability formula.


3Key Concepts

  • ⚖️Equal chance means P(ω1)=P(ω2)=…=P(ωn).
  • 🧩Counting converts probability to a ratio: favourable ÷ total (only for equal likelihood).
  • 🔢Write S first, then count n(S) and n(E); reduce the fraction.
  • ✅Classical formula needs: finite S and equally likely outcomes.

4DERIVATION (FINITE EQUALLY LIKELY SAMPLE SPACE)

  • Let S = {ω1, …, ωn} with P(ωi)=p for all i.
  • Since P(S)=1, we have P(ω1)+…+P(ωn)=1.
  • So np=1 ⇒ p=1/n; each outcome has probability 1n.
  • If event E contains m outcomes, then P(E)=m×(1/n)=m/n.

5WHEN YOU MAY / MAY NOT USE m/n

  • Use m/n only when outcomes are equally likely and S is finite.
  • If outcomes have different probabilities, use P(E)=∑P(ω) over ω ∈ E.
  • In dice/coins/cards, equal likelihood is valid only with fair objects and proper shuffling.

8Solved Examples

1
A fair die is thrown once. Find the probability of getting a prime number.
Solution:
Sample space: S={1,2,3,4,5,6} so n(S)=6 (equally likely).
Event E: prime number ⇒ E={2,3,5} so n(E)=3.
Use classical formula: P(E)=n(E)n(S)=36=12.
✓  P(prime) = 12
2
A bag has 4 red, 3 blue, 2 yellow identical discs. One disc is drawn at random. Find P(not blue) and P(red or blue).
Solution:
Total outcomes n(S)=4+3+2=9 (each disc equally likely).
Let C be event “blue”: n(C)=3 ⇒ P(C)=39=13.
So P(not blue)=1−P(C)=1−13=23.
Let A be “red” and C be “blue”. Then n(A)=4, n(C)=3 and A,C are disjoint.
P(red or blue)=n(A)+n(C)n(S)=4+39=79.
✓  P(not blue)=23, P(red or blue)=79

9⭐Important Points

  • Equal likelihood implies uniform elementary probability p across all ωi.
  • np=1 comes from P(S)=1 and additivity over distinct outcomes.
  • Classical formula is counting-based: P(E)=favourable/total.
  • Always verify S is finite; otherwise m/n is meaningless.
  • In JEE/boards, most errors are due to wrong sample space size n(S).

10❌Common Mistakes

  • Using m/n even when outcomes are not equally likely (biased coin, unequal selection).
  • Counting favourable outcomes correctly but using wrong total outcomes n(S).
  • Mixing up event size: writing n(E) as number of events instead of outcomes.
  • For multi-step experiments, forgetting to use ordered pairs/tuples in S.

TOPIC9

ADDITION AND COMPLEMENT RULES

1Definition & Introduction

  • Addition (2 events): P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
  • Mutually exclusive case: if A ∩ B = φ, then P(A ∪ B) = P(A) + P(B).
  • Complement rule: P(A′) = 1 − P(A), where A′ = S − A.
  • Always true (set identities): A ∪ A′ = S and A ∩ A′ = φ.
  • Three-event extension (statement): P(A ∪ B ∪ C) follows inclusion–exclusion: add singles, subtract pairwise overlaps, add the triple overlap.
  • De Morgan's laws: (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′.

2Diagram

Venn idea: A ∪ B includes both circles; the overlap A ∩ B must not be counted twice.

3Key Concepts

  • +Union adds but corrects double counting: subtract the overlap once.
  • XMutually exclusive means no common outcomes: A ∩ B = φ.
  • 1-Complement means "not": P(A′) equals 1 minus P(A).
  • DMDe Morgan: "not (or)" becomes "and of nots"; "not (and)" becomes "or of nots".
  • IEInclusion–exclusion for 3 events prevents double and triple counting.

4WHY THE ADDITION RULE SUBTRACTS THE OVERLAP

  • Split A into disjoint parts: (A − B) and (A ∩ B).
  • Split B into disjoint parts: (B − A) and (A ∩ B).
  • Then A ∪ B is the disjoint union of: only-A, overlap, only-B.
  • Adding P(A) and P(B) counts the overlap twice; subtract it once.

5THREE EVENTS: INCLUSION–EXCLUSION (IDEA ONLY)

  • Add P(A), P(B), P(C): pairwise overlaps get counted twice.
  • Subtract all pairwise overlaps to fix double counting.
  • Now the triple overlap got removed too many times; add it back once.

6Special cases to recognise fast

7Solved Q&A

1
Why is P(A ∪ B) not always equal to P(A) + P(B)?
Answer:
If A and B can occur together, outcomes in A ∩ B are included in both A and B.
So adding P(A) and P(B) double-counts the overlap.
To correct this, subtract P(A ∩ B) once.
✓  Because overlap outcomes are counted twice unless you subtract P(A ∩ B).
2
How do you find probability of "neither A nor B" using the complement rule?
Answer:
"Neither A nor B" means the complement of "A or B".
So the event is (A ∪ B)′.
Hence P(neither) = 1 − P(A ∪ B).
✓  P(neither A nor B) = 1 − P(A ∪ B).

8⭐Important Points

  • For any event A: 0 ≤ P(A) ≤ 1; also P(φ)=0 and P(S)=1.
  • Use the subtraction term −P(A ∩ B) when A and B may overlap.
  • Mutually exclusive means intersection is φ; independent events are different and may overlap.
  • Complement shortcut: convert "not" to 1 minus the required probability.
  • De Morgan's laws help rewrite complements of unions/intersections.

9❌Common Mistakes

  • Using P(A ∪ B) = P(A) + P(B) without checking overlap.
  • Confusing mutually exclusive with independent.
  • Writing P(A′) = 1/P(A) or forgetting the minus sign.
  • Applying De Morgan incorrectly: taking (A ∪ B)′ as A′ ∪ B′.

10💡Memory Technique

“ADD–SUB–ADD (Inclusion–Exclusion rhythm)”
For 2 events: Add singles, Sub the overlap once.For 3 events: Add singles, Sub pairwise overlaps, Add triple overlap.Complement: "Not" means "1 minus".
