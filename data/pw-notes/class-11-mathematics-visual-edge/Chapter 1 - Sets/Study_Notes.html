TOPIC1

SET CONCEPT BASICS

1Definition & Introduction

  • Set = a well-defined collection of objects where membership can be decided clearly.
  • Objects in a set are called elements or members (synonyms).
  • Sets are usually named by capital letters A, B, C, X, Y, Z; elements by small letters a, b, c, x, y.
  • Membership: a ∈ A means “a belongs to A”; a ∉ A means “a does not belong to A”.
  • Not well-defined: collections based on opinion (e.g., “most renowned mathematicians”).

2Diagram

3Key Concepts

  • 🎯Well-defined means: for any object, membership is decidable (YES/NO).
  • 🔤Naming rule: capital letters for sets; small letters for elements.
  • ∈Membership symbols: ∈ (belongs to), ∉ (does not belong to).
  • 🔢Standard sets: N, Z, Q, R and their positive parts Z+, Q+, R+.

4STANDARD NUMBER SETS (YOU MUST KNOW)

  • N: natural numbers {1, 2, 3, …}.
  • Z: integers {…, −2, −1, 0, 1, 2, …}.
  • Q: rational numbers x = pq, where p, q ∈ Z and q ≠ 0.
  • R: real numbers (all rational and irrational numbers).
  • Z+, Q+, R+: positive integers, positive rationals, positive reals.

5WELL-DEFINED vs NOT WELL-DEFINED (EXAM TRAP)

  • Well-defined: “odd natural numbers less than 10” → membership is decidable.
  • Well-defined: “prime factors of 210” → {2, 3, 5, 7}.
  • Not well-defined: “ten most talented writers” → criteria differs across people.
  • Not well-defined: “best cricket batsmen” → depends on opinion/era.

8⭐Important Points

  • A set is defined by clarity of membership, not by size or ordering.
  • Use ∈ and ∉ only between an element and a set.
  • Remember standard symbols: N, Z, Q, R and positive parts Z+, Q+, R+.
  • In Q, denominator must satisfy q ≠ 0.
  • Capital letters denote sets; small letters denote elements (typical exam convention).

9❌Common Mistakes

  • Writing 3 ∈ Z+ but forgetting Z+ excludes 0 and negatives.
  • Confusing subset symbol with membership: writing A ∈ B instead of A ⊂ B.
  • Thinking a collection with opinions (best, most beautiful) is a set.
  • Forgetting that in Q, q cannot be 0.

TOPIC2

SET REPRESENTATIONS

1Definition & Introduction

  • Representation of a set means writing its elements either by listing or by a property.
  • Roster/tabular form: list elements inside braces { } separated by commas.
  • In roster form, order is immaterial: {1,3,5} = {5,3,1}.
  • In a set, no repetition: {2,2,3,3} represents the same set as {2,3}.
  • Set-builder form: {x : property of x}; ":" is read as such that.
  • Dots ... in roster form indicate a continuing pattern, often infinite.

2Diagram

3Key Concepts

  • 🧾Roster form uses { } and commas: write all distinct elements (or a clear pattern with ...).
  • 🧬Set-builder form states a characteristic property satisfied by exactly the members.
  • 🔤Read {x : condition} as "set of all x such that condition holds".
  • 🔁Equality check: same elements only; order and repetition do not matter.
  • 🎯While converting builder→roster, list only values that satisfy all given conditions.

4ROSTER (TABULAR) FORM: RULES

  • Write as {a, b, c, ...}; elements separated by commas and enclosed in { }.
  • Order irrelevant: {1,2,3} = {3,2,1}.
  • Repetition ignored: {A,L,L,O,Y} represents {A,L,O,Y}.
  • Use ... only when the pattern is unambiguous: {1,3,5,...}.

5SET-BUILDER FORM: HOW TO WRITE + CONVERT

  • General form: {x : condition on x}; choose a suitable universe (e.g., x ∈ N or Z).
  • Write a characteristic property: true for members, false for non-members.
  • Convert builder→roster by listing all distinct elements that satisfy the stated domain and condition.
  • Convert roster→builder by spotting a rule (e.g., squares, divisors, interval, equation solutions).

7Solved Q&A

1
Convert to roster form: S = {x : x is an integer and x2 + x − 2 = 0}.
Answer:
Understand the statement: S contains exactly those integers x which satisfy the given equation.
Find which integer values make the equation true (i.e., the integer solutions).

Answer:
Domain is positive integers; start checking from 1 upward.
Include each x that satisfies x2 < 40; stop once x2 is no longer < 40.
List all satisfying x in roster form without repetition.
✓  A = {1, 2, 3, 4, 5, 6}

8⭐Important Points

  • Always use braces { } for a set; ( ) usually denotes an ordered pair/interval, not a set.
  • In roster form, do not repeat elements; repetition does not create a new set.
  • Order does not matter for sets; equality is based only on membership.
  • In set-builder form, state the domain when needed (e.g., x ∈ N, Z, R).
  • ":" is read as such that; braces mean set of all.

9❌Common Mistakes

  • Treating {1,2,3} and {3,2,1} as different sets due to order change.
  • Repeating elements in roster form and thinking it changes the set.
  • Writing a vague set-builder property (not well-defined), or missing the domain.
  • Misreading ":" as division or ratio instead of "such that".

TOPIC3

EMPTY SET

1Definition & Introduction

  • Empty (null/void) set: a set that contains no elements.
  • Notation: ∅ or { }.
  • Meaning: for every object x, x ∉ ∅.
  • Occurs when the condition in set-builder form is impossible to satisfy (in the stated domain).
  • Empty set is a set, not “nothing”; it is a specific object in set theory.

2Diagram

3Key Concepts

  • IdeaIn set-builder form {x : condition}, if no x satisfies the condition → empty set.
  • RostRoster form of empty set has no listed elements: { }.
  • TestTo test emptiness, try to find at least one element; if none exists (in the given domain), set = ∅.
  • WarnDo not confuse ∅ with {∅}; {∅} has one element (the empty set) and is not empty.
  • SourTypical sources: contradictory conditions, impossible inequalities, or solutions excluded by domain restrictions (like Q or N).

4WHEN DOES A SET BECOME EMPTY?

  • When the defining condition is contradictory (cannot be true together).
  • When an inequality leaves no allowed values in the given domain.
  • When an equation has solutions, but none in the required set (like Q or N).
  • When a property is impossible (e.g., even prime greater than 2).

5CLASSIC EXAM EXAMPLES (FROM SET-BUILDER FORM)

  • A = {x : 1 < x < 2, x ∈ N} ⇒ A = ∅ (no natural number between 1 and 2).
  • B = {x : x2 − 2 = 0, x ∈ Q} ⇒ B = ∅ (±√2 are irrational).
  • C = {x : x is an even prime > 2} ⇒ C = ∅ (2 is the only even prime).
  • D = {x : x2 = 4, x is odd} ⇒ D = ∅ (solutions ±2 are even).

7Solved Q&A

1
Decide whether the set S = {x : x is a natural number and 1 < x < 2} is empty.
Answer:
Natural numbers are 1, 2, 3, ...
There is no natural number strictly between 1 and 2.
So, no element satisfies the condition.
✓  S = ∅ (empty set).
2
True/False with reason: (i) ∅ ∈ {∅} (ii) ∅ ⊆ {∅}
Answer:
(i) {∅} has exactly one element, namely ∅; hence ∅ ∈ {∅} is true.
(ii) A set A is a subset of B if every element of A is an element of B.
Since ∅ has no elements, the statement “every element of ∅ is in {∅}” is vacuously true.
Hence ∅ ⊆ {∅} is true.
✓  (i) True (ii) True.

8⭐Important Points

  • Empty set means zero elements, not an unknown element.
  • Notation ∅ and { } represent the same set.
  • Many “solution sets” become empty after applying domain restrictions like N or Q.
  • If a condition is impossible, the set in set-builder form equals ∅.
  • ∅ is a subset of every set (because it has no elements).

9❌Common Mistakes

  • Writing ∅ = {0} or thinking the empty set contains 0.
  • Confusing ∈ (element) with ⊆ (subset), especially with ∅ and {∅}.
  • Assuming x2 − 2 = 0 has no solution; it has solutions in R but not in Q.
  • Calling a collection empty without checking the given domain (natural/integer/rational/real).

10💡Memory Technique

TOPIC4

FINITE AND INFINITE SETS

1Definition & Introduction

  • Finite set: a set that is empty (φ) or has a definite number of distinct elements; then n(S) is a whole number (0,1,2,...).
  • Infinite set: a set that is not finite; it has infinitely many distinct elements, so n(S) is not finite.
  • In counting elements of a set, repeated entries do not change the set; only distinct elements matter.
  • Some infinite sets can be partially written in roster form using dots … to show continuation of a clear pattern.
  • Some infinite sets (e.g., R, real numbers) cannot be meaningfully written in roster form because there is no single listing pattern that captures all elements.

2Diagram

3Key Concepts

  • KC1n(S) denotes the number of distinct elements in a set S (this count is defined as a whole number for finite sets).
  • KC2Roster form reminders: order does not matter, and elements are not repeated; e.g., letters in "SCHOOL" form {S, C, H, O, L}.
  • KC3Roster form for patterned infinite sets uses a visible rule + dots: {1,2,3,…}, {1,3,5,…}, {…,-2,-1,0,1,2,…}.
  • KC4Solution sets of equations can be finite or empty; the empty set φ is finite by definition.
  • KC5Geometric example: the set of points on a line or line segment is infinite.

4HOW TO DECIDE: FINITE vs INFINITE (EXAM CHECKLIST)

  • If elements can be completely counted (or the set is empty), the set is finite.
  • If the description generates endlessly many distinct values (like primes or odd numbers), the set is infinite.
  • If it is “points on a line/segment/interval”, it is infinite.
  • For many standard school equations, the solution set may be finite or empty; both cases are finite sets.
  • Roster hint: dots … often suggest infinity, but only if the pattern is clear.

5LISTING IN ROSTER FORM: WHEN IT WORKS AND WHEN IT FAILS

  • Works for patterned infinite sets: N = {1,2,3,…}, odd naturals = {1,3,5,…}, Z = {…,-2,-1,0,1,2,…}.
  • Fails for sets without a single roster pattern: R (all real numbers) cannot be expressed as a complete roster list.
  • Even (0,1) contains infinitely many real numbers; writing a few decimals does not represent the entire set.
  • Use set-builder form for such sets: (0,1) = {x : 0 < x < 1, x ∈ R}.

Classify S = {x ∈ N : (x−1)(x−2)=0} as finite or infinite. Also write S in roster form.
Answer:
This set contains natural numbers x that satisfy (x−1)(x−2)=0.
The condition is true exactly when x=1 or x=2.
So the set is S = {1,2}, which has a definite (countable) number of distinct elements.
✓  S is finite; in roster form, S = {1,2}.

8⭐Important Points

  • Finite includes the empty set φ; by definition, φ is finite.
  • n(S) counts distinct elements only; repetition does not change a set.
  • Infinite sets cannot be completely listed in roster form.
  • Dots … in roster form are valid only when they indicate a clear, continuing rule.
  • Sets like primes/odd naturals are infinite because the pattern never ends.

9❌Common Mistakes

  • Thinking φ is neither finite nor infinite; by definition it is finite.
  • Counting repeated elements as extra elements (e.g., treating {A,L,L,O,Y} as 5 distinct elements).
  • Assuming any set written with dots … is automatically correct without stating/seeing the pattern.
  • Trying to roster-list R or (0,1) by writing a few numbers; that never captures all elements.

TOPIC5

EQUAL SETS

1Definition & Introduction

  • Two sets A and B are equal iff they have exactly the same elements.
  • Formally: every element of A is in B and every element of B is in A.
  • Write A = B for equal sets; write A ≠ B for unequal sets.
  • Order is irrelevant: {1,2,3,4} = {3,1,4,2}.
  • Repetition does not matter: {1,2,3} = {2,2,1,3,3}.
  • Equality depends only on membership (which elements belong), not on how the set is written.

2Diagram

3Key Concepts

  • 🔁Order of listing never affects a set in roster form.
  • ♻️Repeated elements are ignored: sets contain distinct elements.
  • 🔍Test for equality: check mutual inclusion (A ⊆ B and B ⊆ A).
  • ✍️Same set can be written in roster or set-builder form; equality compares the resulting elements.
  • 🚫One extra/missing element makes sets unequal, even if most elements match.

4TEST FOR EQUALITY (EXAM-FRIENDLY)

  • Step 1: List elements (or describe clearly) for both sets.
  • Step 2: Check every element of A is in B (i.e., A ⊆ B).
  • Step 3: Check every element of B is in A (i.e., B ⊆ A).
  • Conclusion: A = B iff A ⊆ B and B ⊆ A.
  • Fast disproof: find just one element in one set not in the other.

5SET-BUILDER TO ROSTER: QUICK CHECKS

  • When a set is given by a condition, list all values that satisfy it (within stated domain).
  • Example: x2 ≤ 4 over integers gives {−2,−1,0,1,2}.
  • If two descriptions generate the same roster, the sets are equal.
  • Empty set: impossible conditions give φ (also written as { }).

1

Answer:
Prime numbers less than 6 are 2, 3, 5; so A = {2,3,5}.
Prime factorisation: 30 = 2 × 3 × 5, so prime factors are 2, 3, 5; hence P = {2,3,5}.
Both sets have exactly the same elements ⇒ A = P.
✓  A = P = {2,3,5}

Answer:

8⭐Important Points

  • To prove A = B, show A ⊆ B and B ⊆ A.
  • Order of elements never affects equality: {a,b,c} = {c,b,a}.
  • Repeating an element does not create a new set.
  • If even one element differs, sets are unequal: 0 ∈ A but 0 ∉ B ⇒ A ≠ B.
  • Convert set-builder forms to roster (when finite) to compare quickly.

9❌Common Mistakes

  • Treating {1,2,3} and {1,2,3,3} as different sets.
  • Assuming same number of elements implies equality (it does not).
  • Missing domain restrictions in set-builder form (integers vs reals).
  • Comparing order as if it matters in roster form.

SUBSETS AND PROPER SUBSETS

1Definition & Introduction

  • Subset: A is a subset of B if every element of A is in B.
  • Symbolically: A ⊂ B means for all a, a ∈ A ⇒ a ∈ B.
  • A ⊄ B means there exists an element a with a ∈ A and a ∉ B.
  • Every set is a subset of itself: A ⊂ A (reflexive property).
  • Empty set has special status: φ ⊂ A for every set A (vacuous truth).
  • Proper subset: A is a proper subset of B if A ⊂ B and A ≠ B.

2Diagram

3Key Concepts

  • ✅Test for ⊂: try to find any element of A missing from B; one counterexample proves ⊄.
  • 🔁Mutual containment: A ⊂ B and B ⊂ A iff A = B.
  • 🕳️φ has no elements, so the implication a ∈ φ ⇒ a ∈ A is always true.
  • ⬆️Superset: if A ⊂ B, then B is a superset of A (written B ⊃ A).
  • 1️⃣Singleton set: a set with exactly one element, e.g. {a}.

4LOGIC BEHIND ⊂ AND ⊄ (WHAT TO CHECK)

  • To prove A ⊂ B: pick an arbitrary a ∈ A and show a ∈ B.
  • To prove A ⊄ B: find one element a with a ∈ A but a ∉ B.
  • Key statement: A ⊂ B ⇔ for all a, (a ∈ A ⇒ a ∈ B).
  • A ⊄ B ⇔ there exists a with (a ∈ A and a ∉ B).
  • Equality via subsets: if A ⊂ B and B ⊂ A, then A = B.

5PROPER SUBSET, SUPERSET, SINGLETON, AND φ

  • Proper subset: A ⊂ B and A ≠ B (written often as A ⊊ B if allowed).
  • Superset: B ⊃ A means every element of A lies in B.
  • Singleton set: {a} has one element; do not confuse with element a.
  • Always true: φ ⊂ A and A ⊂ A.
  • Not always: φ ∈ A (true only if empty set is an element of A).

1

Answer:
(i) φ has no elements, so φ ⊂ B.
(ii) Check element 3: 3 ∈ A but 3 ∉ B ⇒ A ⊄ B.
(iii) 1 and 3 are both in C ⇒ A ⊂ C.
(iv) Elements of B are 1,5,9 and all lie in C ⇒ B ⊂ C.
✓  (i) φ ⊂ B (ii) A ⊄ B (iii) A ⊂ C (iv) B ⊂ C
2
If A ∈ B and B ⊂ C, is it always true that A ⊂ C? Give a counterexample if false.
Answer:
Take A = {1}.
Let B = {{1}, 2} so that A ∈ B (since {1} is an element of B).
Let C = {{1}, 2, 3}. Then B ⊂ C is true.
But A ⊄ C because 1 ∈ A, yet 1 ∉ C (only {1} is in C, not 1).
✓  No. Example: A={1}, B={{1},2}, C={{1},2,3}; then A ∈ B, B ⊂ C, but A ⊄ C.

8⭐Important Points

  • To test A ⊂ B, verify every element of A appears in B.
  • To show A ⊄ B, one missing element of A is enough (counterexample).
  • Always true: A ⊂ A and φ ⊂ A for any set A.
  • If A ⊂ B and B ⊂ A, then and only then A = B.
  • Proper subset requires inequality: A ⊂ B plus A ≠ B.

9❌Common Mistakes

  • Confusing symbols: writing a ⊂ A instead of a ∈ A.
  • Assuming A ⊂ B implies A ≠ B; but A ⊂ A is true.
  • Thinking φ ∈ A is always true; actually only φ ⊂ A is always true.
  • Mixing up {a} and a; singleton set is not the element itself.

TOPIC7

NUMBER SET SUBSETS

1Definition & Introduction

  • Real numbers R contain all rational and irrational numbers.
  • Natural numbers N = {1,2,3,...}; counting numbers (as used in this chapter).
  • Integers Z = {...,−2,−1,0,1,2,...}; includes negatives and 0.
  • Rational numbers Q = {x : x = pq, p,q ∈ Z, q ≠ 0}; terminating or repeating decimals.
  • Irrational numbers are real numbers that are not rational; they form R − Q.
  • Inclusion chain: N ⊂ Z ⊂ Q ⊂ R, and R − Q ⊂ R with Q ∩ (R − Q) = ϕ.

2Diagram

3Key Concepts

  • 🧩Every natural number is an integer; every integer is a rational; every rational is real.
  • ➗Rational form: x = pq with p,q ∈ Z and q ≠ 0; integers fit by taking q=1.
  • 🚫Irrationals cannot be written as pq; their decimals are non-terminating and non-repeating (e.g., √2, π).
  • 🔁Rationals have terminating or repeating decimals (e.g., 0.125, 0.3̅).
  • 🧠Set difference: R − Q means “all real numbers except rationals” (the irrational numbers).
  • 🔍Disjoint inside R: Q ∩ (R − Q) = ϕ and Q ∪ (R − Q) = R.

4INCLUSION & EXCLUSION FACTS (EXAM FAVOURITES)

  • N ⊂ Z ⊂ Q ⊂ R and each inclusion is proper (strict).
  • R − Q is the set of irrationals; so every irrational is real but not rational.
  • Q ∩ (R − Q) = ϕ (no number is both rational and irrational).
  • Q ∪ (R − Q) = R (every real is either rational or irrational).
  • N ⊄ (R − Q) since 1 ∈ N but 1 ∉ (R − Q).

5STANDARD MEMBERS & NON-MEMBERS

  • Integers as rationals: −5 = −51, 3 = 31 so Z ⊂ Q.
  • Fractions: 72 ∈ Q; decimals like 2.75 ∈ Q (terminating).
  • Repeating decimals are rational: 0.6̅ = 23.
  • Typical irrationals: √2, √5, π ∈ (R − Q); also √(perfect square) is rational (e.g., √9 = 3).
  • If q = 0, pq is undefined; so it is excluded in the definition of Q.

INTERVALS IN REAL NUMBERS

1Definition & Introduction

  • Interval is a subset of R containing all real numbers between two endpoints.
  • Let a, b ∈ R with a < b; endpoints may be included or excluded.
  • Open uses parentheses: ( a, b ) excludes a and b.
  • Closed uses brackets: [ a, b ] includes both endpoints.
  • Half-open: [a,b) includes a only; (a,b] includes b only.
  • For finite endpoints, all of ( a, b ), [ a, b ], [ a, b ), ( a, b ] have the same geometric length because endpoints are the same.

2Diagram

3Key Concepts

  • 🔁Conversion key: < means open end, ≤ means closed end.
  • ♾️Infinity is never included: always (−∞, …) or (…, ∞).
  • 🧭Number line view: filled dot = included, hollow dot = excluded.
  • 📦Intervals contain infinitely many real numbers, so avoid roster listing.

4TYPES OF INTERVALS (ENDPOINT RULES)

  • (a,b) = {x ∈ R : a < x < b} (both excluded).
  • [a,b] = {x ∈ R : a ≤ x ≤ b} (both included).
  • [a,b) = {x ∈ R : a ≤ x < b} (left included).
  • (a,b] = {x ∈ R : a < x ≤ b} (right included).
  • [0,∞) = non-negative reals; (−∞,0) = negative reals; (−∞,∞) = R.

5CONVERSION + LENGTH (CONCEPT)

  • From set-builder to interval: strict inequality gives ( ), equality allowed gives [ ].
  • Keep endpoints the same; only brackets/parentheses change.
  • Pattern: {x ∈ R : −5 < x ≤ 7} corresponds to (−5, 7].
  • For finite endpoints, length depends only on endpoints, not on inclusion/exclusion.
  • Intervals with ±∞ are unbounded, so they do not have a finite length.

7Solved Q&A

1
Convert {x ∈ R : −4 < x ≤ 6} to interval notation.
Answer:
Left condition −4 < x means −4 is excluded, so use ( at −4.
Right condition x ≤ 6 means 6 is included, so use ] at 6.
Therefore the interval is (−4, 6].
✓  Interval notation: (−4, 6].
2
Write the interval [−3, 5) in set-builder form.
Answer:
Left bracket [ means include −3, so −3 ≤ x.
Right parenthesis ) means exclude 5, so x < 5.
Combine the conditions with x ∈ R.
✓  Set-builder form: {x ∈ R : −3 ≤ x < 5}.

8⭐Important Points

  • In set-builder form for real intervals, write x ∈ R unless another domain is intended.
  • At each endpoint: ≤ or ≥ corresponds to a square bracket; < or > corresponds to a round bracket.
  • Write endpoints in increasing order: left endpoint first, right endpoint second.
  • Including or excluding endpoints changes membership but not the endpoint locations on the number line.
  • ∞ and −∞ are not real numbers; never use a square bracket with infinity.

9❌Common Mistakes

  • Including ∞ with a bracket, e.g. [0,∞] (wrong); must be [0,∞).
  • Reversing an inequality when rewriting: writing x ≤ −3 instead of −3 ≤ x.
  • Using [ or ] with a strict inequality sign (< or >).
  • Confusing integer counting in an interval with the interval itself (real-number membership).

10💡Memory Technique

UNIVERSAL SET AND VENN DIAGRAMS

1Definition & Introduction

  • Universal set U is the basic set of all objects allowed in a given context.
  • All sets discussed in that context (A, B, C, …) are taken as subsets of U.
  • In Venn diagrams, U is drawn as a rectangle; subsets are drawn as closed curves (usually circles).
  • An element is shown by writing it inside the region of the set it belongs to.
  • If B is inside A (both inside U), it represents B ⊂ A.

2Diagram

3Key Concepts

  • 🌍U depends on context: numbers context vs students context changes U.
  • ⭕Closed curve shows a set; points/elements are placed in the correct region.
  • 📦Rectangle boundary matters: nothing outside rectangle belongs to U.
  • 🧠Diagram test: B ⊂ A means every element of B must lie in A.
  • ✍️Do not confuse ∈ (element of) with ⊂ (subset of).

4HOW TO CHOOSE THE UNIVERSAL SET (U)

  • Step 1: Identify the context (numbers, people, triangles, etc.).
  • Step 2: Pick a basic set that contains all sets under discussion.
  • A proposed U is valid only if A ⊂ U, B ⊂ U, C ⊂ U, …
  • Same set can have multiple possible universes: integers can sit inside Q or R.

5READING A VENN DIAGRAM (SUBSET FOCUS)

  • If a circle lies completely inside another, the inner set is a subset of the outer set.
  • To verify B ⊂ A, check every written element of B lies in region of A.
  • Elements written in the rectangle but outside all circles belong to U but to none of those subsets.
  • If a point is outside U (outside rectangle), it is not allowed in the context.

UNION, INTERSECTION & DIFFERENCE OF SETS

1Definition & Introduction

  • Union: A ∪ B = {x : x ∈ A or x ∈ B} (in A or B or both).
  • Intersection: A ∩ B = {x : x ∈ A and x ∈ B} (common elements only).
  • Difference: A − B = {x : x ∈ A and x ∉ B} (in A, not in B).
  • Venn idea: ∪ covers both circles, ∩ covers overlap, A − B covers left-only.
  • Disjoint sets: A and B disjoint ⇔ A ∩ B = φ.
  • Non-commutativity: generally A − B ≠ B − A.

2Diagram

3Key Concepts

  • 1A ∪ B contains every element that is in A or in B.
  • 2A ∩ B contains only elements common to both sets.
  • 3A − B means “start with A, remove elements that are in B”.
  • 4If A ∩ B = φ, the sets are disjoint; they share no elements.
  • 5∪ and ∩ are commutative and associative; difference is neither.

4KEY PROPERTIES (EXAM-FAVOURITES)

  • Commutative: A ∪ B = B ∪ A; A ∩ B = B ∩ A.
  • Associative: (A ∪ B) ∪ C = A ∪ (B ∪ C); similarly for ∩.
  • Distributive: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C).
  • Distributive: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C).
  • Identity & idempotent: A ∪ φ = A, A ∩ φ = φ; also A ∪ A = A, A ∩ A = A.

5DIFFERENCE: QUICK TRANSFORMS

  • Using complement: A − B = A ∩ Bc (complement in U).
  • Partition of A: A = (A − B) ∪ (A ∩ B), and the parts are disjoint.
  • Subset test: A ⊆ B ⇔ A − B = φ.
  • Not commutative: A − B and B − A usually differ.

  • Use distributive laws to simplify expressions with both ∪ and ∩.

  • Including overlap elements in A − B; overlap must be excluded.

  • Repeating elements while listing a set in roster form.

COMPLEMENT AND DE MORGAN LAWS

1Definition & Introduction

  • Complement of A (w.r.t. U) is A′ = {x : x ∈ U and x ∉ A}.
  • Equivalently, A′ = U − A (elements in U but not in A).
  • Complement depends on the chosen universal set U; changing U can change A′.
  • Two basic complement laws: A ∪ A′ = U and A ∩ A′ = φ.
  • Double complement: (A′)′ = A (w.r.t. the same U).

2Diagram

Venn idea: A′ is the part of U outside A (i.e., U − A).

3Key Concepts

  • 🎯Always state U first: complement is meaningless without a universal set.
  • 🧠A′ flips membership: in A becomes out of A, but still inside U.
  • 🔁De Morgan: complement of union becomes intersection of complements; and vice-versa.
  • 🧩Use De Morgan to simplify complements of brackets: push ′ inside and swap ∪, ∩.

4CORE LAWS (EXAM FAVOURITES)

  • Complement laws: A ∪ A′ = U and A ∩ A′ = φ.
  • Double complement: (A′)′ = A (must be w.r.t. same U).
  • Boundary cases: φ′ = U and U′ = φ.
  • If A ⊂ B, then B′ ⊂ A′ (inclusion reverses under complement).

5DE MORGAN’S LAWS (HOW TO APPLY FAST)

  • (A ∪ B)′ = A′ ∩ B′ (swap ∪ to ∩, complement each).
  • (A ∩ B)′ = A′ ∪ B′ (swap ∩ to ∪, complement each).
  • For 3 sets: (A ∪ B ∪ C)′ = A′ ∩ B′ ∩ C′.
  • For nested brackets, apply from outermost ′ inward, swapping operations each time.

7Solved Q&A

1
Why is it necessary to specify the universal set U before writing a complement A′?
Answer:
A′ means “elements not in A but still inside U”.
If U changes, the pool of allowed elements changes, so the complement set can change even if A stays the same.
Hence, without U, A′ is not uniquely defined.
✓  Because complement is defined relative to U; different choices of U generally give different complements.
2
Explain (without listing elements) why (A ∪ B)′ = A′ ∩ B′.
Answer:
Take any element x in U.
x ∈ (A ∪ B)′ means x is not in (A ∪ B).
Not being in the union means x is in neither A nor B.
So x ∈ A′ and x ∈ B′, i.e. x ∈ A′ ∩ B′.
The reverse direction follows by the same logic, so the sets are equal.
✓  An element lies outside the union exactly when it lies outside A and outside B, i.e. it lies in both complements.

8⭐Important Points

  • Complement is always taken relative to U; mention U in questions.
  • A′ = U − A is the fastest form in roster/set-difference questions.
  • A and A′ are disjoint: A ∩ A′ = φ; together they cover U.
  • Double complement holds only for the same U: (A′)′ = A.
  • De Morgan swaps ∪ and ∩ while complementing each set inside brackets.

9❌Common Mistakes

  • Forgetting to specify U and writing a wrong complement set.
  • Treating A′ as “not in A anywhere” instead of “not in A but in U”.
  • Using De Morgan without swapping the operator (keeping ∪ as ∪, or ∩ as ∩).
  • Writing (A ∪ B)′ = A′ ∪ B′ (incorrect).
