SEQUENCES AND SERIES

TOPIC1

BASICS OF SEQUENCES

1Definition & Introduction

  • A sequence is an ordered list of numbers given by a rule: a1, a2, a3, …
  • The numbers in the list are called terms; the subscript shows the position of the term.
  • The nth term (or general term) is the term at position n, written an.
  • A sequence can be viewed as a function a(n) with domain natural numbers (or a subset like {1,2,…,k}).
  • A sequence is finite if it has a last term; it is infinite if it continues without end.

2Diagram

Index n (natural number) maps to the term an via a rule.


3Key Concepts

  • 📌Order matters: 2,4,8,… is different from 4,2,8,…
  • 🧩The notation an means the term at position n.
  • ♾️Finite vs infinite depends on whether the index set ends (like n=1 to 10) or not.
  • 🔁A recurrence defines a term using earlier term(s), so initial term(s) are essential.
  • 🗣️Some sequences have no simple nth-term formula (e.g., primes); they can be defined verbally.

4WAYS TO DEFINE A SEQUENCE

  • Explicit (formula): gives an directly as a rule depending on n (e.g., even numbers in order).
  • Recurrence: gives initial term(s) and tells how to get the next term from previous term(s).
  • Verbal rule: describes the sequence in words (e.g., primes in increasing order).
  • A recurrence is incomplete without initial conditions (like a1, a2).

5FINITE VS INFINITE (INDEX SET IDEA)

  • Finite: indices are {1,2,…,k} so the last term is ak.
  • Infinite: indices are N={1,2,3,…} so there is no last term.
  • Example (finite): ancestors over 10 generations: 2,4,8,…,1024.
  • Example (infinite): successive quotients in 10÷3: 3, 3.3, 3.33, 3.333, …

7Solved Q&A

1
A student says: "A sequence is the same as a set." Is this correct?
Answer:
A set is an unordered collection; order does not matter in a set.
A sequence is ordered; the position (subscript) matters.
So (2,4,8,...) and (4,2,8,...) are different sequences even if they contain the same numbers.
✓  Not correct. A sequence is ordered; a set is unordered.
2
Why are initial terms necessary in a recurrence definition?
Answer:
A recurrence tells how to get a new term from earlier term(s).
Without a starting term (like a1), the rule alone cannot produce a unique list.
Different starting values lead to different sequences even with the same recurrence relation.
✓  Because the recurrence needs a starting point; otherwise the sequence is not uniquely determined.

8⭐Important Points

  • Sequence vs set: sequence is ordered; repetition allowed (e.g., 1,1,2,…).
  • General term means the term at position n, written an.
  • In a recurrence, always state starting term(s); otherwise the sequence is not uniquely fixed.
  • Finite sequence usually has domain {1,2,…,k}; infinite sequence has domain N.
  • Use a(n) and an for the same idea: the term corresponding to index n.

9❌Common Mistakes

  • Treating a sequence like an unordered set and ignoring position/subscripts.
  • Changing the starting index (like taking n=0) when the domain is stated as N={1,2,3,…}.
  • For recurrence, forgetting that terms are generated in order from the initial term(s).
  • Confusing an (term) with n (position).

10💡Memory Technique

“FIR: Formula–Initial–Rule”
To define a sequence, look for: Formula (explicit) OR Initial terms + Recurrence.If neither is available, expect a verbal rule (like primes).Always attach the index set: {1,…,k} (finite) or N (infinite).
TOPIC2

FIBONACCI AND RECURRENCE

1Definition & Introduction

  • Recurrence relation: a rule that defines an using earlier terms like an−1, an−2, etc.
  • To generate a sequence uniquely, initial term(s) (starting values) must be given.
  • Fibonacci sequence: a1=a2=1 and an=an−1+an−2 for n>2.
  • A recurrence-generated sequence may show no simple visible pattern, but it is produced deterministically term-by-term.
  • Recurrence is useful when an explicit formula for an is hard or unnecessary.

2Diagram

Fibonacci sequence is produced step-by-step from initial values and a recurrence rule.

3Key Concepts

  • 🔁Recurrence uses feedback: the next term depends on one or more previous terms.
  • 🧩An order-2 recurrence needs two starting values (e.g., a1, a2).
  • ➡️Generation is sequential: to reach an, earlier terms are used.
  • 📌Fibonacci start: 1, 1, 2, 3, 5, 8, 13, 21, ...

4HOW TO FORM TERMS (ALGORITHM)

  • Write the initial terms: a1=1, a2=1.
  • For each n≥3, compute an by adding the previous two terms.
  • Each term depends only on the immediate past: (an−2, an−1) → an.
  • Changing starting values gives a different sequence even with the same rule.

5RECURRENCE VS EXPLICIT FORM (EXAM VIEW)

  • Explicit form gives an directly in terms of n; recurrence gives a generation rule.
  • Some sequences have no known simple explicit formula; recurrence/verbal rules can still define them.
  • For Fibonacci, term-finding is done by building from the start values.

1

Answer:

a4=a3+a2=2+1=3.
a5=a4+a3=3+2=5.
a6=a5+a4=5+3=8.
a7=a6+a5=8+5=13.
✓  a8=21
2

Answer:
a3=a2+a1=3+2=5.
a4=a3+a2=5+3=8.
a5=a4+a3=8+5=13.
a6=a5+a4=13+8=21.
✓  a6=21

8⭐Important Points

  • Always state initial conditions; recurrence alone does not fix a unique sequence.
  • For Fibonacci, recurrence applies only for n>2; handle a1, a2 separately.
  • Compute in order: find a3 first, then a4, and so on.
  • Write indices clearly to avoid mixing position with value.
  • Fibonacci sequence begins 1, 1, 2, 3, 5, 8, 13, 21, ...

9❌Common Mistakes

  • Applying an=an−1+an−2 for n=1 or 2.
  • Changing starting values (e.g., using 0,1 instead of 1,1) without noticing the sequence changes.
  • Accidentally doubling: using an=an−1+an−1.
  • Skipping indices and writing only values, leading to wrong term number in answers.

Fix start: 1, 1.Every next term: add the previous two.Say aloud: "keep two, add two" while generating terms.
TOPIC3

SERIES AND SIGMA NOTATION

1Definition & Introduction

  • For a sequence a1, a2, a3, … the associated series is a1 + a2 + a3 + …
  • A series is finite if it has a fixed number of terms; otherwise it is infinite.
  • Series refers to the expression of addition; sum of the series is the resulting number (if computed).
  • Sigma notation uses the Greek letter ∑ to denote repeated addition with a running index.
  • General form: ∑k=1n ak represents a1 + a2 + … + an.

2Diagram

Sequence generates terms → series indicates addition → ∑ compresses notation; sum is the evaluated value.

3Key Concepts

  • KC1Sequence gives terms; series is the indicated addition of those terms in order.
  • KC2∑ needs: lower limit (start), upper limit (end), and general term (summand).
  • KC3Index letter (k, i, r) is a dummy variable; renaming it doesn’t change the value.
  • KC4Finite series has a last term; infinite series continues with …

4HOW TO READ ∑ (SIGMA) QUICKLY

  • ∑k=1n ak means add terms with k=1,2,3,…,n.
  • Lower limit: starting index; upper limit: ending index; expression: term to be added.
  • Example of expansion: ∑k=14 (2k−1) = 1+3+5+7.
  • For an infinite series, upper limit is ∞: ∑k=1∞ ak.

5SERIES vs SUM (EXAM-FAVOURITE DISTINCTION)

  • Series: an expression like 1+3+5+7 (four terms).
  • Sum of that series: the number obtained after addition (here 16).
  • A series can be written without evaluating; sum is a computed result.
  • If the series is infinite, its sum may or may not exist (depends on convergence, studied later).

8Solved Examples

1
Write in sigma notation: 7 + 9 + 11 + … + 45.
Solution:
This is an arithmetic sequence of odd numbers starting from 7, with common difference 2.
General odd term is 2k−1. Match first term: 2k−1 = 7 ⇒ k=4.
Match last term: 2k−1 = 45 ⇒ k=23. So take k from 4 to 23.
✓  7 + 9 + … + 45 = ∑k=423 (2k−1).
2
Evaluate ∑k=111 (2 + 3k).
Solution:
Use linearity: ∑(2+3k) = ∑2 + 3∑k.
∑k=111 2 = 2×11 = 22.
∑k=111 k = 11×122 = 66.
Value = 22 + 3×66 = 22 + 198 = 220.
✓  ∑k=111 (2 + 3k) = 220.

9⭐Important Points

  • Write the summand as a function of the index: it should involve the running variable (k).
  • If the lower limit is 1, the upper limit equals the number of terms; otherwise count terms carefully.
  • Series (expression) is not the same as sum (value); wording matters in boards/JEE.
  • Index letter is arbitrary: ∑k=1n ak = ∑i=1n ai.
  • Partial sum: Sn is the sum of first n terms (often used even when the series is infinite).

10❌Common Mistakes

  • Writing ∑k=1n an instead of ak (wrong variable).
  • Forgetting to change limits when shifting index (e.g., starting from 4 not 1).
  • Treating “series” and “sum” as synonyms in answers.
  • Assuming an infinite series always has a sum without checking convergence.

11💡Memory Technique

“Sigma = SLE (Start–Last–Expression)”

If S, L, E are correct, the ∑ is correct.

TOPIC4

GEOMETRIC PROGRESSION (G.P.) CONCEPT

1Definition & Introduction

  • A sequence is a G.P. if there exists a constant r such that for all relevant k (with ak ≠ 0), ak+1ak = r.
  • Common ratio r = (any term) ÷ (previous term), and it is the same for all consecutive non-zero terms.
  • If first term is a, the standard form is a, ar, ar2, ar3, …
  • A G.P. may be finite (ends at last term l) or infinite (continues indefinitely).
  • If r is negative, signs alternate; if 0 < |r| < 1, terms decrease in magnitude (approach 0 in an infinite G.P.).
  • For a G.P. with consecutive non-zero terms, am2 = am−1am+1 (useful identification test).

2Diagram

A G.P. is formed by repeatedly multiplying by the same constant r.

3Key Concepts

  • 🎯Quick test: compute 2nd1st, 3rd2nd, … ; all equal (and denominators non-zero) ⇒ G.P.
  • 🧩Standard term: an = arn−1; multiplying by r moves one step forward.
  • 🔁Recursive form: ak+1 = rak (when a constant ratio r exists).
  • ⚠️Ratio test needs ak ≠ 0; if a term is 0, check the pattern separately instead of dividing by 0.

4HOW TO IDENTIFY A G.P. (EXAM METHOD)

  • Pick any two successive terms with non-zero previous term: compute ak+1ak.
  • Check the same ratio using another adjacent pair; if same, sequence is a G.P.
  • If a zero appears, the ratio test may be undefined; check the intended pattern separately.
  • Alternative check (3 consecutive non-zero terms): if x, y, z, test y2 = xz.

5FINITE vs INFINITE G.P. (CONCEPT ONLY)

  • Finite G.P.: has last term l; written a, ar, …, arn−1.
  • Infinite G.P.: continues forever; written a, ar, ar2, …
  • r controls growth/decay: |r| > 1 grows; 0 < |r| < 1 decays; r < 0 alternates signs.

10⭐Important Points

  • In a G.P., the multiplier r is constant; do not confuse with constant difference (A.P.).
  • Use ratio test only when the previous term is non-zero; otherwise division is undefined.
  • Negative r implies alternating signs; magnitude follows |r|.
  • If 0 < |r| < 1, terms decrease and may approach 0 (in infinite G.P.).
  • For consecutive non-zero terms x, y, z in G.P., middle term satisfies y2 = xz.

11❌Common Mistakes

  • Checking only one ratio pair and concluding G.P. without verifying another pair.
  • Using difference instead of ratio to identify a G.P.
  • Dividing by a zero term while applying ratio test.
  • Wrong exponent in nth term: writing arn instead of arn−1.

TOPIC5

NTH TERM OF G.P.

1Definition & Introduction

  • A sequence is a G.P. if ak+1ak = r (constant), with all terms non-zero.
  • If first term is a and common ratio is r, terms are a, ar, ar2, ar3, ...
  • The general (nth) term is an = arn−1.
  • For a finite G.P. with last term l, l = arn−1.
  • To find “which term is X”, equate X = arn−1 and solve for integer n.

2Diagram

Position n maps to exponent n−1 in an.

3Key Concepts

  • 🧩Exponent matches position: 1st has r0, 2nd has r1, nth has rn−1.
  • 🔁Ratio test: compute a2a1, a3a2; must be equal to the same r.
  • 🎯“Which term” needs integer check; if n is not natural, X is not a term.
  • ➗If am and an are known: aman = rm−n.
  • 📌Special: 16th term = a16 = ar15 (often asked as ar15).

4DERIVATION SNAPSHOT (EXAM-SAFE)

  • Start: a1 = a.
  • Common ratio: a2a1 = r ⇒ a2 = ar.
  • Again: a3a2 = r ⇒ a3 = ar2.
  • Continuing gives an = arn−1.

5HOW TO FIND “WHICH TERM IS X?”

  • Set X = arn−1 (use given a, r).
  • Reduce to same base when possible; then equate exponents.
  • Solve for n; must be a natural number to be a term.
  • If bases differ, take logs: n−1 = log(X/a) ÷ log(r).

  • Always align term number with exponent: nth term uses rn−1, not rn.

  • If two terms given: divide to eliminate a; use aman = rm−n.
  • Last term equals nth term of finite G.P.: l = an.

11❌Common Mistakes

  • Writing an = arn (off by one error).
  • Using r = a1a2 instead of a2a1.
  • For “which term”, stopping after logs but not checking integer value of n.
  • Ignoring that all terms must be non-zero in the definition used here (division by zero issue).

TOPIC6

SUM OF n TERMS OF G.P.

1Definition & Introduction

  • For a G.P. with first term a and common ratio r, the sum of first n terms is Sn.
  • G.P. terms: a, ar, ar2, …, arn−1.
  • If r=1, all terms equal a so Sn=na.
  • If r≠1, use “multiply by r and subtract” to get Sn=a(1−rn)/(1−r).
  • Equivalent form for r≠1: Sn=a(rn−1)/(r−1) (often used when r>1).
  • To solve for n, isolate rn from sum formula, then use integer powers/logs if needed, and finally verify n is a natural number.

2Diagram

Flow: write G.P. → form Sn → choose case r=1 or use multiply-and-subtract for r≠1.


3Key Concepts

  • 🔁Core trick: write Sn, write rSn, then subtract to cancel middle terms.
  • 🟦Two cases are mandatory: r=1 gives na; r≠1 gives a rational-expression formula.
  • 🎯For 0<r<1, it is often convenient to use Sn=a(1−rn)1−r so numerator and denominator are both positive when a>0.
  • 🔍Finding n: compute rn first; check n must be a natural number.

4DERIVATION (r ≠ 1): MULTIPLY BY r AND SUBTRACT

  • Let Sn = a + ar + ar2 + … + arn−1.
  • Multiply by r: rSn = ar + ar2 + … + arn.
  • Subtract: (1−r)Sn = a − arn = a(1−rn).
  • Divide by (1−r) (nonzero): Sn = a(1−rn)1−r.

5SOLVING FOR NUMBER OF TERMS n (USING SUM)

  • From Sn = a(1−rn)1−r (with r≠1), isolate rn: rn = 1 − (1−r)Sna.
  • If rn becomes a perfect power of r, read off integer n directly.
  • If needed, use logs: n = log(rn)log r, then verify by substitution in the sum.
  • Special case r=1: Sn=na ⇒ n=Sna.

9Solved Examples

1
Find the sum of first 8 terms of the G.P. 3, 6, 12, ...
Solution:
Identify a=3, r=2, n=8.

✓  Sum of first 8 terms = 765
2
How many terms of the G.P. 3, 32, 34, ... are needed to get sum 3069512 ?
Solution:
Here a=3, r=12, and Sn=3069512.
Use Sn = a(1−rn)1−r with 0<r<1.
3069512 = 3(1−(1/2)n)1−1/2 = 6(1−(1/2)n).
Divide by 6: 30693072 = 1−(1/2)n.
So (1/2)n = 1 − 30693072 = 33072 = 11024 = (1/2)10.
Hence n=10.
✓  Number of terms required = 10

10⭐Important Points

  • Always split into cases: r=1 and r≠1; the derived formula divides by (1−r).
  • Write both equivalent forms to avoid sign confusion: a(1−rn)1−r and a(rn−1)r−1.
  • For 0<r<1 and a>0, Sn increases with n and stays below a1−r (the sum to infinity).
  • To find n, first compute rn; then match to a power or use logs and verify integer.
  • If sum is given and terms are fractions, clear denominators early to reduce arithmetic errors.

11❌Common Mistakes

  • Using a(1−rn)1−r even when r=1 (division by zero).
  • Wrong power: writing last term as arn instead of arn−1 in the sum setup.
  • Sign mistake in subtraction: mixing up (1−r)Sn vs (r−1)Sn.
  • Solving for n but not checking n is a natural number (term count).

12💡Memory Technique

“MSA Trick: Multiply–Shift–Subtract”

GEOMETRIC MEAN AND INSERTIONS

1Definition & Introduction

  • Geometric mean (G.M.) of two positive numbers a, b is √(ab).
  • If G is the G.M., then a, G, b are consecutive terms of a G.P.
  • To insert n geometric means: form a, G1, …, Gn, b as a G.P. with n+2 terms.
  • b becomes the (n+2)th term; common ratio is fixed by endpoints.
  • In general, real insertions are possible when a and b have the same sign (with sign patterns depending on n). In this infographic we assume a, b > 0 (real, positive means).

2Diagram

Insert n means so that each step multiplies by the same common ratio r.

3Key Concepts

  • 🧩For a, b > 0: G2=ab and G=√(ab).
  • 🧮Insertion idea: endpoints fix r via b=arn+1.
  • 🔁Inserted term formula: Gi=a(b/a)in+1, for i=1…n.
  • ✅If a, b are positive, all inserted means are positive (taking the positive real root for r).

4QUICK DERIVATION (ENDPOINTS → COMMON RATIO)

  • Let the required G.P. be a, G1, …, Gn, b with common ratio r.
  • Then (n+2)th term is b = arn+1 ⇒ r = (b/a)1n+1 (for a,b > 0).
  • Inserted terms: Gi = ari = a(b/a)in+1.

5SPECIAL CASE: SINGLE INSERTION (G.M. OF TWO NUMBERS)

  • Insert 1 mean (n=1): the G.P. is a, G, b.
  • For a G.P., G2=ab, so G=√(ab) when a, b are positive.
  • Equivalently, r=√(b/a) and G=ar.

AM-GM RELATIONSHIP (TWO POSITIVE NUMBERS)

1Definition & Introduction

  • For positive real numbers a, b: A (A.M.) = a+b2 and G (G.M.) = √(ab).
  • AM-GM inequality (two numbers): A ≥ G, valid for a > 0, b > 0.
  • Equality holds iff a = b (then A.M. = G.M.).
  • Exact square form: A − G = (√a − √b)²2 ≥ 0.
  • If A.M. and G.M. are known, then a+b and ab are known; find a, b as roots of a quadratic equation.

2Diagram

Key takeaway: for positive numbers, A.M. is always at least G.M.

3Key Concepts

  • ✅A − G = (√a − √b)²2 ≥ 0 ⇒ A ≥ G.
  • 🟦Equivalent: A² − G² = (a − b)²4 ≥ 0.
  • 🔁Given A, G: a+b = 2A and ab = G² ⇒ solve t² − (2A)t + G² = 0.
  • 🚫Feasibility: real positive a, b exist only if A ≥ G > 0.
  • 🎯If a+b is fixed (A fixed), then G is maximum when a = b.

4PROOF (SQUARE METHOD)

  • Start with (√a − √b)² ≥ 0 (square of a real number).
  • Expand: a + b − 2√(ab) ≥ 0.
  • Divide by 2: a+b2 − √(ab) ≥ 0.
  • Hence A − G ≥ 0 ⇒ A ≥ G; equality iff √a = √b ⇒ a = b.

5FINDING a, b GIVEN A.M. AND G.M.

  • Given A and G: set S = a+b = 2A and P = ab = G².
  • Then a, b are roots of t² − St + P = 0.
  • Discriminant: Δ = S² − 4P = 4(A² − G²) ≥ 0 (same condition as A ≥ G).
  • So a, b = S ± √Δ2 = A ± √(A² − G²).

7Solved Examples

1
If A.M. and G.M. of two positive numbers are 10 and 8 respectively, find the numbers.
Solution:
A = 10 ⇒ a+b = 2A = 20.
G = 8 ⇒ ab = G² = 64.
Let t be a root: t² − 20t + 64 = 0.
Discriminant Δ = 20² − 4×64 = 400 − 256 = 144 ⇒ √Δ = 12.
So t = 20 ± 122 ⇒ t = 16 or 4.
✓  The numbers are 4 and 16 (in any order).
2

Solution:
S = a+b = 2A = 26 and P = ab = G² = 144.
Form quadratic: t² − 26t + 144 = 0.
Δ = 26² − 4×144 = 676 − 576 = 100 ⇒ √Δ = 10.
t = 26 ± 102 ⇒ t = 18 or 8.
✓  The numbers are 8 and 18 (in any order).

8⭐Important Points

  • Condition: a, b must be positive for real G.M. = √(ab).
  • Equality case: A = G ⇔ a = b.
  • From given A and G: sum = 2A, product = G², then solve the quadratic.
  • Feasibility check: if A < G, then no real positive pair exists.
  • Identity used often: (a−b)² = (a+b)² − 4ab.

9❌Common Mistakes

  • Applying A.M. ≥ G.M. when one number is 0 or negative (real G.M. not defined).
  • Using ab = G instead of ab = G².
  • Ignoring that (a,b) and (b,a) represent the same pair.
  • Discriminant error: Δ = (2A)² − 4G² (not (2A)² − 4G).

NONSTANDARD SUMS VIA G.P.

1Definition & Introduction

  • Nonstandard digit-pattern sum: add terms like 7, 77, 777, ... which are not a G.P. directly.
  • Each k-digit repeated-d number equals d × (111...1) (k ones).
  • Use 111...1 = (10k−1)/9 to convert to powers of 10.
  • Then the sum becomes a combination of a G.P. in 10 and a simple constant-sum of 1’s.
  • Works similarly for digits d = 1 to 9, and for repeats like 8, 88, 888, ...

2Diagram

Flow: digit-pattern → (10k−1)/9 → G.P. in 10 minus n ones


3Key Concepts

  • repeWrite repeated digit as d×(10k−1)/9 to expose powers of 10.
  • grapSum of 10, 102, ..., 10n is a G.P. with a=10, r=10.
  • spliSplit: Σ(10k−1) = Σ10k − Σ1 to handle the non-G.P. part.
  • finaFinal template: d9[10(10n−1)9 − n].

4CORE CONVERSION (REPEATED DIGIT)

  • k-digit repdigit: ddd...d (k times) = d(111...1).
  • 111...1 (k ones) = 10k−19.
  • So, ddd...d = d(10k−1)9.
  • Hence Σ of repdigits becomes d9[Σ10k − Σ1].

5FAST SUM TEMPLATE (TO n TERMS)

  • Let Tk be k-digit repdigit of d: Tk = d(10k−1)9.
  • Sum: Sn = Σk=1n Tk = d9[Σ10k − n].
  • G.P.: Σk=1n10k = 10 + 102 + ... + 10n = 10(10n−1)9.
