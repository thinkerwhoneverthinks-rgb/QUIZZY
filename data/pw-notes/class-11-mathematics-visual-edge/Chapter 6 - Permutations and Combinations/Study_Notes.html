SEQUENCES AND SERIES

TOPIC1
Ordered lists a1, a2, … : terms, nth term, finite/infinite, and how sequences are defined

BASICS OF SEQUENCES

1Definition & Introduction

  • A sequence is an ordered list of numbers given by a rule: a1, a2, a3, …
  • The numbers in the list are called terms; the subscript shows the position of the term.
  • The nth term (or general term) is the term at position n, written an.
  • A sequence can be viewed as a function a(n) with domain natural numbers (or a subset like {1,2,…,k}).
  • A sequence is finite if it has a last term; it is infinite if it continues without end.

3Key Concepts

  • 📌Order matters: 2,4,8,… is different from 4,2,8,…
  • 🧩The notation an means the term at position n.
  • ♾️Finite vs infinite depends on whether the index set ends (like n=1 to 10) or not.
  • 🔁A recurrence defines a term using earlier term(s), so initial term(s) are essential.
  • 🗣️Some sequences have no simple nth-term formula (e.g., primes); they can be defined verbally.

4WAYS TO DEFINE A SEQUENCE

  • Explicit (formula): gives an directly as a rule depending on n (e.g., even numbers in order).
  • Recurrence: gives initial term(s) and tells how to get the next term from previous term(s).
  • Verbal rule: describes the sequence in words (e.g., primes in increasing order).
  • A recurrence is incomplete without initial conditions (like a1, a2).

5FINITE VS INFINITE (INDEX SET IDEA)

  • Finite: indices are {1,2,…,k} so the last term is ak.
  • Infinite: indices are N={1,2,3,…} so there is no last term.
  • Example (finite): ancestors over 10 generations: 2,4,8,…,1024.
  • Example (infinite): successive quotients in 10÷3: 3, 3.3, 3.33, 3.333, …

7Solved Q&A

1
A student says: "A sequence is the same as a set." Is this correct?
Answer:
A set is an unordered collection; order does not matter in a set.
A sequence is ordered; the position (subscript) matters.
So (2,4,8,...) and (4,2,8,...) are different sequences even if they contain the same numbers.
✓  Not correct. A sequence is ordered; a set is unordered.
2
Why are initial terms necessary in a recurrence definition?
Answer:
A recurrence tells how to get a new term from earlier term(s).
Without a starting term (like a1), the rule alone cannot produce a unique list.
Different starting values lead to different sequences even with the same recurrence relation.
✓  Because the recurrence needs a starting point; otherwise the sequence is not uniquely determined.

8⭐Important Points

  • Sequence vs set: sequence is ordered; repetition allowed (e.g., 1,1,2,…).
  • General term means the term at position n, written an.
  • In a recurrence, always state starting term(s); otherwise the sequence is not uniquely fixed.
  • Finite sequence usually has domain {1,2,…,k}; infinite sequence has domain N.
  • Use a(n) and an for the same idea: the term corresponding to index n.

9❌Common Mistakes

  • Treating a sequence like an unordered set and ignoring position/subscripts.
  • Changing the starting index (like taking n=0) when the domain is stated as N={1,2,3,…}.
  • For recurrence, forgetting that terms are generated in order from the initial term(s).
  • Confusing an (term) with n (position).

TOPIC2
Sequential choices: total ways = product of choices at each step

COUNTING PRINCIPLE (MULTIPLICATION PRINCIPLE)

1Definition & Introduction

  • Fundamental principle: If an action is completed by doing Step 1 and then Step 2, then total ways = (ways for Step 1) × (ways for Step 2).
  • It applies when choices happen in a fixed order (filling positions one by one).
  • For more than two steps, multiply the number of choices available at each step.
  • If repetition is not allowed, the number of available choices usually decreases after each selection.
  • If repetition is allowed, the same options can remain available for later steps.

2Diagram

Sequential events (fixed order) ⇒ multiply choices at each step.

3Key Concepts

  • 🔗Use the vacant places idea: list positions, count options for each, then multiply.
  • 🧥Outfit rule: choose one item from each category (pant, shirt, etc.) and multiply choices.
  • 🔁Repetition allowed: a chosen item can be used again; not allowed: it cannot.
  • 🚩Signals/flags: top and bottom are different positions, so order matters.
  • ➕If the condition creates different cases (like 2 flags OR 3 flags), count each case, then add.

4WORKING METHOD (VACANT-PLACES APPROACH)

  • Convert the task into filling positions (slots) one by one.
  • Fix an order of filling (left-to-right or the most restrictive position first).
  • At each position, count choices allowed given earlier choices.
  • Multiply the counts for all positions to get the total.
  • If the condition splits into cases, count each case separately, then add.

5BASIC APPLICATION PATTERNS (IDEAS)

  • If you must choose one from each group (pants, shirts), multiply group sizes.
  • If you must fill several positions (letters/digits/flags), multiply choices per position.
  • If repetition is not allowed, the next position has fewer options because used items are removed.
  • If a position has a restriction (like unit digit must be even), fill that restricted position first.
  • For "at least" type questions, split by length (2 items, 3 items, ...) and add the totals.

✓  Fill the most restricted position first (often the unit digit for even/odd conditions), then multiply the step-wise choices.

A signal is formed by placing flags in distinct positions (top, below, etc.), so choices are sequential.

✓  Because positions are filled in order; without repetition, each used flag is removed, so later positions have fewer choices. Different possible lengths are handled case-wise and then added.

8⭐Important Points

  • Use multiplication only when steps happen in sequence in a chosen order.
  • Convert the problem into filling positions (vacant places) step-by-step.
  • No repetition typically means the number of available options decreases at later steps.
  • Repetition allowed means earlier choices do not remove options for later steps.
  • For "at least" / "either-or" conditions, do case-wise counting and then add.

9❌Common Mistakes

  • Adding step counts instead of multiplying for sequential choices.
  • Ignoring that positions are different, so order matters (e.g., top vs bottom flag).
  • Forgetting to reduce options when repetition is not allowed.
  • Not handling "at least" conditions by splitting into separate cases and adding.

TOPIC3
Generating sequences by a rule: each new term depends on previous terms

FIBONACCI AND RECURRENCE

1Definition & Introduction

  • Recurrence relation: a rule that defines an using earlier terms like an−1, an−2, etc.
  • To generate a sequence uniquely, initial term(s) (starting values) must be given.
  • Fibonacci sequence: a1=a2=1 and an=an−1+an−2 for n>2.
  • A recurrence-generated sequence may show no simple visible pattern, but it is produced deterministically term-by-term.
  • Recurrence is useful when an explicit formula for an is hard or unnecessary.

2Diagram

Fibonacci sequence is produced step-by-step from initial values and a recurrence rule.

3Key Concepts

  • 🔁Recurrence uses feedback: the next term depends on one or more previous terms.
  • 🧩An order-2 recurrence needs two starting values (e.g., a1, a2).
  • ➡️Generation is sequential: to reach an, earlier terms are used.
  • 📌Fibonacci start: 1, 1, 2, 3, 5, 8, 13, 21, ...

4HOW TO FORM TERMS (ALGORITHM)

  • Write the initial terms: a1=1, a2=1.
  • For each n≥3, compute an by adding the previous two terms.
  • Each term depends only on the immediate past: (an−2, an−1) → an.
  • Changing starting values gives a different sequence even with the same rule.

5RECURRENCE VS EXPLICIT FORM (EXAM VIEW)

  • Explicit form gives an directly in terms of n; recurrence gives a generation rule.
  • Some sequences have no known simple explicit formula; recurrence/verbal rules can still define them.
  • For Fibonacci, term-finding is done by building from the start values.

TOPIC4
Ordered arrangements: order matters (with/without repetition; also with repeated objects)

PERMUTATIONS CONCEPT

1Definition & Introduction

  • Permutation = arrangement of objects in a definite order (sequence matters).
  • If the same set of objects gives different sequences, they are different permutations (e.g., ABC ≠ BAC).
  • Counting often uses the multiplication principle: multiply choices stage-wise in the chosen order.
  • Main cases: no repetition, repetition allowed, and some objects identical (repeated letters).
  • Example idea: 3-letter words from NUMBER depend on whether letters may repeat.

2Diagram

Fill r positions left-to-right: choices multiply; repetition changes whether choices shrink.

3Key Concepts

  • 🎯Order is important: selecting positions one by one counts sequences.
  • ✖️No repetition: choices reduce: n, n−1, n−2, ...
  • 🔁Repetition allowed: each position has n choices, so total nr.
  • 🧩If some objects are identical, divide by factorials of repeats to remove overcounting.

4CORE COUNTING IDEA (MULTIPLICATION PRINCIPLE)

  • If step-1 has m ways and step-2 has n ways (after step-1), total = m×n.
  • For r positions: total ways = (choices for 1st)×(choices for 2nd)×...×(choices for rth).
  • Choose the order of filling positions wisely (e.g., fix unit digit first if it has restrictions).

5TWO STANDARD PERMUTATION CASES (ALL DISTINCT OBJECTS)

  • Without repetition: n choices for 1st, n−1 for 2nd, ..., n−r+1 for rth.
  • With repetition: each of r positions has n choices independently.
  • Keyword check: arrangement, sequence, rank/position ⇒ permutation.

TOPIC5
Arrangements of n different objects taken r at a time, without repetition

PERMUTATIONS OF DISTINCT OBJECTS (nPr, without repetition)

1Definition & Introduction

  • Permutation = arrangement in a definite order of objects taken some/all at a time.
  • For n different objects, taken r at a time (0 ≤ r ≤ n), no object repeats.
  • Interpretation: fill r vacant places sequentially using available objects.
  • Count is product of choices per position: n, then n−1, then n−2, ...
  • Notation: number of such arrangements is denoted by nPr (read “n permute r”).

2Diagram

Filling r vacant places gives the product rule for nPr.

3Key Concepts

  • 📌Without repetition ⇒ choices decrease by 1 each new place filled.
  • 🧩Order matters: ABC and ACB are different permutations.
  • 🔁Product stops after r factors: n(n−1)...(n−r+1).
  • ⚖️Factorial form compresses the product: nPr = n!(n−r)!.
  • 🧠Edge case: nP0 = 1 (arranging nothing has exactly one way).

4THEOREM 1 (STATEMENT + MEANING)

  • Theorem 1: permutations of n different objects taken r at a time, no repetition.
  • Count = n(n−1)(n−2)...(n−r+1) for 0 ≤ r ≤ n (for r=0, value is 1).
  • Reason: each next place has one fewer available object.
  • This product is called nPr.

5FACTORIAL FORM (COMPACT NOTATION)

  • Use n! = 1×2×...×n and 0! = 1.
  • Product form equals factorial ratio: nPr = n!(n−r)!.
  • Special cases: nPn = n! and nP0 = 1.

TOPIC6
Series = indicated sum of terms of a sequence; write compactly using ∑

SERIES AND SIGMA NOTATION

1Definition & Introduction

  • For a sequence a1, a2, a3, … the associated series is a1 + a2 + a3 + …
  • A series is finite if it has a fixed number of terms; otherwise it is infinite.
  • Series refers to the expression of addition; sum of the series is the resulting number (if computed).
  • Sigma notation uses the Greek letter ∑ to denote repeated addition with a running index.
  • General form: ∑k=1n ak represents a1 + a2 + … + an.

2Diagram

Sequence generates terms → series indicates addition → ∑ compresses notation; sum is the evaluated value.

3Key Concepts

  • KC1Sequence gives terms; series is the indicated addition of those terms in order.
  • KC2∑ needs: lower limit (start), upper limit (end), and general term (summand).
  • KC3Index letter (k, i, r) is a dummy variable; renaming it doesn’t change the value.
  • KC4Finite series has a last term; infinite series continues with …

4HOW TO READ ∑ (SIGMA) QUICKLY

  • ∑k=1n ak means add terms with k=1,2,3,…,n.
  • Lower limit: starting index; upper limit: ending index; expression: term to be added.
  • Example of expansion: ∑k=14 (2k−1) = 1+3+5+7.
  • For an infinite series, upper limit is ∞: ∑k=1∞ ak.

5SERIES vs SUM (EXAM-FAVOURITE DISTINCTION)

  • Series: an expression like 1+3+5+7 (four terms).
  • Sum of that series: the number obtained after addition (here 16).
  • A series can be written without evaluating; sum is a computed result.
  • If the series is infinite, its sum may or may not exist (depends on convergence, studied later).

9⭐Important Points

  • Write the summand as a function of the index: it should involve the running variable (k).
  • If the lower limit is 1, the upper limit equals the number of terms; otherwise count terms carefully.
  • Series (expression) is not the same as sum (value); wording matters in boards/JEE.
  • Index letter is arbitrary: ∑k=1n ak = ∑i=1n ai.
  • Partial sum: Sn is the sum of first n terms (often used even when the series is infinite).

10❌Common Mistakes

  • Writing ∑k=1n an instead of ak (wrong variable).
  • Forgetting to change limits when shifting index (e.g., starting from 4 not 1).
  • Treating “series” and “sum” as synonyms in answers.
  • Assuming an infinite series always has a sum without checking convergence.

1Definition & Introduction

  • A sequence is a G.P. if there exists a constant r such that for all relevant k (with ak ≠ 0), ak+1ak = r.

  • If first term is a, the standard form is a, ar, ar2, ar3, …
  • A G.P. may be finite (ends at last term l) or infinite (continues indefinitely).
  • If r is negative, signs alternate; if 0 < |r| < 1, terms decrease in magnitude (approach 0 in an infinite G.P.).
  • For a G.P. with consecutive non-zero terms, am2 = am−1am+1 (useful identification test).

COMBINATION APPLICATIONS

1Definition & Introduction

  • Combination counts selections where order does not matter: number of ways = nCr.
  • Use multiplication principle when selection happens in independent stages (e.g., men then women).
  • Convert constraints into cases (exactly/at least/at most) and add case-counts.
  • For cards, use fixed totals: 52 cards, 4 suits×13 each, 26 red + 26 black, 12 face cards, 4 aces.
  • Typical outputs are large; keep expressions in nCr form until final step to reduce errors.

2Diagram

Flow: split selection by categories, then multiply; use casework + addition for constraints.

3Key Concepts

  • 👥Committee from groups: (m men choose a) × (w women choose b).
  • 🃏Card constraints: same suit, all suits different, colour split, face cards, exactly one ace.
  • ➕Exactly = sum of disjoint cases; At least = total − (complement cases).
  • 🔁Remember symmetry: nCr = nCn−r (choose vs reject).

4STANDARD PATTERNS (HIGH-YIELD)

  • Exactly (a from group1, b from group2): (mCa)(wCb).
  • At least one from group: total − none from that group.
  • Card same suit: choose suit (4 ways) then choose 4 from 13: 4×13C4.
  • Card four different suits: 13C1 for each suit, multiply: (13C1)4.
  • Card 2 red & 2 black: 26C2×26C2.

5EXACTLY ONE ACE (DISCUSSION TEMPLATE)

  • Use disjoint stages: pick aces then non-aces; order doesn’t matter inside each stage.
  • Exactly one ace in 4 cards: (4C1)×(48C3).
  • At least one ace in 4 cards: 52C4 − 48C4.
  • Exactly k aces in 4 cards: (4Ck)(48C4−k), valid for k = 0,1,2,3,4.

Compute 4C1=4.

  • Always decide first: order matters? If no, use combinations, not permutations.

  • Mixing “exactly” with “at least” without disjoint cases or complement.

MIXED COUNTING PROBLEMS

1Definition & Introduction

  • Mixed counting means using multiple counting ideas in one problem: nPr, nCr, repetition/identical objects, and restrictions.
  • Use multiplication principle for step-by-step filling of positions (slots).
  • Use division by factorials when some objects are identical (repeated letters/digits).
  • Use complement method: required = total − forbidden, when restriction is easier to exclude.
  • For dictionary rank, count how many valid words come before the target word (left to right).

2Diagram

Most mixed problems reduce to slot-filling + handling repeats + restrictions (often via complement).

3Key Concepts

  • SlotSlot-filling: decide position constraints first (e.g., last digit even, first digit nonzero).
  • RepeRepeated objects: arrangements of n items with repeats p,q,… is n!÷(p!q!…).
  • RankDictionary rank: move left→right; for each smaller feasible letter, count completions of remaining letters.
  • SeatSeating with restrictions: often arrange one group first, then place the other in gaps.
  • ChooMarked/blocked places: first choose places (nCr), then arrange people (r!).

4CORE WORKFLOW (EXAM-STYLE)

  • Step 1: Identify objects (distinct/repeated) and whether order matters.
  • Step 2: Convert restrictions into slot choices (fix/choose positions, then fill).
  • Step 3: Use × principle across independent stages; avoid overcount by dividing repeats.
  • Step 4: If direct counting is messy, use total − forbidden (complement).
  • Step 5: For rank, count words before it position-wise; add 1 at end for the word itself.

5HIGH-YIELD PATTERNS (FROM KEYWORDS)

  • Vowel/Consonant selection: choose required letters (combinations), then arrange selected letters (permutation).
  • Repeated letters (e.g., AGAIN): while counting completions, use multiset permutations at each step.
  • > 1000000: leading digit cannot be 0; count total multiset arrangements then subtract those starting with 0.
  • Digits 1,2,0,2,4,2,4: handle repeats 2 (three times) and 4 (twice) via division by 3!2!.
  • 5 girls, 3 boys, no two boys together: arrange girls, then place boys in gaps; multiply by 3! for boys’ order.

8Solved Examples

1
From the letters of INVOLUTE, how many 5-letter words (with or without meaning) can be formed that contain exactly 3 vowels?
Solution:
Letters in INVOLUTE are all distinct: I,N,V,O,L,U,T,E (8 letters).
Vowels = {I,O,U,E} (4) and consonants = {N,V,L,T} (4).
To have exactly 3 vowels in a 5-letter word, we must choose 3 vowels and 2 consonants.
Choose vowels: 4C3 = 4.
Choose consonants: 4C2 = 6.
Arrange the chosen 5 distinct letters: 5! = 120.
Total = 4C3 × 4C2 × 5! = 4 × 6 × 120 = 2880.
✓  2880 words.
2
Using digits 1,2,0,2,4,2,4 (seven digits; repeats allowed only as given), how many 7-digit numbers greater than 1000000 can be formed?
Solution:
Digits form a multiset: {0,1,2,2,2,4,4}. Total arrangements (including leading 0) = 7!3!2! = 504012 = 420.
Invalid numbers start with 0. Fix 0 in the first place; arrange remaining multiset {1,2,2,2,4,4}: count = 6!3!2! = 72012 = 60.
Required = 420 − 60 = 360.
All have nonzero first digit, hence are 7-digit and therefore > 1000000.
✓  360 numbers.

  • Always decide order vs selection first: arrangement → permutation; choose/team → combination.
  • Repeated letters/digits force division by factorials of frequencies (p!q!…).
  • Leading-zero issues: count all multiset arrangements then subtract those starting with 0.
  • For vowel/consonant constraints: choose required letters (nCr) then arrange selected letters (r!).
  • For “no two together”, use gaps method: fix one group first, insert others into gaps.

10❌Common Mistakes

  • Forgetting to divide by 3! for three identical 2s or by 2! for two identical 4s.
  • Using nPr when the task is only selection (order irrelevant).
  • Not subtracting leading-zero cases, so counting non-7-digit arrangements as valid.
  • In dictionary rank with repeats, treating identical letters as distinct and overcounting.
