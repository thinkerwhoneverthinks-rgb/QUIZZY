TOPIC1

NEED FOR DISPERSION

1Definition & Introduction

  • Dispersion means the degree of scatter/spread of observations around a measure of central tendency (like mean or median).
  • Mean/median/mode give the centre but not the variability of data.
  • Two datasets can have the same mean and median yet differ widely in spread.
  • To interpret data better, we need a single number describing variability (a measure of dispersion).
  • Dispersion helps judge consistency (less spread = more consistent values).

2Diagram

Datasets A and B can share the same centre but have different dispersion (spread).

3Key Concepts

  • 🎯Central tendency locates the "centre"; dispersion tells how far values lie from that centre.
  • ⚖️Same mean/median does not imply same distribution (spread can be different).
  • 📏Range uses only max and min: Range = max − min (quick but rough).
  • 🧮Deviation-based measures use distances from a central value: mean deviation, standard deviation.
  • 🏏Cricket scores example: identical mean/median can still mean very different performance consistency.

4WHY DISPERSION IS NEEDED

  • Central tendency gives only one representative value; it cannot show clustering vs scattering.
  • Decision-making needs both: where the data are centred and how much values vary.
  • Low dispersion ⇒ values are close to the centre ⇒ higher consistency.
  • High dispersion ⇒ values far from the centre ⇒ more variability/uncertainty.

5MEASURES OF DISPERSION (OVERVIEW)

  • Range: max − min (fast, uses extremes only).
  • Quartile deviation: based on Q1 and Q3 (not detailed here).
  • Mean deviation: mean of absolute deviations from a central value a (often mean or median).
  • Standard deviation: √(variance); variance is mean of squared deviations from mean.

8Solved Examples

1
Two batsmen have last-10-match scores: A: 30, 91, 0, 64, 42, 80, 30, 5, 117, 71; B: 53, 46, 48, 50, 53, 53, 58, 60, 57, 52. Given that both have mean = 53 and median = 53, explain why performance is not the same.
Solution:
Both series have the same central tendency (x̄ and M are equal), so their "centre" matches.
Compute variability using range: For A, max = 117 and min = 0 ⇒ Range = 117 − 0 = 117.
For B, max = 60 and min = 46 ⇒ Range = 60 − 46 = 14.
Since Range(A) ≫ Range(B), A is far more scattered (less consistent) while B is tightly clustered (more consistent).
✓  Same mean/median, but A has much higher dispersion (Range 117) than B (Range 14); hence consistency differs.

9⭐Important Points

  • A measure of central tendency gives only a rough idea of where data points are centred.
  • Dispersion is essential to distinguish between datasets with same mean/median but different spread.
  • Range is simplest but depends only on extreme values and is a rough measure.
  • Deviation-based measures (mean deviation, standard deviation) reflect spread from a central value.
  • In practice, smaller dispersion implies more reliability/consistency around the centre.

10❌Common Mistakes

  • Concluding two datasets are "same" just because mean (or median) matches.
  • Using only range to fully describe variability (it ignores most observations).
  • Forgetting that dispersion is about distances from a central value, not about the centre itself.
  • Mixing up "deviation" (xi − a) with "dispersion measure" (a single summary number).

TOPIC2

MEASURES OF DISPERSION

1Definition & Introduction

  • A measure of dispersion is a single number that quantifies the scatter/spread of data around a central value.
  • Central tendency (mean/median/mode) alone can be misleading: same mean can have different spread.
  • Dispersion is studied using deviations of observations from a fixed value (usually mean or median).
  • Main measures: Range, Quartile Deviation, Mean Deviation, Standard Deviation.
  • Smaller dispersion ⇒ observations cluster tightly; larger dispersion ⇒ observations are widely scattered.

2Diagram

Dispersion = spread of dots about a central value

3Key Concepts

  • 🎯Spread is always interpreted with respect to a central value (x̄ or M).
  • ↔️Range uses only extremes; it is quick but ignores interior values.
  • 🧮Mean deviation uses absolute deviations, so signs do not cancel.
  • 📐Standard deviation uses squared deviations about the mean; unit matches data after square-root.
  • 📦For grouped data, use frequencies and (for continuous classes) mid-points.

4WHAT EACH MEASURE CAPTURES

  • Range: quickest measure; depends only on extreme values.
  • Quartile deviation: spread of middle 50% data; robust to extremes.
  • Mean deviation: average absolute distance from a (mean/median).
  • Standard deviation: root mean square distance from mean; most used in JEE/boards.

5TYPES OF DATA (HOW FORMULAS CHANGE)

  • Ungrouped: use each observation directly.
  • Discrete frequency: use values x with frequencies f (total N).
  • Continuous: replace each class by mid-point x; then treat like discrete.
  • Step-deviation (for mean) can reduce arithmetic: take assumed mean a, class width h, and di=(xi−a)/h.

✓  Range = 117; M.D. about mean = 31.6 (runs).
2

f: 3, 5, 9, 5, 4, 3, 1
Find mean and standard deviation.
Solution:
Total frequency N = 3+5+9+5+4+3+1 = 30.
Compute ∑fixi = 12+40+99+85+80+72+32 = 420 ⇒ x̄ = 42030 = 14.
Compute squared deviations and weight:
(4−14)²×3 = 100×3=300
(8−14)²×5 = 36×5=180
(11−14)²×9 = 9×9=81

10⭐Important Points

  • Same mean/median does not imply same variability; dispersion must be compared.
  • For continuous data, replace each class by its mid-point before computing deviations.
  • Mean deviation uses |deviation|; standard deviation uses (deviation)², then √.
  • Range is sensitive to outliers and ignores internal clustering.
  • Standard deviation has the same units as observations; variance has squared units.

11❌Common Mistakes

  • For continuous classes, using class limits instead of mid-points in calculations.
  • For mean deviation, forgetting absolute value and letting positive/negative cancel.
  • In frequency data, dividing by n instead of N (total frequency).
  • Computing σ from ∑(x−x̄) instead of ∑(x−x̄)².

TOPIC3

RANGE (MEASURE OF DISPERSION)

1Definition & Introduction

  • Range of a data set = maximum value − minimum value.
  • It gives a rough idea of variability/spread in the observations.
  • Large range ⇒ data are more scattered; small range ⇒ data are more clustered.
  • Range uses only two values (extremes), ignoring all middle observations.
  • Range alone does not describe dispersion about mean/median (central tendency).

2Diagram

Range measures total spread from the smallest to the largest observation.

3Key Concepts

  • 🔺Identify extremes correctly: Max (largest), Min (smallest).
  • 🧾Range is an absolute measure of dispersion (same unit as data).
  • ⚠️Highly sensitive to outliers: one extreme can change range drastically.
  • 🎯Same mean/median can still have very different ranges (different variability).

4HOW TO CALCULATE RANGE (UNGROUPED DATA)

  • Step 1: List observations; locate minimum and maximum values.
  • Step 2: Compute Range = Max − Min (answer in same unit as data).
  • Step 3: Interpret: larger range ⇒ more variability; smaller range ⇒ less variability.

5USEFULNESS & LIMITATIONS (EXAM FOCUS)

  • Useful for quick comparison of two series when rough spread is enough.
  • Limitation: depends only on extremes; ignores how values are distributed in between.
  • Limitation: does not measure spread around mean/median; two sets can share mean, differ in range.
  • Limitation: very sensitive to outliers; one unusual score can inflate range.

8Solved Examples

1
Runs scored by Batsman A in 10 matches: 30, 91, 0, 64, 42, 80, 30, 5, 117, 71. Find the range.
Solution:
Maximum score xmax = 117; minimum score xmin = 0.
R = xmax − xmin = 117 − 0 = 117.
✓  Range = 117 runs.
2
Two students scored in 6 tests: S1: 12, 15, 13, 14, 16, 10 and S2: 11, 12, 13, 14, 15, 16. Compare variability using range.
Solution:
For S1: xmax = 16, xmin = 10 ⇒ R1 = 16 − 10 = 6.
For S2: xmax = 16, xmin = 11 ⇒ R2 = 16 − 11 = 5.
Since 6 > 5, S1 has slightly more spread in scores than S2.
✓  Ranges: S1 = 6, S2 = 5; S1 is more variable by range.

9⭐Important Points

  • Range is a measure of dispersion, not a measure of central tendency.
  • Always compute range as Max − Min; it is never negative.
  • Range changes if any extreme changes; middle values can change without affecting range.
  • Same mean/median does not imply same range or same variability.
  • Use range for quick spread; use deviation-based measures for dispersion about mean/median.

10❌Common Mistakes

  • Taking Min − Max and getting a negative number.
  • Picking wrong max/min because data are unsorted or a value is missed.
  • Concluding two datasets are similar because their means match, ignoring different ranges.
  • Using range to describe clustering around mean/median (range cannot do this).

Say it aloud: "Range runs from Min to Max".Write the two ends first, then subtract: Max on top, Min below.Hook: R in Range = Right end (max) minus left end (min).

MEAN DEVIATION CONCEPT

1Definition & Introduction

  • Mean deviation about a is the mean of absolute deviations |x−a|.
  • Deviation of an observation x from fixed value a is x−a.
  • Raw deviations have + and − signs, so their sum can cancel to zero.
  • For the mean x̄, ∑(xi−x̄) = 0, so mean of raw deviations is always 0.
  • Absolute value converts deviation into a distance on number line, so averaging becomes meaningful.
  • Mean deviation is an absolute measure of dispersion (same units as data).

2Diagram

Absolute deviation is a distance; raw deviations can cancel to zero.

3Key Concepts

  • 📍Distance idea: |x−a| equals distance between x and a on a number line.
  • ➕Cancellation issue: positives and negatives in ∑(xi−a) may offset.
  • 🎯Choose a as a central value: commonly x̄ (mean) or M (median).
  • 🧮M.D.(a) compares scatter across datasets even if they share the same mean/median.

4WHY RAW DEVIATIONS FAIL

  • If a lies between min and max, some xi−a are negative, some positive.
  • So ∑(xi−a) may be 0 even when data are widely scattered.
  • Special fact: for a=x̄, ∑(xi−x̄) = 0 always.
  • Hence mean of raw deviations about mean equals 0, giving no dispersion information.

5BUILDING MEAN DEVIATION M.D.(a)

  • Step 1: choose central value a (often x̄ or median M).
  • Step 2: compute absolute deviations |xi−a| for all observations.
  • Step 3: take their average: M.D.(a) = (1/n)∑|xi−a|.
  • For frequency data: replace average by weighted average using frequencies.

  • M.D.(a) is in the same units as observations, unlike variance.
  • For frequency data, use weighted average: divide by N, not by number of distinct xi.
  • Common exam asks: write formula for M.D. about mean and about median (ungrouped/discrete).

10❌Common Mistakes

  • Averaging xi−a without absolute value and concluding dispersion is zero.
  • Using |xi−a| but still dividing by wrong count (using distinct values instead of N).
  • Computing |xi−a| with arithmetic errors around fractions like 7.5.
  • Mixing up symbols: writing M.D.(M) but using x̄ in deviations (or vice versa).

MEAN DEVIATION (UNGROUPED DATA)

1Definition & Introduction

  • Mean deviation about a value a is the mean of |xi − a| for all observations.
  • It measures scatter of data around a central value using distances on a number line.
  • Absolute values are used so that positive and negative deviations do not cancel.
  • Common choices of a are mean (x̄) and median (M).
  • For ungrouped data with n observations, divide the sum of absolute deviations by n.

2Diagram

Mean deviation uses distances |xi − a| from a central value a.

3Key Concepts

  • 🧮Deviation from a: xi − a; distance on number line: |xi − a|
  • ➗Mean deviation is an absolute measure of dispersion (same unit as data).
  • 📌If a is mean, ∑(xi − x̄) = 0, so absolute value is essential.
  • 📊Smaller mean deviation ⇒ data more clustered around the chosen centre.
  • ⚠️Uses absolute values, so it is not convenient for further algebraic manipulation.

4WORKING STEPS (UNGROUPED)

  • Choose centre a (either x̄ or M).
  • Compute deviations: xi − a for each observation.
  • Take absolute values: |xi − a|.
  • Add all absolute deviations.
  • Divide by n to get M.D.(a).

5WHEN TO USE MEAN VS MEDIAN

  • M.D.(x̄) measures average absolute spread around mean.
  • M.D.(M) measures average absolute spread around median (often preferred when data has outliers or is skewed).
  • For median, first arrange data; if n odd: median is (n+1)/2-th item; if n even: mean of n/2-th and (n/2 + 1)-th items.

9⭐Important Points

  • Mean deviation is an absolute measure of dispersion based on distances from a central value.
  • Always use absolute deviations; otherwise the sum of deviations can be 0 (especially about mean).
  • For ungrouped data: compute a first, then apply M.D.(a) = (1/n)∑|xi−a|.
  • Median needs sorting; for even n, median is average of middle two observations.
  • Mean deviation cannot be conveniently used for further algebraic manipulation due to absolute values.

10❌Common Mistakes

  • Using ∑(xi − a) / n instead of ∑|xi − a| / n.
  • For median-based mean deviation, forgetting to sort the data first.
  • Wrong median for even n (taking only n/2-th item instead of average of two middle items).
  • Arithmetic slips while summing absolute deviations, especially after removing minus signs.

MEAN DEVIATION (GROUPED DATA)

1Definition & Introduction

  • Mean deviation about a central value a is the mean of absolute deviations: average of |x−a|.
  • For grouped data, each distinct value (discrete) or mid-point (continuous) acts as representative x.
  • Total frequency N = Σf is used as the divisor in all grouped mean-deviation formulas.
  • Two common choices: mean deviation about mean (x̄) and about median (M).
  • For continuous data, median is found using the median class and interpolation formula.

2Diagram

Workflow: grouped table → centre (mean/median) → absolute deviations → weighted average.

3Key Concepts

  • 🧮Always compute N=Σf first; it is the divisor in 1NΣf|…|.
  • 📌Continuous classes → replace each class by its mid-point xi for M.D. sums.
  • 🧭Median (grouped) depends on cumulative frequency: locate where c.f. ≥ N/2.
  • ⚙️Step-deviation is only a shortcut to compute x̄; M.D. still needs Σf|x−x̄| using original x.
  • ✂️Take absolute values before summing; do not cancel positive and negative deviations.

4DISCRETE vs CONTINUOUS (SETUP)

  • Discrete: values xi with frequencies fi; use given xi directly.
  • Continuous: class intervals with frequencies; compute mid-point xi = (lower+upper)/2.
  • For both types: N=Σf; compute Σfx (using xi or mid-points).
  • For mean deviation: use 1NΣf|x−centre| with centre = x̄ or M.

5MEDIAN FOR CONTINUOUS GROUPED DATA (EXAM HOTSPOT)

  • Make cumulative frequency (c.f.) column; find first class with c.f. ≥ N/2 → median class.

LIMITATIONS OF MEAN DEVIATION

1Definition & Introduction

  • Mean deviation (M.D.) has practical and theoretical drawbacks that make it less preferred than standard deviation.
  • It uses absolute deviations, so expressions become piecewise and many algebraic manipulations become difficult.
  • M.D. can be taken about mean/median/mode, so it is not uniquely defined unless the centre is specified.
  • The sum (and mean) of absolute deviations is minimum about the median; hence M.D. about mean is generally not the least possible among common centres.
  • Therefore, M.D. is less useful for advanced analysis, and standard deviation is preferred due to strong algebraic and theoretical properties.

2Diagram

Flow: absolute deviations → piecewise expressions → limited algebra → SD preferred.

3Key Concepts

  • 🧩Absolute values make M.D. intuitive (distance) but hinder algebraic manipulation.
  • 🎯M.D. is not uniquely defined unless the central value (mean/median/mode) is specified.
  • 🧪Median minimizes the sum of absolute deviations; so M.D.(median) ≤ M.D.(mean) for the same data.
  • 🧠Variance/SD (squares) supports identities and further statistical theory, so it is preferred.

4PRACTICAL DRAWBACKS (USABILITY)

  • M.D. requires specifying the centre (mean/median/mode); otherwise it is ambiguous.
  • Different datasets can share the same M.D. but differ in shape (clustering/skewness).
  • Because it ignores sign, M.D. does not indicate direction of skew; it measures only magnitude of spread.

5THEORETICAL DRAWBACKS (WHY SD IS PREFERRED)

  • M.D. uses |x − a|, making expressions piecewise and hard to simplify.
  • So M.D. cannot be subjected to further algebraic treatment easily (few useful identities).
  • The sum of absolute deviations is minimum about the median, so M.D. about mean is generally not minimal.
  • Squared deviations (variance/SD) support strong algebraic properties used widely in statistics.

7Solved Q&A

1
Why is mean deviation considered unsuitable for further algebraic treatment?
Answer:
M.D. is based on absolute values of deviations.
Absolute value makes expressions piecewise depending on whether (x − a) is positive or negative.
This prevents smooth expansions and many standard identities used for combining or transforming datasets.
✓  Because |x − a| leads to piecewise expressions, M.D. does not support convenient algebraic manipulation.
2

For any fixed dataset, the median minimizes the sum of absolute deviations ∑|x − a| among all choices of a.
Therefore, M.D. about the median is ≤ M.D. about the mean (and also ≤ M.D. about any other centre).
Using all observations is a property of the mean as a centre, but it does not make absolute deviations minimal.
✓  Incorrect. M.D. about the median is generally the smallest because the median minimizes the sum of absolute deviations.

8⭐Important Points

  • M.D. is not uniquely defined unless we specify the centre (mean/median/mode).
  • The sum/mean of absolute deviations is minimum about the median; hence M.D.(median) ≤ M.D.(mean).
  • M.D. is less useful in advanced statistical work; standard deviation is preferred due to variance-based theory.

9❌Common Mistakes

VARIANCE AND STANDARD DEVIATION

1Definition & Introduction

  • Variance is the mean of squared deviations of observations from their mean.
  • For ungrouped data: σ² = 1n Σ ( xi − x̄ )², where x̄ is the arithmetic mean.
  • Standard deviation σ is the positive square root of variance: σ = √(σ²).
  • Smaller σ or σ² ⇒ observations are closer to x̄ (less spread); larger ⇒ more dispersion.
  • Variance has squared units (e.g., cm²), so σ is preferred for interpreting spread in original units.

2Diagram

Compute x̄ → deviations ( xi−x̄ ) → square and average to get σ², then √ to get σ.

3Key Concepts

  • 🧮Squaring avoids sign-cancellation: (−d)² and d² both increase dispersion measure.
  • 📏σ is a single-number indicator of scatter around mean (not around max/min).
  • ⚖️Use 1n Σ(...)² (mean of squares), not Σ(...)², to compare datasets of different sizes.
  • 🔁Shortcut: σ² = (mean of squares) − (square of mean) for faster computation.

4WHY SQUARED DEVIATIONS?

  • Σ( xi − x̄ ) = 0 always, so raw deviations cannot measure dispersion.
  • Using |deviation| fixes signs but is less algebra-friendly; squaring keeps non-negativity and is tractable.
  • If σ² = 0 ⇒ every ( xi − x̄ )² = 0 ⇒ all observations equal.

5SET A vs SET B (SAME MEAN, DIFFERENT SPREAD)

  • Set A: 5,15,25,35,45,55 has mean 30 and larger spread about mean.
  • Set B: 15 to 45 (31 terms) has mean 30 but values are closer to mean.
  • Comparing Σ squares can mislead when n differs; compare mean of squares i.e., σ².

STANDARD DEVIATION (GROUPED DATA)

1Definition & Introduction

  • Variance (σ2) for grouped data is the mean of squared deviations from the mean, weighted by frequency.
  • For frequency distributions, total frequency N = Σf acts like the total number of observations.
  • Standard deviation σ = √(σ2) and has the same unit as the variable x.
  • For continuous classes, replace each class by its mid-point and treat it as a discrete distribution.
  • Computational formula reduces effort using Σfx and Σfx2.

2Diagram

For continuous data, first convert each class to its mid-point, then follow the same steps.

3Key Concepts

  • 🧮Mean for grouped data: x̄ = (Σfx)/N
  • 📌Core: σ2 = (1/N) Σf(x−x̄)2
  • ⚡Fast compute: σ2 = (Σfx2)/N − ((Σfx)/N)2
  • 📍Continuous case: take mid-point xi = (lower+upper)/2
  • ✅Always compute σ from σ2: σ = √(σ2)

4DISCRETE vs CONTINUOUS: HOW TO SET UP

  • Discrete: values xi with frequencies fi; compute Σf, Σfx, Σfx2.
  • Continuous: class intervals with frequencies; take mid-point xi for each class, then treat as discrete.

5COMPUTATIONAL (SHORTCUT) FORMULA: WHY IT WORKS

  • Start: σ2 = (1/N) Σf(x−x̄)2.
  • Expand: (x−x̄)2 = x2 − 2xx̄ + x̄2 and distribute Σf.
  • Use Σfx = Nx̄ and Σf = N to simplify to σ2 = (Σfx2)/N − x̄2.

SHORTCUT STEP-DEVIATION (MEAN & SD)

1Definition & Introduction

  • Step-deviation rescales data using y = (x−A)/h to simplify mean and standard deviation.
  • Choose A near the centre; take h as common factor (often class width) so y are small integers.
  • Compute with Σfy and Σfy2 instead of large Σfx and Σfx2; then convert back to x-units.
  • Mean conversion: x̄ = A + h ȳ = A + h(Σfy/N).
  • Standard deviation conversion: σx = hσy (independent of chosen A).

2Diagram

Shift origin to A and change scale by h: big x-deviations become small y.


3Key Concepts

  • 🎯Pick A near centre so Σfy is small (often near 0).
  • 📏h is the scale factor: deviations shrink by dividing by h.
  • 🔁Convert back via x = A + hy; SD multiplies by h.
  • 🧮Compute SD from Σfy and Σfy2 directly (no long x̄ table).

4WHEN & HOW TO APPLY (GROUPED/DISCRETE)

  • For continuous classes, take mid-points as x values before step-deviation.
  • Take h = class width (or any common factor of deviations) so y become small integers.
  • Compute totals: N=Σf, Σfy, Σfy2; then plug into shortcut formulas.

5WHY IT REDUCES TEDIOUS CALCULATIONS

  • Avoids large squares like x2; uses small y2 instead.
  • Mean uses only Σfy; SD uses only Σfy and Σfy2.
  • Choice of A changes intermediate Σfy, but final x̄ and σx remain the same (if computed correctly).

Define step-deviation (shift + scale):
yi = xi−Ah ⇒ xi = A + hyi
Mean using Σfx and substitute xi = A+hyi:
x̄ = Σfi(A+hyi)N = A + hΣfiyiN
Variance scales by h2 (since x−x̄ = h(y−ȳ)):
σx2 = Σfi(xi−x̄)2N = h2Σfi(yi−ȳ)2N = h2σy2
Compute σy2 without ȳ explicitly:
σy2 = Σfiyi2N − (Σfiyi)2N2
Hence shortcut formula:
σx2 = h2NΣfiyi2 − (Σfiyi)2N2 and σx = hσy

TOPIC11

EFFECT OF LINEAR CHANGE (MEAN, VARIANCE, SD)

1Definition & Introduction

  • If each observation changes linearly as y = kx + b, then mean and dispersion transform predictably.
  • Adding a constant b shifts the mean by b but leaves variance and standard deviation unchanged.
  • Multiplying all observations by k multiplies mean by k, variance by k2, and standard deviation by |k|.
  • For a wrong observation correction, update totals ∑x and ∑x2, then recompute mean and variance.
  • Variance is based on squared deviations; hence scaling affects it by the square factor.

2Diagram

Linear transformation changes centre (mean) and spread (variance/SD) in fixed ways.

3Key Concepts

  • +Addition: y=x+b ⇒ ȳ=x̄+b, σy2=σx2
  • ×Multiplication: y=kx ⇒ ȳ=kx̄, σy2=k2σx2
  • SDStandard deviation scales as σy=|k|σx
  • ΣWrong entry correction: use σ2 = ∑x2n − (mean)2 (population form for raw/ungrouped data)

4RESULTS FOR y = kx + b (EXAM CORE)

  • Mean: ȳ = kx̄ + b
  • Variance: σy2 = k2 σx2 (independent of b)
  • Standard deviation: σy = |k| σx
  • If k = 2, variance becomes 4 times; SD becomes 2 times.
  • If only +b is applied, variance and SD stay the same; only mean shifts.

5WRONG OBSERVATION CORRECTION (USING ∑x, ∑x2)

  • Given n, old mean x̄: old total is ∑x = nx̄.
  • If wrong value w is replaced by correct value c: new ∑x = old ∑x − w + c.
  • If old variance σ2 is known (population form): ∑x2 = n(σ2 + x̄2).
  • Update ∑x2: new ∑x2 = old ∑x2 − w2 + c2.
  • Recompute: new mean = ∑xn; new variance = ∑x2n − (new mean)2.

9Solved Examples

1
Example: A data set has mean x̄ = 15 and variance σ2 = 9. Find mean and variance of the new data when each observation is (i) multiplied by 2, (ii) increased by 7.
Solution:
(i) Multiply by 2: Here k=2, b=0.
New mean ȳ = kx̄ = 2×15 = 30.
New variance σy2 = k2σ2 = 22×9 = 36.
(ii) Add 7: Here k=1, b=7.
New mean ȳ = x̄+7 = 15+7 = 22.
New variance stays unchanged: σy2 = σ2 = 9.
✓  (i) mean = 30, variance = 36. (ii) mean = 22, variance = 9.
2
Example (wrong observation correction): For n=10 observations, mean was calculated as 20 and standard deviation as 4, but one observation 15 was wrong; correct observation is 25. Find the corrected mean and standard deviation.
Solution:
Old total ∑x = nx̄ = 10×20 = 200.
Corrected ∑x = 200 − 15 + 25 = 210 ⇒ new mean x̄new = 21010 = 21.
Old variance σ2 = 42 = 16.
Using σ2 = ∑x2n − x̄2 ⇒ ∑x2 = n(σ2 + x̄2) = 10(16 + 202) = 10(416) = 4160.
Corrected ∑x2 = 4160 − 152 + 252 = 4160 − 225 + 625 = 4560.
New variance = 456010 − 212 = 456 − 441 = 15 ⇒ new SD = √15.
✓  Corrected mean = 21; corrected standard deviation = √15 ≈ 3.873.

10⭐Important Points

  • Scaling by k squares the variance: σ2 → k2σ2.
  • Standard deviation follows absolute scale: σ → |k|σ.
  • Addition/subtraction affects only mean: x̄ → x̄±b; variance unchanged.
  • For correction problems, update ∑x and ∑x2, not individual deviations.
  • For ungrouped/raw data (population form): σ2 = ∑x2n − (mean)2.

11❌Common Mistakes

  • Writing variance scales by k (wrong); it scales by k2.
  • Changing SD on addition of constant; SD does not change for +b.
  • In correction questions, updating mean but forgetting to update ∑x2.
  • Using σ instead of σ2 inside ∑x2 = n(σ2+x̄2).
