LINEAR INEQUALITIES

TOPIC1
Comparing numbers/expressions using <, >, ≤, ≥ and interpreting solution sets

MEANING OF INEQUALITIES

1Definition & Introduction

  • Two real numbers or two algebraic expressions related by <, >, ≤ or ≥ form an inequality.
  • If the symbol is < or >, it is a strict inequality; if it is ≤ or ≥, it is a slack inequality.
  • A value of the variable that makes the inequality a true statement is called a solution.
  • The set of all solutions is the solution set (depends on the domain: ℕ, ℤ, ℝ).
  • Inequalities model “at most”, “at least”, “less than”, “greater than” type conditions in real life.

2Diagram

Number line representation of a strict inequality (open endpoint).

3Key Concepts

  • 🔣Symbols: > (greater than), < (less than), ≤ (less than or equal), ≥ (greater than or equal)
  • 🧮Numerical: 3 < 5; Literal: x < 5, y > 2, x ≥ 3
  • ↔️Double inequality: a < x < b means x lies between a and b (endpoints excluded)
  • ✅Solution check: substitute the value and verify the statement becomes true
  • 📍Number line: open circle for < or >; closed circle for ≤ or ≥

4TYPES & LANGUAGE CLUES

  • Strict: LHS < RHS or LHS > RHS (endpoint not included).
  • Slack: LHS ≤ RHS or LHS ≥ RHS (endpoint included).
  • “At most” → ≤ ; “At least” → ≥.
  • “Less than” → < ; “Greater than” → >.

5SOLUTION SET & DOMAIN

  • Solution set depends on allowed values: natural numbers (ℕ), integers (ℤ), or real numbers (ℝ).
  • Same inequality can have different solution sets in ℕ, ℤ, ℝ (due to domain restrictions).
  • For real solutions, number line shading represents all values that satisfy the inequality.

8⭐Important Points

  • Inequalities use <, >, ≤, ≥ (not the equality sign).
  • Strict (<, >) excludes equality; slack (≤, ≥) includes equality.
  • A solution is any value that makes the inequality true; all solutions form the solution set.
  • Always state the domain (ℕ/ℤ/ℝ) because it can change the solution set.
  • Double inequality a < x < b describes an interval between a and b (endpoints excluded).

9❌Common Mistakes

  • Treating ≤ as < and losing the endpoint.
  • Forgetting to mention the domain (ℕ/ℤ/ℝ) while giving the solution set.
  • Using a closed dot for < or > (should be open), or an open dot for ≤ or ≥ (should be closed).
  • Reading “at most” as ≥ instead of ≤, or “at least” as ≤ instead of ≥.

TOPIC2
Classify by what is compared, how many bounds, and algebraic form

TYPES OF INEQUALITIES

1Definition & Introduction

  • An inequality relates two real numbers/expressions using <, >, ≤ or ≥.
  • If both sides are numbers, it is a numerical inequality; if variables appear, it is literal.
  • A single inequality has one relation; a double inequality has two relations in one chain.
  • Strict: uses < or > (endpoints excluded). Slack: uses ≤ or ≥ (endpoint included).
  • Linear inequalities have variables of degree 1 (no squares, products like xy). Otherwise they are non-linear.

2Diagram

Flow of common classifications; open dot = strict, filled dot = slack.

3Key Concepts

  • 1Numerical: compare numbers only, e.g. 3 < 5, 7 ≥ 7.
  • 2Literal: compare expressions with variables, e.g. x − 2 ≤ 5.
  • 3Double inequality: a < x < b means x is between a and b.
  • 4Slack includes boundary; strict excludes boundary (filled vs open dot).
  • 5In two variables, ax + by ≤ c represents a half-plane in the x–y plane.

4STANDARD FORMS (WHAT TO RECOGNISE FAST)

  • One-variable linear: ax + b < 0, > 0, ≤ 0, or ≥ 0, with a ≠ 0.
  • Two-variable linear: ax + by < c, > c, ≤ c, or ≥ c, with a, b not both 0.
  • Non-linear (for classification): ax2 + bx + c ≥ 0; xy ≤ 1; √x > 2.

5DOUBLE INEQUALITIES: CHAIN MEANING

  • a ≤ x ≤ b means (a ≤ x) and (x ≤ b) simultaneously (intersection).
  • If bounds are strict: a < x < b excludes both endpoints.
  • On number line: strict end uses open circle; slack end uses filled circle.

6Quick classification contrasts

7Solved Q&A

1
Classify each as numerical/literal, single/double, strict/slack, linear/non-linear: (i) 7 > 5 (ii) 3 < x ≤ 8 (iii) ax + by ≥ c (a,b not both 0) (iv) x2 − 4x + 1 ≤ 0
Answer:
(i) Numbers only ⇒ numerical; one relation ⇒ single; symbol > ⇒ strict.
(ii) Variable present ⇒ literal; chain ⇒ double; left is strict and right is slack ⇒ mixed; highest power of x is 1 ⇒ linear.
(iii) Variables x,y with power 1 only ⇒ literal; one relation ⇒ single; symbol ≥ ⇒ slack; linear in two variables.
(iv) Contains x2 ⇒ literal; single; symbol ≤ ⇒ slack; non-linear (quadratic).
✓  (i) Numerical, single, strict. (ii) Literal, double, mixed, linear. (iii) Literal, single, slack, linear (2 variables). (iv) Literal, single, slack, non-linear.
2
Write in standard form and state type: 2(3x − 1) − 5 < 0 and 40x + 20y ≤ 120
Answer:
First: 2(3x − 1) − 5 < 0 ⇒ 6x − 2 − 5 < 0 ⇒ 6x − 7 < 0.
So it is literal, single, strict, linear in one variable.
Second: 40x + 20y ≤ 120 ⇒ divide by 20 (positive, so sign unchanged) ⇒ 2x + y ≤ 6.
So it is literal, single, slack, linear in two variables.
✓  Standard forms: 6x − 7 < 0 (linear, strict, 1 variable) and 2x + y ≤ 6 (linear, slack, 2 variables).

8⭐Important Points

  • Numerical vs literal depends only on presence of variables.
  • Strict (<, >) excludes boundary; slack (≤, ≥) includes boundary.
  • A double inequality represents an AND condition (intersection).
  • Linear means highest power of each variable is 1 and no products like xy.
  • For linear in two variables, the boundary ax + by = c is a straight line.

9❌Common Mistakes

  • Calling 3 < x ≤ 8 a strict inequality overall; it is mixed.
  • Thinking ax + b ≤ 0 is non-linear because of two terms; it is degree 1.
  • Reading a ≤ x ≤ b as an OR condition; it is an AND condition.
  • Assuming in ax + by ≤ c both a and b must be nonzero; one may be 0.

TOPIC3
Solving an inequality = finding all values that make it a true statement

SOLUTIONS AND SOLUTION SET

1Definition & Introduction

  • A solution of an inequality in one variable is a value of the variable that makes it a true statement.
  • The solution set is the collection (set) of all solutions, written in roster or interval form.
  • To solve an inequality means to describe the entire solution set within a specified domain (ℕ/ℤ/ℝ).
  • Different domains give different solution sets for the same inequality (e.g., integers vs reals).
  • Trial-and-error can find some solutions, but is slow and may miss solutions; algebra gives a systematic method.
  • On a number line: use an open circle for < or >, and a filled circle for ≤ or ≥.

2Diagram

Solution sets can be shown on a number line using open/filled circles at boundary points.

3Key Concepts

  • NoneCheck a value by substitution: inequality becomes true → it is a solution.
  • NoneDomain matters: x ∈ ℕ, ℤ, ℝ changes which values are allowed.
  • NoneGoal is all solutions: express as a set/interval and (often) show on number line.
  • NoneMultiplying/dividing by a negative number reverses the inequality sign.

4WHAT DOES IT MEAN TO SOLVE?

  • Start with an inequality (e.g., 30x < 200) and a domain (ℕ/ℤ/ℝ).
  • A value is a solution if substitution makes the inequality statement true.
  • Write the answer as a set: roster (often for ℕ/ℤ) or interval form (often for ℝ).
  • If the domain is restricted, exclude values not allowed by the domain (e.g., fractions if x counts packets).

5WHY NOT JUST TRIAL-AND-ERROR?

  • Trial-and-error is slow when many values must be checked.
  • It may miss solutions when the set is infinite (e.g., x < 2 in ℝ).
  • Algebraic rules help isolate the variable systematically.
  • Always state the final set consistent with the given domain.

9⭐Important Points

  • Always mention the domain; without it, the solution set can change.
  • A solution is a value; the solution set is a set of all such values.
  • For ℝ, answers are often written in interval form like (−∞,2), [8,∞).
  • Number line: open circle for <,>; filled circle for ≤,≥.
  • Multiplying/dividing by a negative reverses the sign; a common exam trap.

10❌Common Mistakes

  • Forgetting to reverse the inequality sign when multiplying/dividing by a negative number.
  • Giving a real-number interval when the domain is ℤ or ℕ (or vice versa).
  • Including the boundary point in strict inequalities (< or >).
  • Listing a few trial values and calling it the full solution set.

TOPIC4
Operational rules: add/subtract freely; multiply/divide carefully (negative flips sign)

RULES FOR SOLVING LINEAR INEQUALITIES

1Definition & Introduction

  • To solve an inequality, apply operations to both sides to isolate the variable while keeping truth unchanged.
  • Rule 1: Add (or subtract) the same real number on both sides; inequality sign stays the same.
  • Rule 2 (positive): Multiply (or divide) both sides by the same positive number; sign stays the same.
  • Rule 2 (negative): Multiply (or divide) both sides by the same negative number; reverse the inequality sign.
  • After solving, express the solution set (interval form) and verify with a quick test value if needed.

2Diagram

Flow of operations: only multiplying/dividing by a negative reverses the inequality sign.

3Key Concepts

  • ➕Adding/subtracting the same number preserves order: a < b ⇒ a+c < b+c
  • ✖️Multiplying/dividing by positive preserves order; by negative reverses order
  • 🔁Sign flip mapping: < ↔ > and ≤ ↔ ≥ when multiplied/divided by a negative
  • 🧪Quick sanity check: pick a test value from your interval; substitute to confirm truth

4PROPERTY STATEMENTS (ORDER PRESERVING / REVERSING)

  • If a < b, then a + c < b + c for any real c.
  • If a < b and c > 0, then ac < bc and a ÷ c < b ÷ c.
  • If a < b and c < 0, then ac > bc and a ÷ c > b ÷ c.
  • Same rules hold for ≤ and ≥ (keep equality allowed; only direction may flip).

5WHY DOES THE SIGN FLIP FOR NEGATIVES? (MICRO-DERIVATION IDEA)

  • Start with true inequality 3 > 2.
  • Multiply by −1: (−1)·3 = −3 and (−1)·2 = −2.
  • On number line, −3 lies left of −2, so −3 < −2: direction reverses.
  • Hence multiplying/dividing by a negative reverses <↔> and ≤↔≥.

10⭐Important Points

  • Only multiplying/dividing by a negative changes the direction of inequality.
  • Division by 0 is never permitted in inequalities (same as equations).
  • Keep track of strict vs slack: <,> give open endpoints; ≤,≥ include endpoints.
  • When simplifying, apply Rule 1/2 stepwise; avoid jumping steps that hide a sign flip.
  • After final interval, a quick substitution value can catch sign-flip mistakes fast.

11❌Common Mistakes

  • Forgetting to reverse the sign when dividing or multiplying by a negative number.
  • Reversing sign when adding/subtracting a negative (not needed; Rule 1 never flips).
  • Dropping the equality part while moving from ≤/≥ to final answer (endpoint lost).
  • Arithmetic slip in fraction simplification after dividing (especially with negatives).

LINEAR INEQUALITIES IN ONE VARIABLE

1Definition & Introduction

  • A linear inequality in one variable compares two linear expressions using <, >, ≤, ≥.
  • A solution is any value of x that makes the inequality a true statement.
  • Solutions depend on the domain: real numbers, integers, or natural numbers.
  • To solve, use algebra like equations, but reverse the inequality sign when multiplying/dividing by a negative.
  • Final answers are written as intervals (reals) or as a set/list (integers/naturals) and shown on a number line.

2Diagram

Workflow + number-line convention (open dot for strict inequality).

3Key Concepts

  • ➕Add/subtract same number on both sides: sign stays same.
  • ✖️Multiply/divide by positive: sign stays same; by negative: flip (<↔>, ≤↔≥).
  • 🧩For fractions, clear denominators using LCM; track sign if multiplying by a negative.
  • 🔢Domain filter: after solving in reals, restrict to integers/naturals if asked.
  • 📍Graph on number line: open dot for <,>; filled dot for ≤,≥; shade correct side.

4STANDARD PROCEDURE (ONE VARIABLE)

  • Step 1: Expand brackets; simplify both sides.
  • Step 2: Move all x-terms to one side using Rule 1 (add/subtract).
  • Step 3: Move constants to the other side.
  • Step 4: Divide by the coefficient of x; if it is negative, reverse the sign.
  • Step 5: Write solution in interval form; then apply domain (ℝ/ℤ/ℕ) if specified.

5FRACTION INEQUALITIES & DOMAIN NOTES

  • Clear denominators by multiplying both sides by LCM of denominators.
  • If LCM is positive (usual case), sign stays; if multiplied by a negative, flip sign.
  • For real-domain answers: use ( ) for <,>; use [ ] for ≤,≥.
  • For integer/natural domains: list all integers satisfying the final real inequality.

  • Graphing: open dot for <,>; filled dot for ≤,≥; shade correct side.

11❌Common Mistakes

  • Clearing fractions incorrectly (wrong LCM factor or wrong distribution).
  • Writing interval brackets wrongly: using [ ] for strict inequalities.
  • Listing integer solutions without applying the final bound correctly (off-by-one near boundary).

NUMBER LINE GRAPHS

1Definition & Introduction

  • A number line graph shows a set of real numbers on a number line using an endpoint marker and shading.
  • Open circle at a means a is not included (used for < or >).
  • Closed (filled) circle at a means a is included (used for ≤ or ≥).
  • Shading shows all allowed values: left side for “less than”, right side for “greater than”.
  • Interval notation matches the endpoint type: ( ) for open end, [ ] for closed end.
  • For a double inequality, shade only between the two boundary points with correct open/closed endpoints.

2Diagram

Open circle for </>; closed circle for ≤/≥; shade left/right to show the solution set.

3Key Concepts

  • ⚪Strict inequality (<, >) → open circle; boundary excluded.
  • ⚫Inclusive inequality (≤, ≥) → closed circle; boundary included.
  • ➡️Shading direction: x<a left; x>a right.
  • 🔁Graph ↔ interval: open end ↔ ( ), closed end ↔ [ ].
  • 🧩For multiple conditions together, keep only the common shaded part (intersection).

4HOW TO DRAW (EXAM-FAST)

  • Step 1: Mark the boundary value(s) on the number line.
  • Step 2: Use open circle for < or >; closed circle for ≤ or ≥.
  • Step 3: Shade left for “less than”, shade right for “greater than”.
  • Step 4: For two boundaries, shade only the region between them.
  • Step 5: Write the matching interval notation using ( ) or [ ].

5INTERVAL & SET NOTATION (QUICK CONVERSIONS)

  • x < a ↔ (−∞, a) and graph is open at a + left ray.
  • x ≤ a ↔ (−∞, a] and graph is closed at a + left ray.
  • x > a ↔ (a, ∞) and graph is open at a + right ray.
  • x ≥ a ↔ [a, ∞) and graph is closed at a + right ray.
  • p < x < q ↔ (p, q); p ≤ x < q ↔ [p, q).

  • Open circle means the boundary value is excluded; closed circle means included.
  • Left shading corresponds to “less than”; right shading corresponds to “greater than”.
  • Infinity is never included, so ±∞ always uses round brackets: (−∞, a), (a, ∞).
  • Two-sided inequalities shade only between the two endpoints.
  • For multiple inequalities together, final graph shows the intersection (common region).

9❌Common Mistakes

  • Using a closed circle for < or > (including the boundary incorrectly).
  • Shading in the wrong direction after identifying the sign.
  • Writing [−∞, a) or (a, ∞] (incorrectly including infinity).
  • Swapping [ ] and ( ) while converting between a graph and interval notation.

TOPIC7
Solve multiple inequalities together; answer is their common solution set

SYSTEMS OF INEQUALITIES

1Definition & Introduction

  • A system of inequalities is a set of two or more inequalities considered simultaneously.
  • A solution is a value (or ordered pair) that satisfies every inequality in the system.
  • The solution set is the intersection (common part) of the individual solution sets.
  • For one variable, the solution is usually an interval (or union of intervals) on the number line.
  • For two variables, the solution is a region in the plane common to all half-planes (with boundary included for ≤, ≥).

2Diagram

Example intersection: filled dot included, open dot excluded

3Key Concepts

  • 🔁Solve each inequality, then take common values (intersection).
  • ➕Add/subtract the same number on both sides: inequality sign unchanged.
  • ✖️Multiply/divide by a positive number: sign unchanged; by a negative number: sign reverses.
  • ⚪Graphing in 1D: open circle for <, >; filled circle for ≤, ≥.
  • 📍A double inequality like a ≤ expr < b means both: a ≤ expr AND expr < b.

4HOW TO SOLVE (ONE VARIABLE)

  • Step 1: Solve each inequality separately (get intervals).
  • Step 2: If you multiply/divide by a negative number, reverse < ↔ >, ≤ ↔ ≥.
  • Step 3: Take intersection of intervals (common overlap).
  • Step 4: Write answer in interval form, and optionally show on number line.

5DOUBLE INEQUALITIES & SYSTEMS

  • A chain a < expr ≤ b means: (a < expr) AND (expr ≤ b).
  • You can solve the chain by operating on all three parts together, or split into two inequalities and intersect.
  • Final solution keeps each endpoint strict/inclusive based on <, >, ≤, ≥.

  • Keep track of strict vs inclusive endpoints to write correct interval brackets.
  • Multiplying/dividing by a negative number reverses the inequality sign.
  • A double inequality is a compact system; treat it as two inequalities joined by AND.
  • For real-number solutions, intervals are natural; for integer/natural solutions, list allowable values in the interval.

  • Combining inequalities by taking union instead of intersection (using OR instead of AND).
  • Wrong brackets: using [ ] for strict , or using ( ) for ≤ or ≥.

DOUBLE INEQUALITIES

1Definition & Introduction

  • A double (compound) inequality chains two inequalities, e.g. a ≤ f(x) < b.
  • It means both conditions hold simultaneously: a ≤ f(x) and f(x) < b.
  • Solve by splitting into two inequalities, solving each, then taking the common x values (intersection).
  • For linear cases, the solution is usually an interval such as [p, q), (p, q], etc.
  • When multiplying/dividing by a negative number, reverse every inequality sign in the chain.

2Diagram

Number-line view: closed at -1, open at 2 gives [-1, 2).

3Key Concepts

  • 🔗Chain meaning: a ≤ f(x) < b is shorthand for two inequalities at once.
  • ✂️Method: split → solve → intersect (keep common part).
  • ↔️If you multiply/divide the whole chain by a negative, reverse both inequality signs.
  • 📍Interval language: ≤/≥ gives a closed endpoint; </> gives an open endpoint.

4STANDARD PROCESS (SPLIT → SOLVE → COMBINE)

  • Write a ≤ f(x) < b as a ≤ f(x) and f(x) < b.
  • Solve each inequality using normal rules (add/subtract same number; ×/÷ positive keeps sign).
  • If you ×/÷ by a negative, reverse the sign in that inequality (or reverse both signs in the whole chain).
  • Combine by taking the intersection: keep only x-values common to both solutions.
  • Express final answer in interval form and (optionally) show on a number line.

5ENDPOINTS & INTERVAL NOTATION (EXAM-FAVOURITE)

  • If endpoint uses ≤ or ≥, it is included: write [ or ] and use a filled dot.
  • If endpoint uses < or >, it is excluded: write ( or ) and use a hollow dot.
  • Example: p ≤ x < q ⇔ x ∈ [p, q).
  • Always keep chain in increasing order: write smaller bound on left, larger on right.

1
Solve the double inequality −8 ≤ 5x − 3 < 7.
Solution:

Solution:

Subtract 5 throughout: −15 ≤ −3x ≤ 11.
Divide throughout by −3 (negative, reverse both signs): 5 ≥ x ≥ −113.
Write in increasing order: −113 ≤ x ≤ 5.
✓  x ∈ [−11/3, 5]

9⭐Important Points

  • A chained inequality means both inequalities must hold (logical AND).
  • When manipulating a chain, apply operations to all three parts consistently.
  • Dividing/multiplying by a negative reverses each inequality sign; many errors happen here.
  • Final answer is the intersection of the two solution sets; it may be an interval or an empty set.
  • Write endpoints correctly using [ ] for inclusive and ( ) for exclusive.

10❌Common Mistakes

  • Solving the two parts correctly but taking union instead of intersection.
  • Forgetting to reverse signs when dividing by a negative (especially in a chained step).
  • Not applying an operation to the entire chain (changing only one side).
  • Leaving the final chain in decreasing order without rewriting, e.g. 5 ≥ x ≥ −11/3.

TOPIC9
Translate real-life constraints into linear inequalities and find the feasible range

APPLICATIONS IN WORD PROBLEMS

1Definition & Introduction

  • Word problems become linear inequalities when conditions involve “at most / at least / less than / more than”.
  • Choose variables, write each condition as an inequality, then solve to get the feasible set.
  • For “average at least …”, convert to a condition on total: total marks ≥ (number of tests) × (required average).
  • For “between … and …”, write a double inequality and solve simultaneously.
  • In mixture/percentage problems, work with amount of solute and compare it with required % of the total mixture.

2Diagram

Intersection-type answer often appears as an interval on a number line (filled vs open endpoint).

3Key Concepts

  • 🔁“At most” → ≤, “at least” → ≥, “less than” → <, “more than” → >
  • 🧮When multiplying/dividing an inequality by a negative number, reverse the sign
  • 📌If variable represents count/length, apply domain: natural number/integer/real as stated
  • 🧭Solve multiple conditions by taking the intersection (common part) of solution sets
  • 📈On number line: open circle for < or > (endpoint excluded); filled circle for ≤ or ≥

4STANDARD WORD-TO-MATH TRANSLATIONS

  • Budget: “Total cost at most M” → cost expression ≤ M
  • Capacity: “Can occupy at most …” → sum of items ≤ limit
  • Average: “Average at least A” → sum of scoresnumber ≥ A
  • Consecutive integers: use x, x+1; consecutive odd: x, x+2
  • Range: “between p and q” → p < variable < q (use ≤ if endpoints included)

5PROCESS (FAST EXAM METHOD)

  • Step 1: Define variable(s) with units (packets, marks, litres, cm).
  • Step 2: Convert each sentence to an inequality (use ≤/≥ carefully).
  • Step 3: Solve using Rule 1 (add/subtract) and Rule 2 (×/÷; reverse sign if negative).
  • Step 4: If multiple inequalities, take common solution; write interval form.
  • Step 5: Apply domain restriction (natural/integer/real) and state final range.

6Formulas

Average condition
If average ≥ A for n items, then S + xn ≥ A ⇒ S + x ≥ nA (where S is sum of known marks).
Mixture (percentage) model
If x litres of p% is added to V litres of q%, then solute = px100 + qV100, total = x + V.
Required percentage range (r% to s%)
To keep resulting % between r and s: r100(x+V) < solute < s100(x+V), where solute is as above.
x =unknown quantity (marks / litres / length / number of items)
S =sum of known scores/quantities
n =total number of observations/tests/items
p, q, r, s =percent concentrations (in %)
V =given volume/quantity before adding
Key inequality-solving rule
If a < b, then (−a) > (−b) (inequality reverses when multiplied/divided by a negative number).

Example graph: open circle means endpoint not included (strict inequality).

8Solved Examples

1
A student scored 62 and 48 in two exams. Find the minimum marks x in the annual exam to have an average of at least 60 (3 exams total).
Solution:
Average condition: 62 + 48 + x3 ≥ 60
62 + 48 + x ≥ 180 ⇒ 110 + x ≥ 180
x ≥ 70
✓  Minimum marks required = 70.
2
Find all pairs of consecutive odd natural numbers, both larger than 10, whose sum is less than 40.
Solution:
Let smaller odd number be x, next is x + 2.
Conditions: x > 10 and x + (x + 2) < 40
2x + 2 < 40 ⇒ 2x < 38 ⇒ x < 19
So 10 < x < 19 and x odd ⇒ x = 11, 13, 15, 17
✓  Pairs: (11, 13), (13, 15), (15, 17), (17, 19).

9⭐Important Points

  • Write inequalities exactly as the language: “at most” includes equality; “less than” excludes equality.
  • After solving, always state solution in correct set: interval for real numbers, list for integers/naturals when required.
  • For double inequality, perform the same operation on all three parts; if multiplying/dividing by a negative, reverse all inequality signs.
  • In mixture problems, work with “amount of solute” (percentage × quantity) and compare with required fraction of total.
  • Final answer should satisfy every original condition (quick check by substitution if time).

10❌Common Mistakes

  • Forgetting to reverse the inequality sign when multiplying/dividing by a negative number.
  • Mixing up “at least” (≥) with “more than” (>) and “at most” (≤) with “less than” (<).
  • Ignoring domain constraints like x must be a natural number or cannot be negative (length/volume).
  • In mixture problems, comparing percentages directly without converting to solute amounts.
