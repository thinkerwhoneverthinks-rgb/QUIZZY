SYSTEM AND SURROUNDINGS

1Definition & Introduction

  • System = the part of the universe under observation for a thermodynamic study.
  • Surroundings = everything outside the system that can interact with it.
  • Universe = System + Surroundings.
  • Boundary = real or imaginary surface separating system and surroundings.
  • All heat and work bookkeeping is done with respect to the boundary and the direction of transfer.

3Key Concepts

  • 🧪Pick the system clearly (reaction mixture, gas in cylinder, solution in beaker).
  • 🧱Boundary can be real (walls, piston) or imaginary (drawn around a region).
  • 🔁Across boundary, track (i) matter transfer and (ii) energy transfer as heat/work.
  • 🔥Energy exchange can occur even when matter cannot (sealed conducting vessel).
  • 🚫If neither matter nor energy (heat/work) crosses, the system is isolated (ideal thermos).

4HOW TO CHOOSE THE SYSTEM (EXAM STYLE)

  • Choose the minimum region needed to answer the question (often the reacting mixture).
  • State the boundary explicitly: beaker walls, piston face, membrane, or an imaginary surface.
  • Decide what is in surroundings: air/room, water bath, container walls, piston weights.

5EXCHANGE ACROSS BOUNDARY (WHAT YOU TRACK)

  • Matter exchange: molecules/ions enter or leave system (e.g., evaporation, gas escape, inlet/outlet).
  • Energy exchange: transfer as heat and/or work across the boundary (e.g., heating, electrical work, expansion work).
  • A boundary may be diathermic (heat can pass) or adiabatic (heat cannot pass).

7Solved Q&A

1
A and B react in a beaker kept on a table in a room. Identify system, surroundings, boundary, and what can be exchanged.
Answer:
System: reaction mixture inside the beaker (A + B + products).
Boundary: surface separating mixture from rest (beaker walls + an imaginary surface across the open top).
Surroundings: beaker material, table, air of the room, and everything outside the boundary.
Because the beaker is open, matter (vapours/gases) and energy (heat/work) can be exchanged with surroundings.
✓  System = mixture; boundary = beaker walls + imaginary top surface; surroundings = everything outside; open system so both matter and energy can cross.
2
A reaction occurs in a sealed copper vessel placed in a water bath. Classify the system and justify using boundary exchanges.
Answer:
Sealing prevents matter exchange across the boundary (no mass enters/leaves).
Copper is a good conductor, so heat can pass between system and water bath (energy exchange occurs).
Hence it is a closed system: energy can cross, matter cannot.
✓  Closed system: no matter transfer through the sealed boundary, but heat can be exchanged through copper walls.

8⭐Important Points

  • Universe = System + Surroundings is the starting statement.
  • Thermodynamic quantities like heat and work are defined only after fixing the boundary.
  • A boundary may be real (wall, membrane) or imaginary (drawn surface).
  • System type is decided by what crosses boundary: matter, energy (heat/work), both, or neither.
  • In most chemistry problems, system = reacting mixture; surroundings = container + environment (if outside the chosen boundary).

9❌Common Mistakes

  • Calling the container (beaker) the system when the question intends the contents as system.
  • Forgetting that an imaginary boundary is allowed (system need not be a physical vessel).
  • Confusing closed with isolated: closed allows energy exchange; isolated does not.
  • Ignoring that surroundings can include container walls if system is defined as only the contents.

TOPIC3

State Functions and Variables

1Definition & Introduction

  • The state of a system is specified by measurable macroscopic variables like p, V, T, n.
  • A state function depends only on the current state (initial & final), not on how the state was reached.
  • A path function depends on the route/process followed between two states.
  • Only a minimum set of independent variables needs to be fixed; others become definite automatically (for a specified system under given constraints).
  • Examples: U, H, S, G, p, V, T are state functions; q and w are not.

2Diagram

Two different paths between the same states: state functions give the same change, but q and w can differ.

3Key Concepts

  • 🧪Macroscopic properties are bulk-measurable; they ignore molecular-level details.
  • 📌Fixing state variables fixes the state; same state ⇒ same values of all state functions.
  • 🛣️Path matters for q and w: different processes can give different heat/work for same endpoints.
  • 🔁Cyclic process: change in any state function over a cycle is zero.
  • ⚖️State functions enable comparison using only initial and final equilibrium states.

4STATE VARIABLES (MACROSCOPIC DESCRIPTION)

  • Common variables: p (pressure), V (volume), T (temperature), n (amount of substance).
  • These are called state variables because their values define the equilibrium state.
  • Not all variables are independent; the minimum independent set depends on the system and constraints.
  • If the system returns to the same state, each state variable returns to its original value (net change = 0).

5STATE FUNCTION vs PATH FUNCTION (EXAM FAVORITE)

  • State function: depends only on state; change is fixed by endpoints (e.g., ΔU, ΔH, ΔS, ΔG).
  • Path function: depends on process details (e.g., reversible/irreversible); q and w are path functions.
  • Different paths between same states can have different q and w, even though ΔU is the same.
  • In a cycle: Δ(state function) = 0, but net q and net w need not be zero individually.

7Solved Q&A

1
Two different processes take an ideal gas from state 1 (p1, V1, T1) to state 2 (p2, V2, T2). Can ΔU be different for the two processes? What about q and w?
Answer:
ΔU is a state function, so it depends only on the initial and final states.
Therefore, for the same state 1 and state 2, ΔU must be the same for both processes.
q and w describe energy transfer during a process, so they are path functions.
Hence, for different paths between the same endpoints, q and w can take different values, while giving the same ΔU for fixed endpoints.
✓  ΔU is identical for both paths; q and w can be different.
2
A system undergoes a cyclic process and returns to its initial state. What can you conclude about changes in p, V, T, U, H, S, G and about net q, net w over the cycle?
Answer:
In a cycle, the initial state equals the final state.
So all state variables (p, V, T) and state functions (U, H, S, G) have zero net change over the cycle.
q and w are path functions; their net values over a cycle depend on the specific cycle and need not be zero individually.
✓  Net change in all state variables/functions is zero; net q and net w may be nonzero.

8⭐Important Points

  • State of a system is defined by macroscopic variables (p, V, T, n) at equilibrium.
  • State functions are path-independent properties: U, H, S, G, and also p, V, T as state variables.
  • q and w are not properties of a state; they describe energy transfer during a process.
  • Same initial and final states guarantee the same change in any state function, regardless of reversibility.
  • For any cycle, ΔU = ΔH = ΔS = ΔG = 0 because the system returns to the initial state.

9❌Common Mistakes

  • Calling q or w a state function because ΔU is fixed for given endpoints.
  • Thinking fixing any two of p, V, T always defines the state for all systems (depends on system/constraints).
  • Confusing the terms ‘state variable’ and ‘state function’; both are path-independent state properties, while q, w are not properties.
  • Assuming in a cycle net q = 0 and net w = 0 individually (only state function changes must be zero).

TOPIC4

FIRST LAW AND INTERNAL ENERGY

1Definition & Introduction

  • Internal energy (U) is total energy stored within a system; only ΔU is measurable.
  • State function: ΔU depends only on initial and final states, not on path.
  • Joule (adiabatic) experiments show same adiabatic work gives same state change ⇒ ΔU = wad.
  • At constant volume (ΔV=0), PV-work is zero, so heat supplied changes U: ΔU = qV.
  • First Law (IUPAC): ΔU = q + w, where energy gained by system is taken positive.

2Diagram

IUPAC sign convention: energy entering system is positive; ΔU links heat and work.

3Key Concepts

  • 🔁U is a state function; q and w are path functions.
  • 🧊Adiabatic process: q = 0 ⇒ ΔU = wad.
  • 🧱Constant volume: PV work = 0 ⇒ ΔU = qV.
  • ➕IUPAC signs: q positive into system; w positive on system.
  • ♻️Isolated system: q=0 and w=0 ⇒ ΔU=0 (energy conserved).

4JOULE EXPERIMENTS ⇒ U IS A STATE FUNCTION

  • Adiabatic wall: q = 0, so any energy change is due to work only.
  • Same initial → final state reached by different adiabatic methods (stirring, electrical heating).
  • Measured adiabatic work is identical for the same state change ⇒ ΔU depends only on states.
  • Hence for adiabatic change: ΔU = wad (path-independence of ΔU).

5FIRST LAW (MASTER EQUATION) + SPECIAL CASES

  • First Law: ΔU = q + w (for a closed system).
  • Isolated: q=0, w=0 ⇒ ΔU=0.
  • Adiabatic: q=0 ⇒ ΔU=wad.
  • Constant volume: ΔV=0 ⇒ PV-work = 0 ⇒ ΔU=qV.
  • Sign sense: system gains heat/work ⇒ q, w positive; system loses ⇒ negative.

9⭐Important Points

  • Joule experiments establish ΔU depends only on state, not on how work is performed.
  • In adiabatic change, heat exchange is zero: q=0, so ΔU equals adiabatic work.
  • At constant volume, PV-work is zero; measured heat equals ΔU.
  • First Law is conservation of energy for thermodynamic systems: ΔU=q+w.
  • Always state sign convention: IUPAC takes w positive for work done on the system.

10❌Common Mistakes

  • Using old physics sign convention (w by system positive) without noticing IUPAC requirement.
  • Writing ΔU = q − w while still using IUPAC signs (double sign error).
  • Saying "adiabatic means temperature constant"; actually adiabatic means q=0.
  • Assuming constant volume implies ΔU=0; actually ΔU=qV may be nonzero.

PRESSURE–VOLUME WORK

1Definition & Introduction

  • Pressure–volume work is work associated with volume change of a gas against external pressure pex.
  • IUPAC sign: w is positive when work is done on the system; negative when done by the system.
  • For expansion: ΔV > 0 ⇒ w < 0; for compression: ΔV < 0 ⇒ w > 0.
  • Irreversible expansion at constant pex: w depends on pex, hence on the path.
  • Reversible expansion/compression occurs via infinitesimal pressure difference, giving maximum |w| for a given initial and final state.

2Diagram

On a p–V plot, the area under the curve gives |w|; reversible path gives maximum magnitude.

3Key Concepts

  • 🧭Core formula: w = −pexΔV (constant external pressure).
  • 🧩Finite-step path: w = −Σ pexΔV (sum over steps).
  • ♾️Reversible path: wrev = −∫ViVf p dV (use internal pressure p).
  • 🌡️Ideal-gas isothermal reversible: p = nRTV ⇒ wrev = −2.303 nRT log(Vf/Vi).
  • 🕳️Free expansion (into vacuum): pex = 0 ⇒ w = 0 even though ΔV > 0.

4CONSTANT EXTERNAL PRESSURE (IRREVERSIBLE) & FINITE STEPS

  • If surroundings exert constant pex, then w = −pex(Vf−Vi).
  • Expansion: system pushes surroundings ⇒ w negative; compression: surroundings push system ⇒ w positive.
  • If pex changes in stages: w = −Σ pexΔV (use each step’s external pressure).
  • Irreversible work depends on chosen pex; different paths give different w.

5REVERSIBLE WORK & ISOTHERMAL IDEAL-GAS EXPANSION

  • Reversible (quasi-static): system is in mechanical equilibrium, so p differs from pex infinitesimally.
  • wrev = −∫ p dV; for an ideal gas isothermal, p = nRTV.
  • So wrev = −nRT ln(Vf/Vi) = −2.303 nRT log(Vf/Vi).
  • For given Vi→Vf, |wrev| > |wirrev| (maximum work in reversible expansion).

  • Free expansion: pex = 0 ⇒ w = 0, regardless of ΔV.
  • For same initial and final states, |wrev| is maximum; irreversible gives smaller magnitude.

11❌Common Mistakes

  • Forgetting the minus sign in w = −pexΔV, flipping expansion/compression signs.
  • Using p of the gas instead of pex for irreversible constant-pressure work.
  • Mixing log and ln without the 2.303 factor in isothermal reversible work.
  • Unit mismatch: using R in J but pressure-volume in L·atm or bar·L without conversion.

ENTHALPY AND HEAT CAPACITIES

1Definition & Introduction

  • Enthalpy is a state function defined as H = U + pV.
  • At constant pressure (and for a closed system doing only pV-work), heat exchanged equals enthalpy change: ΔH = qp.
  • At constant volume (and for a closed system doing only pV-work), heat exchanged equals internal energy change: ΔU = qV.
  • For reactions involving gases (ideal-gas approximation), ΔH and ΔU differ by ΔngRT.
  • Heat capacity links heat and temperature rise: q = CΔT; molar heat capacity Cm = Cn.

3Key Concepts

  • 🧩H includes the “flow work” term pV; that’s why it matches constant-pressure heats (under only pV-work).
  • 📌Sign (IUPAC): exothermic → ΔH < 0; endothermic → ΔH > 0. Also, heat into system: q > 0.
  • 🔁For ideal gases: ΔH = ΔU + ΔngRT (Δng counts gaseous moles only).
  • ⚖️Cp > CV for gases since some heat at constant p does expansion work.
  • 📈For 1 mol ideal gas: Cp − CV = R.

4EXTENSIVE vs INTENSIVE (EXAM FAVOURITE)

  • Extensive depends on amount: U, H, V, mass, heat capacity C.
  • Intensive independent of amount: T, p, density, molar heat capacity Cm.
  • Doubling the system doubles extensive properties; intensive properties remain unchanged.
  • Enthalpy is extensive: multiplying a thermochemical equation by k multiplies ΔH by k.

5HEAT CAPACITIES: C, Cp, CV

  • Heat capacity: q = CΔT; units J K−1 (or kJ K−1).
  • Molar heat capacity: Cm = Cn; units J mol−1 K−1.
  • At constant volume (closed system, only pV-work): qV = ΔU; for temperature change, qV = nCVΔT.
  • At constant pressure (closed system, only pV-work): qp = ΔH; for temperature change, qp = nCpΔT.
  • For 1 mol ideal gas: Cp − CV = R (8.314 J mol−1 K−1).

REACTION ENTHALPY & HESS'S LAW

1Definition & Introduction

  • Reaction enthalpy ΔrH is heat change at constant pressure for the balanced reaction.
  • ΔrH = ΣaiHi(products) − ΣbiHi(reactants); coefficients are stoichiometric moles.
  • Standard reaction enthalpy ΔrH° applies when all substances are in standard states (pure, 1 bar; usually 298 K).
  • Phase transition enthalpies: ΔHfus°, ΔHvap°, ΔHsub° are defined for 1 mol change at constant T, p (typically endothermic).
  • Standard enthalpy of formation ΔfH°: enthalpy change to form exactly 1 mol compound from elements in reference states; elements in reference state have ΔfH°=0.
  • Hess’s law: since enthalpy is a state function, overall ΔH equals sum of ΔH values of any set of steps giving the same net reaction.

2Diagram

Hess’s law: direct ΔrH equals sum of ΔH values along any indirect path with same net reaction.

3Key Concepts

  • 📌Thermochemical equation must include physical states; ΔH belongs to that exact balanced equation.
  • 🔁Multiply equation by n ⇒ multiply ΔH by n; reverse equation ⇒ change sign of ΔH.
  • 🏷️Standard state is 1 bar (not 1 atm); temperature must be specified if not 298 K.
  • 🧊Phase changes: solid→liquid ΔHfus°>0; liquid→gas ΔHvap°>0; solid→gas ΔHsub°>0.
  • 🧮Using formation enthalpies: ΔrH° = ΣνpΔfH°(products) − ΣνrΔfH°(reactants).

4STANDARD STATES & STANDARD ENTHALPY (ΔrH°)

  • Standard state: pure substance at 1 bar; solutions usually at 1 mol L−1 (if specified).
  • Temperature is commonly 298 K; always write physical state: (s), (l), (g), (aq).
  • Allotropic caution: ΔfH°[C(graphite)]=0 but ΔfH°[C(diamond)] ≠ 0.
  • Meaning of units: kJ mol−1 is per mole of reaction as written.

5THERMOCHEMICAL EQUATION RULES (EXAM MUSTS)

  • Scale: if coefficients are multiplied by n, then ΔH is also multiplied by n.
  • Reverse: reactants ⇌ products swapped ⇒ ΔH changes sign.
  • Add: when equations add to target, add their ΔH values (after scaling/reversing).
  • Never mix states: H2O(l) and H2O(g) have different enthalpies; include phase transition if needed.

ENTHALPIES OF REACTIONS

1Definition & Introduction

  • Standard reaction enthalpy: ΔrH° = ΣνHm°(products) − ΣνHm°(reactants), per mole of balanced reaction (ν = stoichiometric coefficients; Hm° = molar enthalpy in standard state).
  • Standard symbol (°): each substance in its standard state at 1 bar and at the specified temperature (often 298 K).
  • Enthalpy is a state function: use Hess’s law cycles to compute hard-to-measure enthalpies.
  • Signs: exothermic ΔH<0, endothermic ΔH>0; values depend on physical states.
  • Be explicit: “kJ mol−1” refers to per mole of reaction as written.

2Diagram

3Key Concepts

  • 🔥ΔcH°: standard enthalpy change for complete combustion in O2; for hydrocarbons, products include CO2(g) and H2O(l) in standard states.
  • ⚛️ΔaH°: standard enthalpy change to form gaseous atoms from the element in its standard state; diatomic element: equals bond dissociation enthalpy; metals: equals sublimation enthalpy.
  • 🔗Bond enthalpy: dissociation (specific bond in a gaseous molecule) vs mean (average for polyatomic).
  • 🧮Bond-enthalpy method (gas phase, approximate): ΔrH° ≈ ΣD(bonds broken) − ΣD(bonds formed).
  • 🧱ΔlatticeH (dissociation): NaCl(s) → Na+(g)+Cl−(g) is endothermic; obtained via Born–Haber cycle (Hess’s law).
  • 💧Solution (ionic solids): ΔsolH = ΔlatticeH + ΔhydH; dilution enthalpy tends to 0 as solution approaches infinite dilution.

4BORN–HABER CYCLE (LATTICE ENTHALPY)

  • Target definition (common in JEE): ΔlatticeH for MX(s) → M+(g)+X−(g) is positive (lattice dissociation enthalpy).
  • Formation route: elements → atoms → ions → ionic solid; apply Hess’s law around the cycle.
  • For NaCl: ΔfH° = ΔsubH(Na) + 12D(Cl–Cl) + IE(Na) + EA(Cl) − ΔlatticeH(form).
  • Careful with sign: lattice formation enthalpy is negative; dissociation lattice enthalpy is positive (equal magnitude).
  • IE always endothermic; EA here is used as electron gain enthalpy (often negative for halogens).

5BOND ENTHALPIES: DISSOCIATION vs MEAN + USING THEM

  • Bond dissociation enthalpy: energy to break one mole of a specific bond in a gaseous molecule.
  • Mean bond enthalpy: average of successive dissociations in a polyatomic molecule (values differ stepwise).
  • Approximate gas-phase reaction enthalpy: ΔrH°(gas) ≈ ΣD(broken) − ΣD(formed).
  • Better accuracy when bonds and environments are similar; poor for highly polar/ionic or non-gas-phase reactions.
  • For diatomic molecules: ΔaH° = bond dissociation enthalpy.

SPONTANEITY AND ENTROPY

1Definition & Introduction

  • Spontaneous process: can occur without continuous external assistance; criterion is thermodynamic, not kinetic.
  • A spontaneous change is irreversible in practice; reversal requires an external agency.
  • Spontaneous ≠ fast: rate depends on activation energy/mechanism (kinetics), not on spontaneity criteria.
  • ΔH alone is not sufficient: some endothermic (ΔH>0) processes are spontaneous due to entropy increase.
  • Entropy (S) is a state function measuring dispersal of energy/matter (often linked to disorder/randomness).
  • Spontaneity criterion (system + surroundings): ΔStotal > 0; at equilibrium: ΔStotal = 0.

2Diagram

3Key Concepts

  • KThermodynamics predicts direction/feasibility; kinetics predicts rate.
  • HExothermicity often helps spontaneity because surroundings gain entropy when they receive heat.
  • MMixing of gases can be spontaneous even with ΔH ≈ 0 because ΔSsys increases.
  • 2Second Law idea: for an isolated universe, spontaneous change occurs with increasing total entropy.
  • 3Third Law: entropy of a perfect crystal approaches 0 as T approaches 0 K (ideal limit); basis of absolute entropies.
  • EAt equilibrium (for fixed constraints): ΔStotal = 0 and total entropy is at a maximum.

4SPONTANEOUSNESS VS RATE (KINETICS)

  • Spontaneous means thermodynamically feasible; it may still be extremely slow.
  • Example: H2 + O2 at room temperature is feasible but needs spark/catalyst to proceed fast.
  • Rate depends on activation energy/pathway; spontaneity depends on state functions and total entropy.

5WHY ΔH ALONE FAILS + ENTROPY INTUITION

  • Many spontaneous processes are exothermic (ΔH<0), but some spontaneous processes are endothermic (ΔH>0).
  • Entropy often increases on going from solid → liquid → gas (typical trend; exceptions exist).
  • Mixing of gases: ΔH ≈ 0 yet spontaneous because number of accessible microstates increases.
  • Second Law criterion uses the total entropy change of system + surroundings.

7Solved Q&A

1
A reaction has ΔSsys < 0 but is strongly exothermic at room temperature. Can it still be spontaneous? Explain.
Answer:
Spontaneity depends on ΔStotal = ΔSsys + ΔSsurr, not on ΔSsys alone.
If the reaction releases heat, the surroundings typically gain entropy (ΔSsurr > 0).
If the entropy gain of surroundings outweighs the entropy decrease of the system, then ΔStotal becomes positive.
✓  Yes. Even with ΔSsys < 0, a sufficiently exothermic process can have ΔStotal > 0, making it spontaneous.
2
A reversible heat transfer occurs between a system and surroundings maintained at the same temperature. What is ΔStotal and what does it indicate about the driving force?
Answer:
For a reversible process, the system and surroundings remain in equilibrium at each stage (no finite temperature difference).
Entropy gained by one part equals entropy lost by the other under reversible heat exchange.
Therefore, the total entropy change for the universe is zero.
✓  ΔStotal = 0. This indicates the reversible (equilibrium-limit) case with no net driving force.

8⭐Important Points

  • Spontaneous process is irreversible; reversibility is an ideal limit with ΔStotal = 0.
  • Never judge spontaneity from ΔSsystem alone; always consider system + surroundings.
  • ΔH<0 often helps spontaneity, but ΔH is not a universal criterion.
  • For an isolated universe: spontaneous direction corresponds to increasing total entropy.
  • At equilibrium (fixed constraints): total entropy is maximum and ΔStotal = 0.

9❌Common Mistakes

  • Treating "spontaneous" as "fast"; rate is a kinetics concept.
  • Concluding non-spontaneous from ΔSsys<0 without including surroundings.
  • Stating that entropy must always increase for the system; the criterion is for the total (system + surroundings).
  • Claiming the Third Law means all substances have zero entropy at 0 K; it applies to a perfect crystal in the ideal limit.

GIBBS ENERGY AND EQUILIBRIUM

1Definition & Introduction

  • Gibbs energy G is a state function: G = H − TS, useful at constant T and pressure.
  • At constant T, ΔG = ΔH − TΔS helps decide spontaneity for a process (with appropriate constraints).
  • For a reaction at constant T, p: ΔrG < 0 (forward spontaneous), ΔrG = 0 (equilibrium), ΔrG > 0 (forward non-spontaneous).
  • At equilibrium, G is minimum for fixed T, p; hence reaction Gibbs change ΔrG = 0.
  • Standard relation links equilibrium: ΔrG° = −RT ln K = −2.303 RT log K.

2Diagram

For a reaction at constant T, p, the sign of ΔrG gives direction; at equilibrium ΔrG = 0 and K is fixed.

3Key Concepts

  • 🧭At constant T, p, the sign of ΔrG gives reaction direction; ΔH or ΔS alone is not sufficient.
  • 🌡️A sign-change temperature (ΔG crossing zero) occurs only when ΔH and ΔS have the same sign.
  • 🔗ΔrG° < 0 ⇔ K > 1 (products favoured); ΔrG° > 0 ⇔ K < 1.
  • 📉At equilibrium: ΔrG = 0, but generally ΔrG° ≠ 0 unless K = 1.

4TEMPERATURE DEPENDENCE (SIGNS OF ΔH, ΔS)

  • Use ΔG = ΔH − TΔS: increasing T increases the magnitude of the entropy term.
  • ΔH<0, ΔS>0 ⇒ ΔG<0 for all T (always spontaneous).
  • ΔH>0, ΔS<0 ⇒ ΔG>0 for all T (never spontaneous).
  • ΔH<0, ΔS<0 ⇒ spontaneous at low T; becomes non-spontaneous at high T.
  • ΔH>0, ΔS>0 ⇒ non-spontaneous at low T; spontaneous at high T.

5EQUILIBRIUM CONNECTION: ΔrG°, K

  • For reaction quotient Q: ΔrG = ΔrG° + RT ln Q (direction test at a given composition).
  • At equilibrium Q = K and ΔrG = 0 ⇒ ΔrG° = −RT ln K.
  • If K>1, lnK positive ⇒ ΔrG° negative (products favoured).
  • If K<1, lnK negative ⇒ ΔrG° positive (reactants favoured).
  • Also: ΔrG° = ΔrH° − TΔrS° links thermochemistry to equilibrium.

9Solved Examples

1
At 298 K, for a reaction ΔrH° = −40.0 kJ mol−1 and ΔrS° = −100 J K−1 mol−1. Find ΔrG° and state spontaneity under standard conditions.
Solution:
Convert entropy to kJ: ΔrS° = −100 J K−1 mol−1 = −0.100 kJ K−1 mol−1.
Compute TΔrS°: 298 × (−0.100) = −29.8 kJ mol−1.
Use ΔrG° = ΔrH° − TΔrS° = (−40.0) − (−29.8) = −10.2 kJ mol−1.
Since ΔrG° < 0, the reaction is spontaneous under standard conditions at 298 K.
✓  ΔrG° = −10.2 kJ mol−1; spontaneous at 298 K (standard state).
2
At 298 K, ΔrG° = +5.70 kJ mol−1. Calculate equilibrium constant K at 298 K. (R = 8.314 J K−1 mol−1)
Solution:
Use ΔrG° = −RT ln K ⇒ ln K = −ΔrG° ÷ (RT).
Convert ΔrG° to J: 5.70 kJ mol−1 = 5700 J mol−1.
Compute RT: 8.314 × 298 = 2477.6 J mol−1.
ln K = −5700 ÷ 2477.6 = −2.301 (approx).
K = e−2.301 ≈ 0.100.
✓  K ≈ 0.10 at 298 K (reactants favoured).

10⭐Important Points

  • ΔrG criterion for direction is used for reactions at constant T and pressure.
  • Keep units consistent: if R = 8.314 J K−1 mol−1, use ΔrG° in J mol−1.
  • At equilibrium, ΔrG = 0 but ΔrG° need not be zero; it depends on K.
  • If ΔH and ΔS have opposite signs, spontaneity does not switch with T (ΔG stays one sign).
  • Larger |ΔrG°| indicates stronger equilibrium bias: negative → products, positive → reactants.

11❌Common Mistakes

  • Using T in °C instead of K in ΔG = ΔH − TΔS or in −RT ln K.
  • Mixing kJ and J without conversion (especially with R in J K−1 mol−1).
  • Forgetting the negative sign in ΔrG° = −RT ln K.
  • Using log base 10 without the 2.303 factor (or using ln but still multiplying by 2.303).
