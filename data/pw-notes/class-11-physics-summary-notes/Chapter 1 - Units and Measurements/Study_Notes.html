Ch 01 : Units and Measurements

1.1 Introduction

Measurement = comparison of a physical quantity with an internationally accepted reference standard called a unit. Write every measurement as: Physical quantity = (numerical value) × (unit)
  • Even though physical quantities are many, we need only a limited number of units because quantities are inter-related.
  • Fundamental (base) quantities → units called fundamental/base units.
  • All others = derived quantities → units made by combining base units → derived units.
  • A full collection of base + derived units is a system of units.

1.2 The International System of Units

Earlier systems of units

Different countries historically used different systems; three common ones: CGS, FPS (British), MKS.
  • CGS: base units (length, mass, time) = centimetre (cm), gram (g), second (s).
  • FPS: base units = foot (ft), pound (lb), second (s).
  • MKS: base units = metre (m), kilogram (kg), second (s).

SI system: meaning, authority, and adoption

Internationally accepted system = Système International d’Unités (SI). Gives a standard set of symbols, units, and abbreviations.
  • Developed by International Bureau of Weight and Measure in 1971.
  • Definitions revised by the General Conference on Weights and Measures in November 2018.
  • SI is for international usage in scientific, technical, industrial, and commercial work.
  • SI is decimal-based → conversions are simple + convenient.
  • This book uses SI units.

SI base quantities and base units (seven)

SI has seven base units. The fixed numerical values used in modern definitions are not required to memorise for tests; they show achievable accuracy and change as technology improves.
SI base quantities + base units:
  • Length — metre (m)
  • Mass — kilogram (kg)
  • Time — second (s)
  • Electric current — ampere (A)
  • Thermodynamic temperature — kelvin (K)
  • Amount of substance — mole (mol)
  • Luminous intensity — candela (cd)

Modern SI definitions (conceptual basis)

Base units are defined by giving fixed numerical values to fundamental constants. Exact numbers aren’t examined here, but you must know which constant defines which unit (conceptually).
  • metre (m): via the speed of light in vacuum, c (with the second defined via caesium frequency).
  • kilogram (kg): via the Planck constant, h.
  • second (s): via the caesium-133 hyperfine transition frequency (caesium frequency, ΔνCs).
  • ampere (A): via the elementary charge, e.
  • kelvin (K): via the Boltzmann constant, k.
  • mole (mol): via the Avogadro constant, NA (Avogadro number).
  • candela (cd): via the luminous efficacy of monochromatic radiation with frequency 540 × 1012 Hz, i.e. Kcd.
Exam tip: The fixed numerical values “need not be remembered or asked in a test.” Don’t grind the long numbers—know the unit names/symbols + that definitions link to fundamental constants and improve with better measurement tech.

Plane angle and solid angle (additional defined units)

Along with the 7 base units, SI also defines:
  • Plane angle (often written dθ): ratio of arc length to radius.
  • Solid angle (often written dΩ): ratio of intercepted spherical area to radius².
Both plane angle and solid angle are dimensionless.
Plane angle (radian): dθ = ds / r ds = length of arc r = radius of the circle dθ = plane angle
Solid angle (steradian): dΩ = dA / r² dA = area intercepted on a spherical surface r = radius of the sphere dΩ = solid angle
  • Unit of plane angle: radian (rad) — dimensionless.
  • Unit of solid angle: steradian (sr) — dimensionless.

Important note about the mole

When using mole, you must state the elementary entities (what exactly is being counted).
  • Elementary entities can be: atoms, molecules, ions, electrons, other particles, or specified groups of such particles.
Avogadro statement (definition style): 1 mol contains exactly 6.02214076 × 10²³ elementary entities mol = mole, SI unit of amount of substance 6.02214076 × 10²³ = fixed numerical value of Avogadro constant (Avogadro number)

1.3 Significant Figures

Why significant figures are needed

All measurements have errors → the reported value must show the precision.
  • A correctly written measured value includes:
    1. all digits known for sure (certain digits)
    2. & the first doubtful (uncertain) digit
  • These digits together = significant digits / significant figures.

Examples illustrating significant figures

Example 1: Period of pendulum = 1.62 s
  • 1 and 6 are certain.
  • 2 is the first uncertain digit.
  • So it has 3 significant figures.
Example 2: Length = 287.5 cm
  • 2, 8, 7 are certain.
  • 5 is uncertain.
  • So it has 4 significant figures.
Common exam mistake: writing extra digits beyond the instrument precision is superfluous + misleading (fake high precision).

Significant figures and least count; effect of change of units

Significant figures show measurement precision → depends on the instrument’s least count. Changing units does NOT change the number of significant figures.

Rule/observation illustrated: unit conversion keeps significant figures unchanged

Observation (1): 2.308 cm has four significant figures. Same value in other units:
  • 0.02308 m
  • 23.08 mm
  • 23080 μm (same physical length, new unit)
All still have the same 4 s.f.: 2, 3, 0, 8.
Exam tip: more digits after conversion ≠ more s.f. Precision comes from the measurement, not the unit.

Significant Figures: Rules and Common Ambiguities

Significant figures = meaningful digits showing precision. Decimal point position does not decide s.f.; the digits + rules do.

Rules for counting significant figures

  • Rule 1: all non-zero digits are significant.
  • Rule 2: zeros between non-zero digits are significant (decimal point doesn’t matter).
  • Rule 3: for numbers < 1, zeros after the decimal but before the first non-zero digit are not significant.
    Example idea: in 0.002308, the zeros before 2 are not significant.
  • Rule 4: trailing (terminal) zeros in a number with no decimal point are not significant.
    Example: 123 m = 12300 cm = 123000 mm → all have 3 s.f. (extra zeros come from conversion, not extra precision).
  • Rule 5: trailing zeros in a number with a decimal point are significant.
    Examples: 3.500 has 4 s.f.; 0.06900 has 4 s.f.

Confusion with trailing zeros during unit conversion

A value like 4.700 m has trailing zeros on purpose → they are significant (4 s.f.). If it had only 2 or 3 s.f., it would be written as 4.7 m. But converting units gives:
  • 4.700 m = 470.0 cm = 4700 mm = 0.004700 km
4700 mm has no decimal point; using Rule 4 blindly might make you say “2 s.f.” → wrong. Unit change cannot change s.f.; it stays 4.
Key exam point: trailing zeros can become ambiguous when the decimal point disappears after conversion → use scientific notation to make it clear.

Scientific notation and order of magnitude

Scientific notation: write as a × 10b, where:
  • a is between 1 and 10
  • b is an integer (positive/negative/zero)
In scientific notation, 10b does not affect s.f. Any zeros written inside a count as significant.
Putting the decimal after the first digit removes trailing-zero confusion. For the earlier example:
  • 4.700 m = 4.700 × 102 cm = 4.700 × 103 mm = 4.700 × 10−3 km
Each has 4 significant figures, clearly, since the base is always 4.700.

Order of magnitude (10-power estimate)

To estimate scale, round the base a in a × 10b like this:
  • if a ≤ 5, round a → 1
  • if 5 < a ≤ 10, round a → 10
Then the estimate is about 10b (or if rounded to 10, effectively 10b+1). The exponent used is the order of magnitude.
  • Earth’s diameter: 1.28 × 107 m → order ≈ 107 m; order of magnitude = 7.
  • Hydrogen atom diameter: 1.06 × 10−10 m → order ≈ 10−10 m; order of magnitude = −10.
So Earth’s diameter is 17 orders of magnitude bigger than H atom diameter (since 7 − (−10) = 17).

If scientific notation is not used: practical trailing-zero rules

  • Number > 1 with no decimal point: trailing zeros are not significant.
  • Number with a decimal point: trailing zeros are significant.

Leading zero before a decimal in numbers less than 1

  • The zero before the decimal in numbers like 0.1250 is never significant (just a placeholder).
  • But trailing zeros at the end (like the last 0 in 0.1250) are significant because they show precision.

Exact numbers and infinite significant figures

Exact numbers (not measured, not rounded) have infinite significant figures.
  • Exact multiplying/dividing factors do not limit s.f.
  • Examples of exact factors: 2 in d = 2r and s = 2πr (can be written 2.0, 2.00, 2.0000 if needed).
  • Also n is exact in n = T/t (where n is a counted number of cycles/oscillations).
Exam tip: don’t let exact constants/counts (2, π, integer counts n) set the s.f.; only measured/rounded values limit precision.

Rules for Arithmetic Operations with Significant Figures

Calculated answers can’t be more precise than the least precise measurement used. So the final value must match the input uncertainties (s.f. / d.p.).

Rule (1): Multiplication and division

For × or ÷: final answer has the same number of significant figures as the input with the fewest s.f.
Worked example: density
  • Mass = 4.237 g (4 s.f.)
  • Volume = 2.51 cm3 (3 s.f.)
Division gives lots of digits, but round to 3 s.f. (least is 3): Density = 4.237 / 2.51 = 1.69 g cm−3 (3 s.f.) Worked example: light-year
  • Speed of light = 3.00 × 108 m s−1 (3 s.f.)
  • 1 year = 3.1557 × 107 s (5 s.f.)
Distance = (3.00 × 108)(3.1557 × 107) m = 9.47 × 1015 m → report to 3 s.f.: 1 ly = 9.47 × 1015 m

Rule (2): Addition and subtraction

For + or −: final answer has the same number of decimal places as the term with the fewest d.p.
Worked example: sum of masses
  • 436.32 g (2 d.p.)
  • 227.2 g (1 d.p.) ← least d.p.
  • 0.301 g (3 d.p.)
Sum = 663.821 g, but round to 1 d.p.: Final = 663.8 g Worked example: subtraction of lengths 0.307 m − 0.304 m = 0.003 m = 3 × 10−3 m
Common mistake: Don’t use the ×/÷ s.f. rule for +/−. In the sum example, 664 g is wrong (kills the correct d.p.). In the subtraction example, 3.00 × 10−3 m wrongly implies extra precision.

Rounding Off the Uncertain Digits

If a calculated value has more digits than justified (more than one uncertain digit), you must round off to the right s.f. using standard rules.

Standard rounding when the dropped digit is not 5

  • If first dropped digit > 5: increase the last kept digit by 1.
  • If first dropped digit < 5: keep the last kept digit the same.
Examples (to 3 s.f.):
  • 2.746 → 2.75 (drop 6 > 5, so 4 → 5)
  • 1.743 → 1.74 (drop 3 < 5, so 4 stays)

Special convention when the dropped digit is exactly 5 (round-to-even)

When the digit to be dropped is exactly 5:
  • If the previous digit is even → drop the 5 (no increase).
  • If the previous digit is odd → increase the previous digit by 1.
This is round-to-even and helps prevent an overall upward bias from repeated rounding.
Examples (to 3 s.f.):
  • 2.745 → 2.74 (4 is even → drop 5)
  • 2.735 → 2.74 (3 is odd → raise to 4)

Rounding strategy in multi-step calculations and use of approximate constants

  • In multi-step problems: keep 1 extra digit in intermediate values, and round only at the end to the correct s.f.
  • Constants known to many s.f. can be rounded if high precision isn’t needed. Example: speed of light 2.99792458 × 108 m/s is often taken as 3 × 108 m/s.
  • Exact numbers in formulas (e.g. 2π in T = 2π √(L/g)) have infinite s.f. and do not limit rounding.

Significant figures: using π and rounding in calculations

Some constants (e.g. π = 3.1415926...) are known to many s.f., but you should only use/quote as many s.f. as the situation needs (usually limited by the measured data). Common approximations: π = 3.142 (4 s.f.) or π = 3.14 (3 s.f.), chosen to match what’s required.

Example 1.1: surface area and volume of a cube (significant figures)

Rule used: round final answers to the same number of s.f. as the measured value with the fewest s.f. (here: the side length).
Given: side of cube = 7.203 m (4 s.f.).
Total surface area of cube: A = 6a2 a = side length of cube
Calculation: A = 6(7.203)2 m2 = 311.299254 m2 = 311.3 m2 (4 s.f.)
Volume of cube: V = a3 a = side length of cube
Calculation: V = (7.203)3 m3 = 373.714754 m3 = 373.7 m3 (4 s.f.)

Example 1.2: density with significant figures

For ÷ or ×: the answer is limited by the measurement with the fewest significant figures.
Given: mass = 5.74 g (3 s.f.), volume = 1.2 cm3 (2 s.f.) → density must be to 2 s.f.
Density: ρ = m/V ρ = density m = mass V = volume
Calculation: ρ = 5.74 / 1.2 g cm−3 = 4.8 g cm−3 (2 s.f.)

1.3.3 Rules for determining the uncertainty in results of arithmetic calculations

Uncertainty/error propagation rules = how measurement uncertainties combine in +, −, ×, ÷ and multi-step calculations.

(1) Uncertainty in a product: combination of errors rule (rectangular sheet example)

Measurements (metre scale):
  • Length l = 16.2 cm has 3 s.f. ⇒ l = 16.2 ± 0.1 cm = 16.2 cm ± 0.6%
  • Breadth b = 10.1 cm has 3 s.f. ⇒ b = 10.1 ± 0.1 cm = 10.1 cm ± 1%
For products: fractional/percentage uncertainties add (combination of errors rule). If Q = ab, then (ΔQ/Q) ≈ (Δa/a) + (Δb/b). So % error in product ≈ sum of % errors.
Area = lb = 163.62 cm2 Percentage error = 0.6% + 1% = 1.6% So, lb = 163.62 cm2 ± 1.6% Absolute error = 1.6% of 163.62 = 0.016 × 163.62 ≈ 2.6 cm2 Thus, lb = 163.62 ± 2.6 cm2 Quoted final result (round value + uncertainty suitably): lb = 164 ± 3 cm2 Here, 3 cm2 is the uncertainty/error in the estimated area.
When reporting with uncertainty: round the uncertainty sensibly, then round the central value to the same decimal place implied by that uncertainty.

(2) Significant figures in combined results; subtraction can reduce significant figures

If experimental data are given to n significant figures, a combined result is (generally) valid to n significant figures. Exception: for subtraction/addition, precision is set by the smallest number of decimal places (not s.f.), so the result may lose significant figures.
Example: 12.9 g − 7.06 g
  • Both values have 3 s.f.
  • But 12.9 has 1 d.p., 7.06 has 2 d.p.
  • So the answer must be quoted to 1 d.p.
Direct subtraction gives 5.84 g, but correctly it should be written as 5.8 g.
Common mistake: using “least significant figures” for +/−. Use “least decimal places”.

(3) Relative error depends on the value as well as the number of significant figures

Relative (percentage) error = (absolute error / measured value) × 100%. Same absolute error → smaller measured value gives larger relative error.
Example comparisons (both accurate to ±0.01 g):
  • Mass = 1.02 g: relative error = (±0.01 / 1.02) × 100% ≈ ±1%
  • Mass = 9.89 g: relative error = (±0.01 / 9.89) × 100% ≈ ±0.1%

Intermediate results in multi-step computations (avoid rounding build-up)

In multi-step calculations: keep intermediate answers to one more significant figure than the least precise measurement. Round only at the end, otherwise rounding errors build up.
Illustration using reciprocals:
  • If 1/9.58 is rounded to 3 s.f.: 1/9.58 ≈ 0.104
  • Then take reciprocal again (to 3 s.f.): 1/0.104 ≈ 9.62, so you don’t recover 9.58
  • But keep one extra digit: 1/9.58 = 0.1044, then reciprocal to 3 s.f. gives 9.58 (original recovered)
Don’t over-round mid-way. Keep an extra digit (or more if needed) until the final step, then round using s.f. rules.

1.4 Dimensions of physical quantities

Dimensions = the “type/nature” of a quantity written as powers of base quantities. Written in square brackets [ ]. So [Q] means “dimensions of Q” (not its numerical value).
All derived quantities can be expressed using 7 fundamental/base quantities (“seven dimensions of the physical world”):
  • Length: [L]
  • Mass: [M]
  • Time: [T]
  • Electric current: [A]
  • Thermodynamic temperature: [K]
  • Luminous intensity: [cd]
  • Amount of substance: [mol]
The dimensions of a quantity are the exponents (powers) of the base quantities needed to represent it.

Dimensions in mechanics: expressing quantities using [L], [M], [T]

In mechanics, all quantities can be written using only [L], [M], [T]. Example: Volume
  • Volume = length × breadth × height
  • Dimensions: [L] × [L] × [L] = [L]3 (also written [L3])
  • Independence from other bases ⇒ zero powers: [M0] and [T0] (and same idea for other bases)
Example: Force Force = mass × acceleration = mass × (length)/(time)2
  • Dimensions: [M][L]/[T]2 = [M L T−2]
  • Meaning: power of M = 1, L = 1, T = −2; all other base quantities have power 0
Dimensional representation ignores numerical size; it shows only the “type” of quantity. So change in velocity, initial/average/final velocity, and speed are dimensionally the same. Velocity/speed: length/time = [L]/[T] = [L T−1].

1.5 Dimensional formulae and dimensional equations

Dimensional formula

Dimensional formula = expression showing how base quantities (dimensions) appear (with powers) in a physical quantity.
Examples of dimensional formulae:
  • Volume: [M0 L3 T0]
  • Speed/velocity: [M0 L T−1]
  • Acceleration: [M0 L T−2]
  • Mass density: [M L−3 T0]

Dimensional equation

Dimensional equation = equate the quantity symbol to its dimensional formula (i.e. write its dimensions using base quantities).
Examples of dimensional equations:
  • [V] = [M0 L3 T0]
  • [v] = [M0 L T−1]
  • [F] = [M L T−2]
  • [ρ] = [M L−3 T0]
You can get a dimensional equation from the physical relation: start with the defining/derived equation, then replace each quantity by its dimensions. Many dimensional formulae are derived from known relations and written in base quantities.

1.6 Dimensional analysis and its applications (start)

Dimensional analysis uses dimensions to guide/check physical descriptions; recognising dimensions is basic in physics.

Dimensional Analysis: What You Can and Cannot Do

Unit/dimension rules in equations
  • Add / subtract: only quantities with the same dimensions can be added or subtracted.
  • Multiply / divide: treat units/dimensions like algebra → multiply/divide and cancel identical units (same for dimensions) top & bottom.
  • Equation equality: LHS and RHS must have the same dimensions.
Why we use dimensional analysis: helps (i) guess/derive relations between physical quantities, and (ii) check work for dimensional consistency (= dimensional homogeneity).

Checking the Dimensional Consistency (Homogeneity) of Equations

Principle of homogeneity (for equations): any terms being added/subtracted in a valid physical equation must have the same dimensions. So every term must match the dimensions of the quantity the equation is describing.
  • You cannot add velocity to force.
  • You cannot subtract electric current from thermodynamic temperature.
  • If term dimensions don’t match, the equation is wrong.
  • If it passes the dimensional test, it’s not guaranteed correct (could miss numerical factors, have wrong functional form, etc.).
Special note: dimensionless quantities
  • Inputs (arguments) of trig, log, and exponential functions must be dimensionless.
  • A pure number or a ratio of similar physical quantities has no dimensions.
  • Examples of dimensionless quantities:
    • Angle as a ratio: (arc length)/(radius) = length/length.
    • Refractive index = (speed of light in vacuum)/(speed of light in medium).
Dimensions vs units (for consistency tests): checking dimensions gives the same verdict as checking units, but dimensions are easier because no unit-system choice + no conversion between multiples/submultiples.
  • If an equation fails dimensional consistency → proved wrong.
  • If an equation passes → not proved right.

Worked Consistency Check: Equation of Motion for Displacement

Displacement (uniform acceleration): x = x0 + v0 t + (1/2) a t2 Symbols
  • x = position (distance) after time t
  • x0 = initial position at t = 0
  • v0 = initial velocity
  • a = uniform acceleration along direction of motion
  • t = time interval
Dimensional check (each term):
  • [x] = [L]
  • [x0] = [L]
  • [v0 t] = [L T−1][T] = [L]
  • [(1/2) a t2] = [L T−2][T2] = [L]
All RHS terms are [L], same as LHS → equation is dimensionally correct.
Exam tip: in sums like x0 + v0t + (1/2)at2, the number (1/2) is dimensionless → ignore it in dimensional checks. Check only the physical quantities + their powers.

Example 1.3: Dimensional Check of an Energy Relation

(1/2) m v2 = m g h Symbols
  • m = mass
  • v = velocity
  • g = acceleration due to gravity
  • h = height
Dimensions of LHS:
  • [(1/2) m v2] = [M][L T−1]2 = [M][L2 T−2] = [M L2 T−2]
Dimensions of RHS:
  • [m g h] = [M][L T−2][L] = [M L2 T−2]
LHS = RHS in dimensions → equation is dimensionally correct.

Example 1.4: Ruling Out Incorrect Kinetic Energy Formulae by Dimensions

Given SI units (so dimensions):
  • Energy unit J = kg m2 s−2 ⇒ [Energy] = [M L2 T−2]
  • Speed v in m s−1 ⇒ [v] = [L T−1]
  • Acceleration a in m s−2 ⇒ [a] = [L T−2]
  • Mass m ⇒ [m] = [M]
Check each suggested kinetic energy K (must be [M L2 T−2]):
  1. (a) K = m2 v3
    • Dimensions: [M]2[L T−1]3 = [M2 L3 T−3]
    • ≠ [M L2 T−2] → ruled out.
  2. (b) K = (1/2) m v2
    • Dimensions: [M][L T−1]2 = [M L2 T−2]
    • Matches → cannot be ruled out by dimensions.
  3. (c) K = m a
    • Dimensions: [M][L T−2] = [M L T−2]
    • ≠ [M L2 T−2] → ruled out.
  4. (d) K = (3/16) m v2
    • Dimensions: same as (b) = [M L2 T−2]
    • Matches → cannot be ruled out by dimensions.
  5. (e) K = (1/2) m v2 + m a
    • First term: [M L2 T−2]
    • Second term: [M L T−2]
    • Different dimensions can’t be added → no proper dimensions → ruled out.
  • Dimensional reasoning eliminates (a), (c), and (e).
  • Dimensions cannot choose between (b) and (d) (both dimensionally OK).
  • To pick the right one, use the actual definition of kinetic energy; correct is (b).
Common exam trap: same dimensions ≠ same correctness (e.g., (1/2)mv2 vs (3/16)mv2). Dimensional analysis can’t determine numerical coefficients.

Deducing Relations Among Physical Quantities Using Dimensional Method

Dimensional method to deduce a relation:
  • Used to figure out how one physical quantity depends on others.
  • Usually works best when the required quantity depends on up to three physical quantities (independent variables).
  • Assume a product-form with unknown powers → match dimensions → solve powers.

Example 1.5: Time Period of a Simple Pendulum (Dimensional Derivation)

Assumption: Time period T depends on length l, mass m, and gravitational acceleration g.
Step 1: Assume product form
T = k lx gy mz Symbols:
  • T = time period
  • l = length of pendulum
  • g = acceleration due to gravity
  • m = mass of bob
  • k = dimensionless constant
  • x, y, z = unknown powers
Step 2: Write dimensions
  • [T] = [T]
  • [l] = [L]
  • [g] = [L T−2]
  • [m] = [M]
Step 3: Equate dimensions Dimensions of RHS:
  • [lx gy mz] = [L]x [L T−2]y [M]z = Lx+y T−2y Mz
Match with LHS: [T] = L0 T1 M0
  • For L: x + y = 0
  • For T: −2y = 1
  • For M: z = 0
Step 4: Solve
  • y = −1/2
  • x = 1/2
  • z = 0
Result (dimensional form):
T = k l1/2 g−1/2 = k √(l/g) Symbols:
  • k = dimensionless constant (not found by dimensional method)
Limit of method: Numerical constant k cannot be found by dimensional analysis. Multiplying by any pure number doesn’t change dimensions.
Actual result (from theory/experiment):
k = 2π, so T = 2π √(l/g) Symbols:
  • π is a pure number (dimensionless)

Limitations of Dimensional Analysis (Must Know)

  • Cannot find dimensionless constants (e.g., 2, 1/2, 2π, 3/16).
  • Only checks dimensional validity, not the exact relation between quantities.
  • Cannot differentiate between different physical quantities that share the same dimensions.
Exam-safe conclusion: Dimensional analysis is a strong screening tool: it can reject a wrong equation, but cannot alone confirm an equation is physically correct.
