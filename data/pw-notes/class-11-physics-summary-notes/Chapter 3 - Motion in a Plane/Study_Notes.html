Chapter 3 : Motion in a Plane

3.1 Introduction

Why we need vectors: In 1D, direction is handled with + / − (only two directions). In 2D (plane) or 3D (space), quantities like displacement, velocity, acceleration need vectors = magnitude + direction.
  • This chapter builds the “language of vectors” for motion in a plane.
  • Core skills: what a vector is; how to add, subtract, multiply vectors; effect of multiplying a vector by a real number.
  • Motion applications: velocity & acceleration in a plane; plane motion (incl. constant acceleration); projectile motion; uniform circular motion.
  • 2D methods extend naturally to 3D.

3.2 Scalars and Vectors

Scalar: magnitude only; fully described by one number + unit. Vector: magnitude + direction; follows triangle law of addition (≡ parallelogram law).
  • Scalars behave like ordinary numbers under +, −, ×, ÷.
    Unit condition: scalar + / − works only if units are the same. Scalar × / ÷ can mix different units.
  • Examples of scalars: distance between two points, mass, temperature, time of an event. Illustrations:
    1. Perimeter of rectangle: length = 1.0 m, breadth = 0.5 m. Perimeter = 1.0 + 0.5 + 1.0 + 0.5 = 3.0 m (scalar + scalar → scalar).
    2. Temperature difference: max = 35.6 °C, min = 24.2 °C. Difference = 35.6 − 24.2 = 11.4 °C (scalar subtraction).
    3. Density of cube: aluminium cube side = 10 cm = 0.10 m; mass = 2.7 kg. Volume = (0.10 m)3 = 10−3 m3 (scalar). Density = mass/volume = 2.7 / 10−3 = 2.7×103 kg m−3 (scalar).
  • Examples of vectors: displacement, velocity, acceleration, force.
  • Vector notation: In print: vectors in (e.g. v). In handwriting: usually an arrow on top (e.g. V→). Magnitude notation: magnitude of v is |v|; also written using light-face v.
    Convention used: (A, a, p, q, r, …) = vectors; light-face (A, a, p, q, r, …) = magnitudes.

3.2.1 Position and Displacement Vectors

Position vector: Fix origin O. If object is at P at time t, directed segment OP is position vector r: OP = r. Displacement vector: If it moves from P (time t) to P′ (time t′), directed straight segment PP′ is the displacement vector PP′.
  • If object is at P′ at time t′, its position vector is OP′ = r′.
  • Magnitude & direction of position vector: |r| = length OP; direction is from O to P.
  • Path-independence of displacement: depends only on start & end points, not the route. So same start P and end Q ⇒ same displacement PQ even if path is PABCQ, PDQ, or PBEFQ.
  • Key inequality: |displacement| ≤ distance travelled (path length) between the same two points.

3.2.2 Equality of Vectors

Equality of vectors: A = B if same magnitude and same direction.
  • Graphical check: slide B parallel to itself until its tail matches tail of A. If heads also match ⇒ A = B.
  • Common exam trap: same magnitude alone ≠ equal vectors. Same length but different directions ⇒ not equal.
  • Free vectors vs localised vectors:
    • Here we use free vectors: position doesn’t matter; parallel shifting doesn’t change the vector.
    • In some cases, line/point of application matters → localised vectors.

3.3 Multiplication of Vectors by Real Numbers

Scaling by a positive real number: |λA| = λ|A|, for λ > 0 λ: real number (scalar multiplier) A: given vector |A|: magnitude of A |λA|: magnitude after scaling
  • If λ > 0: magnitude becomes λ|A| and direction stays same as A. Example: 2A has same direction as A and magnitude 2|A|.
  • If λ < 0: (i.e. multiply by −λ where λ > 0) magnitude is λ|A| but direction is opposite to A. Examples noted: −1A and −1.5A are opposite to A, with magnitudes 1|A| and 1.5|A|.
  • Dimensional (unit) effect: λ may have units. Then dim(λA) = dim(λ) × dim(A). Example: (constant) velocity vector × time interval = displacement vector.

3.4 Addition and Subtraction of Vectors — Graphical Method

Vector addition law: vectors obey triangle law of addition (≡ parallelogram law).
  • Graphical picture: vectors = directed line segments; length ∝ magnitude; drawn in a plane.
  • Triangle method for A + B:
    1. Place B so its tail touches the head of A (head-to-tail).
    2. Draw a vector from tail of A to head of B; call it R.
    3. Then R = A + B.
Exam tip: In graphical addition, you may shift vectors parallel to themselves (free vectors) before adding, but length and direction must not change.

Vector Addition: Triangle (Head-to-Tail) Method

Head-to-tail (triangle) addition: Put the tail of the 2nd vector at the head of the 1st. Draw the vector from the tail of the first to the head of the last → that’s the resultant. These three vectors make a triangle ⇒ also called triangle method.

Commutative Law of Vector Addition

Commutative law: A + B = B + A A, B = vectors being added
Swapping the order does not change the resultant vector.

Associative Law of Vector Addition

Associative law: (A + B) + C = A + (B + C) A, B, C = vectors being added
For three vectors, changing the grouping doesn’t change the final resultant (as long as you follow the correct geometric addition rule).

Equal and Opposite Vectors: Null (Zero) Vector

If two vectors have same magnitude but opposite direction, their sum is zero magnitude → a null/zero vector, written as 0.
Vector + its negative: A − A = 0, and |0| = 0 A = any vector 0 = null (zero) vector |0| = magnitude of null vector
Null vector has no defined direction (because its magnitude is zero).

Properties of the Null (Zero) Vector

Key properties: A + 0 = A λ 0 = 0 0 A = 0 A = vector 0 = null vector λ = any scalar (real number)
Don’t give 0 a fixed direction. Also: multiplying by zero always gives the zero vector, no matter what direction the vector had.

Physical Meaning of a Zero Vector (Displacement Example)

Zero displacement: Start at P, go to P′, return to P → initial = final position ⇒ displacement = null (zero) vector.

Subtraction of Vectors

Vector subtraction = addition idea: “A minus B” means “A plus (negative of B)”.
Definition: A − B = A + (−B) A, B = vectors −B = same magnitude as B, opposite direction
To get A − B geometrically: flip B to make −B, then add using the usual vector-addition rule.
A − B is not “subtract magnitudes” (except special colinear cases with known directions). Always treat it as A + (−B).

Parallelogram Method of Vector Addition

Parallelogram method: Place tails of A and B at the same point O. Through head of A draw a line ∥ B; through head of B draw a line ∥ A → a parallelogram forms. The diagonal from O to the opposite corner is the resultant R.
Equivalence: Parallelogram method and triangle (head-to-tail) method give the same resultant for A + B.

Worked Example: Rain and Wind (Resultant Velocity)

Example 3.1: Direction to Hold the Umbrella

Apparent rain direction (relative to the boy) comes from the resultant velocity of:
  • rain velocity (vertical downward), and
  • wind velocity (horizontal, east → west).
Umbrella should point opposite to this resultant (tilt into the oncoming rain).
Given: Rain falls vertically at 35 m s−1. Wind blows at 12 m s−1 from east to west.
Resultant speed (perpendicular components): R = √(vr2 + vw2) R = magnitude of resultant velocity vr = rain speed (vertical) vw = wind speed (horizontal)
Angle w.r.t. vertical: tan θ = vw / vr θ = angle resultant makes with the vertical vw, vr as above
Calculation:
  • R = √(352 + 122) m s−1 = √(1225 + 144) = √1369 = 37 m s−1
  • tan θ = 12/35 = 0.343 ⇒ θ = tan−1(0.343) ≈ 19°
Conclusion: Hold the umbrella in the vertical plane, about 19° to the vertical towards the east (tilted into the side the wind pushes rain from).
Angle is measured from the vertical (not from the horizontal). Use tan θ = horizontal/vertical = vw/vr.

Resolution of Vectors

Resolving a Vector Along Two Non-Colinear Vectors

Resolution of a vector: Write vector A as the sum of two components along two given non-zero, non-parallel (non-colinear) vectors a and b in the same plane.
Geometric idea: Let OP represent A (O = tail, P = head). Through O draw a line ∥ a; through P draw a line ∥ b; they meet at Q. Then OP = OQ + QP.
Vector splitting: A = OP = OQ + QP A = vector to be resolved OP = directed segment representing A OQ, QP = components along directions ∥ a and ∥ b
Components along a and b: OQ = l a, and QP = µ b l, µ = real numbers (scalars) a, b = given non-zero vectors in different directions
Resolution result: A = l a + µ b A = resolved vector l a = component along a µ b = component along b
This works for components along any two non-colinear vectors in the same plane. Most often, we resolve along rectangular axes using unit vectors.

Unit Vectors and Rectangular Components

Unit Vectors (Definition and Properties)

Unit vector: vector of magnitude 1 in a fixed direction. Dimensionless (no units) → used to show direction only.
Standard unit vectors: along x, y, z axes are î, ĵ, k̂. All are mutually perpendicular.
Magnitudes: |î| = |ĵ| = |k̂| = 1 î, ĵ, k̂ = unit vectors along x, y, z axes
In 2D motion (x–y plane), only î and ĵ are needed.

Writing a Vector Using a Unit Vector Along Its Direction

Vector = magnitude × direction: A = |A| n̂ A = vector |A| = magnitude of A n̂ = unit vector along direction of A
A unit vector gives direction only; multiply by a scalar → vector of that magnitude in the same direction.

Rectangular Components in the x–y Plane

Any vector A in the x–y plane can be split into two perpendicular parts: along x (î) and along y (ĵ).
Component vectors: A1 = Ax î,   A2 = Ay ĵ A1, A2 = component vectors along x and y Ax, Ay = scalar components (real numbers) î, ĵ = unit vectors along x and y
Vector in component form: A = Ax î + Ay ĵ A = vector in the x–y plane Ax, Ay = x- and y- scalar components
Scalar vs vector: Ax is not a vector; Axî is a vector. Similarly Ayĵ is a vector.

Relating Components to Magnitude and Direction

From magnitude + angle: Ax = A cos θ Ay = A sin θ A = |A| (magnitude of vector A) θ = angle made by A with the +x-axis
A component may be + / − / 0 depending on θ (quadrant or along an axis).

Two Equivalent Ways to Specify a Vector in a Plane

A vector A in a plane can be given by:
  1. Magnitude + direction: (A, θ) where θ is w.r.t. x-axis, or
  2. Rectangular components: (Ax, Ay)

Finding Magnitude and Direction from Components

Magnitude from components: A = √(Ax2 + Ay2) A = magnitude of vector A Ax, Ay = x- and y- scalar components
Direction from components: tan θ = Ay / Ax, so θ = tan−1(Ay/Ax) θ = angle of A with the +x-axis Ax, Ay = x- and y- scalar components
Using θ = tan−1(Ay/Ax): pick the correct quadrant using signs of Ax, Ay (ratio alone may not fix θ).

Vector Addition – Analytical Method

Component (analytical) method: write each vector in rectangular components (along perpendicular unit vectors), then add/subtract component-wise. Usually easier + more accurate than graphical addition.

Vectors in an x–y plane (2D): component form and resultant components

Component form (2D): A = Ax î + Ay ĵ,   B = Bx î + By ĵ Ax, Ay = components of A along x- and y-axes Bx, By = components of B along x- and y-axes î, ĵ = unit vectors along x- and y-axes
Vector laws used: vectors follow commutative + associative laws → regroup components easily during addition.
Resultant of two vectors: R = A + B R = resultant vector A, B = vectors being added
Write in components, then collect like terms: R = (Axî + Ayĵ) + (Bxî + Byĵ) = (Ax + Bx)î + (Ay + By)ĵ
Resultant components (2D): Rx = Ax + Bx,   Ry = Ay + By Rx, Ry = x- and y-components of resultant R
Key exam line: Each component of the resultant equals the sum of the corresponding components.

Vectors in three dimensions (3D): component form and resultant components

Component form (3D): A = Axî + Ayĵ + Azk̂,   B = Bxî + Byĵ + Bzk̂ î, ĵ, k̂ = unit vectors along x-, y-, z-axes Ax, Ay, Az = components of A along x-, y-, z-axes Bx, By, Bz = components of B along x-, y-, z-axes
Resultant components (3D): If R = A + B, then Rx = Ax + Bx Ry = Ay + By Rz = Az + Bz Rx, Ry, Rz = x-, y-, z-components of R

Addition/subtraction of multiple vectors using components

This extends straight to any number of vectors: operate component-wise.
Example form: if a = axî + ayĵ + azk̂, b = bxî + byĵ + bzk̂, c = cxî + cyĵ + czk̂ Then for T = a + b − c: Tx = ax + bx − cx Ty = ay + by − cy Tz = az + bz − cz
Exam tip: watch signs in subtraction: subtracting a vector = subtract every component.

Resolving a Vector in Three Dimensions (Direction Angles)

Any space vector can be split into x-, y-, z- components using the angles it makes with each axis.
Direction angles: α, β, γ are the angles between vector A and the x-, y-, z-axes respectively. These are angles in space (between lines not necessarily in the same plane).
Components via direction angles: Ax = A cosα    Ay = A cosβ    Az = A cosγ A = magnitude of vector A α, β, γ = angles made by A with x-, y-, z-axes
Unit-vector form (3D): A = Axî + Ayĵ + Azk̂ Ax, Ay, Az = rectangular components of A
Magnitude from components: A = √(Ax2 + Ay2 + Az2) A = magnitude of vector A Ax, Ay, Az = components of A

Position vector in three dimensions

Position vector: r = xî + yĵ + zk̂ x, y, z = coordinates/components along x-, y-, z-axes r = position vector of a point w.r.t. the origin

Resultant of Two Vectors in Terms of Magnitudes and Included Angle (Example 3.2)

If vectors A and B have included angle θ, then the resultant R = A + B (magnitude + direction) comes from parallelogram/triangle geometry.

Magnitude of resultant: Law of Cosines

Using the parallelogram idea, split B into parts parallel/perpendicular to A:
  • Along A: B cosθ
  • Perpendicular to A: B sinθ
Law of cosines (|R|): R2 = A2 + B2 + 2AB cosθ R = magnitude of resultant R A, B = magnitudes of vectors A, B θ = angle between A and B
R2 = A2 + B2 + 2AB cosθ is the Law of Cosines for vector addition.

Direction of resultant: Law of Sines and tangent form

Let α be the angle between resultant R and vector A. Match perpendicular components:
  • Perpendicular part of R (w.r.t. A): R sinα
  • Perpendicular part of B (w.r.t. A): B sinθ
Direction relation (perpendicular components): R sinα = B sinθ R = magnitude of resultant α = angle between R and A B = magnitude of vector B θ = angle between A and B
From the vector-addition triangle (angles α, β, θ):
Law of sines (vector triangle): R/sinθ = A/sinβ = B/sinα R, A, B = magnitudes of resultant and vectors θ = angle between A and B α = angle between R and A β = angle between R and B (as used in the triangle)
R/sinθ = A/sinβ = B/sinα is the Law of Sines here.
Solving for α:
Angle of resultant with A: sinα = (B/R) sinθ α = angle between R and A B = magnitude of B R = magnitude of resultant (from law of cosines) θ = included angle between A and B
Also (using parallel + perpendicular parts):
Tangent form (direction): tanα = (B sinθ)/(A + B cosθ) α = angle between R and A A, B = magnitudes of vectors A, B θ = angle between A and B
Common exam mistake: Using sinα = (B/R)sinθ before finding R correctly from R2 = A2 + B2 + 2ABcosθ, or mixing up α (angle with A) vs θ (angle between A and B).

Worked Application: Relative Velocity of Boat and Current (Example 3.3)

When two velocities act together, add vectors: R = vb + vc.

Given and vector geometry

  • Motorboat: vb = 25 km/h due north.
  • Current: vc = 10 km/h at 60° east of south.
In the addition triangle/parallelogram, the included angle for cosine rule is 120° (from the given directions in the construction).

Magnitude using Law of Cosines

Resultant speed: R2 = vb2 + vc2 + 2 vb vc cos120° R = magnitude of resultant velocity vb = boat speed (25 km/h) vc = current speed (10 km/h)
Substitute cos120° = −1/2: R2 = 252 + 102 + 2(25)(10)(−1/2) = 625 + 100 − 250 = 475 R = √475 ≈ 21.8 km/h ≈ 22 km/h

Direction using Law of Sines

Law of sines for direction angle φ: R/vc = sinθ/sinφ  ⇒  sinφ = (vc/R) sinθ φ = angle of resultant as marked in the construction θ = included angle in the triangle (here 120°) vc = 10 km/h R ≈ 21.8 km/h
Compute: sinφ = (10/21.8) sin120° = (10/21.8)(√3/2) ≈ (10×0.866)/21.8 ≈ 0.397 φ ≈ 23.4°
Exam tip: Keep θ consistent in cosine/sine laws: use the included angle between the two velocity vectors in your triangle (here 120°, not 60°).

Motion in a Plane

2D motion is easiest in an x–y frame using vectors: position, displacement, velocity.

Position vector and displacement (Section 3.7.1)

Position vector (2D): r = xî + yĵ x, y = components along x- and y-axes r gives particle position w.r.t. origin
If at time t the particle is at P with position r, and at time t′ it is at P′ with position r′, then displacement points from P → P′:
Displacement: Δr = r′ − r Δr = displacement vector r, r′ = initial, final position vectors
Component form: Δr = Δx î + Δy ĵ Δx = x′ − x Δy = y′ − y

Average velocity and instantaneous velocity

Average velocity: vavg = Δr/Δt = (Δx/Δt)î + (Δy/Δt)ĵ Δr = displacement in time interval Δt Δt = t′ − t Δx, Δy = coordinate changes during Δt
Direction of vavg: since vavg ∥ Δr, it points in the same direction as the displacement (for that interval).
Instantaneous velocity: v = limΔt→0 (Δr/Δt) = dr/dt v = velocity at an instant r = position vector as a function of time t = time
Geometric meaning (Δt → 0): instantaneous velocity v is along the tangent to the path at that point.

Instantaneous Velocity in a Plane: Direction and Components

Direction of velocity at a point: as ∆t gets smaller (∆t1 > ∆t2 > ∆t3) and → 0, ∆r also → 0 and becomes along the tangent to the path. So instantaneous velocity is tangential to the trajectory, in the direction of motion.
Velocity vector (component form) (Eq. 3.29): v = d r / dt = lim(∆t→0) (∆r /∆t) = (dx/dt) î + (dy/dt) ĵ v = instantaneous velocity vector r = position vector x, y = coordinates as functions of time t î, ĵ = unit vectors along x- and y-axes
Velocity components (Eq. 3.30a): v = vx î + vy ĵ vx = dx/dt vy = dy/dt vx, vy = x- and y-components of velocity respectively
If x(t) and y(t) are known: just differentiate each coordinate w.r.t. time to get vx and vy.
Magnitude of velocity: v = √(vx + vy) v = speed (magnitude of velocity) vx, vy = velocity components
Direction of velocity: tan θ = vy / vx and θ = tan⁻¹(vy/vx) θ = angle made by v with the +x-axis vx, vy = velocity components
vx = v cos θ, vy = v sin θ.
Exam tip: θ = tan⁻¹(vy/vx) needs quadrant check: signs of vx and vy decide the true direction of v (0° to 360°).

Acceleration in a Plane: Average and Instantaneous

Average acceleration in the x–y plane over ∆t = change in velocity / time. Direction = direction of ∆v.
Average acceleration: aavg = ∆v / ∆t = (∆vx/∆t) î + (∆vy/∆t) ĵ aavg = average acceleration vector ∆v = change in velocity vector in time ∆t ∆vx, ∆vy = changes in velocity components
Component form : a = ax î + ay ĵ ax, ay = x- and y-components of acceleration respectively
Instantaneous acceleration = limiting value of average acceleration as ∆t → 0. From the diagrams below as ∆t decreases, direction of ∆v changes; in the limit, acceleration at the point has a definite direction.
Instantaneous acceleration : a = lim(∆t→0) (∆v/∆t) = dv/dt a = instantaneous acceleration vector v = instantaneous velocity vector
Acceleration components from velocity components (Eq. 3.32b, 3.32c): a = ax î + ay ĵ ax = dvx/dt ay = dvy/dt ax, ay = acceleration components vx, vy = velocity components
1D vs 2D/3D: in 1D, velocity and acceleration lie on the same line (same/opposite). In 2D/3D, they can make any angle 0° to 180°.

Example 3.4: Differentiating Position Vector to Get Velocity and Acceleration

If position is given as r(t), then:
  • v(t) = dr/dt
  • a(t) = dv/dt = d²r/dt²
Given: r = (3.0t) î + (2.0t²) ĵ + (5.0) k̂ (metres), t in seconds.
(a) Find v(t) and a(t) Differentiate r(t) component-by-component:
v(t) = dr/dt = (d/dt)(3.0t) î + (d/dt)(2.0t²) ĵ + (d/dt)(5.0) k̂ v(t) = 3.0 î + 4.0t ĵ Constant 5.0 ⇒ derivative = 0, so k̂-component of velocity is 0.
Differentiate v(t):
a(t) = dv/dt = d(3.0)/dt î + d(4.0t)/dt ĵ = 0 î + 4.0 ĵ a = 4.0 ĵ m s⁻² (i.e., 4.0 m s⁻² along +y)
(b) Magnitude and direction of v at t = 1.0 s Put t = 1.0 s into v(t): v = 3.0 î + 4.0 ĵ
|v| = √(3.0² + 4.0²) = 5.0 m s⁻¹ |v| = speed
θ = tan⁻¹(vy/vx) = tan⁻¹(4.0/3.0) ≈ 53° with the x-axis θ = direction of velocity with +x-axis
Common mistake: forgetting d(constant)/dt = 0 (here 5.0 k̂). It affects position, but not velocity/acceleration.

Motion in a Plane with Constant Acceleration

Constant acceleration a in the x–y plane average a = instantaneous a at all times. So we can use the usual 1D kinematics ideas, just apply them separately to x- and y-components.

Velocity–Time Relation (Vector and Components)

Definition (constant a) (take t0 = 0): a = (v − v0)/t a = constant acceleration vector v0 = velocity at t = 0 v = velocity at time t
Velocity vs time: v = v0 + a t v = velocity at time t v0 = initial velocity a = constant acceleration t = time elapsed
Component form: $v_x=v_{o x}+a_x t$ $v_y=v_{o y}+a_y t$ vx, vy = initial velocity components ax, ay = constant acceleration components

Position–Time Relation (Using Average Velocity)

For constant acceleration over time t: Average velocity = (v + v0)/2 Displacement = (average velocity) × time.
Vector kinematic equation: $x=x_0+v_{o x} t+\frac{1}{2} a_x t^2$ r0 = position at t = 0 r = position at time t v0 = initial velocity a = constant acceleration t = time elapsed
Text checks:
  • Differentiate Eq.: dr/dt = v
  • Initial condition works: at t = 0, r = r0.
Component position (Eq. 3.34b): x = x0 + vox t + (1/2) ax t² y = y0 + voy t + (1/2) ay t² x0, y0 = initial coordinates vox, voy = initial velocity components ax, ay = constant acceleration components
That is, motion in a plane (two-dimensions) can be treated as two separate simultaneous onedimensional motions with constant acceleration along two perpendicular directions. (Same idea in 3D.) This is the key idea behind projectile motion.

Example 3.5: Using r = r0 + v0 t + (1/2) a t² in 2D

Given: Start at origin (r0 = 0) at t = 0 with v0 = 5.0 î m s⁻¹, and constant a = (3.0 î + 2.0 ĵ) m s⁻². Find: (a) y when x = 84 m, (b) speed then.
Step 1: Write r(t) using Eq. (3.34a):
r(t) = v0 t + (1/2) a t² (since r0 = 0) r(t) = (5.0t + 1.5t²) î + (1.0t²) ĵ 1.5 = (1/2)×3.0 and 1.0 = (1/2)×2.0
So: x(t) = 5.0t + 1.5t² y(t) = 1.0t² (a) When x = 84 m → find t → then y Solve: 5.0t + 1.5t² = 84 ⇒ t = 6 s (as in text). Then y = 1.0(6)² = 36.0 m. (b) Speed at this time Differentiate r(t) to get v(t):
v(t) = dr/dt = (5.0 + 3.0t) î + (2.0t) ĵ d/dt(5.0t + 1.5t²) = (5.0 + 3.0t); d/dt(1.0t²) = (2.0t).
At t = 6 s: v = 23.0 î + 12.0 ĵ (m s⁻¹) Speed:
v = √(23² + 12²) ≈ 26 m s⁻¹ v = magnitude of velocity
Common mistake: Once you know x = 84 m, don’t plug straight into y(x) unless you’ve eliminated time properly. Intended route here: x(t) → find t → then y(t) and v(t).

Projectile Motion: Concept and Basic Equations

Projectile: object moving through air after being thrown/projected (e.g. football, cricket ball, baseball). Core model (ignore air resistance): projectile motion =
  • Horizontal motion with no acceleration
  • Vertical motion with constant acceleration due to gravity
Galileo’s independence principle: horizontal + vertical parts are independent (in Dialogue on the great world systems, 1632).
Main assumption throughout: air resistance is negligible.

Acceleration Components in Projectile Motion

Gravity acceleration (Eq. 3.35): a = −g ĵ ax = 0 ay = −g g = magnitude of gravitational acceleration (vertically downward)

Initial Velocity Components

Initial velocity components: vox = vo cos θo voy = vo sin θo vo = initial speed θo = launch angle with the x-axis vox, voy = initial velocity components

Projectile Motion in a Plane

Projectile motion → split into 2 perpendicular directions:
  • x-direction (horizontal): uniform motion (a = 0).
  • y-direction (vertical): uniformly accelerated with −g (free fall).
Take launch point as origin : x0=0, y0=0.

Position coordinates as functions of time

Position (origin = initial point): x = v0xt = (v0cosθ0)t y = (v0sinθ0)t − (1/2)gt²
  • x, y = coordinates at time t
  • v0 = initial speed
  • θ0 = launch angle above horizontal
  • v0x=v0cosθ0 = initial horizontal component
  • v0y=v0sinθ0 = initial vertical component
  • g = magnitude of gravity (acts downward)
Above equation gives position at time t using just v0 and θ0. Choosing perpendicular x–y axes makes life easy because:
  • vx stays constant for the whole flight.
  • Only vy changes, exactly like vertical free fall.

Velocity components as functions of time

Velocity components:    (Eq. 3.38) vx = v0x = v0cosθ0 vy = v0sinθ0 − gt
  • vx, vy = components of velocity at time t
At maximum height:
  • vy = 0
  • Velocity is purely horizontal, and direction comes from component ratio:
tanθ = vy/vx ⇒ at the top θ=0 since vy=0.

Equation of the path (trajectory)

To get the path shape, eliminate time t between x(t) and y(t).
Trajectory equation: y = x tanθ0 − (g x²)/(2v0²cos²θ0)
  • θ0, v0, g = constants for a given launch
Above equation has form y = ax + bx² (a, b constants) ⇒ it’s a parabola. So, projectile path is parabolic.

Time to reach maximum height

Time to max height (tm): tm = (v0sinθ0)/g
  • Use the top condition vy=0 in vy=v0sinθ0−gt.

Time of flight (returning to initial level)

Time of flight (Tf) when landing back at y=0: Tf = 2(v0sinθ0)/g
  • Put y=0 in y=(v0sinθ0)t − (1/2)gt², take the non-zero root.
Symmetry: Tf = 2tm. Reason: for same launch/landing level, time up = time down to the same height (parabolic symmetry).

Maximum height of a projectile

Maximum height (hm): hm = (v0²sin²θ0)/(2g)
  • Substitute t=tm into y(t) .

Horizontal range

Horizontal range (R): horizontal distance from start (x=y=0) to where it hits y=0 again on the way down (same-level landing).
Range: R = (v0cosθ0)Tf =$\left(v_0^2 \sin 2 \theta_0\right) / g$
  • R = horizontal range
  • Tf = time of flight
For fixed v0, range is max when sin2θ0 is max.
  • Since max(sin) = 1: sin2θ0=1 ⇒ 2θ0=90° ⇒ θ0=45°.
Maximum range (θ0=45°): Rm = v0²/g
  • Rm = max possible range for given v0
Exam trap: The formulas for Tf, R, hm above assume landing is at the same vertical level as launch (final y = initial y).

Example 3.6 (Galileo’s statement about equal ranges)

Statement: “For elevations that exceed or fall short of 45° by equal amounts, the ranges are equal.”
Given: for speed v0 at angle θ0, range is:
R = (v0²/g)sin2θ0
  • v0 fixed, g fixed ⇒ R depends only on sin2θ0
Angles: (45° + α) and (45° − α)
  • If θ0 = 45° + α ⇒ 2θ0 = 90° + 2α
  • If θ0 = 45° − α ⇒ 2θ0 = 90° − 2α
Key trig step:
  • sin(90° + 2α) = sin(90° − 2α) = cos2α
So sin2θ0 is the same for both angles ⇒ by the range formula, the ranges are equal.

Uniform Circular Motion

Uniform circular motion: object moves on a circle at constant speed (uniform = speed stays same). But velocity keeps changing direction ⇒ there is a non‑zero acceleration.

Direction of acceleration (centripetal nature)

Circle of radius R, speed v. At two nearby points P and P′, let:
  • r, r′ = position vectors at P, P′
  • v, v′ = velocity vectors at P, P′
Velocity at any point is along the tangent to the circle (direction of motion). So:
  • v ⟂ r and v′ ⟂ r′ (for circular motion)
Using triangle law of vectors, build Δv from v and v′. From the geometry of the circle, Δv ⟂ Δr. Average acceleration ā = Δv/Δt points along Δv ⇒ ā ⟂ Δr. Putting Δv along the bisector between r and r′ shows Δv (so acceleration) points towards the centre. As Δt → 0, the instantaneous acceleration still points towards the centre at every point.
Key point: speed constant ≠ acceleration zero. Acceleration depends on change in velocity, and direction is changing.

Magnitude of centripetal acceleration (derivation idea)

Let angle between r and r′ be Δθ. Since v ⟂ r and v′ ⟂ r′, the angle between v and v′ is also Δθ. Triangles made by (r, r′, Δr) and by (v, v′, Δv) are similar. So:
Similarity relation: Δv / v = Δr / R
  • Δv = magnitude of change in velocity
  • v = speed (constant)
  • Δr = magnitude of change in position vector
  • R = radius of the circle
Hence:
  • Δv/Δt = (v/R)(Δr/Δt)
For very small Δt, arc PP′ ≈ |Δr|, and distance along arc = vΔt, so:
Small-interval arc approximation: Δr ≈ v Δt
  • Works when Δt is small (so Δθ is small) ⇒ arc ≈ chord
Therefore, as Δt → 0:
  • Δr/Δt → v
  • a = lim(Δv/Δt) = (v/R)·v = v²/R
Centripetal acceleration magnitude: ac = v² / R
  • ac = centripetal (radial) acceleration
  • v = speed
  • R = radius of circular path
Direction: centripetal acceleration is always towards the centre at every point on the path.
Conceptual pitfall: “centripetal” = direction (centre-seeking), not a separate mystery force. Some real force(s) must provide this inward acceleration.

Uniform Circular Motion: Centripetal Acceleration and Angular Speed

Centripetal acceleration (magnitude and direction)

Object moving at constant speed v in a circle (radius R) has an acceleration called centripetal acceleration, always pointing to the centre (centre-seeking).
ac = v2/R ac: centripetal acceleration (magnitude) v: speed (constant in UCM) R: radius of circular path
  • |ac| stays constant if v and R are constant, BUT the direction of ac keeps changing (always inward).
  • So centripetal acceleration is NOT a constant vector (even if its magnitude is constant).
  • ac points along the radius to the centre; velocity at any point is tangential.
Don’t write “acceleration is constant” in uniform circular motion. Only the magnitude can be constant; the vector changes direction every instant.

Angular displacement, angular speed, and relation to linear speed

Moving from P to P′ in time Δt, the radius line turns through Δθ. This Δθ is the angular distance (angular displacement).
ω = Δθ/Δt ω: angular speed (rate of change of angular displacement) Δθ: angular displacement in time Δt Δt: time interval
Arc length traveled in time Δt is Δs. For a circle: Δs = RΔθ.
v = Δs/Δt v: linear (tangential) speed Δs: arc distance traveled in time Δt Δt: time interval
v = Rω v: linear (tangential) speed R: radius ω: angular speed

Centripetal acceleration in terms of angular speed

ac = ω2R ac: centripetal acceleration (magnitude) ω: angular speed R: radius
Substitute v = ωR into ac = v2/R to get ac = ω2R. This conversion is tested a lot.

Time period, frequency, and their relations with ω, v, and ac

  • Time period (T): time for 1 full revolution.
  • Frequency (ν): revolutions per second; ν = 1/T.
  • In 1 revolution, distance along the circle: s = 2πR.
v = 2πR/T = 2πRν v: linear speed R: radius T: time period ν: frequency (ν = 1/T)
ω = 2πν ω: angular speed ν: frequency
ac = 4π2ν2R ac: centripetal acceleration ν: frequency R: radius
Common mix-up: ω = 2π/T and ν = 1/T ⇒ ω = 2πν (NOT πν, NOT 2π/T2).

Worked Example: insect in a circular groove (Example 3.9)

Given: R = 12 cm; revolutions n = 7 in time t = 100 s. This is uniform circular motion (constant speed, circular path).
“Revolutions in time” → find frequency or period → then ω → then v → then a.
(a) Angular speed and linear speed
  • Time period (1 rev): T = 100/7 s.
  • Angular speed: ω = 2π/T = 2π × (7/100) = 0.44 rad s−1.
  • Linear speed: v = ωR = (0.44 s−1)(12 cm) = 5.3 cm s−1.
(b) Is acceleration a constant vector? Magnitude of acceleration
  • Velocity is tangential everywhere; acceleration points to the centre.
  • Because the inward direction keeps changing as it moves, acceleration is not a constant vector.
  • Magnitude is constant (since ω and R are constant): a = ω2R = (0.44 s−1)2(12 cm) = 2.3 cm s−2.
Keep units consistent (all SI or all cm-based). Here it stays in cm, so acceleration is in cm s−2.

Chapter Summary (Exam-usable facts from this portion)

Scalars and vectors

  • Scalar: magnitude only (e.g. distance, speed, mass, temperature).
  • Vector: magnitude + direction; follows vector algebra (e.g. displacement, velocity, acceleration).

Multiplication of a vector by a real number

If vector A is multiplied by real number λ → new vector has magnitude |λ||A|. Direction: same as A if λ > 0, opposite if λ < 0.

Vector addition laws and methods

  • Graphical methods: head-to-tail and parallelogram.
  • Commutative: A + B = B + A.
  • Associative: (A + B) + C = A + (B + C).

Zero (null) vector and its properties

Zero (null) vector: magnitude = 0; direction not required.
A + 0 = A A: any vector 0: zero vector
λ0 = 0 λ: real number 0: zero vector
0A = 0 A: any vector 0: scalar zero

Vector subtraction

Define subtraction via adding the negative: A − B = A + (−B).

Resolution of a vector along two given vectors in a plane

Any vector A in a plane can be resolved along two non-parallel coplanar vectors a and b:
A = λa + μb A: vector to be resolved a, b: given (coplanar) vectors λ, μ: real numbers (scalars)

Unit vector and standard unit vectors i, j, k

Unit vector along A: magnitude 1, direction same as A.
n̂ = A/|A| n̂: unit vector along A A: given vector |A|: magnitude of A
Standard unit vectors î, ĵ, k̂ point along the x-, y-, and z-axes (right-handed system).

Component form of a vector in x–y plane

In x–y plane, write a vector using components:
A = Ax î + Ay ĵ A: vector Ax, Ay: x- and y-components î, ĵ: unit vectors along x- and y-axes
Ax = A cosθ, Ay = A sinθ A: magnitude of vector A θ: angle made by A with x-axis Ax, Ay: x and y components
A = √(Ax2 + Ay2) A: magnitude of vector A Ax, Ay: components
tanθ = Ay/Ax θ: angle with x-axis Ax, Ay: x and y components

Analytical method of vector addition (component-wise)

If R = A + B (vectors in x–y plane), add x-parts and y-parts separately.
R = Rx î + Ry ĵ R: resultant vector Rx, Ry: components of resultant
Rx = Ax + Bx, Ry = Ay + By Ax, Ay: components of A Bx, By: components of B Rx, Ry: components of R

Position vector and displacement in x–y plane

Position vector of point (x, y) in x–y plane:
r = x î + y ĵ r: position vector x, y: coordinates î, ĵ: unit vectors
Displacement from r to r′:
Δr = r′ − r = (x′ − x) î + (y′ − y) ĵ = Δx î + Δy ĵ Δr: displacement vector r, r′: initial and final position vectors Δx = x′ − x: change in x-coordinate Δy = y′ − y: change in y-coordinate

Average velocity and instantaneous velocity

Average velocity = displacement/time. Instantaneous velocity = limit as time interval → 0.
v̄ = Δr/Δt v̄: average velocity Δr: displacement in time interval Δt Δt: time interval
v = limΔt→0(Δr/Δt) = dr/dt v: instantaneous velocity r: position vector t: time
v = vx î + vy ĵ + vz k̂ v: velocity vector vx, vy, vz: velocity components î, ĵ, k̂: unit vectors along axes
vx = dx/dt, vy = dy/dt, vz = dz/dt x, y, z: coordinates t: time
On a trajectory, instantaneous velocity is always tangent to the curve at that point.

Average acceleration and instantaneous acceleration

Average acceleration = change in velocity/time. Instantaneous acceleration = limit as time interval → 0.
ā = (v′ − v)/Δt = Δv/Δt ā: average acceleration v: initial velocity v′: final velocity Δt: time interval Δv = v′ − v: change in velocity
a = limΔt→0(Δv/Δt) = dv/dt a: instantaneous acceleration v: velocity t: time

Plane motion with constant acceleration vector a (components ax, ay and initial position r0 at t = 0:

Projectile motion (definition, equations, trajectory, maximum height, time to rise, range)

Points to Ponder (Exam Essentials from Motion in a Plane)

1) Path length vs displacement (magnitude)

Path length (distance travelled) = actual length of the route/trajectory between two points (depends on the path taken). Displacement = change in position vector from start to end; depends only on initial & final points.
In general: path length ≠ |displacement|. They are equal only if direction never changes (straight-line motion, no turns/reversals). Otherwise: path length > |displacement|.

2) Average speed vs magnitude of average velocity

Average speed = (total path length)/(total time). Average velocity = displacement/time; so |average velocity| = |displacement|/time.
Since path length ≥ |displacement|: average speed ≥ |average velocity|. Equality only when path length = |displacement| (no change in direction).

3) Axis-independence of vector equations

Equations of motion written in vector form (for r, v, a) are axis-free → no need to choose axes first.
You can always resolve the same vector equation along any two independent axes (like x, y) to solve component-wise.

4) Uniform acceleration equations vs uniform circular motion

Uniform-acceleration kinematics assume acceleration is constant as a vector: constant magnitude + direction.
So these kinematic equations cannot be used for uniform circular motion because even if |a| is constant, the direction of a keeps changing.

5) Resultant velocity vs relative velocity (do not confuse)

Resultant (combined) velocity when two velocities act together: v = v1 + v2 (vector addition). Relative velocity of 1 w.r.t. 2: v12 = v1 − v2, where v1, v2 are measured in the same reference frame.
Exam trap: “v = v1 + v2” is a different setup from “velocity of 1 relative to 2”. Relative velocity is always a difference (same frame first!).

6) Acceleration in circular motion: when is it purely centripetal?

In circular motion, acceleration points only towards the centre iff speed is constant (UCM). If speed changes → extra tangential acceleration appears → net acceleration is not purely radial.

7) Trajectory depends on acceleration and initial conditions

Trajectory (path shape) depends on:
  • the acceleration, and
  • the initial conditions: initial position + initial velocity.
Same acceleration (like gravity) can still give different paths:
  • straight line (e.g., purely vertical throw), or
  • parabola (projectile with a horizontal component).

Vector Inequalities (Triangle Inequality and Related Results)

Triangle inequality for vectors

|a + b| ≤ |a| + |b| |a + b| = magnitude of resultant of vectors a and b |a|, |b| = magnitudes of vectors a and b
Strict form used in many questions:
  • |a + b| < |a| + |b| (generally)
  • Equality when a and b are parallel + same direction (collinear, angle 0°).

Reverse triangle inequality

|a + b| ≥ ||a| − |b|| ||a| − |b|| = absolute value of the difference of magnitudes
Strict form used in many questions:
  • |a + b| > ||a| − |b|| (generally)
  • Equality when a and b are antiparallel (collinear, opposite directions, angle 180°).

Inequalities for difference of vectors

|a − b| ≤ |a| + |b| |a − b| ≥ ||a| − |b||
Equality conditions:
  • For |a − b| = |a| + |b|: a and b must be antiparallel (since a − b = a + (−b), and a ∥ (−b) ⇒ a opposite to b).
  • For |a − b| = ||a| − |b||: a and b must be parallel in the same direction.
Fast method: rewrite subtraction as addition with a negative vector: a − b = a + (−b), then apply triangle-inequality conditions to a and (−b).

Consequences of a + b + c + d = 0 (Vector Closure)

Interpreting a + b + c + d = 0

If a + b + c + d = 0, then you can rearrange like a + b + c = −d, etc. Geometrically: placing vectors head-to-tail makes a closed polygon → net displacement = 0.

Must each vector be zero?

From a + b + c + d = 0, it does not mean a, b, c, d are each zero. Non-zero vectors can add to zero if they form a closed shape.

Relation between (a + c) and (b + d)

Given a + b + c + d = 0: a + c = −(b + d) ⇒ |a + c| = |b + d| (equal magnitudes since vectors are negatives).

Magnitude of a compared to magnitudes of b, c, d

From a = −(b + c + d): |a| = |b + c + d| ≤ |b| + |c| + |d| (extended triangle inequality). So |a| can never exceed |b| + |c| + |d|.

Planarity of b + c relative to a and d

b + c = −(a + d).
  • If a and d are not collinear → they define a plane; (a + d) lies in it ⇒ b + c lies in the plane of a and d.
  • If a and d are collinear → (a + d) lies on that line ⇒ b + c lies on the same line.

Circular Motion: Speed, Direction, and Acceleration (Exam Reminders)

Direction of velocity in circular/curved motion

Instantaneous velocity at any point is along the tangent to the path at that point.

Radial (centripetal) and tangential acceleration

In circular motion, acceleration may have:
  • Radial (centripetal): towards centre (changes direction of v).
  • Tangential: along tangent (changes speed).
Net acceleration is purely radial only if speed is constant.

Average acceleration over one full cycle in uniform circular motion

In UCM, after one full cycle velocity becomes the same as initial: Δv over one cycle = 0 ⇒ average acceleration over one cycle = null vector.

Scalars and Vectors (Concept Checks Embedded in Exercises)

Scalar vs vector: what examiners test

Scalar = fully described by magnitude only. Vector = needs magnitude + direction; must obey vector addition rules.

Meaningful algebraic operations with scalars/vectors

  • Scalar + scalar → meaningful.
  • Scalar + vector (even “same units”) → not meaningful (different mathematical types).
  • Scalar × vector → meaningful (scales magnitude; negative scalar flips direction).
  • Scalar × scalar → meaningful.
  • Vector + vector → meaningful (gives a vector), but only if they’re compatible physical quantities.
  • “Add a component to the vector” (e.g., A + Ax) → not meaningful as written (component is a scalar). If you mean the component vector, then OK: A + Ax î.
Common slip: treating “x-component” (scalar) as if it’s a vector. Write component vectors clearly: Ax î, Ay ĵ.

True/false style conceptual facts

  • Magnitude of a vector is a scalar → true.
  • Each component of a vector is a scalar → true (signed number in a chosen coordinate system).
  • Total path length always equals |displacement| → false (only if direction never changes).
  • Average speed ≥ |average velocity| → true (equality only when path length = |displacement|).
  • Three vectors not lying in a plane can never add to zero → tricky: if a + b + c = 0, then they must be coplanar (can form a closed triangle). So truly non-coplanar vectors cannot sum to zero. Many errors come from misreading “not lying in a plane”.
Be exact: if a + b + c = 0 ⇒ c = −(a + b). So c lies in the plane of a and b ⇒ all three are coplanar.

Average Quantities and Validity of Common Relations (Arbitrary Motion in Space)

Correct expression for average velocity

v̄ = [r(t2) − r(t1)] / (t2 − t1) v̄ = average velocity vector over t1 → t2 r(t) = position vector vs time

Correct expression for average acceleration

ā = [v(t2) − v(t1)] / (t2 − t1) ā = average acceleration vector over t1 → t2 v(t) = velocity vector vs time

Relations that are NOT generally valid for arbitrary motion

  • v̄ = (1/2)[v(t1) + v(t2)] → not always true; only special cases (e.g., constant acceleration in 1D, or constant acceleration with fixed direction in an appropriate sense).
  • v(t) = v(0) + a t → not generally true unless acceleration a is constant as a vector.
  • r(t) = r(0) + v(0)t + (1/2)a t2 → not generally true unless acceleration is constant as a vector.
Circular motion at constant speed: |a| is constant but direction changes ⇒ constant-acceleration kinematics don’t apply.

Scalar Quantity: What It Does and Does Not Mean

Misconceptions about scalars (true/false type)

A scalar quantity is one that:
  • (a) is conserved in a process → false (conservation is separate; speed is scalar but not conserved).
  • (b) can never take negative values → false (electric potential, Celsius temperature can be negative).
  • (c) must be dimensionless → false (mass, time, energy are scalars with dimensions).
  • (d) does not vary from one point to another in space → false (scalar fields like temperature can vary with position).
  • (e) has the same value for observers with different orientations of axes → true (scalar value doesn’t depend on axis orientation; vector components do, though the vector itself is invariant).
